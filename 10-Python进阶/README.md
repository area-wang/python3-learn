# 10-Python进阶

Python 进阶阶段关注代码的可维护性、可测试性、可观测性和运行效率，适合在掌握基础语法、函数、面向对象、模块化和文件操作之后学习。

- [10.3-枚举](./10.3-枚举/) - Enum、IntEnum、StrEnum、状态和值约束
- [10.4-正则表达式](./10.4-正则表达式/) - re模块、分组、替换、常见文本解析

- [10.9-网络请求](./10.9-网络请求/) - urllib、requests、httpx、异常处理

## 🎯 学习目标

1. 能给函数、类和容器写清晰的类型提示。
2. 能用 `dataclass`、`Enum` 等工具表达更稳定的数据结构。
3. 能用正则表达式处理常见文本提取、校验和替换任务。
4. 能为脚本和项目配置可读、可定位问题的日志。
5. 能编写基础自动化测试，降低修改代码的回归风险。
6. 能根据任务类型选择线程、进程或异步模型。
7. 能用工具定位性能瓶颈，而不是凭感觉优化。
8. 能使用标准库或第三方库完成常见 HTTP 请求，并正确处理超时和异常。
