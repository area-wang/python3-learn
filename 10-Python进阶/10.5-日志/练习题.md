# 10.5 日志练习题

## 一、概念题

1. `logging` 相比 `print()` 有哪些优势？
2. `DEBUG`、`INFO`、`WARNING`、`ERROR` 分别适合什么场景？
3. 为什么模块中推荐使用 `logging.getLogger(__name__)`？
4. `logger.exception()` 和 `logger.error()` 的主要区别是什么？
5. 为什么日志中不能记录敏感信息？

## 二、代码题

1. 配置日志格式，输出时间、级别、模块名和消息。
2. 编写函数 `divide(a, b)`，除数为 0 时记录异常日志并返回 `None`。
3. 把一个使用 `print()` 输出运行状态的脚本改为使用 `logging`。
4. 写一个模块级 `logger`，在函数开始和结束时分别记录 `INFO` 日志。

## 三、实战题

1. 为一个文件读取程序添加日志：开始读取、读取成功、文件不存在、解析失败。
2. 设计一套简单日志级别规则，说明哪些信息应该记为 `INFO`，哪些应该记为 `ERROR`。
