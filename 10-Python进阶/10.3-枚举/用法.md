# 10.3 枚举

枚举用于定义一组有限、固定、语义明确的取值。相比直接使用字符串或数字，枚举能减少拼写错误，让状态和选项更清晰。

## 1. 基本用法

```python
from enum import Enum

class OrderStatus(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"
    CANCELLED = "cancelled"

status = OrderStatus.PAID
print(status.name)   # PAID
print(status.value)  # paid
```

比较枚举时通常比较枚举成员本身：

```python
if status is OrderStatus.PAID:
    print("已支付")
```

## 2. 从值创建枚举

```python
raw_status = "paid"
status = OrderStatus(raw_status)
print(status is OrderStatus.PAID)  # True
```

如果值不存在，会抛出 `ValueError`。因此解析外部输入时要处理异常：

```python
def parse_status(value: str) -> OrderStatus | None:
    try:
        return OrderStatus(value)
    except ValueError:
        return None
```

## 3. `IntEnum`

`IntEnum` 适合必须和整数交互的场景：

```python
from enum import IntEnum

class Priority(IntEnum):
    LOW = 1
    MEDIUM = 2
    HIGH = 3

print(Priority.HIGH > Priority.LOW)  # True
```

如果只是表达状态，不需要大小比较，普通 `Enum` 更合适。

## 4. `StrEnum`

Python 3.11+ 提供 `StrEnum`，成员同时也是字符串：

```python
from enum import StrEnum

class Role(StrEnum):
    ADMIN = "admin"
    USER = "user"
```

需要兼容更早版本时，可以继续使用普通 `Enum`。

## 5. 枚举的价值

使用枚举能把散落在代码中的魔法字符串集中起来：

```python
def can_cancel(status: OrderStatus) -> bool:
    return status in {OrderStatus.PENDING, OrderStatus.PAID}
```

这样调用者能明确知道允许的状态集合，编辑器和类型检查工具也更容易发现错误。

## 6. 常见建议

- 状态、角色、类型、优先级等固定集合适合枚举。
- 枚举名称使用大写，值根据外部协议选择字符串或数字。
- 不要把频繁变化、来自数据库配置的内容硬编码成枚举。
- 对外部输入转换枚举时，要处理非法值。
