# 10.9 网络请求

Python 可以用标准库发起 HTTP 请求，也可以使用第三方库简化开发。标准库适合理解底层流程和处理简单场景，真实项目中更常用 `requests`、`httpx`、`aiohttp` 等库。

## 1. 标准库选择

Python 标准库里和 HTTP 请求相关的模块主要有：

| 模块 | 说明 |
|---|---|
| `urllib.request` | 标准库中最常用的 HTTP 客户端能力 |
| `urllib.parse` | URL 编码、查询参数拼接、URL 解析 |
| `http.client` | 更底层的 HTTP 客户端，使用较少 |
| `json` | 处理 JSON 请求体和响应体 |

简单请求可以直接用 `urllib.request`：

```python
from urllib.request import urlopen

with urlopen("https://example.com", timeout=5) as response:
    body = response.read().decode("utf-8")
    print(response.status)
    print(body[:100])
```

`http.client` 更接近底层协议，通常不作为日常首选：

```python
import http.client

conn = http.client.HTTPSConnection("example.com", timeout=5)
conn.request("GET", "/")
response = conn.getresponse()
print(response.status)
print(response.read().decode("utf-8")[:100])
conn.close()
```

## 2. GET 请求和查询参数

查询参数要正确编码，避免手动拼接导致特殊字符出错：

```python
from urllib.parse import urlencode
from urllib.request import urlopen

params = urlencode({"q": "python 网络请求", "page": 1})
url = f"https://example.com/search?{params}"

with urlopen(url, timeout=5) as response:
    print(response.status)
```

`urlencode()` 会把空格、中文、特殊符号转换成 URL 安全格式。

## 3. 请求头和 POST 请求

需要设置请求头或请求体时，使用 `Request`：

```python
import json
from urllib.request import Request, urlopen

payload = {"username": "alice", "password": "secret"}
data = json.dumps(payload).encode("utf-8")

request = Request(
    "https://example.com/api/login",
    data=data,
    method="POST",
    headers={"Content-Type": "application/json"},
)

with urlopen(request, timeout=5) as response:
    result = json.loads(response.read().decode("utf-8"))
    print(result)
```

注意：示例里的密码只是演示，请不要把真实密码硬编码在代码中。

## 4. 异常处理

网络请求容易失败，常见原因包括超时、DNS 失败、连接失败、服务端返回错误状态码等。

```python
from urllib.error import HTTPError, URLError
from urllib.request import urlopen

try:
    with urlopen("https://example.com/missing", timeout=5) as response:
        print(response.read().decode("utf-8"))
except HTTPError as e:
    print("HTTP 状态错误:", e.code)
except URLError as e:
    print("网络连接错误:", e.reason)
except TimeoutError:
    print("请求超时")
```

实际项目中要设置超时时间，不要让请求无限等待。

## 5. 第三方库 `requests`

`requests` 不是标准库，但 API 更简洁，是同步 HTTP 请求的常见选择：

```python
import requests

response = requests.get(
    "https://example.com/api/users",
    params={"page": 1},
    timeout=5,
)
response.raise_for_status()
data = response.json()
print(data)
```

发送 JSON：

```python
response = requests.post(
    "https://example.com/api/users",
    json={"name": "Alice"},
    timeout=5,
)
response.raise_for_status()
```

相比 `urllib`，`requests` 在参数、JSON、状态码、会话、Cookie、文件上传等方面更方便。

## 6. 第三方库 `httpx`

`httpx` 的用法和 `requests` 类似，同时支持同步和异步请求：

```python
import httpx

response = httpx.get("https://example.com", timeout=5)
response.raise_for_status()
print(response.text)
```

异步请求：

```python
import asyncio
import httpx

async def main() -> None:
    async with httpx.AsyncClient(timeout=5) as client:
        response = await client.get("https://example.com")
        response.raise_for_status()
        print(response.text[:100])

asyncio.run(main())
```

如果项目已经大量使用 `asyncio`，可以优先考虑 `httpx.AsyncClient` 或 `aiohttp`。

## 7. 会话和连接复用

多次请求同一个服务时，使用会话可以复用连接和公共配置：

```python
import requests

with requests.Session() as session:
    session.headers.update({"User-Agent": "python-learn/1.0"})

    response = session.get("https://example.com/api/users", timeout=5)
    response.raise_for_status()
```

标准库中也能实现类似能力，但使用成本更高。

## 8. 常见建议

- 学习阶段先理解 HTTP 方法、URL、请求头、请求体、状态码。
- 简单标准库示例使用 `urllib.request`，底层理解再看 `http.client`。
- 项目开发中，同步请求常用 `requests` 或 `httpx`。
- 异步项目中使用 `httpx.AsyncClient` 或 `aiohttp`。
- 每个请求都应设置超时时间。
- 外部请求要处理异常、状态码和响应格式错误。
- 不要把 token、密码等敏感信息写死在代码中。
- 批量请求时要考虑重试、限流和服务端压力。
