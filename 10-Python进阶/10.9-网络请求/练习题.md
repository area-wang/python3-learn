# 10.9 网络请求练习题

## 一、概念题

1. Python 标准库中 `urllib.request` 和 `http.client` 分别适合什么层次的使用？
2. 为什么查询参数不建议手动字符串拼接，而要使用 `urlencode()` 或第三方库的 `params` 参数？
3. 为什么网络请求必须设置 `timeout`？
4. `requests` 相比 `urllib.request` 简化了哪些常见操作？
5. 同步 HTTP 请求和异步 HTTP 请求分别适合什么场景？
6. `response.raise_for_status()` 的作用是什么？
7. 为什么批量请求接口时要考虑限流和重试？

## 二、代码题

1. 使用 `urllib.request.urlopen()` 请求一个网页，并打印状态码和前 100 个字符。
2. 使用 `urllib.parse.urlencode()` 拼接搜索参数：关键词为 `python 网络请求`，页码为 `1`。
3. 使用 `urllib.request.Request` 构造一个 JSON POST 请求。
4. 使用 `urllib.error.HTTPError` 和 `URLError` 捕获请求异常。
5. 使用 `requests.get()` 发送 GET 请求，传入 `params` 和 `timeout`。
6. 使用 `requests.post()` 发送 JSON 数据，并调用 `raise_for_status()`。
7. 使用 `httpx.AsyncClient` 编写一个异步 GET 请求函数。

## 三、实战题

1. 编写函数 `fetch_json(url: str) -> dict`：请求 URL、检查状态码、解析 JSON，并处理异常。
2. 编写一个小脚本，批量请求多个 URL，统计每个 URL 的状态码和响应耗时。
3. 把批量请求脚本改造成线程池版本，比较顺序请求和并发请求的耗时。
4. 为请求函数增加简单重试逻辑：失败后最多重试 3 次，每次间隔 1 秒。
