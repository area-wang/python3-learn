# 10.7 并发实践练习题

## 一、概念题

1. IO 密集任务和 CPU 密集任务有什么区别？
2. 为什么线程池适合很多阻塞 IO 场景？
3. 为什么进程池更适合 CPU 密集计算？
4. 在异步函数里直接调用阻塞函数会有什么问题？
5. `map()` 和 `as_completed()` 处理任务结果时有什么区别？

## 二、代码题

1. 使用 `ThreadPoolExecutor` 并发统计多个文本文件的行数。
2. 使用 `ProcessPoolExecutor` 并发计算多个数字范围内平方和。
3. 编写 3 个 `async` 任务，每个任务等待不同秒数并返回名称，用 `asyncio.gather()` 收集结果。
4. 使用 `as_completed()` 处理任务结果，并捕获其中一个任务抛出的异常。

## 三、实战题

1. 找一个需要处理多个文件的脚本，改造成线程池版本，并比较耗时。
2. 找一个计算密集函数，分别用顺序执行和进程池执行，观察数据规模较小时是否一定更快。
