# 10.7 并发实践

并发用于让程序在等待或计算时更高效。Python 常见并发方式包括线程、进程和异步。选择方式前，先判断任务瓶颈是 IO 还是 CPU。

## 1. IO 密集和 CPU 密集

IO 密集任务大部分时间在等待：

- 网络请求
- 文件读写
- 数据库查询
- 等待外部命令

CPU 密集任务主要消耗计算资源：

- 大量数学计算
- 图片处理
- 压缩解压
- 数据转换

线程和异步更适合 IO 密集，进程更适合 CPU 密集。

## 2. 线程池

`ThreadPoolExecutor` 适合并发处理多个阻塞 IO 任务：

```python
from concurrent.futures import ThreadPoolExecutor
from pathlib import Path

def count_lines(path: Path) -> int:
    return len(path.read_text(encoding="utf-8").splitlines())

paths = [Path("a.txt"), Path("b.txt"), Path("c.txt")]

with ThreadPoolExecutor(max_workers=4) as pool:
    results = list(pool.map(count_lines, paths))

print(results)
```

线程共享同一进程内存，传递数据方便，但要小心共享状态竞争。

## 3. 进程池

`ProcessPoolExecutor` 适合 CPU 密集任务：

```python
from concurrent.futures import ProcessPoolExecutor

def square_sum(n: int) -> int:
    return sum(i * i for i in range(n))

with ProcessPoolExecutor() as pool:
    results = list(pool.map(square_sum, [100000, 200000, 300000]))

print(results)
```

进程之间内存隔离，启动和通信成本更高。传入进程池的函数和参数通常需要可序列化。

## 4. 异步任务

异步适合大量可等待的 IO 操作，例如异步网络请求：

```python
import asyncio

async def fetch(name: str, delay: float) -> str:
    await asyncio.sleep(delay)
    return name

async def main() -> None:
    results = await asyncio.gather(
        fetch("A", 1),
        fetch("B", 1),
        fetch("C", 1),
    )
    print(results)

asyncio.run(main())
```

异步代码要求调用链上的库也支持异步。阻塞函数放进异步函数里不会自动变快。

## 5. 结果和异常处理

使用 `as_completed()` 可以谁先完成先处理谁：

```python
from concurrent.futures import ThreadPoolExecutor, as_completed

def work(n: int) -> int:
    if n < 0:
        raise ValueError("n 不能为负数")
    return n * 2

with ThreadPoolExecutor() as pool:
    futures = [pool.submit(work, n) for n in [1, -1, 3]]
    for future in as_completed(futures):
        try:
            print(future.result())
        except ValueError as e:
            print("失败:", e)
```

## 6. 选择建议

| 场景 | 优先选择 |
|---|---|
| 少量简单任务 | 普通顺序代码 |
| 多个阻塞 IO | 线程池 |
| 大量异步 IO 且库支持 async | asyncio |
| CPU 密集计算 | 进程池 |
| 需要共享复杂状态 | 先简化设计，再谨慎并发 |

并发会引入调试难度，不要为了“看起来高级”而使用。
