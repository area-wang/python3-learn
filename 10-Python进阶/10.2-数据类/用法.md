# 10.2 数据类

`dataclass` 用于快速定义以数据为主的类。它可以自动生成 `__init__`、`__repr__`、`__eq__` 等方法，减少样板代码。

## 1. 基本用法

```python
from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int

user = User("Alice", 18)
print(user)                 # User(name='Alice', age=18)
print(user == User("Alice", 18))  # True
```

字段顺序就是初始化参数顺序。有默认值的字段要放在无默认值字段后面：

```python
@dataclass
class Product:
    name: str
    price: float
    stock: int = 0
```

## 2. 可变默认值

不要直接把列表、字典作为默认值，应使用 `field(default_factory=...)`：

```python
from dataclasses import dataclass, field

@dataclass
class Team:
    name: str
    members: list[str] = field(default_factory=list)
```

这样每个实例都会拥有独立的列表。

## 3. 不可变数据类

`frozen=True` 可以让对象创建后不允许修改字段：

```python
@dataclass(frozen=True)
class Money:
    amount: float
    currency: str = "CNY"

money = Money(100)
# money.amount = 200  # FrozenInstanceError
```

不可变对象适合表示配置、坐标、金额等不希望被意外修改的数据。

## 4. 排序

`order=True` 会根据字段顺序生成比较方法：

```python
@dataclass(order=True)
class Student:
    score: int
    name: str

students = [Student(90, "A"), Student(80, "B")]
print(sorted(students))
```

如果只想按某个字段排序，也可以使用 `sorted(items, key=...)`，通常更直观。

## 5. 初始化后处理

`__post_init__` 会在自动生成的 `__init__` 执行后调用，适合做校验或派生字段：

```python
@dataclass
class Rectangle:
    width: float
    height: float

    def __post_init__(self) -> None:
        if self.width <= 0 or self.height <= 0:
            raise ValueError("宽和高必须大于 0")
```

## 6. 适用场景

适合使用 `dataclass`：

- 配置对象
- 请求或响应数据
- 值对象
- 轻量数据模型

不适合使用 `dataclass`：

- 行为复杂、状态变化很多的业务对象
- 需要精细控制初始化过程的类
- 已经由框架模型管理的对象
