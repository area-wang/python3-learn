# 10.2 数据类练习题

## 一、概念题

1. `dataclass` 默认会自动生成哪些常见方法？
2. 为什么列表字段不能直接写成 `members: list[str] = []`？
3. `frozen=True` 适合哪些场景？
4. `__post_init__` 通常用来做什么？
5. `order=True` 的比较顺序由什么决定？

## 二、代码题

1. 定义一个 `Book` 数据类，包含 `title: str`、`author: str`、`price: float`。
2. 定义一个 `Cart` 数据类，包含 `items: list[str]`，要求每个实例拥有独立列表。
3. 定义一个不可变的 `Point` 数据类，包含 `x`、`y` 两个整数。
4. 定义一个 `User` 数据类，在 `__post_init__` 中检查 `age` 不能小于 0。

## 三、实战题

1. 用 `dataclass` 重构一个使用字典保存学生信息的程序。
2. 为商品列表实现按价格排序、按库存排序两个功能。
