# 10.4 正则表达式

正则表达式用于匹配、提取、校验和替换文本。Python 使用标准库 `re` 处理正则。

## 1. 基本匹配

```python
import re

text = "phone: 13812345678"
match = re.search(r"\d{11}", text)

if match:
    print(match.group())  # 13812345678
```

常见方法：

| 方法 | 说明 |
|---|---|
| `re.search()` | 查找第一个匹配 |
| `re.match()` | 从字符串开头匹配 |
| `re.fullmatch()` | 整个字符串必须匹配 |
| `re.findall()` | 返回所有匹配结果 |
| `re.sub()` | 替换匹配内容 |

## 2. 常用元字符

| 写法 | 含义 |
|---|---|
| `.` | 任意字符，默认不匹配换行 |
| `\d` | 数字 |
| `\w` | 字母、数字、下划线 |
| `\s` | 空白字符 |
| `*` | 重复 0 次或多次 |
| `+` | 重复 1 次或多次 |
| `?` | 重复 0 次或 1 次 |
| `{m,n}` | 重复 m 到 n 次 |
| `^` | 字符串开头 |
| `$` | 字符串结尾 |

建议使用原始字符串 `r"..."` 编写正则，避免反斜杠转义混乱。

## 3. 分组提取

```python
text = "name=Alice; age=18"
match = re.search(r"name=(\w+); age=(\d+)", text)

if match:
    print(match.group(1))  # Alice
    print(match.group(2))  # 18
```

命名分组更适合复杂表达式：

```python
pattern = r"name=(?P<name>\w+); age=(?P<age>\d+)"
match = re.search(pattern, text)

if match:
    print(match.groupdict())  # {'name': 'Alice', 'age': '18'}
```

## 4. 替换

```python
text = "价格：100元，优惠：20元"
result = re.sub(r"\d+", "***", text)
print(result)  # 价格：***元，优惠：***元
```

替换函数可以根据匹配内容动态生成结果：

```python
def double(match: re.Match[str]) -> str:
    return str(int(match.group()) * 2)

print(re.sub(r"\d+", double, "a=3, b=5"))  # a=6, b=10
```

## 5. 编译表达式

同一个正则会反复使用时，可以先编译：

```python
email_pattern = re.compile(r"^[\w.-]+@[\w.-]+\.\w+$")

def is_email(value: str) -> bool:
    return email_pattern.fullmatch(value) is not None
```

## 6. 注意事项

- 能用普通字符串方法解决时，不必强行使用正则。
- 校验完整字符串时用 `fullmatch()`，不要误用 `search()`。
- 复杂正则要拆分、命名或加注释，否则维护成本很高。
- 正则适合规则文本，不适合解析复杂嵌套语法。
