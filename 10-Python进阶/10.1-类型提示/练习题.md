# 10.1 类型提示练习题

## 一、概念题

1. Python 的类型提示会不会在运行时自动阻止错误类型的参数？为什么？
2. `str | None` 和 `str` 的含义有什么区别？
3. 为什么公共函数比局部临时变量更值得添加类型提示？
4. `TypeVar` 主要用来表达什么关系？
5. `Protocol` 和普通基类相比有什么灵活性？

## 二、代码题

1. 给下面函数补充类型提示：

```python
def total(prices):
    return sum(prices)
```

2. 编写函数 `safe_get(data, key)`，参数 `data` 是 `dict[str, int]`，参数 `key` 是字符串，返回 `int | None`。

3. 编写一个泛型函数 `last(items)`，返回列表最后一个元素。

4. 定义一个 `Protocol`：只要求对象实现 `send(message: str) -> None`，并写一个函数接收该协议对象发送消息。

## 三、实战题

1. 找一个之前写过的通讯录、购物车或学生成绩程序，为核心函数补充类型提示。
2. 尝试安装并运行 `mypy` 或 `pyright`，记录它发现的一个问题。
