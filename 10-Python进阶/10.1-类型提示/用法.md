# 10.1 类型提示

类型提示用于说明变量、函数参数和返回值的预期类型。Python 运行时默认不会强制检查类型，但类型提示能提升代码可读性，并配合 `mypy`、`pyright` 等工具提前发现问题。

## 1. 基础类型注解

```python
name: str = "Alice"
age: int = 18
scores: list[int] = [90, 85, 100]
profile: dict[str, str] = {"city": "Beijing"}
```

函数注解最常用：

```python
def add(a: int, b: int) -> int:
    return a + b
```

如果函数没有返回值，使用 `None`：

```python
def log_message(message: str) -> None:
    print(message)
```

## 2. 可选值和联合类型

Python 3.10+ 推荐使用 `|` 表示联合类型：

```python
def find_user(user_id: int) -> dict[str, str] | None:
    if user_id == 1:
        return {"name": "Alice"}
    return None
```

`str | None` 表示值可能是字符串，也可能是空值。使用前要先判断：

```python
user = find_user(2)
if user is not None:
    print(user["name"])
```

## 3. 类型别名

复杂类型可以用别名提升可读性：

```python
User = dict[str, str]
UserId = int

def get_user(user_id: UserId) -> User | None:
    ...
```

类型别名适合表达业务含义，但不要滥用。简单的 `list[str]` 通常不需要单独起别名。

## 4. 泛型函数

泛型用于表达输入和输出之间的类型关系：

```python
from typing import TypeVar

T = TypeVar("T")

def first(items: list[T]) -> T:
    return items[0]
```

`first([1, 2, 3])` 的返回值会被推断为 `int`，`first(["a", "b"])` 的返回值会被推断为 `str`。

## 5. `Protocol`

`Protocol` 用于描述对象需要具备的行为，不关心对象属于哪个类：

```python
from typing import Protocol

class Writable(Protocol):
    def write(self, text: str) -> int:
        ...

def save(content: str, target: Writable) -> None:
    target.write(content)
```

只要对象有符合签名的 `write()` 方法，就可以传给 `save()`。这比强制继承某个基类更灵活。

## 6. 常见建议

- 公共函数、复杂函数、模块边界函数优先添加类型提示。
- 变量类型能被明显推断时，不必到处写注解。
- 类型提示是设计的一部分，不要写和真实行为不一致的类型。
- 遇到 `Any` 要谨慎，它会降低类型检查价值。
- 类型提示不能代替单元测试，二者解决的问题不同。
