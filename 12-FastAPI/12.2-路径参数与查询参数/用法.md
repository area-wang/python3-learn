# 12.2 路径参数与查询参数

12.1 里我们已经见过 `/items/{item_id}?q=hello` 这样的请求：`item_id` 来自路径，`q` 来自查询字符串。本节把这两类参数讲透：FastAPI 如何根据函数签名判断参数来源、如何做类型转换、如何用 `Annotated` + `Path` / `Query` 声明长度、范围、正则等约束，以及校验失败时返回的 422 错误体该怎么读。掌握这些后，绝大多数「取参数 + 校验参数」的样板代码都可以消失。

## 1. 路径参数

### 1.1 基本用法与类型转换

路径中用 `{名字}` 声明的部分就是路径参数，函数里声明同名参数即可接收：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}


@app.get("/users/{user_id}/orders/{order_id}")
async def read_order(user_id: int, order_id: str):
    return {"user_id": user_id, "order_id": order_id}
```

```bash
curl http://127.0.0.1:8000/items/5
# {"item_id":5}                    ← 注意是数字 5，不是字符串 "5"

curl http://127.0.0.1:8000/users/1/orders/A100
# {"user_id":1,"order_id":"A100"}

curl http://127.0.0.1:8000/items/5.5
# {"detail":[{"type":"int_parsing","loc":["path","item_id"],
#   "msg":"Input should be a valid integer, unable to parse string as an integer","input":"5.5"}]}
```

URL 里的一切本质上都是字符串，FastAPI 会按类型提示做转换。常见类型的转换规则：

| 类型提示 | 能接受的输入示例 | 会被拒绝的输入 |
|---|---|---|
| `str` | 任意文本 | — |
| `int` | `5`、`-3`、`4.0`（小数部分为 0） | `5.5`、`abc` |
| `float` | `3.14`、`5`、`1e3` | `abc` |
| `bool` | 见 2.2 节 | `abc` |
| `UUID` | `c0a80121-7ac0-4e1c-8f3a-6b2d8f1e0a11` | 格式不对的字符串 |
| `datetime` / `date` | `2025-01-01T10:00:00`、`2025-01-01` | `2025/01/01` |
| `Enum` 子类 | 枚举中定义的值 | 不在枚举中的值 |

> 💡 路径参数**总是必填的**——它是 URL 的一部分，不存在「不传」的情况。所以给路径参数设默认值没有意义。

### 1.2 路由声明顺序

路由按**声明顺序**逐个匹配，命中第一个就停止。看下面的例子：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}


@app.get("/users/me")
async def read_current_user():
    return {"user": "当前登录用户"}
```

```bash
curl http://127.0.0.1:8000/users/me
# {"user_id":"me"}          ← /users/me 永远到不了！
```

`/users/me` 先被 `/users/{user_id}` 匹配走了（`"me"` 是合法的 `str`）。**固定路径必须声明在参数路径之前**：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/me")
async def read_current_user():
    return {"user": "当前登录用户"}


@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}
```

> ⚠️ 如果 `user_id` 声明为 `int`，`/users/me` 会先匹配到 `{user_id}` 路由、再因类型转换失败返回 **422**，而不是继续尝试后面的路由。路由匹配只看路径模式，不看类型。

### 1.3 Enum：限定取值范围

参数只允许几个固定值时，用枚举：

```python
from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"


app = FastAPI()


@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "深度学习 FTW!"}

    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}

    return {"model_name": model_name, "message": "Have some residuals"}
```

```bash
curl http://127.0.0.1:8000/models/lenet
# {"model_name":"lenet","message":"LeCNN all the images"}

curl http://127.0.0.1:8000/models/vgg
# {"detail":[{"type":"enum","loc":["path","model_name"],
#   "msg":"Input should be 'alexnet', 'resnet' or 'lenet'","input":"vgg",
#   "ctx":{"expected":"'alexnet', 'resnet' or 'lenet'"}}]}
```

要点：

- 继承 `str, Enum`（或 Python 3.11+ 的 `StrEnum`，见 10.3）让枚举成员同时是字符串，JSON 序列化时输出其值；
- 函数内拿到的是**枚举成员**，可以用 `is` 比较，也可以用 `.value` 取原始值；
- `/docs` 会把它渲染成下拉框，可选值一目了然。

> 💡 `Literal["alexnet", "resnet", "lenet"]` 也能达到限定取值的效果，写法更轻量；需要在多个地方复用、或要给每个值附带行为时，用 Enum 更合适。

### 1.4 包含 `/` 的路径参数：`:path` 转换器

默认情况下路径参数不能包含 `/`。如果需要接收一个文件路径，用 Starlette 的 `:path` 转换器：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

```bash
curl http://127.0.0.1:8000/files/docs/2025/report.pdf
# {"file_path":"docs/2025/report.pdf"}

curl http://127.0.0.1:8000/files//home/user/a.txt     # 注意 files 后面是两个斜杠
# {"file_path":"/home/user/a.txt"}
```

> ⚠️ 拿到用户传入的路径后**绝不能直接拼接去读文件**，否则 `../../etc/passwd` 这类输入会造成路径穿越漏洞。务必用 `Path.resolve()` 后检查是否仍在允许的目录内（参考 7.3）。

## 2. 查询参数

### 2.1 基本规则：不在路径里的就是查询参数

函数参数如果**不在路径模板中**，且类型是 `int`、`str`、`bool` 这类单值类型，FastAPI 就把它当作查询参数：

```python
from fastapi import FastAPI

app = FastAPI()

fake_items = [{"name": f"item{i}"} for i in range(10)]


@app.get("/items")
async def list_items(skip: int = 0, limit: int = 3):
    return fake_items[skip : skip + limit]


@app.get("/search")
async def search(keyword: str, page: int = 1, size: int | None = None):
    return {"keyword": keyword, "page": page, "size": size}
```

是否必填由**有没有默认值**决定：

| 声明 | 含义 | 不传时 |
|---|---|---|
| `keyword: str` | 必填 | 422，`type: missing` |
| `page: int = 1` | 可选，有默认值 | 使用 `1` |
| `size: int \| None = None` | 可选，可以为空 | 得到 `None` |

```bash
curl "http://127.0.0.1:8000/items?skip=2&limit=2"
# [{"name":"item2"},{"name":"item3"}]

curl "http://127.0.0.1:8000/search?keyword=python"
# {"keyword":"python","page":1,"size":null}

curl "http://127.0.0.1:8000/search"
# {"detail":[{"type":"missing","loc":["query","keyword"],"msg":"Field required","input":null}]}
```

> 💡 `int | None = None` 中的 `| None` 只是告诉类型检查器和文档「这个值可能是 None」；**真正让参数变成可选的是 `= None` 这个默认值**。`size: int | None`（不写默认值）仍然是必填的。

### 2.2 bool 参数的转换

`bool` 类型的查询参数非常宽松，以下取值都能被识别（大小写不敏感）：

| 传入值 | 结果 |
|---|---|
| `1`、`true`、`True`、`on`、`yes` | `True` |
| `0`、`false`、`False`、`off`、`no` | `False` |
| 其他（如 `abc`） | 422，`type: bool_parsing` |

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/articles")
async def list_articles(published: bool = False):
    return {"published": published}
```

```bash
curl "http://127.0.0.1:8000/articles?published=yes"
# {"published":true}
```

### 2.3 路径参数与查询参数混用

FastAPI 按**名字**识别参数，与函数参数的顺序无关：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/{user_id}/items/{item_id}")
async def read_user_item(item_id: str, user_id: int, q: str | None = None, short: bool = False):
    item = {"item_id": item_id, "owner_id": user_id}
    if q:
        item["q"] = q
    if not short:
        item["description"] = "这是一个描述很长的商品"
    return item
```

```bash
curl "http://127.0.0.1:8000/users/1/items/abc?q=hi&short=1"
# {"item_id":"abc","owner_id":1,"q":"hi"}
```

## 3. 用 `Annotated` + `Query` / `Path` 声明校验规则

只靠类型提示，能约束的只有「是什么类型」。要约束「长度 3~10」「必须大于 0」「必须匹配某正则」，就需要 `Query()` 和 `Path()`。

### 3.1 推荐写法：`Annotated`

```python
from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/search")
async def search(
    q: Annotated[str, Query(min_length=3, max_length=10, pattern="^[a-z]+$")],
    page: Annotated[int, Query(ge=1)] = 1,
):
    return {"q": q, "page": page}
```

`Annotated[类型, 额外信息]` 是标准库 `typing` 提供的语法（10.1）：第一个参数是真正的类型，后面的部分 Python 本身会忽略，由 FastAPI 读取。

> 💡 旧教程中常见 `q: str = Query(default=None, max_length=50)` 的写法，它仍然可用，但官方现在推荐 `Annotated`：默认值回到了 `=` 后面，语义更清晰；同一个函数脱离 FastAPI 被直接调用时，默认值也是正常的值而不是一个 `Query` 对象；`Annotated` 类型还能被提取成别名复用。

### 3.2 校验失败的效果

```bash
curl "http://127.0.0.1:8000/search?q=ab"
```

```json
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": ["query", "q"],
      "msg": "String should have at least 3 characters",
      "input": "ab",
      "ctx": {"min_length": 3}
    }
  ]
}
```

```bash
curl "http://127.0.0.1:8000/search?q=ABC"
# ... "type":"string_pattern_mismatch","msg":"String should match pattern '^[a-z]+$'" ...

curl "http://127.0.0.1:8000/search?q=abc&page=0"
# ... "type":"greater_than_equal","loc":["query","page"],"msg":"Input should be greater than or equal to 1","input":"0","ctx":{"ge":1} ...
```

### 3.3 常用校验参数一览

| 参数 | 适用类型 | 含义 |
|---|---|---|
| `min_length` / `max_length` | `str`、`list` | 最小 / 最大长度 |
| `pattern` | `str` | 正则表达式（旧版本叫 `regex`，已废弃） |
| `gt` / `ge` | 数字 | 大于 / 大于等于 |
| `lt` / `le` | 数字 | 小于 / 小于等于 |
| `multiple_of` | 数字 | 必须是某数的倍数 |

元数据参数（不做校验，只影响文档或参数名）：

| 参数 | 作用 |
|---|---|
| `title` / `description` | 在文档中显示的标题与说明 |
| `alias` | URL 中使用的参数名与 Python 变量名不同 |
| `deprecated=True` | 在文档中标记为已废弃（参数仍然可用） |
| `include_in_schema=False` | 不出现在文档中（参数仍然可用） |
| `examples` | 文档中的示例值 |

### 3.4 `Path`：给路径参数加约束

```python
from typing import Annotated

from fastapi import FastAPI, Path, Query

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(
    item_id: Annotated[int, Path(title="商品 ID", ge=1, le=1000)],
    size: Annotated[float, Query(gt=0, lt=10.5)] = 1,
):
    return {"item_id": item_id, "size": size}
```

```bash
curl http://127.0.0.1:8000/items/0
# ... "type":"greater_than_equal","loc":["path","item_id"],"msg":"Input should be greater than or equal to 1" ...

curl "http://127.0.0.1:8000/items/5?size=11"
# ... "type":"less_than","loc":["query","size"],"msg":"Input should be less than 10.5" ...
```

### 3.5 alias：URL 参数名不是合法的 Python 标识符

URL 里常见 `item-query` 这种带连字符的名字，它不能作为 Python 变量名，用 `alias` 映射：

```python
from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items")
async def read_items(
    item_query: Annotated[str | None, Query(alias="item-query")] = None,
):
    return {"item_query": item_query}
```

```bash
curl "http://127.0.0.1:8000/items?item-query=phone"
# {"item_query":"phone"}

curl "http://127.0.0.1:8000/items?item_query=phone"
# {"item_query":null}      ← 设置了 alias 后，只认 alias 名
```

### 3.6 文档元数据、废弃与隐藏

```python
from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/products")
async def list_products(
    keyword: Annotated[
        str | None,
        Query(title="关键词", description="按名称模糊搜索，至少 2 个字符", min_length=2, examples=["键盘"]),
    ] = None,
    sort: Annotated[str | None, Query(deprecated=True, description="请改用 order_by")] = None,
    debug: Annotated[bool, Query(include_in_schema=False)] = False,
):
    return {"keyword": keyword, "sort": sort, "debug": debug}
```

在 `/docs` 中可以看到：`keyword` 带有标题、描述和示例；`sort` 被划上删除线标记为废弃；`debug` 完全不显示，但请求时传 `?debug=1` 依然生效——适合内部调试开关。

### 3.7 自定义校验：`AfterValidator`

内置约束不够用时，可以借助 Pydantic 的 `AfterValidator` 写任意校验逻辑：

```python
from typing import Annotated

from fastapi import FastAPI
from pydantic import AfterValidator

app = FastAPI()


def check_book_id(value: str) -> str:
    if not value.startswith(("isbn-", "imdb-")):
        raise ValueError('必须以 "isbn-" 或 "imdb-" 开头')
    return value


@app.get("/books")
async def read_book(book_id: Annotated[str | None, AfterValidator(check_book_id)] = None):
    return {"book_id": book_id}
```

```bash
curl "http://127.0.0.1:8000/books?book_id=x"
# {"detail":[{"type":"value_error","loc":["query","book_id"],
#   "msg":"Value error, 必须以 \"isbn-\" 或 \"imdb-\" 开头","input":"x","ctx":{"error":{}}}]}
```

校验函数抛出 `ValueError`，FastAPI 会把它转为 422，错误信息前面自动加上 `Value error, `。当参数为 `None`（未传）时，校验函数不会被调用。

### 3.8 用类型别名复用约束

`Annotated` 的一大好处是可以抽成别名，在多个接口间复用：

```python
from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()

Page = Annotated[int, Query(ge=1, description="页码，从 1 开始")]
PageSize = Annotated[int, Query(ge=1, le=100, description="每页条数")]


@app.get("/articles")
async def list_articles(page: Page = 1, size: PageSize = 20):
    return {"page": page, "size": size}


@app.get("/comments")
async def list_comments(page: Page = 1, size: PageSize = 50):
    return {"page": page, "size": size}
```

## 4. 列表查询参数

同一个参数传多次（`?tag=a&tag=b`），要接收为列表：

```python
from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/posts")
async def list_posts(
    tag: Annotated[list[str] | None, Query()] = None,
    ids: Annotated[list[int], Query()] = [],
):
    return {"tag": tag, "ids": ids}
```

```bash
curl "http://127.0.0.1:8000/posts?tag=python&tag=web&ids=1&ids=2"
# {"tag":["python","web"],"ids":[1,2]}

curl "http://127.0.0.1:8000/posts"
# {"tag":null,"ids":[]}
```

> ⚠️ **列表类型的查询参数必须显式写 `Query()`**。如果只写 `tag: list[str] | None = None`，FastAPI 会把它当成**请求体**参数——因为单值类型默认是查询参数，而列表、模型等复杂类型默认是请求体。这是一个非常隐蔽的坑，`/docs` 中会看到它出现在 Request body 里。
>
> 💡 在 `Annotated` 里用 `= []` 作为默认值是安全的：FastAPI/Pydantic 会为每个请求复制默认值，不会出现 Python 函数可变默认参数的共享问题（3.2）。

## 5. 查询参数模型

当一个接口有很多查询参数（分页、排序、过滤……），可以把它们收拢进一个 Pydantic 模型，再用 `Query()` 标注：

```python
from typing import Annotated, Literal

from fastapi import FastAPI, Query
from pydantic import BaseModel, Field

app = FastAPI()


class FilterParams(BaseModel):
    model_config = {"extra": "forbid"}

    limit: int = Field(100, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []


@app.get("/items")
async def read_items(filter_query: Annotated[FilterParams, Query()]):
    return filter_query
```

```bash
curl "http://127.0.0.1:8000/items?limit=10&tags=a&tags=b"
# {"limit":10,"offset":0,"order_by":"created_at","tags":["a","b"]}

curl "http://127.0.0.1:8000/items?limit=10&foo=1"
# {"detail":[{"type":"extra_forbidden","loc":["query","foo"],
#   "msg":"Extra inputs are not permitted","input":"1"}]}
```

要点：

- 模型中的每个字段都变成一个独立的查询参数，`/docs` 中也是分开显示的；
- 模型里的 `list[str]` 字段会自动按多值查询参数处理，不需要额外标注；
- `model_config = {"extra": "forbid"}` 让**未声明的查询参数直接报错**，可以避免客户端拼错参数名（如 `ofset=10`）却毫无察觉；
- 这个模型可以在多个接口间复用，也方便单独测试；
- 同样的思路也适用于 Header 和 Cookie（12.4）。

> ⚠️ 字段设置了 `alias`（如 `Field(10, alias="pageSize")`）时，URL 中要用别名 `?pageSize=5`；同时开启了 `extra="forbid"` 的话，传原名 `?page_size=5` 会被当作额外参数报错。

## 6. 读懂 422 错误响应

所有参数校验失败都会返回状态码 **422 Unprocessable Content**，响应体结构固定：

```json
{
  "detail": [
    {
      "type": "greater_than_equal",
      "loc": ["query", "page"],
      "msg": "Input should be greater than or equal to 1",
      "input": "0",
      "ctx": {"ge": 1}
    }
  ]
}
```

| 字段 | 含义 |
|---|---|
| `detail` | 错误**列表**——所有参数一次校验完，有几个错误就有几项，而不是遇到第一个就停 |
| `type` | 机器可读的错误类型，前端可以据此做国际化提示 |
| `loc` | 错误位置：第一项是来源（`path` / `query` / `header` / `cookie` / `body`），后面是字段名，嵌套时会更长，如 `["body", "images", 0, "url"]` |
| `msg` | 人类可读的错误说明（英文） |
| `input` | 客户端实际传入的值；**缺失**时为 `null`。注意来自 URL 的值总是字符串（如 `"0"`） |
| `ctx` | 可选，附加上下文，如约束的阈值 |

常见 `type` 速查：

| type | 触发场景 |
|---|---|
| `missing` | 必填参数没传 |
| `int_parsing` / `float_parsing` / `bool_parsing` | 类型转换失败 |
| `string_too_short` / `string_too_long` | 违反 `min_length` / `max_length` |
| `string_pattern_mismatch` | 不匹配 `pattern` |
| `greater_than` / `greater_than_equal` / `less_than` / `less_than_equal` | 违反 `gt` / `ge` / `lt` / `le` |
| `enum` / `literal_error` | 不在枚举 / Literal 允许的值中 |
| `extra_forbidden` | 传了模型未声明的参数（`extra="forbid"`） |
| `value_error` | 自定义校验函数抛出了 `ValueError` |

> 💡 422 响应的格式是可以定制的，例如统一改成 `{"code": 40001, "message": "..."}`，见 12.6。

## 7. FastAPI 如何判断参数来源

把本节规则汇总成一张表（12.3 还会补充请求体的规则）：

| 函数参数的特征 | 被识别为 |
|---|---|
| 名字出现在路径模板 `{...}` 中 | 路径参数 |
| 单值类型（`int`、`str`、`bool`、`float`、`Enum`、`UUID`、`datetime`…），不在路径中 | 查询参数 |
| 显式标注 `Query()` | 查询参数（包括 `list[...]` 和 Pydantic 模型） |
| Pydantic 模型、`list`、`dict` 等复杂类型，无显式标注 | **请求体** |
| 显式标注 `Path()` / `Header()` / `Cookie()` / `Body()` / `Form()` / `File()` | 对应来源 |

## 常见坑

1. **固定路径被参数路径「吃掉」**：`/users/me` 必须声明在 `/users/{user_id}` 之前。
2. **以为 `int | None` 就是可选**：可选性取决于是否有默认值，`x: int | None` 仍然必填。
3. **列表查询参数没写 `Query()`**：`tags: list[str] = []` 会被识别为请求体。
4. **设置了 `alias` 后还用原名传参**：设置 alias 后只认 alias。
5. **`pattern` 写成 `regex`**：`regex` 是旧参数名，已废弃，统一用 `pattern`。
6. **`:path` 参数直接拼接文件路径**：存在路径穿越风险，必须校验。
7. **把 422 当成 400**：参数校验失败默认是 422，前端或网关如果只处理 400 会漏掉；需要的话在 12.6 中统一改写。
8. **curl 请求中直接写中文、空格、`&` 等特殊字符**：需要 URL 编码，否则请求会被拒绝或参数被截断。可以用 `curl -G --data-urlencode "q=中文" URL` 让 curl 自动编码。

## 小结

- 路径参数用 `{name}` 声明，总是必填；按类型提示自动转换，转换失败返回 422。
- 路由按声明顺序匹配，固定路径要写在参数路径前面；`{x:path}` 可以匹配包含 `/` 的值。
- 不在路径中的单值参数是查询参数，**有默认值即可选**。
- 用 `Annotated[类型, Query(...)]` / `Annotated[类型, Path(...)]` 声明长度、范围、正则等约束，以及 alias、描述、废弃等元数据；`AfterValidator` 可以写自定义校验；`Annotated` 别名可以复用。
- 列表查询参数必须显式 `Query()`；参数多时用「查询参数模型」收拢，配合 `extra="forbid"` 拒绝未知参数。
- 422 错误体的 `detail` 是列表，`loc` 指明来源和字段，`type` 用于程序判断。
