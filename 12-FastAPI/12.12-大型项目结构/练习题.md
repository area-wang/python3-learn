### 1. 依赖与标签的叠加

```python
from fastapi import APIRouter, Depends, FastAPI
from fastapi.testclient import TestClient

calls = []


def dep_a():
    calls.append("a")


def dep_b():
    calls.append("b")


router = APIRouter(prefix="/orders", tags=["orders"], dependencies=[Depends(dep_a)])


@router.get("/{order_id}", dependencies=[Depends(dep_b)])
def get_order(order_id: int):
    return {"order_id": order_id}


app = FastAPI()
app.include_router(router, prefix="/api/v1", tags=["v1"], dependencies=[Depends(dep_b)])

client = TestClient(app)
print(client.get("/api/v1/orders/7").json())
print(calls)

print(client.get("/orders/7").status_code)
```

### 3. 子应用的异常处理

## 三、编程题

### 1. 拆分单文件应用

把下面的单文件应用拆分为按层组织的多文件结构（`main.py`、`api/v1/books.py`、`api/v1/authors.py`、`schemas/`），要求：

- 所有接口挂在 `/api/v1` 下；
- books 和 authors 分别有自己的 `tags`；
- 拆分后所有接口的路径、行为与拆分前完全一致（用 `app.openapi()["paths"]` 对比验证）。

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()
books, authors = {}, {}


class Book(BaseModel):
    title: str
    author_id: int


class Author(BaseModel):
    name: str


@app.post("/api/v1/books/")
def create_book(book: Book):
    books[len(books) + 1] = book
    return {"id": len(books), **book.model_dump()}


@app.get("/api/v1/books/{book_id}")
def get_book(book_id: int):
    return books[book_id]


@app.post("/api/v1/authors/")
def create_author(author: Author):
    authors[len(authors) + 1] = author
    return {"id": len(authors), **author.model_dump()}
```

### 2. 配置管理

为上题编写 `core/config.py`：

- 支持 `BOOK_` 前缀的环境变量和 `.env` 文件；
- 包含 `app_name`、`debug`、`page_size`（默认 20，范围 1~100，越界启动报错）、`database`（嵌套模型，含 `url` 和 `pool_size`）；
- `secret_key` 使用 `SecretStr`，并验证打印 settings 时密钥被隐藏；
- 提供 `get_settings()` 依赖，并写一个 `/api/v1/meta` 接口返回 `app_name` 和 `page_size`；
- 当 `debug=False` 时关闭 `/docs` 和 `/redoc`。

### 3. 分层改造

继续改造第 1 题，引入 `repositories/` 和 `services/`：

- 业务规则：创建书籍时 `author_id` 对应的作者必须存在，否则 service 抛出 `AuthorNotFoundError`；
- 书名在同一作者下不能重复，否则抛出 `DuplicateBookError`；
- 通过全局异常处理器把两种业务异常分别转换为 404 和 409，router 中不允许出现 `try/except`；
- 不启动 HTTP，直接实例化 service 写几个断言验证业务规则。

### 4. 嵌套路由与版本化

- 实现 `GET /api/v1/authors/{author_id}/books/`，要求用「books router 嵌套进 authors router」的方式实现；
- 新增 `/api/v2`，其中 `GET /api/v2/books/{book_id}` 返回结构改为 `{"id": ..., "title": ..., "author": {"id": ..., "name": ...}}`，v1 接口保持不变；
- 让 `/docs` 中 v1 和 v2 的接口显示在不同的分组里。

### 5. 子应用与静态页面

- 新建一个独立的 FastAPI 应用作为「后台」，挂载到 `/admin`，它有自己的 `/admin/docs`；
- 后台有一个 `GET /admin/` 页面，用 `Jinja2Templates` 渲染所有书籍的 HTML 表格；
- 挂载 `/static` 提供一个 CSS 文件，并在模板中通过 `url_for('static', path='style.css')` 引用；
- 静态文件和模板目录使用基于 `Path(__file__)` 的绝对路径，保证在任意目录启动都能工作。

### 6. OpenAPI 定制

- 用 `openapi_tags` 为每个分组写上 Markdown 格式的说明，并控制分组的显示顺序；
- 自定义 `generate_unique_id_function`，生成形如 `books_create_book` 的 operationId；
- 将健康检查接口 `/health` 从文档中隐藏；
- 用 `servers` 配置开发和生产两个地址；
- 写一个脚本把 `app.openapi()` 导出为 `openapi.json` 文件。
