# 6.2 捕获异常练习题

## 一、概念题

1. `try` 语句块的四个子句分别是什么？它们的固定书写顺序是怎样的？
2. `else` 子句什么时候执行？它和直接把后续代码写在 `try` 末尾有什么区别？
3. `finally` 子句的执行时机有哪些？`try` 中 `return` 了，`finally` 还会执行吗？
4. 为什么不建议使用裸 `except:`？它和 `except Exception:` 有什么关键区别？
5. `except` 匹配异常时用的是 `isinstance` 语义，这对捕获父类和子类异常意味着什么？
6. 一个 `except` 想同时捕获 `ValueError` 和 `TypeError`，应该怎么写？
7. `except` 中不带参数的 `raise` 与 `raise e` 有什么区别？哪种更推荐？为什么？
8. `finally` 中再次抛出异常会发生什么？为什么这是一个需要警惕的操作？
9. 若 `try` 中抛出的异常没有被任何 `except` 匹配，`finally` 还会执行吗？之后异常去哪了？
10. 简述“优先精确捕获”的理由，并说出一个反例（裸 except 带来的危害）。

### 3. else 用法

```python
def process(path):
    try:
        data = open(path).read()
        number = int(data.strip())
        return number * 2
    except FileNotFoundError:
        return 0
    except ValueError:
        return 0
```

如果在 `data.strip()` 之后、`int(...)` 之前，`data` 是一个巨大字符串，`number * 2` 不会出错。但若以后把 `number * 2` 改成某个可能抛 `ValueError` 的处理函数，会出现什么隐患？用 `else` 改写，避免该隐患。

## 四、编程题

### 1. 安全整数转换

编写 `safe_int(text, default=None)`：

- 成功返回整数；
- 失败返回 `default`；
- `default` 为 `None` 时返回 `None`；

并编写测试，覆盖空串、纯字母、带空白、负数、超大数字等输入。

### 2. 重试装饰器（基础版）

编写函数 `retry(times)`，它接收一个无参可调用对象，最多尝试 `times` 次：每次失败捕获 `Exception` 并打印第 `N` 次重试信息，全部失败后把最后一次的异常重新抛出。要求使用 `raise`（不带参数）保留原始异常。

### 3. 资源管理模拟

模拟一个数据库连接类 `FakeConnection`，提供 `connect`、`execute`、`close` 方法。编写函数 `import_records(conn, records)`，要求：

- 成功时执行所有插入并标记“已提交”；
- 任何一条 `execute` 抛出异常时回滚（打印“已回滚”）；
- 不论成功失败，最后必须 `close`；
- 用 `finally` 实现清理，用 `except + raise` 实现回滚后保留原始异常。

### 4. 多种输入验证

读取用户输入直到得到合法值。要求：

- 输入应为整数，且在 1 到 100 之间；
- 不是整数时提示“请输入整数”；
- 超出范围时提示“应在 1-100 之间”；
- 最多尝试 3 次，超过则抛出 `ValueError`；
- 用 `try-except` 精确捕获，不要用裸 except。

### 5. 异常类型分组统计

编写函数 `summarize(func, examples)`，`examples` 是一个可调用输入列表。调用 `func(x)` 对每个输入：

- 成功则统计成功次数；
- `ValueError`、`TypeError`、其他 `Exception` 分别统计；
- 其他 `Exception` 要打印 `traceback` 信息（使用 `traceback.format_exc()`）。

最后返回一个字典形式的统计结果。

### 6. else 与 finally 配合

实现函数 `read_and_double(path)`：

- 读取文件内容并解析为整数后乘以 2 返回；
- 文件不存在抛 `FileNotFoundError`；文件存在但解析失败抛 `ValueError`；
- 使用 `else` 存放“读取成功后的进一步处理”，使用 `finally` 打印“文件处理结束”；
- 不要在 `try` 里做 `*2`，要放到 `else` 里，并解释这样写的好处。
