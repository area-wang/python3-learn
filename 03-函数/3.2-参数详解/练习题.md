## 位置与关键字参数

### 练习题

**题目 1：基础**
定义 `def info(name, age, city): ...`，用三种方式调用输出 `Alice, 25, Beijing`：
1. 全位置
2. 全关键字
3. 混合

**题目 2：陷阱**
以下哪些调用合法？
```python
def f(a, b, c): ...

f(1, 2, 3)
f(1, 2, c=3)
f(a=1, 2, 3)
f(1, b=2, c=3)
f(a=1, b=2, c=3)
f(1, 2, a=3)
```

**题目 3：语义清晰**
定义 `send_email(to, subject, body, cc, bcc)`，写成调用清晰、不易传错的版本（用关键字参数提高可读性）。

## 默认参数

### 练习题

**题目 1：默认值**
定义 `greet(name, greeting="Hello")`，分别：
1. 调用 `greet("Alice")` 输出 `Hello, Alice!`
2. 调用 `greet("Alice", "Hi")` 输出 `Hi, Alice!`

**题目 2：默认值顺序**
以下哪些定义合法？
```python
def f(a, b=1): ...
def f(a=1, b): ...
def f(a=1, b=2): ...
def f(a, b=1, c=2): ...
```

**题目 3：默认值求值时机**
```python
import random
def f(x=random.randint(1, 100)):
    return x
```
两次调用 `f()` 输出会一样还是不同？为什么？

**题目 4：用 None 哨兵**
实现 `add_tag(text, tag="<>")` 是个糟糕设计（因为字符串不可变没陷阱，但若改成 `tag=[]`）。实际请实现 `append_item(lst=None, item=1)`，保证每次新 list。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")           # Hello, Alice!
greet("Alice", "Hi")     # Hi, Alice!

# 题目 2
# 合法：def f(a, b=1), def f(a=1, b=2), def f(a, b=1, c=2)
# 非法：def f(a=1, b)   - 默认参数后不能有非默认

# 题目 3
# 两次输出**相同**。因为默认值在 def 执行时只求值一次，
# 之后所有调用都用同一个已确定的随机数。
import random
def f(x=random.randint(1, 100)):
    return x
print(f(), f())   # 例如 42 42，一样

# 题目 4
def append_item(lst=None, item=1):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(append_item())          # [1]
print(append_item())          # [1]  每次新 list
print(append_item([9], 5))    # [9, 5]
```

## *args 与 **kwargs

### 练习题

**题目 1：求和**
用 `*args` 实现 `my_sum(*args)`，返回所有参数之和。

**题目 2：连接字符串**
用 `*args` 和 keyword-only `sep` 实现 `join_first(sep, *args)`，返回用 sep 连接的 args。如 `join_first("-", "a", "b", "c")` 返回 `"a-b-c"`。

**题目 3：用户构建**
用 `**kwargs` 实现 `create_user(name, **info)`，返回 `{"name": name, **info}` 的字典。

**题目 4：万能 logger**
用 `*args, **kwargs` 实现 `log(msg, *args, **kwargs)`，把 `msg, *args` 用 `print(..., sep, end)` 输出，`**kwargs` 传给 print。

**题目 5：陷阱**
```python
def f(*args):
    return args

f(1, 2, 3)        # ?
f(a=1)            # ?
f(*[10, 20])      # ?
```
逐行说明输出或错误。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
def my_sum(*args):
    return sum(args)

print(my_sum(1, 2, 3, 4))  # 10
print(my_sum())              # 0
print(my_sum(*range(1, 101)))  # 5050

# 题目 2
def join_first(sep, *args):
    return sep.join(str(x) for x in args)

print(join_first("-", "a", "b", "c"))  # a-b-c

# 题目 3
def create_user(name, **info):
    return {"name": name, **info}

print(create_user("Alice", age=20, email="a@x.com"))
# {'name': 'Alice', 'age': 20, 'email': 'a@x.com'}

# 题目 4
def log(msg, *args, **kwargs):
    print(msg, *args, **kwargs)

log("Hello", 1, 2, 3, sep="-", end="!\n")
# Hello-1-2-3!

# 题目 5
def f(*args):
    return args

print(f(1, 2, 3))   # (1, 2, 3)
# f(a=1)            # TypeError: f() got an unexpected keyword argument 'a'
#                    *args 只收位置参数，不收关键字参数
print(f(*[10, 20]))  # (10, 20) - 列表解包成位置参数
```

## positional-only / keyword-only

### 练习题

**题目 1：positional-only**
定义 `def power(x, /, exp=2)`，要求 `x` 只能位置传，`exp` 可关键字可位置。
1. 写出 3 种合法调用
2. 写一个非法调用

**题目 2：keyword-only**
定义 `def connect(host, port, *, timeout=10, retry=3)`：
1. 合法调用 3 种
2. 非法调用 1 种

**题目 3：综合顺序**
定义 `def f(a, b, /, c, d=10, *args, e, f=20, **kwargs)`，写一个调用让所有参数都赋上值，并打印 `locals()`。

**题目 4：API 稳定性**
为什么 `len` 不让用关键字 `len(obj=x)`？自己实现一个 `my_len(obj, /)`，并验证 `obj=` 形式非法。

```python
# 题目 1
def power(x, /, exp=2):
    return x ** exp

# 合法
print(power(3))        # 9
print(power(3, 4))     # 81
print(power(3, exp=4)) # 81
# 非法
# power(x=3)          # TypeError - x 是 positional-only

# 题目 2
def connect(host, port, *, timeout=10, retry=3):
    print(f"{host}:{port}, timeout={timeout}, retry={retry}")

# 合法
connect("localhost", 8080)
connect("localhost", 8080, timeout=5)
connect("localhost", 8080, retry=5, timeout=3)
# 非法
# connect("localhost", 8080, 5, 3)  # TypeError - timeout, retry 必须用关键字

# 题目 3
def f(a, b, /, c, d=10, *args, e, f=20, **kwargs):
    return locals()

print(f(1, 2, 3, 4, 5, 6, e=7, f=8, x=9, y=10))
# {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'args': (5, 6), 'e': 7, 'f': 8, 'kwargs': {'x': 9, 'y': 10}}
# 注意：d 收了第 4 个位置参数 4，而不是默认 10！

# 题目 4
# 因为参数名是实现细节，不应被外部依赖。len 不接受关键字参数保证 API 稳定。
def my_len(obj, /):
    return len(obj) if hasattr(obj, "__len__") else 0

print(my_len("abc"))     # 3
# my_len(obj="abc")      # TypeError - obj 是 positional-only
```

## 参数解包

### 练习题

**题目 1：列表解包**
`def add(a, b, c): ...`，用列表 `[1, 2, 3]` 解包调用。

**题目 2：字典解包**

**题目 3：混合解包**
`def f(a, b, c, d): ...`，用 `1`（位置）+ 列表 `[2, 3]`（解包）+ `d=4`（关键字）三种方式调用让结果为 10。

**题目 4：转发**
写 `wrapper func`：`def proxy(func, *args, **kwargs): return func(*args, **kwargs)`，用它代理 `print(1, 2, 3, sep="-")`。

**题目 5：陷阱**
```python
def f(a, b, c):
    return a + b + c

print(f(**{"a": 1, "b": 2}))   # ?
print(f(*[1, 2, 3, 4]))        # ?
print(f(*"abc"))               # ?
```

<summary>点击查看答案</summary>

```python
# 题目 1
def add(a, b, c):
    return a + b + c
print(add(*[1, 2, 3]))  # 6

# 题目 2

    return f"{name}/{age}/{city}"

    return a + b + c + d
```

## 可变默认参数陷阱

### 练习题

**题目 1：经典陷阱**
```python
def f(lst=[]):
    lst.append(1)
    return lst

print(f())
print(f())
print(f())
```
输出？为什么？如何修复？

**题目 2：dict 默认值**
```python
def f(d={}):
    d["x"] = d.get("x", 0) + 1
    return d

print(f())
print(f())
```
输出？为什么？

**题目 3：用陷阱做缓存**
利用可变默认值（dict）实现快速斐波那契（带 memo）。

**题目 4：不可变默认**
```python
def f(x=0):
    x += 1
    return x

print(f())
print(f())
```
输出？为什么没有累积？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
def f(lst=[]):
    lst.append(1)
    return lst

print(f())  # [1]
print(f())  # [1, 1]
print(f())  # [1, 1, 1]
# 原因：默认值 [] 在 def 时只创建一次，所有调用复用同一个 list。

# 修复
def f(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst

print(f())  # [1]
print(f())  # [1]

# 题目 2
def f(d={}):
    d["x"] = d.get("x", 0) + 1
    return d

print(f())  # {'x': 1}
print(f())  # {'x': 2}
# 同样原因，dict 也跨调用共享

# 题目 3
def fib(n, cache={}):
    if n in cache:
        return cache[n]
    if n < 2:
        r = n
    else:
        r = fib(n-1) + fib(n-2)
    cache[n] = r
    return r

print(fib(50))  # 12586269025，极快
# 注意：这种写法依赖全局缓存副作用，生产推荐 functools.lru_cache。

# 题目 4
def f(x=0):
    x += 1
    return x

print(f())  # 1
print(f())  # 1
# 原因：x += 1 对不可变对象是赋值，创建新对象，
#       不影响存在 __defaults__ 里的 0。所以每次都用 0。
```

</details>

## 参数传递机制

### 练习题

**题目 1：不可变对象**
```python
def f(x):
    x = x + 1
    print(x)

a = 10
f(a)
print(a)
```
输出？为什么 a 没变？

**题目 2：可变对象**
```python
def f(lst):
    lst.append(100)

a = [1, 2]
f(a)
print(a)
```
输出？为什么 a 被改了？

**题目 3：赋值不影响外部**
```python
def f(lst):
    lst = [10, 20]

a = [1, 2]
f(a)
print(a)
```
输出？为什么这次 a 没变？

**题目 4：切片赋值**
```python
def f(lst):
    lst[:] = [10, 20]

a = [1, 2]
f(a)
print(a)
```
输出？为什么这次 a 又变了？

**题目 5：避免副作用**
实现纯函数 `add_item(lst, item)`，不修改 `lst`，返回新列表。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
def f(x):
    x = x + 1
    print(x)   # 11

a = 10
f(a)            # 11
print(a)        # 10
# a 没变：x = x + 1 是重新绑定，创建新对象，外部 a 仍指向 10。

# 题目 2
def f(lst):
    lst.append(100)

a = [1, 2]
f(a)
print(a)  # [1, 2, 100]
# a 被改：append 是原地修改可变对象，函数内外看到同一对象。

# 题目 3
def f(lst):
    lst = [10, 20]

a = [1, 2]
f(a)
print(a)  # [1, 2]
# a 没变：lst = [...] 只是让局部名 lst 重新指向新对象，
#         原对象 [1,2] 不受影响。

# 题目 4
def f(lst):
    lst[:] = [10, 20]   # 切片赋值是原地修改原对象

a = [1, 2]
f(a)
print(a)  # [10, 20]
# a 变了：lst[:] = ... 修改的是原对象内部内容，
#         外部 a 仍指向原对象，所以看到变化。

# 题目 5
def add_item(lst, item):
    return lst + [item]   # 或 lst.copy() + [item]

a = [1, 2]
b = add_item(a, 3)
print(a)  # [1, 2]      - 原对象未改
print(b)  # [1, 2, 3]   - 返回新对象
```

</details>

## 综合练习

### 练习题

**综合题 1：灵活的求均值函数**
实现 `average(*nums)`，接收任意个数字，返回均值。空参时返回 `None`。

**综合题 2：带配置的URL构建器**
`build_url(host, *, port=80, path="/", scheme="http", **query)`，把 `query` 作为查询参数拼成 URL，如：
```python
build_url("example.com", port=443, scheme="https", path="/api", id=1, name="a")
# "https://example.com:443/api?id=1&name=a"
```

**综合题 3：函数 memoize**
利用 `**kwargs`（或 dict）实现 `memoize(func)`，缓存 `(args, kwargs_key)` → 结果。

**综合题 4：装饰 wrap 顺序**
定义 `debug_call(func, *args, **kwargs)`：打印函数名、args、kwargs，再返回 `func(*args, **kwargs)` 的结果。

**综合题 5：纯函数 vs 副作用**
分别实现：
- `normalize_inplace(nums)`：原地规范化（每值除以最大值），返回 None
- `normalize_copy(nums)`：返回规范化后的新列表，不修改入参

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 综合题 1
def average(*nums):
    if not nums:
        return None
    return sum(nums) / len(nums)

print(average(1, 2, 3))   # 2.0
print(average())          # None

# 综合题 2
from urllib.parse import urlencode

def build_url(host, *, port=80, path="/", scheme="http", **query):
    url = f"{scheme}://{host}:{port}{path}"
    if query:
        url += "?" + urlencode(query)
    return url

print(build_url("example.com", port=443, scheme="https", path="/api", id=1, name="a"))
# https://example.com:443/api?id=1&name=a

# 综合题 3
def memoize(func):
    cache = {}
    def wrapper(*args, **kwargs):
        key = (args, tuple(sorted(kwargs.items())))
        if key not in cache:
            cache[key] = func(*args, **kwargs)
        return cache[key]
    return wrapper

@memoize
def slow_add(a, b):
    print("computing", a, b)
    return a + b

print(slow_add(1, 2))   # computing 1 2 \n 3
print(slow_add(1, 2))   # 3（不再次计算）
print(slow_add(1, b=2))  # computing 1 2 \n 3  (kwargs 版视为不同)

# 综合题 4
def debug_call(func, *args, **kwargs):
    print(f"调用 {func.__name__}({args}, {kwargs})")
    return func(*args, **kwargs)

print(debug_call(max, 1, 2, 3))   # 调用 max((1, 2, 3), {}) \n 3

# 综合题 5
def normalize_inplace(nums):
    if not nums:
        return
    m = max(abs(x) for x in nums)
    for i in range(len(nums)):
        nums[i] = nums[i] / m

def normalize_copy(nums):
    if not nums:
        return []
    m = max(abs(x) for x in nums)
    return [x / m for x in nums]

a = [1, 2, 3, -4]
print(normalize_copy(a))  # [0.25, 0.5, 0.75, -1.0]
print(a)                   # [1, 2, 3, -4] - 未改

b = [1, 2, 3, -4]
normalize_inplace(b)
print(b)  # [0.25, 0.5, 0.75, -1.0] - 已改
```

## 小结

- 参数顺序：`positional-only → 普通/默认 → *args → keyword-only → **kwargs`
- 可变默认值是经典陷阱，改用 `None` 哨兵
- `*args` 收位置参数（元组），`**kwargs` 收关键字参数（字典）
- `/` 前是 positional-only，`*` 后是 keyword-only
- 解包 `*`/`**` 让转发很方便
- 可变对象参数会被函数内修改，要注意副作用
