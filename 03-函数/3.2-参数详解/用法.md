## 参数分类总览

Python 函数参数有 5 大类，按定义位置顺序：

```
def f(a, b, /, c, d=10, *args, e, f=20, **kwargs):
        └──┬──┘  └─┬─┘  └──┬──┘  └─┬─┘  └──┬──┘
      位置强制   位置/关键字  默认值   keyword-only  可变关键字
```

| 类型 | 定义 | 调用方式 | 示例 |
|------|------|----------|------|
| 位置参数（positional） | `def f(a, b):` | 按位置传 | `f(1, 2)` |
| 关键字参数（keyword） | 同上 | 按名字传 | `f(a=1, b=2)` |
| 默认参数（default） | `def f(a=1):` | 可省略 | `f()` 或 `f(5)` |
| 可变位置 `*args` | `def f(*args):` | 任意个位置参数 | `f(1,2,3)` |
| 可变关键字 `**kwargs` | `def f(**kwargs):` | 任意个关键字 | `f(x=1,y=2)` |
| positional-only `/` | `def f(a, /):` | 只能按位置 | `f(1)` |
| keyword-only `*` | `def f(*, a):` | 只能按关键字 | `f(a=1)` |

## 位置参数

**位置参数** 是最基础的参数，调用时按位置顺序一一对应。

```python
def greet(name, greeting):
    print(f"{greeting}, {name}!")

greet("Alice", "Hello")      # Hello, Alice!
greet("Hello", "Alice")      # Alice, Hello! - 顺序错了含义就变
```

### 1. 数量必须匹配

```python
def add(a, b):
    return a + b

add(1, 2)     # 3
# add(1)      # TypeError: add() missing 1 required positional argument: 'b'
# add(1,2,3)  # TypeError: add() takes 2 positional arguments but 3 were given
```

### 2. 位置即语义

当函数有多个同类型参数时，位置参数容易出错：

```python
def create_user(name, age, email):
    ...

# 难读：哪个是 age 哪个是 email？
create_user("Alice", 20, "a@x.com")
create_user("Alice", "a@x.com", 20)   # 悄悄传错，运行不报错但数据错乱
```

→ 这种情况改用关键字参数更安全。

## 关键字参数

**关键字参数** 在调用时给参数指定名字，可以无视顺序，更清晰安全。

```python
def greet(name, greeting):
    print(f"{greeting}, {name}!")

greet(greeting="Hello", name="Alice")  # Hello, Alice! 顺序无关
greet(name="Alice", greeting="Hi")     # Hi, Alice!
```

### 1. 关键字参数必须在位置参数之后

```python
def f(a, b, c):
    return (a, b, c)

f(1, 2, 3)              # OK
f(1, 2, c=3)            # OK
f(1, b=2, c=3)          # OK
f(a=1, b=2, c=3)        # OK
# f(a=1, 2, 3)          # SyntaxError - 位置参数不能在关键字之后
```

### 2. 同一参数不能重复传

```python
def f(a, b):
    return a + b

# f(1, a=2)   # TypeError: f() got multiple values for argument 'a'
f(1, 2)        # 3
```

### 3. 用关键字参数提升可读性

```python
def send_email(to, subject, body, cc=None, bcc=None):
    ...

# 清晰：
send_email(to="alice@x.com", subject="周报", body="见附件", cc="boss@x.com")

# 不清晰：
send_email("alice@x.com", "周报", "见附件", "boss@x.com")  # cc 是啥？
```

## 默认参数

**默认参数** 在定义时给参数一个默认值，调用时可省略该参数。

```python
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")              # Hello, Alice!
greet("Alice", "Hi")        # Hi, Alice!
greet("Alice", greeting="你好")  # 你好, Alice!
```

### 1. 默认参数必须放在普通参数之后

```python
def f(a, b=1):     # OK
    return a + b

# def f(a=1, b):   # SyntaxError - 默认参数后不能有非默认参数
#     return a + b
```

### 2. 默认值可以是表达式（但只在 def 时求值一次）

```python
import random

def f(x=random.randint(1, 10)):
    return x

print(f())   # 每次都是同一个随机数！因为默认值在 def 时已确定
print(f())   # 同上
```

### 3. 用 None 表示"无默认"

```python
def f(data=None):
    if data is None:
        data = []
    data.append(1)
    return data

print(f())   # [1]
print(f())   # [1] - 每次新 list
```

### 4. 默认值类型注解 vs 默认值

```python
def f(a: int = 5) -> int:   # 注解 int，默认 5
    return a + 1
```

## 可变位置参数 *args

`*args` 收集**多余的位置参数**为一个元组。`args` 只是约定名，可改。

### 1. 基本用法

```python
def show(*args):
    print(type(args), args)

show(1, 2, 3)         # <class 'tuple'> (1, 2, 3)
show()                # <class 'tuple'> ()
show("a", "b", "c")   # <class 'tuple'> ('a', 'b', 'c')
```

### 2. 混合普通参数

```python
def f(first, *rest):
    print("first =", first)
    print("rest =", rest)

f(1, 2, 3, 4)
# first = 1
# rest = (2, 3, 4)
```

### 3. 求和函数

```python
def my_sum(*args):
    return sum(args)

print(my_sum(1, 2, 3))        # 6
print(my_sum())               # 0
print(my_sum(*range(100)))    # 4950
```

### 4. args 是元组（不可变）

```python
def f(*args):
    # args.append(1)   # AttributeError - tuple 没有 append
    args = args + (1,)  # 只能重新赋值
    return args

print(f(1, 2))  # (1, 2, 1)
```

## 可变关键字参数 **kwargs

`**kwargs` 收集**多余的关键字参数**为一个字典。`kwargs` 是约定名。

### 1. 基本用法

```python
def show(**kwargs):
    print(type(kwargs), kwargs)

show(a=1, b=2)      # <class 'dict'> {'a': 1, 'b': 2}
show()              # <class 'dict'> {}
show(name="Alice", age=20)  # <class 'dict'> {'name': 'Alice', 'age': 20}
```

### 2. 混合参数

```python
def f(name, **kwargs):
    print("name =", name)
    print("kwargs =", kwargs)

f("Alice", age=20, city="NYC")
# name = Alice
# kwargs = {'age': 20, 'city': 'NYC'}
```

### 3. 配置传递

```python
def create_user(name, **options):
    user = {"name": name}
    user.update(options)
    return user

print(create_user("Alice", age=20, email="a@x.com", active=True))
# {'name': 'Alice', 'age': 20, 'email': 'a@x.com', 'active': True}
```

### 4. kwargs Key 必须是字符串

```python
def f(**kwargs):
    return kwargs

print(f(x=1))           # {'x': 1}
# f(**{1: "a"})         # TypeError - 关键字必须是字符串
# f(**{"a b": 1})        # 实际可传（因为通过 ** 解包，不经过标识符解析）
```

## 参数顺序规则

定义函数时，参数顺序必须遵循：

```
positional-only  →  普通/默认  →  *args  →  keyword-only  →  **kwargs
   (a, /)            (b, c=1)     (*args)     (*, d, e=2)      (**kwargs)
```

```python
def f(a, b, /, c, d=10, *args, e, f=20, **kwargs):
    return locals()

print(f(1, 2, 3, 4, 5, 6, e=7, x=8, y=9))
# {'a': 1, 'b': 2, 'c': 3, 'd': 10, 'args': (5, 6), 'e': 7, 'f': 20, 'kwargs': {'x': 8, 'y': 9}}
```

**解释：**
- `a, b` 在 `/` 前 → positional-only
- `c` → 普通（位置或关键字）
- `d=10` → 带默认值
- `*args` → 收集多余位置参数
- `e` → keyword-only（在 `*` 后）
- `f=20` → keyword-only 带默认值
- `**kwargs` → 收集多余关键字参数

## positional-only 参数 `/`

Python 3.8+ 引入。`/` 之前的参数**只能用位置**传，不能用关键字。

```python
def f(a, b, /, c):
    return a + b + c

f(1, 2, 3)            # OK
f(1, 2, c=3)          # OK
# f(a=1, b=2, c=3)    # TypeError - a, b 不能用关键字
```

### 1. 为什么用 positional-only

- **API 稳定性**：参数名可能改，不让外部依赖名字
- **避免歧义**：内部实现细节不暴露
- **内置函数早就这么做了**：`len(obj)` 不能写 `len(obj=...)`

```python
# 内置就是 positional-only
len("ab")       # OK
# len(obj="ab") # TypeError: len() takes no keyword arguments

# 自己定义
def power(x, /, exp=2):
    return x ** exp

print(power(3))       # 9
print(power(3, 3))    # 27
print(power(3, exp=4))  # 81
# power(x=3)          # TypeError
```

### 2. 纯 positional-only 函数

```python
def add(a, b, /):
    return a + b

add(1, 2)           # 3
# add(a=1, b=2)     # TypeError
```

## keyword-only 参数 `*`

`*` 之后的参数**只能用关键字**传，不能用位置。

```python
def f(a, *, b, c):
    return a + b + c

f(1, b=2, c=3)       # OK
# f(1, 2, 3)         # TypeError - b, c 必须关键字
```

### 1. 强制关键字提高可读性

```python
def connect(host, port, *, timeout=10, retry=3):
    print(f"连接 {host}:{port}, 超时 {timeout}, 重试 {retry}")

connect("localhost", 8080)                    # 默认值生效
connect("localhost", 8080, timeout=5)         # 只改 timeout
connect("localhost", 8080, retry=5, timeout=3)  # 顺序无关
# connect("localhost", 8080, 5, 3)            # TypeError - 5,3 必须关键字
```

### 2. *args 后的参数自动是 keyword-only

```python
def f(*args, sep, end):
    print(sep.join(args), end=end)

f("a", "b", "c", sep="-", end="!\n")   # a-b-c!
# f("a","b","c","-","!\n")             # TypeError
```

### 3. 与 argcomplete/可选参数提升 API

```python
def build(name, *, version="1.0", verbose=False):
    ...

build("app")                              # 只传必需
build("app", version="2.0")               # 清晰
build("app", verbose=True, version="2.0")  # 顺序无关
```

## 参数解包 * **

调用时用 `*` 和 `**` 把序列/字典解包成参数。

### 1. * 解包序列为位置参数

```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))     # 6 - 等价 add(1, 2, 3)

t = (10, 20, 30)
print(add(*t))        # 60

# 元素个数必须匹配
# add(*[1, 2])        # TypeError - 少参数
# add(*[1, 2, 3, 4]) # TypeError - 多参数
```

### 2. ** 解包字典为关键字参数

```python
def f(a, b, c):
    return a + b + c

d = {"a": 1, "b": 2, "c": 3}
print(f(**d))         # 6 - 等价 f(a=1, b=2, c=3)

# 键必须是字符串且匹配参数名
# f(**{1: "x"})      # TypeError - 键不是字符串
# f(**{"a": 1})      # TypeError - 缺少 b, c
```

### 3. 混合解包

```python
def f(a, b, c, d):
    return a + b + c + d

print(f(*[1, 2], c=3, d=4))         # 10
print(f(1, *[2, 3], d=4))           # 10
print(f(*[1, 2], **{"c": 3, "d": 4}))  # 10
```

### 4. 转发参数（关键应用）

```python
def log(msg, *args, **kwargs):
    print(f"[LOG] {msg}", *args, **kwargs)
    # 注意 print 的 *args, **kwargs 由 log 接收的转发

log("Hello", 1, 2, 3, sep="-", end="!\n")
# [LOG] Hello-1-2-3!
```

经典：包装器转发所有参数：

```python
def wrapper(*args, **kwargs):
    # 预处理 ...
    return original(*args, **kwargs)
```

## 可变默认参数陷阱

**这是 Python 最经典的坑：** 默认参数值在 `def` 执行时**只求值一次**并被所有后续调用共享。

### 1. 复现陷阱

```python
def f(lst=[]):
    lst.append(1)
    return lst

print(f())   # [1]
print(f())   # [1, 1]   <- 不是空 list！
print(f())   # [1, 1, 1]
```

### 2. 原因

`def f(lst=[])` 中的 `[]` 在函数定义时创建一次，存在 `f.__defaults__`。每次调用都用同一个对象。

```python
def f(lst=[]):
    lst.append(1)
    return lst

print(f.__defaults__)  # (None,) 还没调用时
# 调用后
f(); f()
print(f.__defaults__)  # ([1, 1],)
```

### 3. 同样影响 dict、set、自定义可变对象

```python
def f(d={}):
    d["count"] = d.get("count", 0) + 1
    return d

print(f())  # {'count': 1}
print(f())  # {'count': 2}

def g(s=set()):
    s.add(1)
    return s

print(g())  # {1}
print(g())  # {1, 1}  实际是 {1}，因为加同样的 1，但若是 add 随机数就会累积
```

### 4. 不可变默认值无此问题

```python
def f(count=0):
    count += 1     # 不可变：赋值创建新对象，不影响默认值
    return count

print(f())  # 1
print(f())  # 1
```

### 5. 标准修复：用 None 哨兵

```python
def f(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst

print(f())  # [1]
print(f())  # [1]

# 或者每调用一次再判断
def f(lst=None):
    lst = list(lst) if lst is not None else []
    lst.append(1)
    return lst
```

### 6. 何时陷阱反而是特性

利用可变默认值做缓存：

```python
def fib(n, cache={}):
    if n in cache:
        return cache[n]
    if n < 2:
        result = n
    else:
        result = fib(n-1) + fib(n-2)
    cache[n] = result
    return result

print(fib(100))   # 极快，.cache 共享但只读不破坏不可变性需求
# 注意：更推荐的写法是 functools.lru_cache，避免全局缓存副作用
```

## 参数传递：值还是引用

Python 的参数传递是**"传对象的引用"（传赋值）**——函数内对可变对象的修改会反映到外部，对不可变对象的"修改"实际是创建新对象。

### 1. 不可变对象（int、str、tuple）

```python
def f(x):
    x = x + 1   # 重新绑定到新对象
    print("in func:", x)

a = 10
f(a)
print("out func:", a)   # 10 - a 不变
```

### 2. 可变对象（list、dict、set）

```python
def f(lst):
    lst.append(100)   # 修改原对象
    print("in func:", lst)

a = [1, 2]
f(a)
print("out func:", a)  # [1, 2, 100] - a 被改了
```

### 3. 赋值 vs 修改

```python
def f(lst):
    lst = [10, 20]   # 重新绑定，不影响外部
    print("in func:", lst)

a = [1, 2]
f(a)
print("out func:", a)  # [1, 2] - a 没变

def g(lst):
    lst[:] = [10, 20]  # 切片赋值，修改原对象
    print("in func:", lst)

b = [1, 2]
g(b)
print("out func:", b)  # [10, 20]
```

### 4. 避免副作用的写法

```python
# 不纯：修改入参
def add_item(lst, item):
    lst.append(item)
    return lst

# 纯：返回新对象
def add_item(lst, item):
    return lst + [item]   # 或 lst.copy().append(item)
```

## inspect 检查参数

```python
import inspect

def f(a, b=2, *args, c, d=4, **kwargs):
    pass

sig = inspect.signature(f)
print(sig)        # (a, b=2, *args, c, d=4, **kwargs)

for name, param in sig.parameters.items():
    print(name, param.kind, param.default)
# a POSITIONAL_OR_KEYWORD <class 'inspect.Parameter.empty'>
# b POSITIONAL_OR_KEYWORD 2
# args VAR_POSITIONAL <class 'inspect.Parameter.empty'>
# c KEYWORD_ONLY <class 'inspect.Parameter.empty'>
# d KEYWORD_ONLY 4
# kwargs VAR_KEYWORD <class 'inspect.Parameter.empty'>

# 检查参数种类
print(param.kind.name)
# POSITIONAL_OR_KEYWORD / VAR_POSITIONAL / KEYWORD_ONLY / VAR_KEYWORD
# POSITIONAL_ONLY / KEYWORD_ONLY
```

## 常见错误与陷阱

### 1. 默认值用可变对象

详见 [可变默认参数陷阱](#可变默认参数陷阱)。最经典的坑。

### 2. 默认参数顺序

```python
# def f(a=1, b): ...   # SyntaxError
def f(a, b=1): ...      # OK
```

### 3. 位置参数跟在关键字参数后

```python
def f(a, b, c):
    return (a, b, c)

# f(a=1, 2, 3)        # SyntaxError
f(1, 2, c=3)           # OK
```

### 4. *args 收不到关键字

```python
def f(*args):
    return args

f(1, 2, 3)        # (1, 2, 3)
# f(a=1)          # TypeError - *args 不收关键字参数
f(**{"x": 1})     # 实际上：f(x=1) 也是 TypeError
```

### 5. **kwargs Key 必须是字符串

```python
def f(**kwargs):
    return kwargs

f(a=1)               # {'a': 1}
f(**{"a": 1, "b": 2})  # {'a': 1, 'b': 2}
# f(**{1: "a"})      # TypeError: keywords must be strings
```

### 6. 关键字重复传

```python
def f(a, b):
    return a + b

# f(1, a=2)         # TypeError: got multiple values for argument 'a'
```

### 7. mutable 默认值导致跨调用共享

是最常见 bug，见前文。

### 8. 想用 *args 同时收位置和关键字

不可能。`*args` 只收位置，`**kwargs` 只收关键字。要全收就用两者都写。

```python
def f(*args, **kwargs):
    print("位置:", args)
    print("关键字:", kwargs)

f(1, 2, 3, x=4, y=5)
# 位置: (1, 2, 3)
# 关键字: {'x': 4, 'y': 5}
```

## 最佳实践

### 1. 默认值用 None

可变默认值都改成 `None` 哨兵。

### 2. 多参数用 keyword-only 强制命名

```python
def connect(host, port, *, timeout=10, retry=3):
    ...
```

### 3. 参数不要太多

3-4 个为佳，超过考虑用 dataclass / dict 封装。

### 4. 利理解顺序：positional → keyword

位置参数表示"必需且语义清晰"，关键字参数表示"可选且容易搞错"。

```python
def create_file(path, *, mode="w", encoding="utf-8"):
    ...
```

### 5. 转发使用 *args/**kwargs

```python
def log_wrapper(*args, **kwargs):
    print("调用前")
    result = func(*args, **kwargs)
    print("调用后")
    return result
```

### 6. 验证参数类型（必要时）

```python
def f(items):
    if not isinstance(items, (list, tuple)):
        raise TypeError("items 必须是 list 或 tuple")
    ...
```

## 小结

| 类型 | 定义示例 | 调用示例 |
|------|----------|----------|
| 位置 | `f(a, b)` | `f(1, 2)` |
| 关键字 | `f(a, b)` | `f(a=1, b=2)` |
| 默认 | `f(a=1)` | `f()` |
| *args | `f(*args)` | `f(1,2,3)` |
| **kwargs | `f(**kwargs)` | `f(x=1)` |
| positional-only | `f(a, /)` | `f(1)` |
| keyword-only | `f(*, a)` | `f(a=1)` |

顺序：`positional-only → 普通/默认 → *args → keyword-only → **kwargs`

牢记：**默认值用可变对象是陷阱**，改用 `None` 哨兵。
