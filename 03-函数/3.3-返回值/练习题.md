## 返回 None

### 练习题

**题目 1：_finder**
实现 `find_even(nums)`，返回第一个偶数，找不到返回 `None`。

**题目 2：哨兵**
定义 `_MISSING = object()`，实现 `pop_or_default(stack, default=_MISSING)`，空栈返回 `default`（未提供 default 时返回 `_MISSING`）。

**题目 3：判 None**
```python
def f():
    return None

r = f()
# 用 is 和 == 两种判断 r 是否 None
```

**题目 4：区分 None 与 False**
实现 `parse(value)`：
- `value is None` → 返回 `"-"`
- `value` 真值 → 返回 `"yes"`
- 否则 → 返回 `"no"`
要求 `parse(None)` 和 `parse(False)` 和 `parse(0)` 输出不同。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
def find_even(nums):
    for n in nums:
        if n % 2 == 0:
            return n
    return None

print(find_even([1, 3, 5, 6]))  # 6
print(find_even([1, 3, 5]))     # None

# 题目 2
_MISSING = object()

def pop_or_default(stack, default=_MISSING):
    if stack:
        return stack.pop()
    return default

print(pop_or_default([1, 2]))        # 2
r = pop_or_default([])
print(r is _MISSING)                 # True
print(pop_or_default([], "空"))       # 空

# 题目 3
def f():
    return None

r = f()
print(r is None)  # True（推荐）
print(r == None)  # True（不推荐）

# 题目 4
def parse(value):
    if value is None:
        return "-"
    if value:
        return "yes"
    return "no"

print(parse(None))    # -
print(parse(False))   # no
print(parse(0))       # no
print(parse(1))       # yes
```

**题目 3：四值统计**

**题目 5：dataclass 返回**

**题目 6：陷阱**
```python
def f():
    return 1, 2, 3

a = f()

```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
from dataclasses import dataclass

# 题目 1
def min_max(nums):
    if not nums:
        return None, None
    return min(nums), max(nums)

print(min_max([3, 1, 2]))  # (1, 3)
print(min_max([]))          # (None, None)

# 题目 2
def my_divmod(a, b):
    return a // b, a % b

print(my_divmod(17, 5))  # (3, 2)

# 题目 3
def stats(nums):
    if not nums:
        return None, None, 0, 0
    return min(nums), max(nums), sum(nums), len(nums)

print(stats([1, 2, 3]))  # (1, 3, 6, 3)

# 题目 4
def stats_dict(nums):
    if not nums:
        return {"min": None, "max": None, "sum": 0, "len": 0}
    return {"min": min(nums), "max": max(nums), "sum": sum(nums), "len": len(nums)}

print(stats_dict([1, 2, 3]))
# {'min': 1, 'max': 3, 'sum': 6, 'len': 3}

# 题目 5
@dataclass
class Stats:
    min_v: int
    max_v: int
    total: int
    count: int

def stats_dc(nums):
    if not nums:
        return Stats(None, None, 0, 0)
    return Stats(min(nums), max(nums), sum(nums), len(nums))

s = stats_dc([4, 1, 2, 3])
print(s.min_v, s.max_v, s.total, s.count)  # 1 4 10 4

# 题目 6
def f():
    return 1, 2, 3

a = f()
print(a)        # (1, 2, 3)
# b, c = f()    # ValueError: too many values to unpack (expected 2)
# 因为元组有 3 个元素，左边只有 2 个变量，解包失败
# 修复：b, c, d = f()
```

</details>

```python

def f(d, key):
    if key in d:
        v = d[key]
        if v > 0:
            return v * 2

# 版本 2

    if key not in d:
        return None
    v = d[key]
```

```python
# 题目 1
def f():
    try:
        return "try"
    finally:
        print("finally")
    print("after try")

print(f())
# 输出：
# finally
# try
# 注意：return 前执行 finally；return 之后函数已结束，
#       "after try" 在 try/finally 块外但在 return 后，永远不可达，不打印。

# 题目 2
def f():
    try:
        return "try"
    finally:
        return "finally"

print(f())   # finally - finally 里的 return 覆盖了 try 的

# 题目 3
def f():
    x = 1
    try:
        return x
    finally:
        x = 99

print(f())   # 1
# 原因：return x 在执行时已经把 x 当前值 1 存起来作为返回值，
#       finally 中改 x=99 不影响已存好的返回值。

# 题目 4
def f():
    try:
        raise ValueError("err")
    except ValueError:
        return "handled"
    finally:
        print("cleanup")

print(f())
# 输出顺序：
# cleanup
# handled
# 解释：先 raise → 进入 except → 执行 return，
#       return 前触发 finally 打印 cleanup，最后返回 "handled"。
```

```python
import os

# 题目 1
# 问题：成功时返回字符串内容，失败时返回"文件不存在"也是字符串，
#       调用方无法区分"文件内容就是'文件不存在'"和"文件不存在"。
# 修复：失败应返回 None 或抛异常
def load(path):
    if os.path.exists(path):
        return open(path).read()
    return None

# 题目 2
def double(x):
    print(x * 2)

result = double(5)    # 打印 10，但函数返回 None
print(result)          # None
# print(result + 1)   # TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'

# 题目 3
def squares(n):
    for i in range(n):
        yield i * i

result = squares(3)
print(result)         # <generator object squares at ...>
# print(result[0])    # TypeError: 'generator' object is not subscriptable
# 生成器不支持索引，要用 list() 或 next()
print(list(result))   # [0, 1, 4]

# 题目 4
def get_default_list():
    return [1, 2, 3]   # 每次调用都新建 list

a = get_default_list()
a.append(4)
b = get_default_list()
print(a, b)   # [1, 2, 3, 4] [1, 2, 3]
# 不互相影响：因为每次调用都 return 新的 [1,2,3] 对象
# (注意：如果 return 的是某个模块级别的共享变量，则会共享)

# 题目 5
_cache = {}

def get_cache():
    return _cache   # 直接返回内部 dict 引用

c = get_cache()
c["x"] = 1
print(_cache)   # {'x': 1}
# 修改 c 影响 _cache：因为 c 和 _cache 指向同一个 dict。
# 修复：返回 _cache.copy()
```

## 综合练习

### 练习题

**综合题 1：成绩分析器**
实现 `analyze(scores)` 返回 `Stats` dataclass，含字段 `count、average、highest、passed`（及格人数）。空列表时所有字段为 0/None。

**综合题 2：安全除法**
实现 `safe_div(a, b)`，返回 `(ok, result)`：成功 `ok=True`、`result=商`；除零 `ok=False`、`result=错误信息`。

**综合题 3：查找器**
实现 `find_first(predicate, iterable)`，找到第一个满足 `predicate` 的元素返回，找不到返回 `None`。再用哨兵 `_NOT_FOUND` 版本，让 None 也能作为合法返回。

**综合题 4：retry 与返回值**
实现 `retry(times, func)`，最多调用 times 次，全部失败返回 `None`，任一成功返回结果。

**综合题 5：工厂返回函数**
实现 `make_validator(min_v, max_v)`，返回一个函数 `check(x)`，x 在范围内返回 `True`，否则 `False`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
from dataclasses import dataclass
from typing import List, Optional

# 综合题 1
@dataclass
class Stats:
    count: int
    average: Optional[float]
    highest: Optional[int]
    passed: int

def analyze(scores: List[int]) -> Stats:
    if not scores:
        return Stats(0, None, None, 0)
    return Stats(
        count=len(scores),
        average=sum(scores) / len(scores),
        highest=max(scores),
        passed=sum(1 for s in scores if s >= 60),
    )

s = analyze([80, 90, 50, 60])
print(s)  # Stats(count=4, average=70.0, highest=90, passed=3)

# 综合题 2
def safe_div(a, b):
    if b == 0:
        return False, "除零错误"
    return True, a / b

ok, r = safe_div(10, 2)
print(ok, r)   # True 5.0
ok, r = safe_div(10, 0)
print(ok, r)   # False 除零错误

# 综合题 3
_NOT_FOUND = object()

def find_first(predicate, iterable):
    for x in iterable:
        if predicate(x):
            return x
    return None

def find_first_safe(predicate, iterable):
    for x in iterable:
        if predicate(x):
            return x
    return _NOT_FOUND

print(find_first(lambda x: x > 3, [1, 2, 4]))  # 4
r = find_first_safe(lambda x: x is not None, [None, None])
print(r is _NOT_FOUND)  # False - 因为 None 也满足 predicate
# 修正：能区分"没找到"和"找到的是 None"

# 综合题 4
def retry(times, func):
    for i in range(times):
        try:
            return func()
        except Exception as e:
            print(f"尝试 {i+1} 失败: {e}")
    return None

import random
def flaky():
    if random.random() < 0.7:
        raise RuntimeError("炸了")
    return "ok"

print(retry(5, flaky))

# 综合题 5
def make_validator(min_v, max_v):
    def check(x):
        return min_v <= x <= max_v
    return check

check_age = make_validator(0, 120)
print(check_age(25))   # True
print(check_age(-1))   # False
print(check_age(200))  # False
```

</details>

## 小结

- `return` 立即结束函数并返回值
- 不写 return 或 return 无值 → 返回 None
- `return a, b` 返回元组，可解包成"多值"
- 复杂返回用 dict / dataclass 更清晰
- 早 return 减少嵌套
- finally 中 return 会覆盖前面，慎用
- 别让函数返回多种不相关类型
