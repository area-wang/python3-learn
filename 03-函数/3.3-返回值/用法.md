## return 语句

`return` 把值送回调用者，并**结束函数执行**。无 `return` 或 `return` 无值时返回 `None`。

### 1. 基本返回

```python
def add(a, b):
    return a + b

result = add(2, 3)   # result = 5
print(result)
```

### 2. return 立即结束函数

```python
def check(x):
    if x < 0:
        return "负数"
    if x == 0:
        return "零"
    return "正数"

print(check(-5))   # 负数
print(check(0))    # 零
print(check(5))    # 正数
```

### 3. return 无值 → None

```python
def f():
    return          # 等价 return None

print(f())         # None

def g():
    pass           # 没有 return，也返回 None

print(g())         # None
```

### 4. return 只能用在函数内

```python
# 在模块顶层用 return 会报错
# return 5    # SyntaxError: 'return' outside function

def f():
    return 5    # OK
```

## 返回 None

`None` 是 Python 表示"无值"的单例。函数无 `return` 或 `return` 空都返回 `None`。

### 1. 不写 return

```python
def greet(name):
    print(f"Hi, {name}")

result = greet("Alice")   # Hi, Alice
print(result)             # None
print(result is None)     # True
```

### 2. 显式 return None 表示"找不到"

```python
def find_user(uid):
    users = {1: "Alice"}
    return users.get(uid)   # 找不到返回 None

print(find_user(1))   # Alice
print(find_user(2))   # None
```

### 3. 用 None 作哨兵

```python
def pop_or_default(stack, default=None):
    if stack:
        return stack.pop()
    return default

print(pop_or_default([1, 2]))   # 2
print(pop_or_default([]))        # None
print(pop_or_default([], "空"))  # 空
```

### 4. 判 None 用 is，不用 ==

```python
def f():
    return None

r = f()
if r is None:        # 推荐
    print("None")

if r == None:        # 不推荐（PEP 8 反对）
    print("None")
```

### 5. 区分 None 和 False

```python
def f(flag=None):
    if flag is None:
        return "未提供"
    if flag:
        return "真值"
    return "假值"

print(f(None))    # 未提供
print(f(False))   # 假值 - False 而不是 None
print(f(0))       # 假值
print(f(""))      # 假值
```

## 多返回值

Python 没有"多返回值"，但 `return a, b, c` 实际是返回一个**元组**，调用方解包即可达到多返回值效果。

### 1. 返回元组

```python
def min_max(nums):
    return min(nums), max(nums)

result = min_max([3, 1, 2])
print(type(result))   # <class 'tuple'>
print(result)         # (1, 3)

low, high = min_max([3, 1, 2])   # 解包
print(low, high)                 # 1 3
```

### 2. 两个值

```python
def divmod_self(a, b):
    return a // b, a % b

q, r = divmod_self(17, 5)
print(q, r)   # 3 2
```

### 3. 三个或更多

```python
def stats(nums):
    return min(nums), max(nums), sum(nums), len(nums)

mn, mx, sm, n = stats([4, 1, 2, 3])
print(mn, mx, sm, n)  # 1 4 10 4
```

### 4. 返回不同数量（用 * 解包）

```python
def maybe(name):
    if not name:
        return ()
    return ("hi", name)

*(msg,), = maybe("a")   # 容易出错，慎用
# 推荐：
result = maybe("a")
if result:
    msg, name = result
```

### 5. 返回字典（命名多返回值）

当返回值含义复杂时，用字典比元组更清晰：

```python
def load_user(uid):
    return {"id": uid, "name": "Alice", "age": 20}

u = load_user(1)
print(u["name"])   # Alice
```

### 6. 返回 dataclass（更专业）

```python
from dataclasses import dataclass

@dataclass
class Stats:
    min: int
    max: int
    avg: float

def compute_stats(nums):
    return Stats(min(nums), max(nums), sum(nums) / len(nums))

s = compute_stats([1, 2, 3])
print(s.min, s.max, s.avg)  # 1 3 2.0
```

## return 与隐式返回

### 1. 隐式 None

```python
def abs_val(x):
    if x >= 0:
        return x
    # 没写 else 分支的 return，自动返回 None

print(abs_val(5))    # 5
print(abs_val(-5))   # None - bug！漏写分支
```

### 2. 显式写全

```python
def abs_val(x):
    if x >= 0:
        return x
    return -x

print(abs_val(-5))   # 5
```

### 3. 提前 return（guard clause）

```python
def process(data):
    if not data:
        return None      # 提前返回，简化嵌套
    if len(data) > 100:
        return data[:100]
    return data

# 比深嵌套清晰
def process_bad(data):
    if data:
        if len(data) <= 100:
            return data
        else:
            return data[:100]
    else:
        return None
```

## return 与生成器

### 1. return 在普通函数中

```python
def f():
    print("before")
    return 1
    print("after")   # 不可达，永远不会执行

f()
# before
# (1)
```

### 2. return 在生成器中（Python 3.3+）

生成器中 `return value` 会让 `StopIteration` 携带该值，普通 for 循环看不到，但 `next` 后能取：

```python
def gen():
    yield 1
    yield 2
    return "done"    # 生成器结束，并返回值

g = gen()
print(next(g))   # 1
print(next(g))   # 2
try:
    next(g)
except StopIteration as e:
    print("结束:", e.value)   # 结束: done
```

详见 [3.8-生成器函数](../3.8-生成器函数/用法.md)。

## 函数作为返回值

函数可以返回另一个函数（高阶函数），这是闭包和装饰器的基础。

### 1. 返回函数

```python
def make_adder(n):
    def adder(x):
        return x + n
    return adder

add5 = make_adder(5)
print(add5(3))    # 8
print(add5(10))   # 15
```

### 2. 返回 lambda

```python
def make_multiplier(n):
    return lambda x: x * n

times3 = make_multiplier(3)
print(times3(4))   # 12
```

### 3. 根据参数返回不同函数

```python
def get_op(name):
    if name == "add":
        return lambda a, b: a + b
    elif name == "mul":
        return lambda a, b: a * b
    raise ValueError(name)

print(get_op("add")(2, 3))   # 5
print(get_op("mul")(2, 3))   # 6
```

详见 [3.5-高阶函数](../3.5-高阶函数/用法.md) 与 [3.9-闭包](../3.9-闭包/用法.md)。

## 提前 return 与哨兵

### 1. 多个 return 提早结束

```python
def safe_div(a, b):
    if b == 0:
        return None
    return a / b

print(safe_div(10, 2))   # 5.0
print(safe_div(10, 0))   # None
```

### 2. 用哨兵 return distinguish

```python
_NOT_FOUND = object()   # 唯一哨兵

def get_item(d, key):
    return d.get(key, _NOT_FOUND)

r = get_item({"a": None}, "a")
print(r is _NOT_FOUND)  # False - None 也是有效值

r = get_item({"a": None}, "x")
print(r is _NOT_FOUND)  # True - 真的没找到
```

### 3. 早返回 vs 嵌套 if

```python
# 嵌套深
def f(x):
    if x:
        if x > 0:
            if x < 100:
                return x

# 早返回平
def f(x):
    if not x:
        return
    if x <= 0:
        return
    if x >= 100:
        return
    return x
```

## return 在 try/finally

### 1. finally 总会执行

```python
def f():
    try:
        return "try"
    finally:
        print("finally 执行了")   # 会在 return 前执行

print(f())
# finally 执行了
# try
```

### 2. finally 中的 return 覆盖前面

```python
def f():
    try:
        return "try"
    finally:
        return "finally"   # 覆盖 "try"

print(f())   # finally - 慎用，容易让人误解
```

### 3. finally 中改变变量不影响 return 值

```python
def f():
    x = 1
    try:
        return x
    finally:
        x = 99   # 不影响已 return 的值

print(f())   # 1
```

**解释**：`return x` 在执行时已经把 `x` 的值（1）存起来，`finally` 改 `x` 不改变已存好的返回值。

### 4. with 也会执行清理

```python
def f():
    with open("x.txt", "w") as fp:
        fp.write("hi")
        return "done"   # with 退出时会自动关闭文件
```

## 返回值的内存与引用

### 1. 返回可变对象

```python
def f():
    return [1, 2, 3]

a = f()
a.append(4)
print(a)   # [1, 2, 3, 4] - 修改的是返回的对象

b = f()
print(b)   # [1, 2, 3] - 函数没保留上次的列表，每次新建
```

### 2. 返回内部可变对象（注意共享）

```python
_cache = {}

def get_cache():
    return _cache    # 返回内部 dict

c = get_cache()
c["x"] = 1
print(_cache)    # {'x': 1} - 修改反映到内部！
```

### 3. 避免共享（返回副本）

```python
def get_safe_cache():
    return _cache.copy()   # 返回副本，外部修改不影响内部

c = get_safe_cache()
c["y"] = 2
print(_cache)   # {} - 内部未受影响
```

## 常见错误与陷阱

### 1. 漏写分支的隐式 None

```python
def grade(score):
    if score >= 90:
        return "A"
    if score >= 60:
        return "B"
    # 漏写 < 60 分支，返回 None

print(grade(50))   # None - 不是预期的字符串
```

修复：

```python
def grade(score):
    if score >= 90:
        return "A"
    if score >= 60:
        return "B"
    return "C"
```

### 2. print 当 return

```python
def double(x):
    print(x * 2)

r = double(5)
print(r)   # None - 应该用 return
```

### 3. 多 return 后代码不可达

```python
def f(x):
    return x
    return x + 1   # 永远不会执行

print(f(5))   # 5
```

### 4. 返回值丢失

```python
def add(a, b):
    return a + b

add(1, 2)   # 计算了但没接收，结果丢失
result = add(1, 2)  # 正确
```

### 5. 在 finally 中 return 覆盖

见前文 [return 在 try/finally](#return-在-tryfinally)。

### 6. 用 == 比 None

```python
def f():
    return None

r = f()
# if r == None:    # 不推荐
if r is None:      # 推荐
    print("None")
```

### 7. 多返回值时忘记解包

```python
def min_max(nums):
    return min(nums), max(nums)

m = min_max([3, 1, 2])
print(m)        # (1, 3) - 没解包是一个元组
mn, mx = min_max([3, 1, 2])
print(mn, mx)   # 1 3
```

### 8. 返回生成器而非列表

```python
def gen_squares(n):
    for i in range(n):
        yield i * i

result = gen_squares(3)
print(result)         # <generator object ...>
print(list(result))   # [0, 1, 4] - 要展开才看到值
```

## 最佳实践

### 1. 函数应返回明确类型

避免一会儿返回值一会儿返回 None，让调用方难以处理。

```python
# 不好：返回类型不一致
def get(x):
    if x:
        return x
    # 隐式 None

# 好：明确 None 或哨兵
def get(x):
    return x if x else None
```

### 2. 单一返回类型

函数最好只返回一种类型（或该类型的 Optional）。

```python
# 不好
def f(flag):
    if flag:
        return [1, 2]
    return "error"   # 类型不一致

# 好
def f(flag):
    if not flag:
        raise ValueError("flag")
    return [1, 2]
```

### 3. 用 return 表达式简化

```python
def is_even(n):
    return n % 2 == 0   # 直接返回布尔
```

### 4. 多返回值用命名结构

```python
# 一般 2-3 个值用元组，超过考虑 dataclass / dict
@dataclass
class Result:
    value: float
    error: str = ""
```

### 5. 早返回减少嵌套

guard clause 让代码更易读。

### 6. 文档说明返回 None 的情况

```python
def find(uid):
    """根据 uid 查找用户。

    Returns:
        dict | None: 找不到返回 None。
    """
```

### 7. 不要在 finally 里 return

会让 bug 难以诊断。

---

## 小结

- `return` 返回值并结束函数；不写则返回 None
- `return a, b` 返回元组，可解包为"多返回值"
- 多值意义不明时用 dict / dataclass
- 早 return（guard clause）减少嵌套
- 返回可变对象要小心共享，必要时返回副本
- 别在 finally 中 return
