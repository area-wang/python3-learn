## 高阶函数基础

**高阶函数（Higher-order function）** 是满足以下任一条件的函数：
1. 接受一个或多个函数作为参数
2. 返回一个函数

Python 中函数是**第一类对象**，所以高阶函数非常自然。

```python
# 函数作为参数
def apply(func, x):
    return func(x)

print(apply(abs, -5))   # 5
print(apply(str, 100))  # '100'

# 函数作为返回值
def make_adder(n):
    return lambda x: x + n

add5 = make_adder(5)
print(add5(3))   # 8
```

**为什么用高阶函数：**
- **抽象**：把"做什么"和"对谁做"分离
- **复用**：同一处理逻辑可用于不同数据
- **组合**：把小函数组合成大逻辑
- **声明式**：更接近数学描述

## 函数作为参数

### 1. 把"操作"传进去

```python
def operate(a, b, op):
    return op(a, b)

print(operate(3, 4, lambda x, y: x + y))   # 7
print(operate(3, 4, lambda x, y: x * y))   # 12
```

### 2. 自定义 map 类操作

```python
def my_map(func, iterable):
    result = []
    for x in iterable:
        result.append(func(x))
    return result

print(my_map(str, [1, 2, 3]))   # ['1', '2', '3']
print(my_map(lambda x: x ** 2, [1, 2, 3]))   # [1, 4, 9]
```

### 3. 谓词函数（返回布尔）

```python
def is_even(n): return n % 2 == 0
def is_positive(n): return n > 0

def count_if(predicate, nums):
    return sum(1 for x in nums if predicate(x))

print(count_if(is_even, [1, 2, 3, 4]))       # 2
print(count_if(is_positive, [-1, 0, 1, 2]))   # 2
```

### 4. 经典：把策略当参数

```python
def process_orders(orders, strategy):
    return [strategy(o) for o in orders]

def discount(o): return o * 0.9
def full(o): return o

orders = [100, 200, 300]
print(process_orders(orders, discount))   # [90.0, 180.0, 270.0]
print(process_orders(orders, full))        # [100, 200, 300]
```

## 函数作为返回值

### 1. 工厂函数

```python
def make_multiplier(n):
    def multiply(x):
        return x * n
    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(5), triple(5))   # 10 15
```

### 2. 用 lambda

```python
def make_adder(n):
    return lambda x: x + n

add10 = make_adder(10)
print(add10(5))   # 15
```

### 3. 根据配置返回不同函数

```python
def get_validator(kind):
    if kind == "age":
        return lambda x: 0 <= x <= 120
    if kind == "score":
        return lambda x: 0 <= x <= 100
    raise ValueError(kind)

age_ok = get_validator("age")
score_ok = get_validator("score")
print(age_ok(25), age_ok(200))     # True False
print(score_ok(80), score_ok(150)) # True False
```

### 4. 装饰器其实是高阶函数

```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log
def hello():
    return "hi"

print(hello())   # 调用 hello \n hi
```

详见 [3.7-装饰器](../3.7-装饰器/用法.md)。

## map 函数

`map(func, *iterables)`：对每个元素应用 `func`，返回**迭代器**。

### 1. 基本用法

```python
nums = [1, 2, 3, 4]
squared = map(lambda x: x ** 2, nums)
print(squared)            # <map object at ...>
print(list(squared))      # [1, 4, 9, 16]
```

**注意**：map 返回迭代器，只能迭代一次，要多次用先转 list。

### 2. 转类型

```python
strs = ["1", "2", "3"]
nums = list(map(int, strs))
print(nums)   # [1, 2, 3]
```

### 3. 多 iterable

```python
a = [1, 2, 3]
b = [10, 20, 30]
print(list(map(lambda x, y: x + y, a, b)))   # [11, 22, 33]

# 长度以最短为准
print(list(map(pow, [2, 3], [10, 20, 30])))  # [1024, 3486784401]  (2**10, 3**20)
```

### 4. 与推导式对比

```python
# map 风格
list(map(lambda x: x * 2, range(5)))   # [0, 2, 4, 6, 8]

# 推导式（更 Pythonic）
[x * 2 for x in range(5)]             # [0, 2, 4, 6, 8]
```

→ 大多数 Python 程序员更喜欢推导式，但 map 在函数式风格代码里仍广泛使用。

### 5. map 是惰性的

```python
m = map(print, [1, 2, 3])   # 不会执行 print！
# 触发迭代才执行
list(m)   # 1 2 3

# 但对没有返回值的 print，map 会返回 [None, None, None]
print(list(map(print, [1, 2, 3])))   # 1 2 3 [None, None, None]
```

## filter 函数

`filter(func, iterable)`：保留 `func(x)` 为真的元素，返回迭代器。

### 1. 基本用法

```python
nums = [1, 2, 3, 4, 5, 6]
evens = filter(lambda x: x % 2 == 0, nums)
print(list(evens))   # [2, 4, 6]
```

### 2. func 为 None 时过滤真值

```python
data = [0, 1, "", "a", None, [], [1], {}]
print(list(filter(None, data)))   # [1, 'a', [1]]
```

### 3. 过滤字符串

```python
words = ["apple", "banana", "cherry", "date"]
long = filter(lambda w: len(w) > 5, words)
print(list(long))   # ['banana', 'cherry']
```

### 4. 与推导式对比

```python
# filter 风格
list(filter(lambda x: x > 2, range(10)))   # [3, 4, 5, 6, 7, 8, 9]

# 推导式
[x for x in range(10) if x > 2]           # [3, 4, 5, 6, 7, 8, 9]
```

## reduce 函数

`reduce(func, iterable, initial=None)`：把二元函数累积应用，把序列**归约**成一个值。Python 3 中在 `functools` 模块。

### 1. 基本用法

```python
from functools import reduce

nums = [1, 2, 3, 4]
total = reduce(lambda a, b: a + b, nums)
print(total)   # 10
# 等价 1+2+3+4
```

### 2. 带初始值

```python
total = reduce(lambda a, b: a + b, nums, 100)
print(total)   # 110 - 100 + 1 + 2 + 3 + 4
```

### 3. 求积

```python
product = reduce(lambda a, b: a * b, range(1, 6))
print(product)   # 120 - 5!
```

### 4. 找最大

```python
m = reduce(lambda a, b: a if a > b else b, [3, 7, 1, 9, 2])
print(m)   # 9
```

### 5. 累积嵌套结构

```python
nested = [[1, 2], [3, 4], [5]]
flat = reduce(lambda a, b: a + b, nested, [])
print(flat)   # [1, 2, 3, 4, 5]
```

### 6. reduce 执行过程

```python
# reduce(f, [a,b,c,d], init)
# 等价：f(f(f(f(init, a), b), c), d)

# 例：
def step(acc, x):
    print(f"acc={acc}, x={x}, new={acc+x}")
    return acc + x

result = reduce(step, [1, 2, 3], 0)
# acc=0, x=1, new=1
# acc=1, x=2, new=3
# acc=3, x=3, new=6
print(result)   # 6
```

### 7. 注意：很多 reduce 能用内置替代

```python
# reduce + 加 = sum
sum([1, 2, 3])                       # 6

# reduce + and = all
all([True, False, True])             # False

# reduce + or = any
any([False, True, False])            # True

# reduce + max = max
max([3, 7, 1])                       # 7
```

## sorted 的 key 参数

`sorted(iterable, key=func, reverse=False)`：用 `key` 函数计算排序依据，返回新列表。这是最常用的高阶函数之一。

### 1. 按 key 排序

```python
people = [("Alice", 30), ("Bob", 25), ("Carol", 35)]

# 按年龄
by_age = sorted(people, key=lambda p: p[1])
print(by_age)   # [('Bob', 25), ('Alice', 30), ('Carol', 35)]

# 按名字
by_name = sorted(people, key=lambda p: p[0])
print(by_name)   # [('Alice', 30), ('Bob', 25), ('Carol', 35)]
```

### 2. 多关键字

```python
people = [("Alice", 30), ("Bob", 30), ("Carol", 25)]

# 先按年龄再按名字
sorted(people, key=lambda p: (p[1], p[0]))
# [('Carol', 25), ('Alice', 30), ('Bob', 30)]
```

### 3. 反向

```python
nums = [3, 1, 4, 1, 5]
print(sorted(nums, reverse=True))   # [5, 4, 3, 1, 1]
```

### 4. 用类属性排序

```python
class User:
    def __init__(self, name, age):
        self.name, self.age = name, age
    def __repr__(self): return f"User({self.name},{self.age})"

users = [User("A", 30), User("B", 25), User("C", 20)]
print(sorted(users, key=lambda u: u.age))
# [User(C,20), User(B,25), User(A,30)]
```

### 5. 用 attrgetter / itemgetter

```python
from operator import itemgetter, attrgetter

people = [("Alice", 30), ("Bob", 25)]
print(sorted(people, key=itemgetter(1)))   # 按第 2 项

print(sorted(users, key=attrgetter("age"))) # 按属性
```

### 6. 字符串按长度

```python
words = ["apple", "kiwi", "banana"]
print(sorted(words, key=len))   # ['kiwi', 'apple', 'banana']
```

### 7. 不区分大小写

```python
words = ["Apple", "banana", "Cherry"]
print(sorted(words, key=str.lower))   # ['Apple', 'banana', 'Cherry']
```

### 8. list.sort() 是原地版

```python
nums = [3, 1, 2]
nums.sort(key=lambda x: -x)   # 原地排序，返回 None
print(nums)                   # [3, 2, 1]
```

## 常用高阶函数汇总

| 函数 | 作用 | 返回 | 备注 |
|------|------|------|------|
| `map(f, *iter)` | 对每个元素应用 f | 迭代器 | 惰性 |
| `filter(f, iter)` | 保留 f(x) 真的 | 迭代器 | 惰性 |
| `reduce(f, iter, init)` | 累积归约 | 单值 | functools |
| `sorted(iter, key=)` | 按 key 排序 | 新 list | 稳定 |
| `list.sort(key=)` | 原地排序 | None | 稳定 |
| `any(iter)` | 任一为真 | bool | |
| `all(iter)` | 全部为真 | bool | |
| `max/min(iter, key=)` | 最值 | 元素 | |
| `sum(iter, start=)` | 求和 | 数值 | |
| `enumerate(iter)` | 带索引枚举 | 迭代器 | |
| `zip(*iters)` | 并行打包 | 迭代器 | |
| `itertools.chain/...` | 复杂迭代 | 迭代器 | itertools |

### any / all

```python
scores = [60, 70, 80, 90]
print(any(s >= 90 for s in scores))   # True
print(all(s >= 60 for s in scores))   # True

print(any([]))   # False
print(all([]))   # True - 空 iterable 视作"全满足"
```

### max / min with key

```python
words = ["apple", "kiwi", "strawberry"]
print(max(words, key=len))   # strawberry
print(min(words, key=len))   # kiwi
```

### enumerate

```python
for i, name in enumerate(["Alice", "Bob"], start=1):
    print(i, name)
# 1 Alice
# 2 Bob
```

### zip

```python
names = ["A", "B", "C"]
ages = [20, 30, 40]
for name, age in zip(names, ages):
    print(name, age)

# 配对
print(list(zip([1, 2, 3], ["a", "b", "c"])))
# [(1, 'a'), (2, 'b'), (3, 'c')]

# zip_longest
from itertools import zip_longest
print(list(zip_longest([1, 2], ["a", "b", "c"], fillvalue="?")))
# [(1, 'a'), (2, 'b'), ('?', 'c')]
```

## 偏函数 partial

`functools.partial(func, *args, **kwargs)`：固定部分参数，返回一个新函数。

### 1. 固定参数

```python
from functools import partial

def power(base, exp):
    return base ** exp

square = partial(power, exp=2)
cube = partial(power, exp=3)
print(square(5))   # 25
print(cube(2))     # 8
```

### 2. 简化回调

```python
def greet(greeting, name):
    return f"{greeting}, {name}!"

hi = partial(greet, "Hi")
hello = partial(greet, "Hello")
print(hi("Alice"))      # Hi, Alice!
print(hello("Bob"))      # Hello, Bob!
```

### 3. 常见：partial + sorted

```python
# 不常用 partial，但和内置配合可省 lambda
print(sorted([1, -2, 3, -4], key=abs))   # [1, -2, 3, -4] - 按 abs 排
```

### 4. partial 替代 lambda

```python
# 用 lambda
nums = list(map(lambda x: int(x), ["1", "2"]))
# 用 partial
from functools import partial
nums = list(map(int, ["1", "2"]))     # 其实这里直接用 int
```

### 5. partial 是闭包的简化

```python
# 闭包版
def make_greet(greeting):
    def g(name):
        return f"{greeting}, {name}!"
    return g

# partial 版
from functools import partial
def greet(greeting, name):
    return f"{greeting}, {name}!"

hi = partial(greet, "Hi")   # 等价
```

## 推导式 vs 高阶函数

Python 风格很多时候**推导式更受欢迎**，但高阶函数在简短操作时仍有价值。

### 1. map vs 列表推导

```python
nums = [1, 2, 3]

# map
squared = list(map(lambda x: x ** 2, nums))

# 推导（更 Pythonic）
squared = [x ** 2 for x in nums]
```

### 2. filter vs 列表推导

```python
nums = [1, 2, 3, 4, 5]

# filter
evens = list(filter(lambda x: x % 2 == 0, nums))

# 推导
evens = [x for x in nums if x % 2 == 0]
```

### 3. map + filter vs 推导

```python
# map + filter
result = list(map(lambda x: x * 2, filter(lambda x: x > 2, nums)))

# 推导（更清晰）
result = [x * 2 for x in nums if x > 2]
```

### 4. 何时用哪个

- **short & simple**：map/filter 用 lambda 可读性还行
- **filter 后又 map**：推导式更清楚
- **多个 iterable**：map 接多 iter 更顺
- **复杂条件**：推导式更易读
- **返回单值**：用 reduce
- **泛型/函数式 API**：用 map/filter 更纯函数

## 常见错误与陷阱

### 1. map/filter 返回迭代器只能用一次

```python
m = map(str, [1, 2, 3])
print(list(m))   # ['1', '2', '3']
print(list(m))   # [] - 已耗尽
```

修复：用 `list(m)` 缓存。

### 2. lambda 闭包延迟绑定

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])   # [2, 2, 2]

# 修复
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]
```

### 3. map 应用 print 不返回有用值

```python
# map(print, ...) 会返回 [None, None, ...]
result = list(map(print, [1, 2, 3]))
print(result)   # [None, None, None]
```

### 4. reduce 没初始值且 iterable 空

```python
from functools import reduce
# reduce(lambda a, b: a + b, [])    # TypeError: reduce() of empty sequence
reduce(lambda a, b: a + b, [], 0)   # OK 返回 0
```

### 5. sorted 的 key 应返回可比较的值

```python
# key 必须返回统一的可排序类型
data = [{1: "a"}, {2: "b"}]
# sorted(data, key=lambda d: d)   # dict 不可比较，TypeError
# 改：
sorted(data, key=lambda d: list(d.keys())[0])  # 按键排序
```

### 6. zip 长度不齐

```python
list(zip([1, 2, 3], ["a", "b"]))
# [(1, 'a'), (2, 'b')] - 以最短为准，3 被丢弃

# 用 zip_longest 处理不等长
from itertools import zip_longest
list(zip_longest([1, 2, 3], ["a", "b"], fillvalue="-"))
# [(1, 'a'), (2, 'b'), (3, '-')]
```

### 7. 过度使用 reduce 难读

```python
# 难读
reduce(lambda d, k: d.setdefault(k, {}), ["a", "b", "c"], {})
# 直接 while for 更清晰
```

### 8. 用 lambda 反而不如 def

```python
# 复杂 lambda 难读
data.sort(key=lambda x: (x["age"], -x["score"], x["name"]))

# 复杂时用 def
def key_func(x):
    return (x["age"], -x["score"], x["name"])
data.sort(key=key_func)
```

## 最佳实践

### 1. 简单单步用 map/filter，复杂用推导式

```python
# map 一目了然
list(map(str, range(5)))

# 复杂条件用推导
[(x, y) for x in range(3) for y in range(3) if x + y == 2]
```

### 2. 复杂 key 用 def 而非长 lambda

让代码可读性优先。

### 3. reduce 能用内置就别用

`sum / max / min / any / all` 都比 reduce 清楚。

### 4. partial 用于固定配置

把"已知部分参数"的工具函数预先准备好。

### 5. 函数式风格注意可读性

不要追求数学美感而忘了代数可读性：

```python
# 难读
list(filter(None, map(str.strip, lines)))

# 可读
[line.strip() for line in lines if line.strip()]
```

### 6. 函数作为参数命名清晰

```python
# 不清晰
def process(items, f): ...

# 清晰
def process(items, key_func): ...
```

---

## 小结

- 高阶函数：接受函数作参数 或 返回函数
- `map(f, iter)` 对每个元素应用 f（惰性）
- `filter(f, iter)` 保留真的元素（惰性）
- `reduce(f, iter, init)` 累积归约为单值（functools）
- `sorted(iter, key=f)` 按 key 函数排序，最常用
- `any / all / max / min / enumerate / zip` 也是高阶用法
- `partial` 固定部分参数生成新函数
- 推导式通常比 map/filter 更 Pythonic，但看场景
