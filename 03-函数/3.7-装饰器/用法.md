## 装饰器基础

**装饰器（decorator）** 是一种"接收函数、返回函数"的机制，用来在**不修改原函数源码**的前提下，给函数增加功能（日志、缓存、权限、重试等）。

**最经典的例子**：用 `@log` 包装函数，调用自动打印日志。

```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        result = func(*args, **kwargs)
        print(f"{func.__name__} 返回 {result}")
        return result
    return wrapper

@log
def add(a, b):
    return a + b

add(2, 3)
# 调用 add
# add 返回 5
```

**特点：**
- 装饰器是语法糖，本质是函数变换
- 装饰后的函数**仍可像原函数一样调用**
- 可叠加多个装饰器
- 应用极广（Web 框架、ORM、缓存、日志、限流）

## 装饰器原理

`@decorator` 等价的旧写法：

```python
@log
def f(): pass

# 等价于
def f(): pass
f = log(f)   # 把 f 传给 log，再用返回的 wrapper 替换 f
```

所以装饰器**本质是**：

```python
new_func = decorator(old_func)
```

装饰器返回的新函数接管了原函数名，外部调用 `f()` 实际是 `new_func()`。

### 1. 拆解 @log

```python
@log
def add(a, b):
    return a + b
```

等价：

```python
def add(a, b):
    return a + b
add = log(add)        # add 现在是 wrapper
```

### 2. 调用过程

```python
add(2, 3)
# 1. 实际调用 wrapper(2, 3)
# 2. wrapper 打印 "调用 add"
# 3. wrapper 调用 func(2, 3) - 即原始 add，返回 5
# 4. wrapper 打印 "add 返回 5"
# 5. 返回 5
```

## 手写第一个装饰器

### 1. 简单包装

```python
def my_decorator(func):
    def wrapper():
        print("前置")
        func()
        print("后置")
    return wrapper

@my_decorator
def hello():
    print("hello")

hello()
# 前置
# hello
# 后置
```

### 2. 用 *args/**kwargs 兼容任意参数

```python
def trace(func):
    def wrapper(*args, **kwargs):
        print(f"trace: {func.__name__}({args}, {kwargs})")
        return func(*args, **kwargs)
    return wrapper

@trace
def add(a, b):
    return a + b

@trace
def greet(name, greeting="Hi"):
    return f"{greeting}, {name}!"

print(add(1, 2))                # trace: add((1, 2), {}) \n 3
print(greet("Alice", greeting="Yo"))  # trace: greet(('Alice',), {'greeting': 'Yo'}) \n Yo, Alice!
```

→ 包装器用 `*args, **kwargs` 才能透传任意参数。

## @decorator 语法糖

`@` 是装饰器语法糖，写在 `def` 上一行，等价于"函数定义后立即 `func = decorator(func)`"。

### 1. 基本位置

```python
@decorator      # 必须在 def 上一行
def f(): ...
```

### 2. 装饰器在函数定义时就生效

```python
@my_decorator
def hello(): print("hi")

# 此后 hello 已是 wrapper，不是原函数
hello()   # 经装饰
```

### 3. 不用 @ 也能装饰（手动）

```python
def hello(): print("hi")
hello = my_decorator(hello)
hello()
```

## functools.wraps

**问题**：装饰后 `hello.__name__` 变成 `"wrapper"`，丢失原函数元信息。

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def hello():
    """say hi"""
    print("hi")

print(hello.__name__)   # wrapper - 而非 hello
print(hello.__doc__)     # None - 而非 "say hi"
```

### 1. 用 @wraps 保留原信息

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("前置")
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def hello():
    """say hi"""
    print("hi")

print(hello.__name__)   # hello - 保留
print(hello.__doc__)     # say hi
print(hello.__wrapped__) # 也能取到原 hello
```

### 2. @wraps 做了什么

`@wraps(func)` 等价：

```python
wrapper.__name__ = func.__name__
wrapper.__doc__ = func.__doc__
wrapper.__module__ = func.__module__
wrapper.__qualname__ = func.__qualname__
wrapper.__wrapped__ = func    # 加这个属性指向原函数
# 还会复制 __dict__、__dict__.update
```

### 3. 任何正经装饰器都该用 @wraps

否则会破坏调试、文档生成、序列化等依赖 `__name__` 的功能。

## 带参数的装饰器

带参数的装饰器需要**三层嵌套**：外层接收参数，返回真正的装饰器，装饰器返回 wrapper。

### 1. 形式

```python
def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def hello():
    print("hi")

hello()
# hi
# hi
# hi
```

### 2. 拆解调用

```python
@repeat(3)
def hello(): ...

# 等价：
hello = repeat(3)(hello)
# 即：先调用 repeat(3) 得到 decorator，再 decorator(hello) 得到 wrapper
```

### 3. 用 functools.partial 简化（可选）

```python
from functools import wraps, partial

def repeat(times, func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        for _ in range(times):
            result = func(*args, **kwargs)
        return result
    return wrapper

# 用 partial 把 times 固定成装饰器
repeat3 = partial(repeat, 3)

@repeat3
def hello(): print("hi")

# 或更标准的方式：
def repeat(times):
    return partial(_repeat, times=times)
```

→ 但 `partial` 方式较不直观，三层嵌套是主流写法。

### 4. 多参数装饰器

```python
def logged(level="INFO", file=None):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            print(f"[{level}] {func.__name__}")
            return func(*args, **kwargs)
        return wrapper
    return decorator

@logged(level="DEBUG")
def hello(): print("hi")

hello()
# [DEBUG] hello
# hi
```

### 5. 不带括号也能用的装饰器

如果既想支持 `@logged` 又想支持 `@logged(level="DEBUG")`，要判断参数是不是函数：

```python
def logged(func=None, *, level="INFO"):
    def decorator(fn):
        @wraps(fn)
        def wrapper(*args, **kwargs):
            print(f"[{level}] {fn.__name__}")
            return fn(*args, **kwargs)
        return wrapper

    if func is None:
        return decorator           # @logged(level="DEBUG")
    else:
        return decorator(func)    # @logged 直接用在没参数函数上

@logged
def a(): print("a")

@logged(level="DEBUG")
def b(): print("b")
```

## 类装饰器

用类来装饰函数：通过 `__call__`，让实例像函数一样可调用。

### 1. 计数器装饰器（用类）

```python
class CountCalls:
    def __init__(self, func):
        self.func = func
        self.count = 0
        wraps(func)(self)            # 保留元信息，可选

    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"{self.func.__name__} 被调用第 {self.count} 次")
        return self.func(*args, **kwargs)

@CountCalls
def hello(): print("hi")

hello(); hello()
# hello 被调用第 1 次
# hi
# hello 被调用第 2 次
# hi

print(hello.count)   # 2
```

### 2. 类装饰器装饰类

类装饰器也可以接收并改造**类**：

```python
def add_repr(cls):
    def __repr__(self):
        return f"{cls.__name__}({self.__dict__})"
    cls.__repr__ = __repr__
    return cls

@add_repr
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

p = Point(1, 2)
print(p)   # Point({'x': 1, 'y': 2})
```

### 3. 单例装饰器

```python
def singleton(cls):
    instances = {}
    @wraps(cls)
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Config:
    def __init__(self):
        print("Init once")

a = Config()   # Init once
b = Config()
print(a is b)  # True
```

## 装饰类方法

### 1. 普通装饰器作用在方法

```python
def log(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

class Service:
    @log
    def start(self):
        print("started")

    @log
    def stop(self):
        print("stopped")

s = Service()
s.start()
# 调用 start
# started
```

### 2. property 也是一种装饰器

```python
class C:
    def __init__(self): self._x = 0
    @property
    def x(self): return self._x
    @x.setter
    def x(self, v): self._x = v
```

### 3. 静态/类方法装饰器

```python
class C:
    @staticmethod
    def static_m(): print("static")

    @classmethod
    def class_m(cls): print(cls.__name__)
```

### 4. 类自身装饰器和类方法装饰器不冲突

```python
@singleton
class Service:
    @log
    def serve(self): ...
```

## 内置装饰器

### 1. @property

类属性访问器，详见 [04-面向对象](../../04-面向对象/)。

```python
class Circle:
    def __init__(self, r): self.r = r

    @property
    def area(self): return 3.14 * self.r ** 2

c = Circle(2)
print(c.area)   # 12.56 - 像属性访问
```

### 2. @staticmethod / @classmethod

见类方法章节。

### 3. @functools.lru_cache（最常用缓存）

自动缓存函数结果（按参数）：

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

print(fib(100))   # 极快，无重复计算

print(fib.cache_info())   # 查看命中情况
```

Python 3.9+ 新增 `@functools.cache`（无上限），更简洁：

```python
from functools import cache

@cache
def fib(n):
    ...
```

### 4. @functools.singledispatch

按第一参数类型分派（函数重载）：

```python
from functools import singledispatch

@singledispatch
def process(data):
    raise TypeError(f"不支持的类型 {type(data)}")

@process.register(str)
def _(s): return s.upper()

@process.register(int)
def _(i): return i * 2

@process.register(list)
def _(lst): return sum(lst)

print(process("hi"))    # HI
print(process(10))      # 20
print(process([1,2,3])) # 6
# process(1.5)          # TypeError
```

### 5. @functools.total_ordering

补全比较运算：

```python
from functools import total_ordering

@total_ordering
class Student:
    def __init__(self, name, score): self.name, self.score = name, score
    def __eq__(self, o): return self.score == o.score
    def __lt__(self, o): return self.score < o.score

# 自动补全了 __le__, __gt__, __ge__
```

### 6. @dataclass

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(1, 2)
```

## 多个装饰器叠加

装饰器从**下往上**应用，从**上往下**执行。

### 1. 顺序

```python
@decorator_a
@decorator_b
@decorator_c
def f(): pass

# 等价：
f = decorator_a(decorator_b(decorator_c(f)))
```

### 2. 执行顺序（洋葱）

```python
def deco_a(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("A 前")
        r = func(*args, **kwargs)
        print("A 后")
        return r
    return wrapper

def deco_b(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("B 前")
        r = func(*args, **kwargs)
        print("B 后")
        return r
    return wrapper

@deco_a
@deco_b
def hello(): print("hello")

hello()
# A 前
# B 前
# hello
# B 后
# A 后
```

→ 洋葱模型：A 先打头，最后退出。

```python
# 装饰器顺序影响效果，比如 cached + logged 哪个在外
```

## 常见实用装饰器

### 1. 计时

```python
import time
from functools import wraps

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        r = func(*args, **kwargs)
        print(f"{func.__name__} 耗时 {time.perf_counter() - t0:.4f}s")
        return r
    return wrapper

@timer
def slow():
    time.sleep(0.5)
    return "done"

slow()   # slow 耗时 0.50xxs
```

### 2. 重试

```python
import time
from functools import wraps

def retry(times=3, delay=0):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last = None
            for i in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last = e
                    print(f"第 {i+1} 次失败：{e}")
                    time.sleep(delay)
            raise last
        return wrapper
    return decorator

@retry(times=3, delay=1)
def flaky():
    if time.time() % 2 > 1:
        raise RuntimeError("炸")
    return "ok"
```

### 3. 缓存

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def slow_compute(x):
    import time
    time.sleep(1)
    return x * 2

print(slow_compute(5))   # 慢
print(slow_compute(5))   # 瞬间（缓存）
```

### 4. 权限检查

```python
from functools import wraps

def require_admin(func):
    @wraps(func)
    def wrapper(user, *args, **kwargs):
        if not getattr(user, "is_admin", False):
            raise PermissionError("需要管理员权限")
        return func(user, *args, **kwargs)
    return wrapper

@require_admin
def delete_user(user, uid):
    print(f"{user.name} 删除了 {uid}")
```

### 5. 限速 / 节流

```python
import time
from functools import wraps

def rate_limit(calls, period):
    history = []
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            now = time.time()
            history[:] = [t for t in history if now - t < period]
            if len(history) >= calls:
                raise RuntimeError("超限")
            history.append(now)
            return func(*args, **kwargs)
        return wrapper
    return decorator

@rate_limit(3, 1)
def ping(): print("pong")
```

### 6. 类型检查（简单）

```python
from functools import wraps

def type_check(**expected):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            import inspect
            bound = inspect.signature(func).bind(*args, **kwargs)
            for name, val in bound.arguments.items():
                if name in expected and not isinstance(val, expected[name]):
                    raise TypeError(f"{name} 应为 {expected[name]}")
            return func(*bound.args, **bound.kwargs)
        return wrapper
    return decorator

@type_check(a=int, b=int)
def add(a, b): return a + b
```

### 7. deprecated 警告

```python
import warnings
from functools import wraps

def deprecated(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        warnings.warn(f"{func.__name__} 已废弃", DeprecationWarning, stacklevel=2)
        return func(*args, **kwargs)
    return wrapper
```

## 常见错误与陷阱

### 1. 忘记 @wraps

```python
def deco(func):
    def wrapper(*a, **k):
        return func(*a, **k)
    return wrapper

@deco
def hello(): """hi"""

print(hello.__name__)  # wrapper  - 调试困难
# 修复：functools.wraps
```

### 2. wrapper 没返回值

```python
def deco(func):
    def wrapper(*a, **k):
        func(*a, **k)        # 忘了 return
    return wrapper   # 会返回 None

@deco
def add(a, b): return a + b

print(add(1, 2))   # None - 漏了 return
```

### 3. wrapper 不能变签名导致二义

```python
# 想给装饰后的函数加一个新参数是不行的（外部调用方懂吗？）
# 一般装饰器应完全透传签名
```

### 4. 装饰类方法忘记 self

```python
def deco(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(args[0])   # 这其实是 self
        return func(*args, **kwargs)
    return wrapper

class C:
    @deco
    def m(self, x): return x

C().m(1)   # wrapper 收到 (self, 1)
# self 是 args[0]
```

**用 *args/self 透传即可**，不要手动管理 self。

### 5. 装饰器参数顺序

```python
# 错：三层少一层
def deco(times):
    def wrapper(*a, **k):
        for _ in range(times): func(...)   # func 没出处
        ...
    return wrapper   # 缺一层 decorator
```

→ 三层：参数装饰 → 装饰器(func) → wrapper。

### 6. 装饰带默认参数的函数用 inspect 时

@wraps 不会复制默认参数到 wrapper 的签名上，`inspect.signature` 仍可看到原签名（functools.wraps 已复制 __wrapped__）。

### 7. 用 mutable 默认缓存表时全局共享

```python
def cached(func):
    cache = {}
    @wraps(func)
    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]
    return wrapper
# 这里 cache 是每个被装饰函数一份，没问题
```

### 8. lru_cache 不可缓存可变参数

```python
@lru_cache()
def f(a):
    return a * 2

# f([1,2])   # TypeError - list 不可哈希
```

只能 cache 哈希参数。

## 最佳实践

### 1. 任何装饰器都 @wraps

加 `@wraps(func)` 保护元信息。

### 2. 用 *args/**kwargs 透传

```python
def wrapper(*args, **kwargs):
    return func(*args, **kwargs)
```

### 3. wrapper 必须返回值

```python
return func(*args, **kwargs)
```

### 4. 带参数装饰器用三层嵌套

```python
def deco(param):
    def decorator(func):
        @wraps(func)
        def wrapper(*a, **k):
            return func(*a, **k)
        return wrapper
    return decorator
```

### 5. 用 functools预习 lru_cache 替代手写缓存

官方实现高效、线程安全。

### 6. 装饰器可单元测试

把装饰器单独 `def timedecimaltor(func)` 写出来，对它做单元测试。

### 7. 类装饰器适合带状态

计数器、缓存命中、单例 —— 状态多时用类装饰器更清晰。

### 8. 内置优先

`lru_cache`、`singledispatch`、`total_ordering`、`dataclass` 都是经过充分测试的现成方案。

---

## 小结

- 装饰器：接收函数返回函数，语法 `@decorator`
- 等价 `f = decorator(f)`
- 包装器用 `*args, **kwargs` 透传任何签名
- 必加 `@wraps(func)` 保护元信息
- 带参数的装饰器要三层嵌套
- 类装饰器用 `__call__` 实现，适合带状态
- 多个装饰器从下往上应用、洋葱执行
- 善用 `lru_cache / singledispatch / total_ordering / dataclass`
