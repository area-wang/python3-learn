## LEGB 查找顺序

### 练习题

**题目 1：LEGB 验证**
逐步说明以下代码每个 print 输出哪个层次的 x：
```python
x = "global"
def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)        # ①
    inner()
    print(x)            # ②
outer()
print(x)                # ③
```

**题目 2：内置验证**
```python
def f():
    return len("abc")
```
函数 f 里用的 `len` 来自哪个作用域？

**题目 3：覆盖内置**
```python
def f():
    list = [1, 2, 3]
    return list

def g():
    return list((1, 2, 3))

print(f())
print(g())
```
两个函数中的 `list` 分别来自哪里？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
x = "global"
def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)        # ① local - L 域找到
    inner()
    print(x)            # ② enclosing - 局部已经退出，回到 outer 的 E 域
outer()
print(x)                # ③ global

# 题目 2
# len 来自 B（builtins）作用域，因为 f 内没有 len 的局部或全局定义，
# 一路查到 builtins.len
def f():
    return len("abc")
print(f())   # 3

# 题目 3
def f():
    list = [1, 2, 3]   # 局部 list 屏蔽了内置 list
    return list
def g():
    return list((1, 2, 3))   # g 里没有 list 定义，用内置 list

print(f())   # [1, 2, 3]
print(g())   # [1, 2, 3]
# f 中 list 是局部，g 中 list 是 builtins。
```

## global

### 练习题

**题目 1：global 计数器**
用 `global` 实现一个全局计数器 `counter`，`inc()` 每次让 counter+1。

**题目 2：修改对象 vs 重新绑定**
```python
cache = {}
def set_item(k, v):
    cache[k] = v   # 这里需要 global 吗？
def reset():
    cache = {}      # 这里呢？
```
分别说明是否需要 global。

**题目 3：global 位置**
以下代码合法吗？
```python
x = 1
def f():
    print(x)
    global x
```

**题目 4：多个 global**
```python
a = 1
b = 2
def f():
    global a, b
    a = 10
    b = 20

f()
print(a, b)
```
输出？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
counter = 0
def inc():
    global counter
    counter += 1

inc(); inc(); inc()
print(counter)   # 3

# 题目 2
cache = {}
def set_item(k, v):
    cache[k] = v   # 不需要 global，因为这是修改对象，不是赋值绑定

def reset():
    global cache   # 需要 global，因为 cache = {} 是重新绑定
    cache = {}

# 验证
set_item("a", 1)
print(cache)     # {'a': 1}
reset()
print(cache)     # {}

# 题目 3
# 全球声明应放在函数开头（PEP8 和解释器期望）。
# 注意：实际上在变量使用前声明 global 在 CPython 是允许的，
#       但放在 print(x) 之后再 global x，编译器在编译 print(x) 时
#       已经把 x 当作局部，会 UnboundLocalError！
# 应：
x = 1
def f():
    global x
    print(x)

# 题目 4
a = 1
b = 2
def f():
    global a, b
    a = 10
    b = 20

f()
print(a, b)   # 10 20
```

</details>

## nonlocal

### 练习题

**题目 1：计数器**
用 nonlocal 实现 `make_counter()`，每次调用返回+1。

**题目 2：累加器**
`make_accumulator()` 返回 `add(x)`，每次让内层 total+=x 并返回新 total。

**题目 3：nonlocal 只改外层**
```python
def a():
    x = 1
    def b():
        x = 2
        def c():
            nonlocal x
            x = 100
        c()
        print("b:", x)
    b()
    print("a:", x)

a()
```
输出？c 修改的是哪一层的 x？

**题目 4：nonlocal 找不到**
```python
def f():
    nonlocal x   # 这里会怎样？
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
def make_counter():
    c = 0
    def inc():
        nonlocal c
        c += 1
        return c
    return inc

counter = make_counter()
print(counter(), counter(), counter())  # 1 2 3

# 题目 2
def make_accumulator():
    total = 0
    def add(x):
        nonlocal total
        total += x
        return total
    return add

acc = make_accumulator()
print(acc(10), acc(20), acc(5))   # 10 30 35

# 题目 3
def a():
    x = 1
    def b():
        x = 2
        def c():
            nonlocal x
            x = 100        # 修改的是 b 的 x（最近一层 nonlocal 候选）
        c()
        print("b:", x)      # b: 100
    b()
    print("a:", x)           # a: 1 - a 的 x 没被改

a()
# 输出：
# b: 100
# a: 1

# 题目 4
# def f():
#     nonlocal x
# SyntaxError: no binding for nonlocal 'x' found
# 原因：nonlocal 只能指向外层函数的变量，f 没有外层函数 enclosing。
#       全局变量要用 global。
```

## 闭包与作用域

### 练习题

**题目 1：糟糕的 lambda**
```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])
```
输出？为什么？怎么修复？

**题目 2：核查闭包**
```python
def make_adder(n):
    def adder(x):
        return x + n
    return adder

add5 = make_adder(5)
```
打印 `add5.__closure__` 和 `add5.__code__.co_freevars`，说明看到了什么。

**题目 3：cell_contents**
通过 `__closure__[0].cell_contents` 访问 add5 捕获的 n，打印出来。

**题目 4：用闭包做幂**
`make_power(n)` 返回 `pow(x)`：`pow(x) = x**n`。验证 `make_power(3)(2) == 8`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])   # [2, 2, 2] - 延迟绑定，i 循环结束是 2

# 修复（默认参数捕获当时的值）
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]

# 题目 2
def make_adder(n):
    def adder(x):
        return x + n
    return adder

add5 = make_adder(5)
print(add5.__code__.co_freevars)   # ('n',) - 自由变量
print(add5.__closure__)            # 元组 cell 对象
# (<cell ...>,)

# 题目 3
print(add5.__closure__[0].cell_contents)   # 5

# 题目 4
def make_power(n):
    def pow_n(x):
        return x ** n
    return pow_n

cube = make_power(3)
print(cube(2))   # 8
print(make_power(3)(2))   # 8
```

```python
class A:
    v = 10

        return v

A().m()
```
输出或报错？为什么方法内访问不到 v？

**题目 2：locals 修改**
```python
def f():
    locals()["x"] = 1

f()
```
会发生什么？

**题目 3：globals 访问**
```python
x = 10
def f():
    x = 20
    print(x)
    print(globals()["x"])

f()
```
输出？

**题目 4：nonlocal 在内部 lambda**
```python
def f():
    total = 0
    def helper():
        nonlocal total
        total += 1
        return total
    return helper

h = f()
print(h(), h())
```
输出？

**题目 5：可变全局**
```python
data = []
def appendx(x):
    data.append(x)

def reset():
    data = []
    return data

appendx(1)
appendx(2)
print(data)
print(reset())
print(data)
```
输出？reset 真的把全局 data 清空了吗？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
class A:
    v = 10
    def m(self):        # 这是普通方法
        return v       # NameError: v 不在作用域内

# 原因：类作用域不计入方法的 enclosing scope。
#       方法内部要用 self.v 或 A.v 访问类属性 v。
# 修复：
class A:
    v = 10
    def m(self):
        return self.v   # 或 A.v
print(A().m())   # 10

# 题目 2
# def f():
#     locals()["x"] = 1
#     return x
# f()
# NameError: name 'x' is not defined
# 原因：CPython 中修改 locals() 不会真正地绑定局部变量。
#       locals() 是返回当前局部命名空间的副本，仅用于读取。

# 题目 3
x = 10
def f():
    x = 20
    print(x)               # 20 - 局部
    print(globals()["x"])  # 10 - 通过 globals() 看到全局

f()
# 输出：
# 20
# 10

# 题目 4
def f():
    total = 0
    def helper():
        nonlocal total
        total += 1
        return total
    return helper

h = f()
print(h(), h())  # 1 2

# 题目 5
data = []
def appendx(x):
    data.append(x)   # 修改可变全局，不需要 global

def reset():
    data = []         # 没有 global，这是创建局部 data，不影响全局！
    return data

appendx(1)
appendx(2)
print(data)       # [1, 2]
print(reset())    # []
print(data)       # [1, 2] - 全局 data 没被清空！

# 修复：
def reset_fixed():
    global data
    data = []
    return data
# 或要原地清空：
def reset_inplace():
    data.clear()
```

## 综合练习

### 练习题

**综合题 1：用闭包做配置缓存**
`make_config(defaults)` 返回 `get(key, override=None)`：调用时优先用 override，否则用 defaults[key]，最后返回 None。注意闭包要捕获 defaults。

**综合题 2：全局注册表 + 类封装对比**
- 用 `global registry` 实现一个全局函数注册表 `register(func)`
- 用 `class Registry` 实现等价功能，对比两者可维护性

**综合题 3：nonlocal 实现toggle**
`make_toggle()` 返回函数 `toggle()`，每次调用让状态在 True/False 之间切换并返回新状态。

**综合题 4：模块级单例**
用闭包和 nonlocal 实现一个"只创建一次"的 `get_singleton()`，第一次返回新对象，之后返回同一个。

**综合题 5：作用域调试**
写函数 `inspect_scope()` 返回一个 dict，包含此函数内的 locals、调用栈、以及 globals 里的函数名。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 综合题 1
def make_config(defaults):
    def get(key, override=None):
        if override is not None:
            return override
        return defaults.get(key)
    return get

cfg = make_config({"host": "localhost", "port": 8080})
print(cfg("host"))         # localhost
print(cfg("port", 9090))   # 9090
print(cfg("missing"))      # None

# 综合题 2
# 版本 A：全局注册表
registry = {}
def register(func):
    registry[func.__name__] = func
    return func

@register
def hello(): print("hi")

print(list(registry.keys()))  # ['hello']

# 版本 B：类封装
class Registry:
    def __init__(self):
        self._items = {}
    def register(self, func):
        self._items[func.__name__] = func
        return func
    def call(self, name, *a, **k):
        if name not in self._items:
            raise KeyError(name)
        return self._items[name](*a, **k)

reg = Registry()

@reg.register
def bye(): print("bye")

reg.call("bye")  # bye
# 类版更可维护：可以创建多个独立注册表，状态不蔓延到全局。

# 综合题 3
def make_toggle():
    state = [False]   # 用可变也可
    def toggle():
        nonlocal_flag = not state[0]
        state[0] = nonlocal_flag
        return state[0]
    return toggle

# 更纯的 nonlocal 版本
def make_toggle2():
    state = False
    def toggle():
        nonlocal state
        state = not state
        return state
    return toggle

t = make_toggle2()
print(t(), t(), t())  # True False True

# 综合题 4
def make_singleton():
    instance = None
    def get():
        nonlocal instance
        if instance is None:
            instance = object()   # 第一次创建
        return instance
    return get

get_singleton = make_singleton()
a = get_singleton()
b = get_singleton()
print(a is b)   # True - 同一个对象

# 综合题 5
import inspect
def inspect_scope():
    frame = inspect.currentframe()
    return {
        "locals": dict(frame.f_locals),
        "globals_funcs": [n for n, v in frame.f_globals.items() if callable(v) and not n.startswith("_")],
        "stack_depth": len(inspect.stack()),
    }

print(inspect_scope())
# 局部包含 frame；globals_funcs 列出全局函数名；stack_depth 表示调用栈深度。
```

</details>

## 小结

- LEGB：Local → Enclosing → Global → Built-in
- 函数内赋值默认创建局部变量，要用 global/nonlocal 才能修改外层
- 改全局可变对象不需要 global，重新绑定需要
- nonlocal 改外层函数变量（非全局），Python 3 才有
- 闭包延迟绑定是常见坑，用默认参数修复
- 类作用域不算 enclosing，方法要用 self/类名
- 修改 locals() 不可靠，globals() 修改可行
