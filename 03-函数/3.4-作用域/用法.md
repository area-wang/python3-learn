## 作用域基础

**作用域（scope）** 是变量的可见范围。Python 用 **LEGB** 规则查找变量：在哪个区域里能找到这个名字。

```python
x = 10            # 全局作用域

def f():
    x = 20        # 局部作用域
    print(x)      # 20 - 找局部

f()
print(x)          # 10 - 外部看到全局
```

**为什么需要作用域：**
- 隔离命名，避免冲突
- 自动回收不再使用的变量
- 限制副作用，便于推理代码

---

## LEGB 规则

Python 查找变量名时按 **L → E → G → B** 顺序找：

| 缩写 | 名称 | 含义 | 示例 |
|------|------|------|------|
| L | Local | 当前函数内 | `def f(): x = 1` 中的 `x` |
| E | Enclosing | 外层嵌套函数 | 嵌套函数中外层函数的变量 |
| G | Global | 模块全局 | 模块顶层定义的变量 |
| B | Built-in | 内置 | `print`, `len`, `int` 等 |

### 1. 查尾示例

```python
x = "global"        # G

def outer():
    x = "enclosing"  # E

    def inner():
        x = "local"  # L
        print(x)     # local - 找到 L 就停了

    inner()
    print(x)         # enclosing

outer()
print(x)              # global
```

### 2. 逐步找不到会报错

```python
def f():
    print(unknown)   # 函数内未定义 → 全局 → 内置 → NameError
```

### 3. NameError vs UnboundLocalError

```python
x = 1
def f():
    # print(x)      # 这里能访问全局 x = 1
    x = x + 1        # 但赋值使 x 变局部，赋值前 print(x) 会 UnboundLocalError
    print(x)

f()
# 如果上面 print(x) 在赋值前，会 UnboundLocalError
```

## 局部作用域

### 1. 函数内定义的变量是局部的

```python
def f():
    a = 1
    b = 2
    print(a, b)

f()           # 1 2
# print(a)    # NameError - 函数外访问不到
```

### 2. 函数参数也是局部

```python
def f(arg):
    arg = arg + 1
    print(arg)   # 局部 arg

f(10)
# print(arg)     # NameError
```

### 3. 局部变量在函数结束即销毁

```python
def f():
    big = list(range(1000000))

f()              # 函数返回后 big 局部变量无引用，会被 GC 回收
```

### 4. 局部变量优先级最高

```python
x = 999
def f():
    x = 1        # 创建局部 x，不影响全局
    print(x)

f()             # 1
print(x)         # 999
```

## 嵌套作用域（Enclosing）

外层函数的变量对内层函数可见，这就是 E 域。

### 1. 读取外层变量

```python
def outer():
    x = 10
    def inner():
        print(x)    # 10 - 来自 enclosing
    inner()

outer()
```

### 2. 修改外层要用 nonlocal

```python
def outer():
    x = 10
    def inner():
        # x = x + 1    # UnboundLocalError - x 被视为局部
        nonlocal x
        x = x + 1
        print(x)       # 11
    inner()
    print(x)           # 11 - 外层的 x 被改了

outer()
```

详见 [nonlocal 关键字](#nonlocal-关键字)。

### 3. 多层嵌套

```python
def a():
    x = 1
    def b():
        x = 2
        def c():
            nonlocal x   # 改的是 b 里的 x（最近一层有 x 的）
            x = 3
        c()
        print("b:", x)   # b: 3
    b()
    print("a:", x)       # a: 1

a()
```

## 全局作用域

模块顶层定义的变量是全局的，模块内任何地方可访问。

### 1. 读取全局

```python
PI = 3.14

def circle_area(r):
    return PI * r * r   # 直接读全局 PI

print(circle_area(2))   # 12.56
```

### 2. 函数内赋值默认创建局部

```python
counter = 0

def inc():
    counter += 1     # UnboundLocalError - 赋值使 counter 变局部
                     # 但右边的 counter 还没赋值就用了

def inc_good():
    global counter
    counter += 1
    return counter

inc_good()
print(counter)   # 1
```

### 3. 模块即作用域

```python
# module_a.py
VALUE = 100
def f(): pass

# 其它模块 import module_a 后
# module_a.VALUE, module_a.f()
```

每个 `.py` 文件是一个模块，模块顶层是全局作用域；不同模块的全局互不干扰。

## 内置作用域

Python 解释器启动时把一批名字放入 builtins，任何地方都能用。

### 1. 常见内置名

```python
print(type(len), type(int), type(print))   # 都是 builtin
# 在闭包、函数、模块里都能直接用
def f():
    return list(range(3))   # range, list 都是 builtin

print(f())   # [0, 1, 2]
```

### 2. 查看 builtins

```python
import builtins
print(len(dir(builtins)))    # 大约 150+ 个
print("len" in dir(builtins))
print("print" in dir(builtins))
```

### 3. 覆盖内置（坑）

```python
def f():
    list = [1, 2, 3]      # 局部 list 覆盖了内置
    list.append(4)
    return list

print(f())   # [1, 2, 3, 4]

def g():
    return list((1, 2))   # 在 f 之外 list 仍是内置 → [1, 2]
print(g())
```

**在局部覆盖不影响外部**，但在全局覆盖就很危险：

```python
# 模块顶层
list = [1]          # 危险：覆盖内置 list
# 后面整个模块都用不了 list()
del list            # 恢复内置
print(list((1, 2)))  # [1, 2]
```

## global 关键字

`global` 声明一个名字指向**全局**作用域，在函数内对它赋值会修改全局变量。

### 1. 基本用法

```python
counter = 0

def inc():
    global counter
    counter += 1

inc()
inc()
print(counter)   # 2
```

### 2. 不用 global 的陷阱

```python
counter = 0

def inc_bad():
    counter += 1   # UnboundLocalError: 等价 counter = counter + 1
                    # 赋值使 counter 变局部，右边读局部 counter 却未赋值
```

### 3. global 修改可变全局对象（不需要 global）

```python
cache = {}

def set_cache(k, v):
    cache[k] = v        # 修改对象，不是赋值，不需要 global

set_cache("a", 1)
print(cache)   # {'a': 1}

# 但若要"重新绑定"全局变量指向新对象，仍需 global
def reset_cache():
    global cache
    cache = {}
```

### 4. 声明要在使用前

```python
x = 1
def f():
    print(x)        # NameError before global declaration（其实先读会出错）
    global x        # 应该放在函数开头
    x = 2
```

→ 把 `global x` 放在函数开头最安全。

### 5. 跨函数共享状态（不推荐）

```python
total = 0
def add(x):
    global total
    total += x
    return total

print(add(1), add(2), add(3))   # 1 3 6
```

→ 这种风格难测试，推荐用类或闭包封装。

## nonlocal 关键字

`nonlocal` 在嵌套函数中声明一个名字指向**外层（Enclosing）函数**的变量，Python 3 才有。

### 1. 基本用法

```python
def make_counter():
    count = 0
    def inner():
        nonlocal count
        count += 1
        return count
    return inner

c = make_counter()
print(c(), c(), c())   # 1 2 3
```

### 2. 没用 nonlocal 的错误

```python
def make_counter():
    count = 0
    def inner():
        count += 1   # UnboundLocalError
                    # 赋值使 count 变局部，但右边 count 未赋值
        return count
    return inner
```

### 3. nonlocal 找最近一层

```python
def a():
    x = 1
    def b():
        x = 2
        def c():
            nonlocal x   # 指向 b 的 x
            x = 100
        c()
        print("b.x:", x)   # b.x: 100
    b()
    print("a.x:", x)       # a.x: 1

a()
```

### 4. nonlocal 不能指向全局

```python
g = 0
def f():
    # nonlocal g    # SyntaxError: no binding for nonlocal 'g' found
    pass
```

→ 全局要改用 `global`。

### 5. nonlocal 用于闭包计数器/累加器

```python
def make_accumulator():
    total = 0
    def add(x):
        nonlocal total
        total += x
        return total
    return add

acc = make_accumulator()
print(acc(10), acc(20), acc(5))   # 10 30 35
```

## global vs nonlocal

| 关键字 | 指向 | 适用 | Python 版本 |
|--------|------|------|-------------|
| global | 模块级全局变量 | 在函数内改全局 | 2, 3 |
| nonlocal | 最近的外层函数变量 | 在嵌套函数内外层变量 | 3+ |

```python
g = 0       # 全局

def outer():
    e = 0   # 嵌套

    def inner():
        nonlocal e   # 改 e
        global g     # 改 g
        e += 1
        g += 1
        return e, g

    return inner

fn = outer()
print(fn(), fn(), fn())   # (1, 1) (2, 2) (3, 3)
```

## 闭包与作用域

闭包的关键就是**内层函数捕获外层作用域的变量**（即使外层已返回，变量仍存活）。详见 [3.9-闭包](../3.9-闭包/用法.md)。

```python
def make_adder(n):
    def adder(x):
        return x + n   # n 来自 enclosing，外层返回后仍存活
    return adder

add5 = make_adder(5)
print(add5(3))    # 8 - n=5 仍在 add5 的闭包里
```

### 1. 查看闭包变量

```python
def make_adder(n):
    def adder(x):
        return x + n
    return adder

add5 = make_adder(5)
print(add5.__code__.co_freevars)   # ('n',)
print(add5.__closure__)            # 元组，包含 cell 对象
print(add5.__closure__[0].cell_contents)   # 5
```

### 2. 闭包延迟绑定陷阱

```python
funcs = []
for i in [1, 2, 3]:
    funcs.append(lambda: i)   # 注意：lambda 捕获的是 i 的引用，不是值

print([f() for f in funcs])   # [3, 3, 3] - i 循环结束后是 3

# 修复（默认参数捕获值）
funcs = []
for i in [1, 2, 3]:
    funcs.append(lambda i=i: i)
print([f() for f in funcs])   # [1, 2, 3]
```

## 变量名查找时机

Python 在**编译期**决定一个变量是局部还是全局/nonlocal（看函数内有没有对它赋值，有没有 global/nonlocal 声明），而**运行期**才查值。

### 1. 赋值使变量变局部

```python
x = 1
def f():
    print(x)   # UnboundLocalError（不是 1！）
    x = 2       # 编译期已经把 x 标记为局部
```

### 2. 在 print 前还没赋值的局部

```python
x = 1
def f():
    x = x + 1   # UnboundLocalError: 右边读局部 x，但它还没赋值
    print(x)
```

→ 改用 global 声明或读全局用 `globals()`。

### 3. 写个例子说明

```python
v = "global"
def f():
    print(v)        # 若没有下面的赋值，会打印 "global"
    v = "local"     # 但有赋值，v 是局部，所以上面 print(v) 报 UnboundLocalError
```

## globals 与 locals

### 1. globals() 返回全局名

```python
g_var = 1

def f():
    print(globals().get("g_var"))   # 1
    print("f" in globals())         # True - 函数名也在全局

f()
```

### 2. locals() 返回局部名

```python
def f():
    a = 1
    b = 2
    print(locals())   # {'a': 1, 'b': 2}

f()
```

### 3. 动态读写

```python
def set_global(name, value):
    globals()[name] = value

set_global("dyn", 42)
print(dyn)   # 42

def set_local():
    locals()["x"] = 1   # 注意：修改 locals() 不可靠！
    # print(x)           # NameError - 实际并未绑定
```

**注意**：`locals()` 在函数内修改**不会真正生效**（CPython 实现限制）；`globals()` 修改则生效。

### 4. 用 globals() 绕过局部屏蔽

```python
x = 1
def f():
    x = 2
    print(x)              # 2 - 局部
    print(globals()["x"]) # 1 - 通过 globals 访问全局

f()
```

## 常见错误与陷阱

### 1. UnboundLocalError

```python
x = 1
def f():
    x += 1    # UnboundLocalError: x 是局部但还没赋值

def g():
    global x
    x += 1    # OK
```

### 2. 覆盖内置

```python
# 模块顶层
list = [1]
# 后面再不能 list()
# 修复：del list
```

### 3. 闭包延迟绑定

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])   # [2, 2, 2] - 不是 [0,1,2]

# 修复
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]
```

### 4. 用 global 共享状态难追踪

```python
total = 0
def add(x):
    global total   # 难维护，函数间隐式耦合
    total += x
```

→ 用类封装更清晰。

### 5. nonlocal 找不到外层

```python
def f():
    # nonlocal x   # SyntaxError: no binding for nonlocal 'x' found
    pass
```

### 6. 在函数内修改可变全局没加 global 引发的误解

```python
cache = {}
def set_cache(k, v):
    cache[k] = v   # OK，是修改对象不需要 global

# 但若想重新绑定：
def new_cache():
    global cache
    cache = {}
```

### 7. 默认参数 mro 导致的全局共享

变量名重复定义会覆盖：

```python
x = 1
def f():
    x = 2
f()
print(x)   # 1 - x 没变（f 里的 x 是局部）
```

### 8. 类作用域不算 enclosing

```python
class A:
    v = 10
    def m(self):
        # print(v)   # NameError - 类作用域不算 enclosing
        print(A.v)    # 通过类名访问

A().m()   # 10
```

类体是一个独立作用域，方法内查不到类的局部名，需要通过 `self.v` 或类名。

## 最佳实践

### 1. 尽量避免用 global

全局变量让代码难追踪，推荐用参数传入或类封装。

```python
# 不好
total = 0
def add(x):
    global total
    total += x

# 好：用类
class Total:
    def __init__(self):
        self.value = 0
    def add(self, x):
        self.value += x

t = Total()
t.add(5)
print(t.value)
```

### 2. 用 nonlocal 实现闭包计数器

```python
def make_counter():
    c = 0
    def inc():
        nonlocal c
        c += 1
        return c
    return inc
```

### 3. 不要在顶层覆盖内置

让 `list`、`dict`、`id` 等保持原义。

### 4. 闭包捕获用默认参数固定

避免延迟绑定问题：

```python
# 用默认参数
funcs = [lambda i=i: i for i in range(3)]
```

### 5. 函数依赖通过参数传入，而非读全局

```python
# 不推荐
def f():
    return CONFIG["x"]   # 隐式依赖 CONFIG

# 推荐
def f(cfg):
    return cfg["x"]
```

### 6. 大型逻辑封装在类里管理状态

如果函数间共享多个变量，类是更好的容器。

---

## 小结

- LEGB：Local → Enclosing → Global → Built-in 查找顺序
- 函数内对变量赋值，默认创建局部变量
- 改全局用 `global`，改外层函数变量用 `nonlocal`
- 修改可变全局不需要 global，重新绑定才需要
- 闭包延迟绑定是常见陷阱，用默认参数修复
- 尽量少用 global，用类或闭包封装状态
