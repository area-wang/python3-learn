## 闭包基础

**闭包（closure）** 是指**引用了外部作用域变量的内层函数**，并且该外部环境在函数调用时仍能保留。

```python
def make_adder(n):
    def adder(x):
        return x + n   # 引用外层 n
    return adder

add5 = make_adder(5)
print(add5(3))   # 8 - n=5 仍存活在 add5 的闭包中
```

**关键：**
- `adder` 引用外层函数 `make_adder` 的局部变量 `n`
- 即使 `make_adder` 已经返回，`n` 仍被 `adder` 持有，存活在闭包里
- 每次调用 `make_adder` 都生成新闭包，互不干扰

## 闭包的形成条件

形成闭包需要三个要素：
1. **嵌套函数**：内层函数定义在外层函数内
2. **引用外层变量**：内层函数用到了外层作用域的变量
3. **外层函数返回内层函数**：把内层函数当作值返回出去

```python
def outer():
    x = 10                  # 外层局部变量
    def inner():            # 嵌套函数
        return x            # 引用外层变量
    return inner            # 返回内层函数，形成闭包

f = outer()
print(f())   # 10 - x 仍存活
```

### 1. 缺少哪个条件都不是闭包

```python
# 只内层函数不闭包：
def f():
    x = 1
def g():
    return 1
# g 不引用 f 的 x，非闭包

# 不返回内层函数：内层只在外层用
def f():
    x = 1
    def inner():
        return x
    return inner()    # 返回值不是函数，外层 f 返回 1
```

### 2. 闭包对象由 cell 实现

```python
def f():
    x = 10
    def inner():
        return x
    return inner

g = f()
print(g.__closure__)              # 元组，含 cell 对象
print(g.__code__.co_freevars)    # ('x',)
```

## 闭包捕获的是引用

闭包**不是值快照**，它持有的是外层变量的**引用**。所以外层内层同时变化时，闭包内见到的也是最新值。

### 1. 外层变量变化，闭包看见变化

```python
def f():
    n = 1
    def g():
        return n   # 引用外层 n
    n = 2
    return g

g = f()
print(g())   # 2 - n 已被改为 2
```

### 2. 循环变量延迟绑定（最经典坑）

```python
funcs = []
for i in [1, 2, 3]:
    funcs.append(lambda: i)

print([f() for f in funcs])   # [3, 3, 3]
# 不是 [1, 2, 3]！
# 原因：lambda 捕获 i 的引用，循环结束后 i = 3
```

### 3. 修复方式

```python
# 方式 1：用默认参数捕获当时的值
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]

# 方式 2：用工厂函数
def make_f(i):
    return lambda: i

funcs = [make_f(i) for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]
```

### 4. 每个外层调用产生独立闭包

```python
def make_adder(n):
    def add(x): return x + n
    return add

a5 = make_adder(5)
a10 = make_adder(10)
print(a5(3), a10(3))   # 8 13
# 两个闭包各自独立的 n
```

## 闭包与 nonlocal

闭包默认**只读**外层变量，要修改需要 `nonlocal` 声明。

### 1. 没声明就是局部

```python
def f():
    n = 0
    def g():
        n += 1   # UnboundLocalError - 赋值让 n 变 g 的局部
        return n
    return g
```

### 2. 用 nonlocal 写外层

```python
def make_counter():
    n = 0
    def inc():
        nonlocal n
        n += 1       # 修改外层 n
        return n
    return inc

c = make_counter()
print(c(), c(), c())   # 1 2 3
```

### 3. 修改可变对象不用 nonlocal

```python
def f():
    data = []        # 列表是可变对象
    def append(x):
        data.append(x)   # 修改不绑定名字，不需 nonlocal
        return data
    return append

ap = f()
print(ap(1))   # [1]
print(ap(2))   # [1, 2]
```

### 4. nonlocal 找最近一层

```python
def a():
    x = 1
    def b():
        x = 2
        def c():
            nonlocal x   # 改 b 的 x
            x = 100
        c()
        print("b:", x)  # b: 100
    b()
    print("a:", x)     # a: 1
```

详见 [3.4-作用域](../3.4-作用域/用法.md)。

## 查看闭包变量

### 1. __closure__ 与 cell_contents

```python
def make_adder(n):
    def adder(x):
        return x + n
    return adder

add5 = make_adder(5)
print(add5.__closure__)                  # (<cell at ...>,)
print(add5.__closure__[0].cell_contents) # 5

add10 = make_adder(10)
print(add10.__closure__[0].cell_contents)  # 10
```

### 2. co_freevars 列出闭包变量名

```python
print(add5.__code__.co_freevars)   # ('n',)
```

### 3. 单变量闭包

```python
def f():
    x, y = 1, 2
    def g():
        return x + y
    return g

g = f()
print(g.__code__.co_freevars)    # ('x', 'y') - 两个自由变量
print([c.cell_contents for c in g.__closure__])   # [1, 2]
```

### 4. 不含闭包的函数

```python
def f():
    return 1
print(f.__code__.co_freevars)   # () - 无自由变量
print(f.__closure__)             # None
```

## 闭包的应用场景

### 1. 工厂函数

```python
def make_multiplier(n):
    return lambda x: x * n

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(5), triple(5))   # 10 15
```

### 2. 计数器

```python
def make_counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc

c = make_counter()
print(c(), c(), c())   # 1 2 3
```

### 3. 累加器

```python
def make_accumulator():
    total = 0
    def add(x):
        nonlocal total
        total += x
        return total
    return add

acc = make_accumulator()
print(acc(10), acc(20), acc(5))   # 10 30 35
```

### 4. 缓存（自然闭包）

```python
def memoize(func):
    cache = {}
    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]
    return wrapper

@memoize
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)

print(fib(50))   # 极快
# cache 是闭包变量，只能通过 wrapper 访问
```

### 5. 配置参数

```python
def make_config(name):
    config = {"name": name}
    def get(key, default=None):
        return config.get(key, default)
    def set_(key, val):
        config[key] = val
    return get, set_

get, set_ = make_config("app")
print(get("name"))     # app
set_("version", "1.0")
print(get("version"))  # 1.0
```

### 6. 闭包 callback 注册

```python
def on_click(button):
    clicked = [False]
    def callback():
        clicked[0] = True
        print(f"{button} 被点击")
    return callback

cb_a = on_click("A")
cb_a()   # A 被点击
```

### 7. 偏函数（fixed arguments）

```python
def make_partial(func, *args, **kwargs):
    def wrapper(*a, **k):
        return func(*args, *a, **kwargs, **k)
    return wrapper

add5 = make_partial(lambda a, b: a + b, 5)
print(add5(10))   # 15
```

## 装饰器其实就是闭包

装饰器内部 wrapper 引用外层 func，这本身就是闭包。

```python
def log(func):
    name = func.__name__   # 被闭包持有
    def wrapper(*args, **kwargs):
        print("call", name)
        return func(*args, **kwargs)
    return wrapper

@log
def hello(): return "hi"

hello()   # call hello
# wrapper 通过闭包持有 func 和 name
```

详见 [3.7-装饰器](../3.7-装饰器/用法.md)。

## 闭包陷阱

### 1. 延迟绑定（最经典）

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])   # [2, 2, 2]

# 修复
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]
```

详见 [3.4-作用域](../3.4-作用域/用法.md)。

### 2. 共享可变对象导致跨闭包影响

```python
def make_list_appender():
    data = []        # 同一个工厂产生的 appender 共享同一个 data！
    def append(x):
        data.append(x)
        return data
    return append

ap = make_list_appender()
print(ap(1))   # [1]
print(ap(2))   # [1, 2]
# 不同工厂调用产生不同 data：
ap2 = make_list_appender()
print(ap2(5))   # [5] - 新的空 list
```

### 3. 试图修改外层忘记 nonlocal

```python
def f():
    n = 0
    def g():
        n += 1   # UnboundLocalError
        return n
    return g
```

### 4. 闭包持有大对象造成"泄漏"

闭包持有外层变量，外层函数返回后即使外层栈帧销毁，被引用的变量也不会被 GC。如果变量很大，又一直持有闭包，会占内存。

```python
def f():
    big_data = list(range(10**7))
    def g():
        return len(big_data)  # 闭包持有 big_data，永不被回收
    return g

g = f()   # big_data 一直存活直到 g 释放
```

→ 不需要了就要释放对闭包的引用（`del g` 或越过作用域）。

### 5. 跨闭包意外的 mutable 共享

```python
def f():
    counters = {"a": 0, "b": 0}
    def inc_a():
        counters["a"] += 1   # a 和 b 共享同一 dict
        return counters["a"]
    def inc_b():
        counters["b"] += 1
        return counters["b"]
    return inc_a, inc_b

inc_a, inc_b = f()
print(inc_a(), inc_a(), inc_b())   # 1 2 1
# 但是它们共享 counters，每当增加 a 的值后 inc_b 看到的也是更新后的 dict
```

## 闭包 vs 类

闭包和类都可以**封装状态**。

### 1. 闭包版计数器

```python
def counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc

c = counter()
print(c(), c())   # 1 2
```

### 2. 类版计数器

```python
class Counter:
    def __init__(self):
        self.n = 0
    def inc(self):
        self.n += 1
        return self.n

c = Counter()
print(c.inc(), c.inc())   # 1 2
```

### 3. 对比

| 维度 | 闭包 | 类 |
|------|------|----|
| 状态 | 闭包变量 | 实例属性 |
| 多方法 | 不便（要返回多个函数） | 类多方法自然 |
| 继承 | 不支持 | 支持 |
| 调试 | 难（变量是 closure cell） | 易（self.x 可见） |
| 复杂度 | 适合简单逻辑 | 适合复杂状态 |

→ **简单共享状态用闭包，多方法/复杂封装用类**。

### 4. 闭包版"对象"（演示）

```python
def make_account(balance):
    def deposit(amount):
        nonlocal balance
        balance += amount
        return balance
    def withdraw(amount):
        nonlocal balance
        if balance < amount:
            raise RuntimeError("不足")
        balance -= amount
        return balance
    return {
        "deposit": deposit,
        "withdraw": withdraw,
        "balance": lambda: balance,
    }

acc = make_account(100)
print(acc["deposit"](50))    # 150
print(acc["withdraw"](30))   # 120
print(acc["balance"]())      # 120
```

→ 闭包组合字典也能模拟对象，但不如用类清晰。

## 常见错误与陷阱

### 1. 修改外层忘记 nonlocal

```python
def f():
    x = 0
    def g():
        x += 1   # UnboundLocalError
# 修复：nonlocal x
```

### 2. 循环延迟绑定

```python
fs = [lambda: i for i in range(3)]
# 全输出 2 - 修复 lambda i=i
```

### 3. 误以为闭包是值快照

```python
def f():
    n = 1
    g = lambda: n
    n = 2
    return g

print(f()())   # 2 - 不是 1
```

### 4. 闭包内共享 mutable 未隔离

```python
def make_list_app():
    data = []
    def f(x):
        data.append(x)
        return data
    return f
```

—— 每个工厂调用产生新 data，所以这里没问题；但如果工厂本身被复用就要注意。

### 5. 大对象泄露

闭包持有大对象，要主动 `del`。

### 6. nonlocal 在无外层函数时报错

```python
g = 0
def f():
    # nonlocal g    # SyntaxError
    global g
    g += 1
```

### 7. 试图在 list/dict 表达式里用 nonlocal

```python
# list 内部不能 nonlocal（不是 def 体）
```

## 最佳实践

### 1. 简单封装用闭包

工厂函数、计数器、累加器、缓存都很好用闭包。

### 2. 复杂状态用类

多方法、继承、复杂状态机用类更可维护。

### 3. 修复延迟绑定用默认参数或工厂函数

```python
funcs = [lambda i=i: i for i in range(3)]
# 或
funcs = [make_f(i) for i in range(3)]
```

```python
def make_validator(min_v, max_v):
    def check(x):           # 不叫 v 用 check 让意图清晰
        return min_v <= x <= max_v
    return check
```

## 小结

- 闭包：嵌套函数引用外层变量 + 外层返回内层 → 外层变量仍存活
- 捕获的是**引用**不是值，延迟绑定是经典坑
- 修改外层要 `nonlocal`，修改可变对象不用
- `__closure__` 与 `co_freevars` 可查看闭包变量
- 应用：工厂、计数器、累加器、缓存、配置、装饰器
- 简单状态用闭包，复杂状态用类
- 警惕延迟绑定、可变共享、大对象泄露
