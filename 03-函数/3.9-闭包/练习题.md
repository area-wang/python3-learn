### 练习题

**题目 1：adder**

**题目 2：multiply**
`make_multiplier(n)` 返回函数 `mul(x)` = x*n。

**题目 3：form_闭包**

**题目 4：三条件**

**题目 5：__closure__**
```python
def f():
    n = 10
    def g(): return n
    return g

print(h.__closure__)
print(h.__code__.co_freevars)
```

输出？

```python
def f():
```

```python
fs = [lambda: i for i in range(3)]

```
输出？修复。

**题目 3：工厂函数**
用 `make_f(i)` 工厂修复题目 2。

**题目 4：独立闭包**
`make_counter()` 调用两次产生两个闭包，验证它们互不影响。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
def f():
    n = 1
    g = lambda: n
    n = 2
    return g

print(f()())   # 2
# 闭包捕获引用，n 改为 2 后，g 返回 2。

# 题目 2
fs = [lambda: i for i in range(3)]
print([f() for f in fs])   # [2, 2, 2]

# 修复
fs = [lambda i=i: i for i in range(3)]
print([f() for f in fs])   # [0, 1, 2]

# 题目 3
def make_f(i):
    return lambda: i

fs = [make_f(i) for i in range(3)]
print([f() for f in fs])   # [0, 1, 2]
# 每次 make_f(i) 创建独立闭包，i 是不同函数的局部变量。

# 题目 4
def make_counter():
    n = [0]   # 用可变对象更直观
    def inc():
        n[0] += 1
        return n[0]
    return inc

c1 = make_counter()
c2 = make_counter()
print(c1(), c1())   # 1 2
print(c2())          # 1 - 与 c1 互不影响
```

## nonlocal 实战

### 练习题

**题目 1：counter**
用 nonlocal 实现 `make_counter()`，每次调用让内部 n+1。

**题目 2：accumulator**
`make_accumulator()` 返回 `add(x)`，累加并返回当前 total。

**题目 3：toggle**
`make_toggle()` 返回在 True/False 间切换的函数。

**题目 4：不用 nonlocal 的可变版**
用 list[int] 一元素存储实现等价 counter（不用 nonlocal）。

**题目 5：nonlocal 嵌套层**
```python
def a():
    x = 1
    def b():
        x = 2
        def c():
            nonlocal x
            x = 5
        c()
        print("b:", x)
    b()
    print("a:", x)
a()
```
输出？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
def make_counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc

c = make_counter()
print(c(), c(), c())   # 1 2 3

# 题目 2
def make_accumulator():
    total = 0
    def add(x):
        nonlocal total
        total += x
        return total
    return add

acc = make_accumulator()
print(acc(10), acc(20), acc(5))   # 10 30 35

# 题目 3
def make_toggle():
    state = False
    def toggle():
        nonlocal state
        state = not state
        return state
    return toggle

t = make_toggle()
print(t(), t(), t())   # True False True

# 题目 4
def make_counter2():
    n = [0]
    def inc():
        n[0] += 1
        return n[0]
    return inc

c = make_counter2()
print(c(), c())   # 1 2

# 题目 5
def a():
    x = 1
    def b():
        x = 2
        def c():
            nonlocal x
            x = 5
        c()
        print("b:", x)   # 改 b 的 x：5
    b()
    print("a:", x)        # a 的 x 没动：1

a()
# 输出：
# b: 5
# a: 1
```

## 应用：工厂

### 练习题

**题目 1：validator**
`make_validator(low, high)` 返回 `check(x)`，x 在 [low, high] 返回 True。

**题目 2：partial**
`make_partial(func, *args)` 返回带预绑定 args 的函数。

**题目 3：cache**
`make_cache()` 返回 `get(key, default)` 和 `set(key, val)` 两个函数（共享同一 dict）。

**题目 4：rate limiter**
`make_rate_limit(calls_per_second)` 返回 `allow()`，超限返回 False 否则 True。

**题目 5：memoize**
`memoize(func)` 返回带缓存的 wrapper（用闭包存 cache）。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
import time
from functools import wraps

# 题目 1
def make_validator(low, high):
    def check(x):
        return low <= x <= high
    return check

age_ok = make_validator(0, 120)
print(age_ok(25), age_ok(200))   # True False

# 题目 2
def make_partial(func, *args, **kwargs):
    def wrapper(*a, **k):
        return func(*args, *a, **{**kwargs, **k})
    return wrapper

add5 = make_partial(lambda a, b: a + b, 5)
print(add5(10))   # 15

# 题目 3
def make_cache():
    cache = {}
    def get(key, default=None):
        return cache.get(key, default)
    def set_(key, val):
        cache[key] = val
    return get, set_

get, set_ = make_cache()
set_("a", 1)
print(get("a"))       # 1
print(get("b", "?"))  # ?

# 题目 4
def make_rate_limit(calls_per_second):
    history = []
    def allow():
        now = time.time()
        history[:] = [t for t in history if now - t < 1]
        if len(history) >= calls_per_second:
            return False
        history.append(now)
        return True
    return allow

rl = make_rate_limit(3)
print([rl() for _ in range(5)])
# [True, True, True, False, False] （在 1 秒内调用 5 次）

# 题目 5
def memoize(func):
    cache = {}
    @wraps(func)
    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]
    return wrapper

@memoize
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)

print(fib(60))   # 极快，因缓存存在闭包
```

</details>

```python
# 题目 1
def f():
    data = []
    def append(x):
        data.append(x)
        return data
    return append

ap = f()
ap(1); ap(2)
print(ap(3))     # [1, 2, 3]
ap2 = f()        # 新工厂调用，新 data
print(ap2(1))    # [1] - 与 ap 不共享

# 题目 2
def f():
    n = 0
    def g():
        n += 1   # UnboundLocalError - 没声明 nonlocal
        return n
    return g
# f()() 会报 UnboundLocalError
# 修复：加 nonlocal n

# 题目 3
def f():
    big = list(range(1_000_000))
    def g(): return len(big)
    return g
h = f()
# big 不会被 GC，因为闭包 h 引用了它，h 存活则 big 存活
# 释放：不再用 h 时 del h

# 题目 4
funcs = [lambda: i for i in [10, 20, 30]]
print([f() for f in funcs])   # [30, 30, 30] - 延迟绑定

# 修复
funcs = [lambda i=i: i for i in [10, 20, 30]]
print([f() for f in funcs])   # [10, 20, 30]

# 题目 5
def f():
    s = "hi"
    def g():
        s = s + "!"   # UnboundLocalError - 字符串不可变，赋值让 s 变 g 的局部
        return s
    return g
# f()() 会 UnboundLocalError
# 修复：用 nonlocal s
def f_fixed():
    s = "hi"
    def g():
        nonlocal s
        s = s + "!"
        return s
    return g
g = f_fixed()
print(g())   # hi!
```

## 综合练习

### 练习题

**综合题 1：状态机日历**
用闭包实现一个事件计数器：`make_event_tracker()` 返回 `track(event)`，每次调用累加 event 出现次数，并返回当前累计。可用 dict 存。

**综合题 2：基于闭包的"账户"**
`make_account(balance)` 返回一个 dict 含 `deposit / withdraw / balance` 函数（密码保护可选）。

**综合题 3：流式求平均**
`make_streaming_avg()` 返回 `add(x)`，每次返回当前平均值。

**综合题 4：闭包装饰重试**
用闭包实现 `retry(times)` 装饰器（层次：参数 → 装饰器 → wrapper）。

**综合题 5：一次函数**
`make_once()`：第一次调用返回函数计算结果，之后返回缓存值。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
from functools import wraps

# 综合题 1
def make_event_tracker():
    counts = {}
    def track(event):
        counts[event] = counts.get(event, 0) + 1
        return counts[event]
    def all_():
        return dict(counts)
    track.all = all_
    return track

t = make_event_tracker()
print(t("click"), t("click"), t("view"))   # 1 2 1
print(t.all())   # {'click': 2, 'view': 1}

# 综合题 2
def make_account(balance, password=None):
    state = {"balance": balance, "pwd": password}
    def check(p):
        return password is None or p == state["pwd"]
    def deposit(p, amount):
        if not check(p): raise PermissionError("密码错")
        state["balance"] += amount
        return state["balance"]
    def withdraw(p, amount):
        if not check(p): raise PermissionError("密码错")
        if state["balance"] < amount: raise RuntimeError("余额不足")
        state["balance"] -= amount
        return state["balance"]
    def balance(p):
        if not check(p): raise PermissionError("密码错")
        return state["balance"]
    return {"deposit": deposit, "withdraw": withdraw, "balance": balance}

acc = make_account(100, password="123")
print(acc["deposit"]("123", 50))      # 150
print(acc["withdraw"]("123", 30))     # 120
print(acc["balance"]("123"))           # 120
# acc["withdraw"]("wrong", 30)        # PermissionError

# 综合题 3
def make_streaming_avg():
    state = {"sum": 0, "count": 0}
    def add(x):
        state["sum"] += x
        state["count"] += 1
        return state["sum"] / state["count"]
    return add

avg = make_streaming_avg()
print(avg(10), avg(20), avg(30))   # 10.0 15.0 20.0

# 综合题 4
def retry(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last = None
            for i in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last = e
            raise last
        return wrapper
    return decorator

@retry(3)
def f():
    print("尝试")
    raise RuntimeError("炸")
# f() 会在三次尝试后抛 RuntimeError
# 但实际执行需 try 块（这里不实际调用）

# 综合题 5
def make_once(func):
    cache = {"computed": False, "value": None}
    @wraps(func)
    def wrapper(*args, **kwargs):
        if not cache["computed"]:
            cache["value"] = func(*args, **kwargs)
            cache["computed"] = True
        return cache["value"]
    return wrapper

import random
@make_once
def slow_compute():
    return random.random()

v1 = slow_compute()
v2 = slow_compute()
print(v1 == v2)   # True - 第二次命中缓存
```

## 小结

- 闭包 = 嵌套函数引用外层变量 + 外层返回内层
- 捕获的是引用，不是值。延迟绑定是经典坑，用默认参数或工厂修复
- 修改外层要 `nonlocal`；修改可变对象不需要
- `__closure__` 与 `co_freevars` 可看内部捕获
- 应用：工厂、计数器、累加器、缓存、配置、装饰器核心
- 简单共享状态用闭包，复杂状态用类
- 警惕：可变共享、nonlocal 缺失、大对象泄露、延迟绑定
