## 函数定义与调用

### 练习题

**题目 1：基础定义**
1. 定义函数 `hello()`，打印 `"Hello, World!"`
2. 定义函数 `square(x)`，返回 `x` 的平方
3. 定义函数 `is_even(n)`，返回整数 `n` 是否为偶数（布尔值）

**题目 2：BMI 计算器**
定义函数 `bmi(weight, height)`，参数为体重（kg）和身高（m），返回 BMI 值（保留 1 位小数）和状态字符串，状态按以下规则：
- `BMI < 18.5` → `"偏瘦"`
- `18.5 ≤ BMI < 24` → `"正常"`
- `24 ≤ BMI < 28` → `"超重"`
- `BMI ≥ 28` → `"肥胖"`

要求函数同时返回两个值。

**题目 3：调用顺序**
以下代码会输出什么？为什么？
```python
def f():
    print("A")

def g():
    f()
    print("B")
    f()

g()
```

**题目 4：链式调用**
定义 `inc(x)` 返回 `x+1`，`double(x)` 返回 `x*2`。计算 `double(inc(double(inc(3))))` 的值，并说明计算过程。

**题目 5：解包调用**
给定 `def f(a, b, c, d): return a+b+c+d`，用三种方式调用求和为 10：
1. 用列表解包传入
2. 用字典解包传入
3. 混合解包

```python
from typing import List, Dict, Optional

# 题目 1
def repeat(text: str, times: int = 3) -> str:
    return text * times

print(repeat("ab"))  # ababab

# 题目 2
def process(items: List[int]) -> Dict[str, int]:
    return {str(x): x for x in items}

print(process([1, 2, 3]))  # {'1': 1, '2': 2, '3': 3}

# 题目 3
def find_user(uid: int) -> Optional[Dict[str, str]]:
    users = {1: {"name": "Alice"}}
    return users.get(uid)

print(find_user(1))  # {'name': 'Alice'}
print(find_user(2))  # None

# 题目 4
def f(a: int, b: str = "x") -> bool:
    return True

print(f.__annotations__)
# {'a': <class 'int'>, 'b': <class 'str'>, 'return': <class 'bool'>}

# 题目 5
def f(a, b, /, c, *, d, e):
    return (a, b, c, d, e)

# 合法
print(f(1, 2, 3, d=4, e=5))     # (1, 2, 3, 4, 5)
print(f(1, 2, c=3, d=4, e=5))   # (1, 2, 3, 4, 5)

# 非法：
# f(a=1, b=2, c=3, d=4, e=5)  # TypeError, a, b 是 positional-only
# f(1, 2, 3, 4, 5)             # TypeError, d, e 是 keyword-only
```

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
# 输出：
# [1]
# [1, 1]
# [1, 1, 1]
# 原因：默认值 [] 在 def 执行时只创建一次，存在 __defaults__，
#       每次调用复用同一个 list 对象。

# 修复：
def append_one(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst

print(append_one())  # [1]
print(append_one())  # [1]

# 题目 2
# greet      只引用了函数对象，不调用，无输出
# greet()    调用，输出 hi
# 所以整体输出一行：hi

# 题目 3
# double(5) 打印 10，但函数返回 None
# print(r) 打印 None
# 输出：
# 10
# None
# 应改为 return x * 2

# 题目 4
# print(list((1, 2, 3)))   直接返回 (1, 2, 3)，因为是元组，看起来没变
#   但其实自定义的 list 不再有内置 list 的转换作用。
# print(list(range(3)))    返回 range(3) 原样，而不能把它转成 [0,1,2]！
# 隐患：覆盖内置 list 后，所有依赖 list() 的代码都会失效或行为异常。
# 修复：重命名为 make_list

# 题目 5
# 输出：inner
# 为什么：outer 体执行时才查找名字 inner，此时 inner 已定义，
#        所以能正常调用。Python 没有提升（hoisting），但延迟解析
#        函数体里的名字，只要调用时名字已经存在即可。

# 题目 6
# 输出：[3, 3, 3]
# 为什么：循环里定义的 f 不捕获 i 当时的值，而是引用循环变量 i。
#       循环结束后 i=3，所有 f() 都返回 3。
# 修复（用默认参数捕获当时的值）：
funcs = []
for i in [1, 2, 3]:
    def f(i=i):       # 用默认参数固定 i
        return i
    funcs.append(f)

print([f() for f in funcs])  # [1, 2, 3]
```

### 练习题

**综合题 1：学生成绩处理器**
编写函数 `analyze_scores(scores)`，参数为成绩列表，返回 `(最高分, 最低分, 平均分, 及格率)`。其中及格率指 60 分及以上的比例（0~1 浮点）。要求：
- 处理空列表（返回 `(None, None, None, None)`）
- 写完整 docstring
- 加类型注解

**综合题 2：简易计算器**
写函数 `calc(op, a, b)`，`op` 是字符串 `"+-*/"`，返回对应运算结果。非法 `op` 抛出 `ValueError`。用函数字典实现。

**综合题 3：函数注册表**
实现一个装饰风格的注册器：函数 `register` 接受一个函数并把它存入全局字典 `registry`（键为函数名）。定义 3 个命令函数并通过 `register` 注册。

**综合题 4：retry 包装**
实现 `retry(func, times=3)`：调用 `func()`，如果抛异常就重试，最多 `times` 次，全失败抛出最后一次异常。要求返回值是 `func` 的返回值。

**综合题 5：CLI 风格命令分发**
写一个函数 `run_command(name, *args)`，根据 `name` 查 `registry` 调用对应函数，把 `*args` 传给它。未注册时打印"未知命令"。

```python
from typing import List, Optional, Tuple

# 综合题 1
def analyze_scores(scores: List[int]) -> Tuple[Optional[int], Optional[int], Optional[float], Optional[float]]:
    """分析成绩列表。

    Args:
        scores: 成绩列表。

    Returns:
        四元组 (最高分, 最低分, 平均分, 及格率)。
        空列表时返回 (None, None, None, None)。
    """
    if not scores:
        return None, None, None, None
    high = max(scores)
    low = min(scores)
    avg = sum(scores) / len(scores)
    pass_rate = sum(1 for s in scores if s >= 60) / len(scores)
    return high, low, avg, pass_rate

print(analyze_scores([80, 90, 50, 60, 100]))
# (100, 50, 76.0, 0.8)
print(analyze_scores([]))
# (None, None, None, None)

# 综合题 2
def add(a, b): return a + b
def sub(a, b): return a - b
def mul(a, b): return a * b
def div(a, b): return a / b

_ops = {"+": add, "-": sub, "*": mul, "/": div}

def calc(op, a, b):
    if op not in _ops:
        raise ValueError(f"未知操作 {op}")
    return _ops[op](a, b)

print(calc("+", 1, 2))  # 3
print(calc("*", 3, 4))  # 12

# 综合题 3
registry = {}

def register(func):
    registry[func.__name__] = func
    return func

@register
def hello():
    print("Hi!")

@register
def bye():
    print("Bye!")

@register
def info():
    print("Info.")

print(list(registry.keys()))  # ['hello', 'bye', 'info']

# 综合题 4
def retry(func, times=3):
    last_exc = None
    for i in range(times):
        try:
            return func()
        except Exception as e:
            last_exc = e
            print(f"第 {i+1} 次失败: {e}")
    raise last_exc

import random
def flaky():
    if random.random() < 0.5:
        raise RuntimeError("随机失败")
    return "ok"

try:
    print(retry(flaky, times=5))
except Exception as e:
    print("全部失败:", e)

# 综合题 5
def run_command(name, *args):
    func = registry.get(name)
    if func is None:
        print("未知命令:", name)
        return None
    return func(*args)

run_command("hello")  # Hi!
run_command("info")   # Info.
run_command("nope")   # 未知命令: nope
```

## 小结

- `def` 定义函数，缩进体，冒号不可省
- 调用要加括号 `()`，否则只是引用
- 命名用 snake_case，动词开头
- 第一行字符串才是 docstring
- 函数是第一类对象：赋值、装容器、传参、作返回值
- 类型注解让代码更安全但不强制
- 警惕可变默认值、忘记 return、覆盖内置
