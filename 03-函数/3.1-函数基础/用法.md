## 函数基础概念

**函数（Function）** 是组织好的、可重复使用的、用来实现单一或相关联功能的代码段。函数能提高应用的模块性和代码的重复利用率。

**为什么使用函数：**
- **代码复用**：避免重复编写相同逻辑
- **模块化**：把复杂问题拆分成小块
- **可读性**：通过函数名表达意图
- **可维护性**：修改时只需改一处
- **测试性**：函数是天然的测试单元
- **作用域隔离**：函数内变量不影响外部

**Python 函数的特点：**
- 函数是**第一类对象（first-class object）**：可赋值给变量、可作参数、可作返回值、可存入容器
- 使用 `def` 关键字定义
- 通过缩进表示函数体
- 支持参数和返回值
- 支持嵌套定义

```python
# 一个最简单的函数
def greet():
    print("Hello, Python!")

greet()  # 调用：Hello, Python!
```

## 定义函数 def

### 1. 基本语法

**语法：**
```python
def 函数名(参数列表):
    """文档字符串（可选）"""
    函数体
    return 返回值（可选）
```

**要点：**
- `def` 是关键字，后跟函数名
- 参数列表可以为空，但括号 `()` 必须有
- 冒号 `:` 不可省略
- 函数体必须**缩进**（通常 4 空格）
- 没有显式 `return` 时，函数返回 `None`

```python
# 无参数无返回值
def say_hi():
    print("Hi!")

# 无参数有返回值
def get_pi():
    return 3.14159

# 有参数有返回值
def add(a, b):
    return a + b

# 调用
say_hi()          # Hi!
print(get_pi())   # 3.14159
print(add(2, 3))  # 5
```

### 2. 函数定义必须在调用前

Python 是**自上而下**执行的，函数必须先定义后调用。

```python
# 正确：先定义后调用
def foo():
    print("foo")

foo()

# 错误：先调用后定义
# bar()          # NameError: name 'bar' is not defined
# def bar():
#     print("bar")
```

**注意**：函数定义的"提升"不同于 JavaScript 的 hoisting。Python 只在执行到 `def` 语句时才把函数名绑定到当前命名空间。

```python
# 函数体内引用后定义的函数（调用时才查找）没问题
def caller():
    return later()   # 调用时 later 必须已定义

def later():
    return "I am later"

print(caller())  # I am later - 调用时 later 已存在
```

### 3. 多条语句的函数体

```python
def compute_bmi(weight, height):
    bmi = weight / (height ** 2)
    if bmi < 18.5:
        status = "偏瘦"
    elif bmi < 24:
        status = "正常"
    elif bmi < 28:
        status = "超重"
    else:
        status = "肥胖"
    return bmi, status   # 返回元组

bmi, status = compute_bmi(70, 1.75)
print(f"BMI={bmi:.1f}, 状态={status}")
```

## 调用函数

### 1. 基本调用

```python
def power(base, exp):
    return base ** exp

print(power(2, 10))   # 1024 - 位置参数
print(power(base=2, exp=10))  # 关键字参数
```

### 2. 调用时的参数传递方式

| 方式 | 示例 | 说明 |
|------|------|------|
| 位置参数 | `f(1, 2)` | 按位置对应 |
| 关键字参数 | `f(a=1, b=2)` | 按名字对应 |
| 混合 | `f(1, b=2)` | 位置在前，关键字在后 |

```python
def info(name, age, city):
    print(f"{name}, {age}岁, {city}")

info("Alice", 20, "Beijing")          # 全位置
info("Alice", age=20, city="Beijing")  # 混合
info(name="Alice", age=20, city="Beijing")  # 全关键字
# info(name="Alice", 20, "Beijing")   # SyntaxError - 位置参数不能在关键字参数之后
```

### 3. 解包调用

```python
def add(a, b, c):
    return a + b + c

args = [1, 2, 3]
print(add(*args))      # 6 - 列表解包为位置参数

kwargs = {"a": 1, "b": 2, "c": 3}
print(add(**kwargs))   # 6 - 字典解包为关键字参数

# 混合解包
print(add(*[1, 2], c=3))   # 6
```

### 4. 函数调用是表达式

函数调用本身是一个表达式，可以嵌套使用：

```python
def double(x):
    return x * 2

def inc(x):
    return x + 1

print(double(inc(5)))      # 12 - inc(5)=6, double(6)=12
print(double(double(3)))   # 12

# 链式调用
result = sorted(map(str, range(5)))
print(result)  # ['0', '1', '2', '3', '4']
```

## 函数命名规范

### 1. 命名规则（强制）

- 只能包含**字母、数字、下划线**
- **不能以数字开头**
- 不能是 Python 关键字（`def`、`class`、`if` 等）
- 区分大小写

```python
def my_func(): pass     # 合法
def myFunc(): pass      # 合法（但不推荐）
def _private(): pass    # 合法，约定表示内部使用
def __dunder(): pass    # 合法，魔术方法风格
# def 2func(): pass     # SyntaxError - 数字开头
# def def(): pass       # SyntaxError - 关键字
```

### 2. PEP 8 命名约定（推荐）

| 类型 | 风格 | 示例 |
|------|------|------|
| 函数名 | 小写下划线（snake_case） | `calculate_average` |
| 私有函数 | 前置单下划线 | `_helper` |
| 内部使用 | 双下划线（名称改写，多用于类） | `__method` |
| 调用即弃 | 临时 | `_` |
| 魔术方法 | 双下划线前后 | `__init__` |

```python
# 推荐
def calculate_bmi(weight, height): ...

# 不推荐
def CalculateBMI(Weight, Height): ...   # Java/C 风格
def calc_bmi(w, h): ...                   # 参数名过短，无意义
```

### 3. 动词命名

函数通常表示一个动作，名字以**动词**开头更清晰：

```python
# 推荐（动词开头）
def get_user(id): ...
def send_email(to, content): ...
def parse_json(text): ...
def validate_input(data): ...

# 不推荐（名词）
def user(id): ...      # 是获取还是创建？
def data(): ...        # 含义不清
```

### 4. 避免覆盖内置函数

```python
# 危险：覆盖了内置函数 list
def list(items):
    return items

# 后续再也不能用 list()：
# list((1, 2, 3))  # 调用的是上面这个

# 解决：用 del 恢复，或改名
def make_list(items):
    return list(items)

# 即使在交互环境，这种覆盖也只影响当前作用域，但极易引发 bug
```

## docstring 文档字符串

**docstring** 是函数体第一行的字符串字面量，用于说明函数的用途、参数、返回值。它是函数的 `__doc__` 属性，可被 `help()` 和 IDE 提示读取。

### 1. 基本用法

```python
def add(a, b):
    """返回两个数的和。"""
    return a + b

print(add.__doc__)  # 返回两个数的和。
help(add)           # 显示文档
```

### 2. 三种主流风格

**风格一：Google 风格（推荐，最清晰）**
```python
def fetch_user(user_id, active_only=False):
    """根据 ID 获取用户信息。

    Args:
        user_id (int): 用户唯一标识。
        active_only (bool): 是否只查激活用户，默认 False。

    Returns:
        dict: 用户信息字典，键包含 name、age、email。
        找不到时返回 None。

    Raises:
        ValueError: user_id 为负数时抛出。

    Example:
        >>> fetch_user(1)
        {'name': 'Alice', 'age': 20, 'email': 'a@x.com'}
    """
    if user_id < 0:
        raise ValueError("user_id 不能为负")
    return {"name": "Alice", "age": 20, "email": "a@x.com"}
```

**风格二：NumPy 风格（科学计算常用）**
```python
def mean(x):
    """计算平均值。

    Parameters
    ----------
    x : array-like
        输入数据。
    Returns
    -------
    float
        算术平均值。
    """
    return sum(x) / len(x)
```

**风格三：reST 风格（Sphinx 文档）**
```python
def divide(a, b):
    """执行除法。

    :param a: 被除数。
    :param b: 除数。
    :returns: 商。
    :raises ZeroDivisionError: b 为 0。
    """
    return a / b
```

### 3. 单行 vs 多行 docstring

```python
# 单行：用于简单、自解释的函数
def square(x):
    """返回 x 的平方。"""
    return x * x

# 多行：第一行是摘要（以句号结尾，不超过 79 字符），
#       空一行后写详细说明
def complex_func(data, mode):
    """对数据进行复杂变换。

    根据 mode 选择不同的变换策略，返回处理后的数据。
    支持的 mode 有 'fast' 和 'safe'。
    """
    pass
```

### 4. 查看 docstring

```python
def f():
    """我的函数。"""
    pass

print(f.__doc__)    # 我的函数。
help(f)
# Help on function f in module __main__:
# f()
#     我的函数。

# 模块、类、方法都可以有 docstring
"""本模块提供示例函数。"""  # 模块 docstring，放在文件开头

class C:
    """类的 docstring。"""
    def m(self):
        """方法的 docstring。"""
        pass

print(C.__doc__)
print(C.m.__doc__)
```

### 5. 用 __doc__ 动态生成帮助

```python
def login(user, pwd):
    """登录系统。

    Args:
        user: 用户名。
        pwd: 密码。
    Returns:
        bool: 登录是否成功。
    """
    return user == "admin" and pwd == "123"

# 程序化读取
docs = [(name, obj.__doc__) for name, obj in list(globals().items())
        if callable(obj) and not name.startswith("_")]
print(docs)
```

## 函数是第一类对象

Python 函数是对象，可以被**赋值、传递、返回、存储**。

### 1. 赋值给变量

```python
def shout(text):
    return text.upper()

yell = shout        # 赋值，注意没有括号
print(yell("hi"))   # HI - 通过别名调用
print(yell is shout)  # True

del shout
print(yell("hi"))   # 还是能调用 - yell 仍持有引用
```

### 2. 存入容器

```python
def add(a, b): return a + b
def sub(a, b): return a - b
def mul(a, b): return a * b

ops = {"+": add, "-": sub, "*": mul}
print(ops["+"](3, 4))   # 7
print(ops["*"](3, 4))   # 12
```

### 3. 作为参数传递

```python
def apply(func, value):
    return func(value)

print apply(abs, -5)   # 这个写法错误（演示反例），正确如下：
print(apply(abs, -5))  # 5
print(apply(str, 123)) # '123'
```

### 4. 作为返回值

```python
def make_multiplier(n):
    def multiply(x):
        return x * n
    return multiply

times3 = make_multiplier(3)
print(times3(4))   # 12
print(times3(10))  # 30
```

### 5. 函数对象的属性

```python
def f():
    """示例函数。"""
    pass

print(type(f))          # <class 'function'>
print(f.__name__)        # 'f' - 函数名
print(f.__doc__)         # 示例函数。
print(f.__module__)      # '__main__'
print(hasattr(f, "__call__"))  # True
print(callable(f))       # True
```

## 空函数与占位

### 1. pass 语句

当你需要定义一个暂不实现内容的函数时，用 `pass` 占位（函数体不能为空）：

```python
def todo():
    pass     # 占位，什么也不做

def not_implemented():
    pass
```

### 2. ... 省略号（Ellipsis）

Python 3 中 `...` 也可作为占位，常见于类型存根（stub）：

```python
def stub_func(x: int) -> str:
    ...

# 等价于 pass
def stub_func2():
    ...
```

### 3. 只写 docstring

```python
def future_feature():
    """计划在下个版本实现。"""

future_feature()  # 不报错，函数体只有字符串，返回 None
```

### 4. raise NotImplementedError

明确告知"未实现"，调用即报错：

```python
def must_override():
    raise NotImplementedError("子类必须重写")
```

## 函数属性

函数对象可以附加**自定义属性**（不常用，但有特殊场景）。

```python
def counter():
    counter.calls += 1
    return counter.calls

counter.calls = 0       # 给函数加属性
print(counter())        # 1
print(counter())        # 2
print(counter.calls)    # 2

# 缓存配置
counter.cache = {}
print(counter.cache)    # {}
```

**注意**：自定义函数属性可读性差，一般用闭包、类或 `functools` 替代。

## type hints 类型注解

Python 3.5+ 支持**类型注解**，注解**不影响运行**，但便于静态检查和 IDE 提示。

### 1. 参数与返回值注解

```python
def greet(name: str) -> str:
    return f"Hello, {name}"

def add(a: int, b: int) -> int:
    return a + b

print(greet("Alice"))  # Hello, Alice
# greet(123)           # 运行时不报错（注解不强制），但 mypy 会警告
```

### 2. 复杂类型

```python
from typing import List, Dict, Tuple, Optional, Union

def process(items: List[int]) -> List[int]:
    return [x * 2 for x in items]

def get_user(uid: int) -> Optional[Dict[str, Union[str, int]]]:
    if uid == 1:
        return {"name": "Alice", "age": 20}
    return None

# Python 3.9+ 可直接用内置类型小写
def f(items: list[int]) -> dict[str, int]:
    return {str(x): x for x in items}
```

### 3. 默认值与注解

注解写在冒号后，默认值在注解后：

```python
def repeat(text: str, times: int = 3) -> str:
    return text * times

print(repeat("ab"))   # ababab
```

### 4. 查看注解 __annotations__

```python
def f(a: int, b: str = "x") -> bool:
    return True

print(f.__annotations__)
# {'a': <class 'int'>, 'b': <class 'str'>, 'return': <class 'bool'>}
```

### 5. Python 3.8+ positional-only / 3.0+ keyword-only

```python
# / 之前是 positional-only（只能按位置传）
def f(a, b, /, c, d):
    return a + b + c + d

f(1, 2, 3, 4)        # OK
f(1, 2, c=3, d=4)    # OK
# f(a=1, b=2, c=3, d=4)  # TypeError - a,b 不能用关键字

# * 之后是 keyword-only（只能用关键字传）
def g(a, *, b, c):
    return a + b + c

g(1, b=2, c=3)       # OK
# g(1, 2, 3)         # TypeError - b,c 必须用关键字
```

## 内置函数与自定义函数

### 1. 常见内置函数（可直接用，无需 import）

```python
print(len("abc"))          # 3
print(abs(-5))             # 5
print(max(1, 2, 3))        # 3
print(min([4, 1, 2]))      # 1
print(sum([1, 2, 3]))      # 6
print(round(3.7))          # 4
print(pow(2, 10))           # 1024
print(sorted([3, 1, 2]))   # [1, 2, 3]
print(list(map(str, [1, 2])))  # ['1', '2']
print(isinstance(5, int))  # True
print(callable(print))     # True
```

### 2. 自定义函数与内置函数等价

```python
# 自定义 max
def my_max(*args):
    m = args[0]
    for x in args[1:]:
        if x > m:
            m = x
    return m

print(my_max(3, 7, 2, 9, 1))  # 9
print(max(3, 7, 2, 9, 1))     # 9
```

### 3. 避免与内置重名

```python
# 不好
def sum(a, b):     # 覆盖了内置 sum
    return a + b

# 好
def my_sum(a, b):
    return a + b
```

## 函数的内存与对象模型

### 1. 简单看相内存

```python
def f(): pass
print(id(f))            # 某内存地址
print(type(f))          # <class 'function'>
```

### 2. 作为内存地址比较

```python
def f(): pass
g = f
print(f is g)        # True - 同一个对象

import copy
f2 = copy.copy(f)
print(f is f2)       # True - 函数对象浅拷贝仍指向同一个对象
```

### 3. 重新定义同函数

```python
def f():
    print("v1")

f1 = f

def f():
    print("v2")

f()   # v2 - 当前名字指向新定义
f1()  # v1 - 旧对象仍存活，被 f1 引用
```

**原因**：函数名只是命名空间中的一个引用，重新 `def` 绑定到新对象，旧对象不会被回收（只要还有其它引用）。

### 4. 函数 __dict__ 与 __defaults__

```python
def f(a, b=2, c=3):
    return a + b + c

print(f.__defaults__)  # (2, 3) - 默认参数元组
print(f.__code__.co_varnames)  # ('a', 'b', 'c') 局部变量名
print(f.__code__.co_argcount)  # 3 个参数
```

## 常见错误与陷阱

### 1. 缩进错误

```python
# 错误：函数体没缩进
# def f():
# return 1   # IndentationError

# 正确
def f():
    return 1
```

### 2. 忘记冒号

```python
# def f()     # SyntaxError: expected ':'
#     return 1

def f():
    return 1
```

### 3. 忘记调用括号

```python
def greet():
    print("hi")

greet     # 不报错，但什么也不做（只是引用了函数对象）
greet()   # hi - 真正调用
```

### 4. 返回值被忽略

```python
def add(a, b):
    return a + b

add(1, 2)   # 计算了但没接收，结果丢失
result = add(1, 2)  # 正确接收
```

### 5. 默认值用可变对象（极经典陷阱）

```python
def f(lst=[]):
    lst.append(1)
    return lst

print(f())  # [1]
print(f())  # [1, 1] - 默认值在函数定义时只创建一次！
print(f())  # [1, 1, 1]

# 正确做法
def f(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst

print(f())  # [1]
print(f())  # [1]
```

**详细原因**：默认参数值在 `def` 执行时被求值一次，并存在 `__defaults__` 中，每次调用复用同一个对象。详见 [3.2-参数详解](../3.2-参数详解/用法.md)。

### 6. 函数名重复绑定

```python
def f():
    return 1

def f():     # 重新定义，旧的被覆盖
    return 2

print(f())   # 2
```

### 7. 全局同名覆盖内置

```python
# 危险
list = [1, 2, 3]   # 覆盖内置 list
# list((4,5))      # TypeError: 'list' object is not callable
```

### 8. 误用 print 当 return

```python
# 错误：想返回结果但用了 print
def double(x):
    print(x * 2)   # 打印了，但函数返回 None

r = double(5)
print(r)          # None

# 正确
def double(x):
    return x * 2
```

## 最佳实践

### 1. 单一职责

一个函数只做一件事。如果函数超过 50 行或职责过杂，考虑拆分。

```python
# 不好：又算又打印
def process(data):
    total = sum(data)
    print(f"总和是 {total}")   # 副作用，难测试
    avg = total / len(data)
    print(f"平均是 {avg}")
    return total

# 好：计算归计算，打印归打印
def compute_stats(data):
    total = sum(data)
    avg = total / len(data)
    return total, avg

def show_stats(data):
    total, avg = compute_stats(data)
    print(f"总和={total}, 平均={avg}")
```

### 2. 优先用返回值而非副作用

```python
# 不好：依赖可变参数副作用
def add_one(lst):
    lst.append(1)

# 好：返回新对象
def add_one(lst):
    return lst + [1]
```

### 3. 函数名要能表达意图

```python
# 不好
def proc(d):
    ...

# 好
def filter_active_users(users):
    ...
```

### 4. 参数不宜过多

参数超过 5 个考虑用对象封装或关键字参数。

```python
# 不好
def create_user(name, age, email, phone, city, country, zip):
    ...

# 好
def create_user(info: dict):
    ...
```

### 5. 写 docstring

哪怕是单行也要写，方便他人和未来的自己。

### 6. 用类型注解

让 IDE 和静态检查器帮你发现 bug。

---

## 小结

- 函数用 `def` 定义，缩进体，可返回值
- 函数名遵循 snake_case，动词开头
- docstring 是函数文档，第一行字符串
- 函数是第一类对象，可赋值传递返回
- 类型注解让代码更清晰但不强制
- 注意默认参数可变陷阱、缩进、冒号
