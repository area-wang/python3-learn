## 基础语法

### 练习题

**题目 1：lambda 基础**
1. 用 lambda 创建 `square(x)` 返回 x²
2. 用 lambda 创建 `add(a,b)` 返回 a+b
3. 用 lambda 创建 `greet(name, greeting="Hi")` 返回问候字符串

**题目 2：无参数**
用 lambda 创建 `f()` 返回 `"hi"`，调用它。

**题目 3：*args/**
用 lambda 创建 `f(*args)` 返回和、`g(**kw)` 返回键值对列表。

**题目 4：三元**
用 lambda 实现 `abs_val(x)` 返回绝对值。

**题目 5：__name__**
```python
f = lambda x: x
print(f.__name__)
```
输出？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
square = lambda x: x ** 2
add = lambda a, b: a + b
greet = lambda name, greeting="Hi": f"{greeting}, {name}!"
print(square(5))        # 25
print(add(2, 3))        # 5
print(greet("Alice"))   # Hi, Alice!
print(greet("Bob", "Yo"))  # Yo, Bob!

# 题目 2
f = lambda: "hi"
print(f())   # hi

# 题目 3
f = lambda *args: sum(args)
g = lambda **kw: list(kw.items())
print(f(1, 2, 3))            # 6
print(g(a=1, b=2))           # [('a', 1), ('b', 2)]

# 题目 4
abs_val = lambda x: x if x >= 0 else -x
print(abs_val(5), abs_val(-7))   # 5 7

# 题目 5
f = lambda x: x
print(f.__name__)   # <lambda>
```

## 跟高阶函数配合

### 练习题

**题目 1：sort by age**
`users = [{"name":"A","age":30},{"name":"B","age":25}]`，用 sorted+lambda 按年龄排。

**题目 2：map 平方**
用 map+lambda 把 `[1,2,3]` 变平方。

**题目 3：filter 偶**
用 filter+lambda 保留 `[1,2,3,4,5,6]` 中偶数。

**题目 4：ops 字典**
用 lambda 创建 `ops = {"+": ..., "-": ...}` 并调用 `ops["+"](5,3)`。

**题目 5：max length**
`words = ["a","banana","cherry"]`，用 `max(words, key=...)` 找最长的。

**题目 6：reduce**
用 reduce+lambda 求 `[1,2,3,4]` 乘积。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
from functools import reduce

# 题目 1
users = [{"name": "A", "age": 30}, {"name": "B", "age": 25}]
print(sorted(users, key=lambda u: u["age"]))
# [{'name': 'B', 'age': 25}, {'name': 'A', 'age': 30}]

# 题目 2
print(list(map(lambda x: x ** 2, [1, 2, 3])))   # [1, 4, 9]

# 题目 3
print(list(filter(lambda x: x % 2 == 0, [1, 2, 3, 4, 5, 6])))   # [2, 4, 6]

# 题目 4
ops = {
    "+": lambda a, b: a + b,
    "-": lambda a, b: a - b,
}
print(ops["+"](5, 3))   # 8
print(ops["-"](5, 3))   # 2

# 题目 5
words = ["a", "banana", "cherry"]
print(max(words, key=lambda w: len(w)))   # banana

# 题目 6
print(reduce(lambda a, b: a * b, [1, 2, 3, 4]))   # 24
```

## 闭包与陷阱

### 练习题

**题目 1：闭包捕获**
```python
n = 10
f = lambda x: x + n
print(f(5))
n = 20
print(f(5))
```
两次输出？为什么？

**题目 2：循环延迟**
```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])
```
输出？修复。

**题目 3：partcapture by default**
实现 `make_adder(n)` 返回 `lambda x: x + n`，验证 `make_adder(10)(5) == 15`。

**题目 4：循环按钮命令**
模拟 5 个按钮的不同点击行为：要打印按钮序号 i，避免统一打印最后一个 i。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
n = 10
f = lambda x: x + n
print(f(5))   # 15
n = 20
print(f(5))   # 25
# 原因：lambda 捕获的是 n 这个名字的引用，不是当时的值。
#       n 变了，f 跟着用新值。

# 题目 2
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])   # [2, 2, 2] - 延迟绑定

# 修复：默认参数捕获当时的 i
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]

# 题目 3
def make_adder(n):
    return lambda x: x + n

print(make_adder(10)(5))   # 15
add5 = make_adder(5)
print(add5(3))             # 8

# 题目 4
commands = []
for i in range(5):
    # 默认参数捕获 i
    commands.append(lambda i=i: print("click", i))

commands[0]()   # click 0
commands[2]()   # click 2
commands[4]()   # click 4
```

</details>

## operator 替代

### 练习题

**题目 1：itemgetter**
用 `itemgetter("age")` 替代 `lambda u: u["age"]` 排序。

**题目 2：attrgetter**
有 `class U(name, age)`，用 attrgetter 按 age 排序。

**题目 3：methodcaller**
用 `methodcaller("upper")` 替代 `lambda s: s.upper()`，作用于 `["a","b"]`。

**题目 4：add**
用 `operator.add` 替代 `lambda a, b: a + b` 配合 reduce。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
from operator import itemgetter, attrgetter, methodcaller, add
from functools import reduce

# 题目 1
users = [{"name": "A", "age": 30}, {"name": "B", "age": 25}]
print(sorted(users, key=itemgetter("age")))
# [{'name': 'B', 'age': 25}, {'name': 'A', 'age': 30}]

# 题目 2
class U:
    def __init__(self, name, age):
        self.name, self.age = name, age
    def __repr__(self): return f"U({self.name},{self.age})"

us = [U("A", 30), U("B", 25)]
print(sorted(us, key=attrgetter("age")))
# [U(B,25), U(A,30)]

# 题目 3
print(list(map(methodcaller("upper"), ["a", "b"])))   # ['A', 'B']

# 题目 4
print(reduce(add, [1, 2, 3, 4]))   # 10
# 等价 reduce(lambda a, b: a + b, ...)
```

</details>

## 陷阱题

**题目 1：lambda 不能有 statement**
```python
# f = lambda x: return x + 1
```
会发生什么？

**题目 2：lambda 没有 docstring**
```python
f = lambda x: x
print(f.__doc__)
```
输出？

**题目 3：复杂 lambda**
```python
sort_key = lambda u: (u["age"], u["score"], u["name"], -u["id"])
```
有什么问题？

**题目 4：lambda 立即调用**
```python
print((lambda x: x * 2)(5))
```
输出？

**题目 5：lambda 不能用 nonlocal**
```python
def f():
    n = 0
    g = lambda: n + 1
    return g
```
能否实现 `g` 让 n 累加？为什么 lambda 做不到 nonlocal？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
# f = lambda x: return x + 1   # SyntaxError: 'return' outside function
# 实际报 SyntaxError - lambda 体不能有 return 关键字，
#                      它本身已经隐式 return 表达式值。
# 正确：f = lambda x: x + 1

# 题目 2
f = lambda x: x
print(f.__doc__)   # None - lambda 不能有 docstring

# 题目 3
# 问题：lambda 太长、内含多个表达式含义，可读性差。PEP 8 不推荐。
# 改用 def
def sort_key(u):
    return (u["age"], u["score"], u["name"], -u["id"])
# 这样有名字、可读、可调试。

# 题目 4
print((lambda x: x * 2)(5))   # 10 - 立即调用立即用

# 题目 5
def f():
    n = 0
    g = lambda: n + 1   # 只读 n，不能修改
    return g

inc = f()
print(inc())   # 1
print(inc())   # 1 - 每次 +1 但 n 没变，因为 lambda 不能 nonlocal 修改

# 想要累加必须用 def + nonlocal：
def f2():
    n = 0
    def g():
        nonlocal n
        n += 1
        return n
    return g

inc = f2()
print(inc(), inc())   # 1 2
```

</details>

## 综合练习

### 练习题

**综合题 1：天然函数字典**
用 lambda 创建一个简单算式解释器：
```python
ops = {"+":..., "-":..., "*":..., "/":...}
def calc(op, a, b): return ops[op](a, b)
```

**综合题 2：sort 多次级**
对 `[("A", 90, 20), ("B", 90, 18), ("C", 80, 22)]` 按 score 降序、age 升序、name 升序排（用 lambda）。

**综合题 3：filter+map 链**
对 `1~20`，过滤 3 的倍数、留下的取二次方，list 化。

**综合题 4：闭包函数字典**
实现 `add = lambda a: lambda b: a + b`（curry），`add(3)(4) == 7`。

**综合题 5：lambda + walrus**
（Python 3.8+）用 walrus 让 lambda 在 filter 时记录"被处理过的值"。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 综合题 1
ops = {
    "+": lambda a, b: a + b,
    "-": lambda a, b: a - b,
    "*": lambda a, b: a * b,
    "/": lambda a, b: a / b,
}
def calc(op, a, b):
    if op not in ops:
        raise ValueError(op)
    return ops[op](a, b)

print(calc("+", 2, 3))   # 5
print(calc("*", 2, 3))   # 6
print(calc("/", 10, 4))   # 2.5

# 综合题 2
data = [("A", 90, 20), ("B", 90, 18), ("C", 80, 22)]
# 按分数降序、age 升序、name 升序
result = sorted(data, key=lambda u: (-u[1], u[2], u[0]))
print(result)
# [('B', 90, 18), ('A', 90, 20), ('C', 80, 22)]

# 综合题 3
result = list(map(lambda x: x ** 2, filter(lambda x: x % 3 == 0, range(1, 21))))
print(result)
# [9, 36, 81, 144, 225, 324, 400]（3,6,9,12,15,18 的平方）

# 推导式等价
result = [x ** 2 for x in range(1, 21) if x % 3 == 0]

# 综合题 4
add = lambda a: lambda b: a + b
print(add(3)(4))   # 7 - curry

# 综合题 5 (Python 3.8+)
# 想在 filter 时同时记录被处理前的值（这里仅演示 walrus 在 lambda 里的合法性）
data = [1, 2, 3, 4, 5]
# 取平方大于 4 的，并把这些平方值记录到 processed
processed = []
result = [x for x in data if (sq := x ** 2) > 4 and not processed.append(sq)]
print("result:", result)         # [3, 4, 5]
print("processed:", processed)   # [9, 16, 25]

# 用纯 lambda 的 walrus 也行，但更难读，仅作演示：
# f = lambda lst: [sq for x in lst if (sq := x ** 2) > 4 for _ in range(1)]
```

</details>

## 小结

- `lambda 参数: 表达式` 创建匿名函数，体只能是单个表达式
- 甜蜜区：参数极短、传给高阶函数、一次性
- 不要赋给命名变量（PEP 8 E731），用 def
- 不能写 return/赋值语句/多行/注解/docstring
- 闭包延迟绑定用默认参数修复
- 部分场景 operator 模块比手写 lambda 更好
