## Lambda 基础

**Lambda 表达式** 是创建匿名函数的简写方式。它生成一个 `function` 对象，本质和 `def` 一样。

```python
# def 定义
def square(x):
    return x ** 2

# lambda 等价
square = lambda x: x ** 2

print(square(5))   # 25
```

**适用场景：** 一次性、短小、立即传入高阶函数的函数。

```python
nums = [1, 2, 3]
print(list(map(lambda x: x * 2, nums)))   # [2, 4, 6]
```

## 语法规则

```
lambda 参数列表: 表达式
```

### 1. 单参数

```python
f = lambda x: x + 1
print(f(5))   # 6
```

### 2. 多参数

```python
add = lambda a, b: a + b
print(add(2, 3))   # 5
```

### 3. 带默认值

```python
greet = lambda name, greeting="Hi": f"{greeting}, {name}!"
print(greet("Alice"))        # Hi, Alice!
print(greet("Bob", "Yo"))    # Yo, Bob!
```

### 4. *args / **kwargs

```python
f = lambda *args: sum(args)
print(f(1, 2, 3))   # 6

g = lambda **kw: list(kw.items())
print(g(a=1, b=2))  # [('a', 1), ('b', 2)]
```

### 5. 无参数

```python
f = lambda: "hello"
print(f())   # hello
```

### 6. 表达式只能是单个表达式

```python
# lambda 体只能是**一个表达式**，不能有语句
f = lambda x: x + 1              # OK
f = lambda x: print(x); return   # SyntaxError - 不能有 return
f = lambda x: y = x + 1; y      # SyntaxError - 不能有赋值语句
```

### 7. 多行不行，要用 def

```python
# 复杂逻辑只能写 def
# f = lambda x:
#     if x > 0: return x
#     return -x        # SyntaxError
```

## Lambda 与 def 的区别

| 特性 | lambda | def |
|------|--------|-----|
| 语法 | `lambda x: expr` | `def f(x): return expr` |
| 命名 | 匿名（可赋给变量） | 必有名字 |
| 体 | **单个表达式** | 多条语句 |
| 返回值 | 隐式返回表达式值 | 需要 `return` |
| docstring | 无 | 可有 |
| 名称 | `<lambda>` | 函数名 |
| 注解 | 不能有 | 可有 |

```python
# lambda 无 __name__
f = lambda x: x
print(f.__name__)    # <lambda>

# def 有
def g(x): return x
print(g.__name__)    # g
```

### 1. 演示等价

```python
# 描述同一逻辑：取两数最大
max1 = lambda a, b: a if a > b else b
def max2(a, b): return a if a > b else b
print(max1(3, 4), max2(3, 4))   # 4 4
```

### 2. type 相同

```python
print(type(lambda x: x))   # <class 'function'>
print(type(lambda x: x) is type(lambda y: y))   # True
```

## 常见使用场景

### 1. 排序 key

```python
users = [{"name": "A", "age": 30}, {"name": "B", "age": 25}]
print(sorted(users, key=lambda u: u["age"]))
# [{'name': 'B', 'age': 25}, {'name': 'A', 'age': 30}]
```

### 2. map / filter / reduce

```python
nums = [1, 2, 3, 4, 5]
print(list(map(lambda x: x ** 2, nums)))           # [1, 4, 9, 16, 25]
print(list(filter(lambda x: x % 2 == 0, nums)))    # [2, 4]
from functools import reduce
print(reduce(lambda a, b: a + b, nums))            # 15
```

### 3. GUI / event 回调

```python
# Tkinter 常见
# button = Button(text="hi", command=lambda: print("clicked"))
```

### 4. dict 中存小函数

```python
ops = {
    "+": lambda a, b: a + b,
    "-": lambda a, b: a - b,
    "*": lambda a, b: a * b,
    "/": lambda a, b: a / b,
}
print(ops["+"](3, 4))   # 7
```

### 5. 默认参数 / tag 函数

```python
def make_incrementor(n):
    return lambda x: x + n

inc10 = make_incrementor(10)
print(inc10(5))   # 15
```

### 6. max/min 的 key

```python
words = ["apple", "kiwi", "strawberry"]
print(max(words, key=lambda w: len(w)))   # strawberry
print(min(words, key=lambda w: len(w)))   # kiwi
```

## Lambda 与高阶函数

详见 [3.5-高阶函数](../3.5-高阶函数/用法.md)。Lambda 是高阶函数最常见的**短小参数**。

### 1. 立即调用（IIFE）

```python
# 不常见，但可用
result = (lambda x: x * 2)(5)
print(result)   # 10

# 更典型
print((lambda a, b: a + b)(3, 4))   # 7
```

### 2. 怪异的"立即定义立即调用"

```python
print((lambda: "instant")())   # instant
```

### 3. 在 list 中批量造 lambda

```python
funcs = [lambda x: x + i for i in range(3)]   # 注意闭包陷阱！
# 这是闭包延迟绑定，详见 3.4-作用域
```

## Lambda 与闭包

Lambda 可以捕获外部变量，行为和 def 闭包一致。

### 1. 捕获外部

```python
n = 10
f = lambda x: x + n
print(f(5))   # 15 - 捕获了外部 n
n = 20
print(f(5))   # 25 - n 变了，f 跟着变（捕获引用，不是值）
```

### 2. 闭包捕获 + nonlocal（不可直接）

Lambda 无法用 `nonlocal`，但有需要时改用 def：

```python
def make_counter():
    c = 0
    def inc():
        nonlocal c
        c += 1
        return c
    return inc

# lambda 版做不到 nonlocal，只能用可变对象：
def make_counter_lambda():
    c = [0]
    def inc():
        c[0] += 1
        return c[0]
    return inc   # 这里其实仍用 def

# 或完全用 lambda + 可变默认参数：
make = lambda: (
    lambda: (c.__setitem__(0, c[0] + 1), c[0])[1]
) if False else None  # 太丑，不推荐
```

→ 需要修改外层状态时，**用 def**，不要硬用 lambda。

### 3. 延迟绑定陷阱

```python
i = 1
f = lambda: i
i = 2
print(f())   # 2 - i 变了延迟生效

# 修复（默认参数捕获值）
i = 1
f = lambda i=i: i
i = 2
print(f())   # 1
```

## 条件表达式

Lambda 体不能有 `if/else` 语句，但可以用**三元表达式**：

```python
# if 语句版本（用 def）
def f(x):
    if x >= 0:
        return x
    return -x

# lambda 版（三元）
f = lambda x: x if x >= 0 else -x
print(f(5), f(-5))   # 5 5
```

### 1. 多元嵌套（慎用）

```python
grade = lambda s: "A" if s >= 90 else "B" if s >= 75 else "C"
print(grade(95), grade(80), grade(50))   # A B C
```

→ 嵌套三元让 lambda 变长变难读，破例了就改 def。

### 2. 用 and/or 模拟（不推荐）

```python
# 旧式：利用短路
f = lambda x: x > 0 and "正" or "非正"
# 这种写法有陷阱（当 x>0 时 and 短路到 "正"， Truethy 返回 "正"）
# 但若结果是 falsy 的就坏掉，不推荐用这种"技巧"
```

→ Python 提倡显式的三元表达式。

## Lambda 陷阱

### 1. 闭包延迟绑定（最常见）

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])   # [2, 2, 2]

# 修复
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])   # [0, 1, 2]
```

### 2. lambda 不能有语句

```python
# f = lambda x: x = 1       # SyntaxError - 不能赋值
# f = lambda x: import os   # SyntaxError - 不能 import
# f = lambda x: return 1    # SyntaxError - 不能 return
```

### 3. lambda 默认名都是 <lambda>

```python
f = lambda x: x
print(f.__name__)          # <lambda>
# 调试栈里看不到有意义的名字，难追踪
```

### 4. lambda 在循环中常捕获错的值

```python
# 想给每个按钮传不同值（典型 GUI 陷阱）
# for i in range(5):
#     buttons[i].command = lambda: print(i)
# 点哪个都是打印 4（最后一个 i）

# 修复：默认参数
# for i in range(5):
#     buttons[i].command = lambda i=i: print(i)
```

### 5. lambda 不是为放在变量里设计的

```python
# 不推荐：
square = lambda x: x * x   # 没有名字、没有 docstring

# 推荐
def square(x):
    """返回平方。"""
    return x * x
```

PEP 8 明确建议：**若 lambda 用于赋值给一个变量名，则用 def 替代**。

## 不该用 Lambda 的场景

### 1. 长表达式

```python
# 差
sorted(users, key=lambda u: (u["age"], u["score"], u["name"], -u["id"]))

# 好
def sort_key(u):
    return (u["age"], u["score"], u["name"], -u["id"])
sorted(users, key=sort_key)
```

### 2. 需要的不仅是单个表达式

```python
# 差
process = lambda data: (
    [x * 2 for x in data if x > 0] if data else []
)

# 好
def process(data):
    if not data:
        return []
    return [x * 2 for x in data if x > 0]
```

### 3. 需要名字和 docstring 方便调试

```python
# 差：栈里只有 <lambda>
handler = lambda e: handle_event(e)

# 好
def click_handler(e):
    """处理点击事件。"""
    return handle_event(e)
```

### 4. 复杂状态需要 nonlocal 修改

### 5. 需要类型注解

```python
# lambda 不能写注解
# f = lambda x: int: x + 1   # 语法不允许

# def 可以
def f(x: int) -> int:
    return x + 1
```

### 6. 给变量命名时

PEP 8：

```python
# 不推荐（PEP 8 E731）
f = lambda x: x + 1

# 推荐
def f(x):
    return x + 1
```

## 常见错误与陷阱

### 1. SyntaxError：体不能有语句

```python
# lambda x: return x         # SyntaxError
lambda x: x + 1              # OK
```

### 2. 闭包延迟绑定

见上文。

### 3. lambda 没 return 关键字

```python
# lambda x: return x + 1     # SyntaxError
lambda x: x + 1              # OK - 隐式 return 表达式值
```

### 4. 立即调用方法链难读

```python
# 难读
result = (lambda x: (lambda y: x + y))(1)(2)   # 3

# 改 def
def add(x):
    def f(y):
        return x + y
    return f
print(add(1)(2))   # 3
```

### 5. 多行 lambda 不存在

```python
# 不支持多行 lambda
# f = lambda x:
#     a = x + 1
#     b = a * 2
#     return b      # SyntaxError 一切
```

### 6. 用 assignment expression ( walrus )

Python 3.8+ 引入 `:=`，让 lambda 可以"赋值"：

```python
# Python 3.8+
data = [1, 2, 3, 4]
# 想 filter 后的剩余
f = lambda lst: [y for x in lst if (y := x ** 2) > 1]
print(f(data))   # [4, 9, 16]
```

这是合法的，但不必为赋值硬塞 lambda。

## 最佳实践

### 1. 短、一次性、立即传高阶函数

```python
# 这是 lambda 的甜蜜区
sorted(users, key=lambda u: u["age"])
list(map(lambda x: x * 2, nums))
```

### 2. 长了就改 def

```python
# 复杂就别用 lambda
def key_func(o):
    return (o.priority, -o.timestamp)

process_queue(queue, key=key_func)
```

### 3. 给函数命名用 def

PEP 8 E731：不要把 lambda 赋值给变量名。

### 4. 避免闭包延迟绑定

```python
# 默认参数捕获
funcs = [lambda i=i: i for i in range(3)]
```

### 5. 用 operator 替代某些 lambda

```python
from operator import itemgetter, attrgetter, methodcaller

# 替代 lambda u: u["age"]
sorted(users, key=itemgetter("age"))

# 替代 lambda u: u.age
sorted(users, key=attrgetter("age"))

# 替代 lambda s: s.upper()
result = list(map(methodcaller("upper"), ["a", "b"]))
```

### 6. GUI 回调用默认参数

```python
for i in range(5):
    btn = Button(command=lambda i=i: do(i))
```

---

## 小结

- `lambda 参数: 表达式` 创建匿名函数
- 体只能是**单个表达式**，隐式返回
- 适合短小、一次性、传给高阶函数的场景
- 不要把它赋给变量命名（用 def），PEP 8 反对
- 长逻辑、需要语句/注解/docstring 时改用 def
- 闭包延迟绑定用默认参数修复
- 简单 lambda 可换用 operator 模块的现成函数
