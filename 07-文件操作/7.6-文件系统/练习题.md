# 7.6 文件系统练习题

## 一、概念题

1. `os.listdir()`、`os.scandir()`、`Path.iterdir()` 三者在返回类型和性能上有什么区别？为什么 `scandir` 通常更快？
2. `os.walk()` 中 `topdown=True` 和 `topdown=False` 有什么区别？为什么只有 `topdown=True` 时才能通过修改 `dirnames` 剪枝？
3. `os.mkdir()`、`os.makedirs()`、`Path.mkdir()` 在处理「父目录不存在」和「目录已存在」两种情况时分别是什么行为？
4. `os.rmdir()` 与 `shutil.rmtree()` 的适用场景有什么不同？为什么说 `rmtree` 是危险操作？
5. `shutil.copyfile()`、`shutil.copy()`、`shutil.copy2()`、`shutil.copytree()` 各自复制了哪些内容？
6. `os.rename()` 和 `os.replace()` 在「目标已存在」时的行为有何差异？为什么原子写入应该选 `os.replace()`？
7. `os.stat()` 返回结果中的 `st_mtime`、`st_atime`、`st_ctime` 分别代表什么？`st_ctime` 在 Unix 和 Windows 上含义为什么不同？
8. 什么是 TOCTOU 竞态条件？为什么「先 `os.path.exists()` 判断，再操作」不能完全避免出错？
9. `tempfile.NamedTemporaryFile` 与 `tempfile.mkstemp` 在自动清理上有什么区别？
10. 举例说明大小写敏感性在 macOS/Windows 与 Linux 上的差异，以及它可能给跨平台代码带来什么问题。

## 二、判断代码输出

```python

# 目录结构：root/ a/ b/ c/
for dirpath, dirnames, filenames in os.walk("root"):
    dirnames = [d for d in dirnames if d != "c"]   # 注意：重新绑定而非切片赋值
    print(dirpath, dirnames)
```

预测这段代码是否真的跳过了 `c` 目录的遍历，并说明原因，写出正确写法应该是什么。

### 2. `os.rename` 覆盖行为

```python
import os

with open("new.txt", "w") as f:
    f.write("new")
with open("old.txt", "w") as f:
    f.write("old")

os.rename("old.txt", "new.txt")
```

分别说明这段代码在 Linux/macOS 与 Windows 上运行结果是否一致，如果想让两个平台行为一致，应该改用哪个函数？

### 3. 临时目录生命周期

```python
import tempfile
import os

with tempfile.TemporaryDirectory() as tmpdir:
    path = os.path.join(tmpdir, "a.txt")
    with open(path, "w") as f:
        f.write("hi")
    saved_path = path

print(os.path.exists(saved_path))
```

写出最后一行的输出，并解释原因。

### 4. `copytree` 目标已存在

## 三、编程题

### 1. 安全递归删除

编写函数 `safe_rmtree(path, dry_run=True)`：

- `dry_run=True` 时只打印将要删除的所有文件/目录路径，不真正执行删除；
- `dry_run=False` 时才真正调用 `shutil.rmtree`；
- 删除前校验 `path` 必须是绝对路径且不能是根目录或用户主目录，防止误删；
- 捕获权限错误并给出清晰提示，允许通过回调修正权限后重试。

### 2. 目录树统计

实现 `dir_stats(root)`：

- 使用 `os.walk()` 遍历整棵目录树；
- 返回 `(文件总数, 目录总数, 总字节数)`；
- 跳过 `.git`、`__pycache__`、`.venv` 等目录（不进入这些子树，注意剪枝写法）；
- 对无法访问的子目录（权限不足）不中断整体统计，只记录警告。

### 3. 按扩展名归档

编写 `archive_by_extension(src_dir, dst_dir)`：

- 遍历 `src_dir` 下的所有文件（含子目录）；
- 按扩展名分类，把文件复制到 `dst_dir/<扩展名>/` 下（用 `os.makedirs(exist_ok=True)` 创建子目录）；
- 无扩展名的文件归入 `dst_dir/no_ext/`；
- 使用 `shutil.copy2` 保留原始的修改时间；
- 目标文件已存在时自动加数字后缀避免覆盖（如 `a.txt` → `a_1.txt`）。

### 4. 原子配置写入器

实现 `save_config(path, data: dict)`：

- 把 `data` 序列化为文本（可用简单的 `key=value` 格式，或调用 `json.dumps`）；
- 先写入与 `path` 同目录下的临时文件（用 `tempfile.mkstemp`）；
- 写入成功后用 `os.replace()` 原子替换目标文件；
- 写入过程中如果发生异常，确保临时文件被清理，且原 `path` 内容不受影响；
- 编写一个简单的测试：模拟写入中途抛异常，验证原文件内容仍然完整。

## 四、综合实践：项目目录清理与备份工具

编写一个命令行小工具，用于清理并备份项目目录，要求：

1. 输入一个项目根目录路径，使用 `os.walk()` 遍历，剪枝跳过 `.git`、`__pycache__`、`node_modules`、`.venv`；
2. 找出所有 `*.pyc`、`*.log`、`__pycache__` 目录，统计总大小（用 `os.stat` 累加 `st_size`），打印清理前的预估释放空间；
3. 提供 `--dry-run` 模式，只打印将删除的文件列表不实际删除；非 dry-run 模式下调用 `os.remove`/`shutil.rmtree` 真正清理，并对权限错误做容错处理；
4. 清理完成后，用 `shutil.copytree(src, dst, dirs_exist_ok=True)` 把项目目录（排除已清理的缓存文件）备份到指定的备份目录，备份目录名带时间戳（如 `backup_20260724_153000`）；
5. 备份过程使用 `shutil.disk_usage()` 检查备份目标所在磁盘的剩余空间，剩余空间不足时提前报错终止，不做半截备份；
6. 全程记录一份操作日志，日志写入采用「临时文件 + `os.replace()`」的原子写入模式，防止程序中途崩溃导致日志损坏；
7. 思考并在注释中说明：如果清理和备份过程中另一个进程正在修改项目文件，你的工具可能遇到哪些竞态问题？哪些地方应该用 try/except 而不是提前判断存在性？
