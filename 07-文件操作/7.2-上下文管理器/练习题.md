## 二、判断代码输出

### 1. 异常与清理顺序

```python
class Resource:
    def __init__(self, name):
        self.name = name
    def __enter__(self):
        print(f"enter {self.name}")
        return self
    def __exit__(self, *exc):
        print(f"exit {self.name}")
        return False

with Resource("A") as a, Resource("B") as b:
    print("using")
    raise ValueError("boom")
```

写出输出序列，并说明异常是否被吞掉。

### 2. contextmanager 的异常语义

```python
from contextlib import contextmanager

@contextmanager
def logged(name):
    print(f"before {name}")
    try:
        yield name
    finally:
        print(f"after {name}")

with logged("x") as v:
    print(v)
    raise RuntimeError("oops")
```

预言输出，并标出 `after x` 是否一定会打印。

### 3. suppress

```python
from contextlib import suppress

with suppress(ZeroDivisionError):
    print("start")
    print(1 / 0)
    print("never")
print("end")
```

写出输出，并解释为什么 `never` 不会出现而 `end` 会出现。

### 4. 退出后引用

```python
with open("x.txt", "w", encoding="utf-8") as f:
    f.write("hi")

print(f.closed)
f.write("again")
```

预言输出，并指出第二行会抛出什么异常。

## 三、编程题

### 1. 磁盘计时上下文

实现 `disk_timer(label)`：

- 进入时记录起始时间；
- 退出时打印 `label` 与耗时（毫秒）；
- 异常路径也要打印耗时，并在退出时传播异常；
- 同时实现类版本与 `@contextmanager` 版本。

### 2. 自动新建父目录的文件

实现 `opened(path, mode="w", encoding="utf-8")`：

- 打开前若父目录不存在，自动 `pathlib.Path(path).parent.mkdir(parents=True, exist_ok=True)`；
- 返回文件对象，并保证 `with` 退出时关闭；
- 若创建父目录失败，不应留下半开的文件描述符。

### 3. 临时工作目录

实现 `within_temp_dir(prefix="work-")`：

- 进入时用 `tempfile.mkdtemp(prefix=prefix)` 创建临时目录；
- 把当前工作目录切到该目录；
- 退出时切回原目录并 `shutil.rmtree` 清空，无论是否异常；
- 通过 `as` 变量返回该临时目录路径。

### 4. ExitStack 动态资源

给定一组日志文件名（运行时确定，数量可变）：

- 用 `ExitStack` 同时打开它们用于读取；
- 找出所有出现过 `ERROR` 的文件名；
- 退出时确保全部正确关闭；
- 处理其中某些文件不存在的情况（该文件跳过，其余继续）。

## 四、综合实践：带锁的批处理文件

设计一个工具，按以下步骤处理某目录下所有 `*.dat` 二进制文件：

1. 用 `ExitStack` 同时打开一个汇总报告文件与若干数据文件；
2. 进入处理前获取文件锁（用 `with open(lock_path, "x")` 模拟独占）；
3. 处理中途发生异常时，记录到错误日志文件但不中断其余文件；
4. 全程使用上下文管理器封装「打开—锁定—处理—关闭—解锁」；
5. 任何情况下都不应留下锁文件未释放；
6. 给出至少两种实现：类实现与 `@contextmanager` 实现，并比较可读性。
