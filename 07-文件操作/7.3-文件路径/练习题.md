# 7.3 文件路径练习题

## 一、概念题

1. `os.path` 与 `pathlib` 两套方案分别面向什么编程范式？各自的典型使用场景是什么？
2. 为什么不应该用字符串拼接（如 `a + "/" + b`）来构造路径？`os.path.join` 和 `Path` 的 `/` 运算符分别如何解决这个问题？
3. `os.path.join("a", "/b", "c")` 的结果是什么？为什么会这样？
4. `PurePath`（如 `PurePosixPath`）与 `Path` 有什么本质区别？举一个只能用 `PurePath` 而不便用 `Path` 的场景。
5. `Path` 对象的 `stem` 与 `suffix` 属性对 `"archive.tar.gz"` 分别返回什么？如何拿到第二层扩展名 `.tar`？
6. `resolve()` 和 `absolute()` 有什么区别？`resolve(strict=True)` 与默认调用又有什么区别？
7. `relative_to()` 与 `is_relative_to()` 在使用体验上有什么不同？分别适合什么场景？
8. 为什么两个字符串不同但代表同一位置的 `Path` 对象（如 `Path("a/./b")` 与 `Path("a/b")`）默认比较结果是 `False`？如何让比较更可靠？
9. 简述路径穿越（path traversal）风险产生的原因，以及如何用 `resolve()` + `is_relative_to()` 防范。
10. Windows 与 POSIX 系统在路径分隔符、大小写敏感性上有什么差异？这对跨平台代码有什么要求？

## 二、判断代码输出

### 1. `join` 与绝对路径

```python
import os.path

r1 = os.path.join("a", "b", "c")
r2 = os.path.join("a", "/b", "c")
r3 = os.path.join("/a", "b", "/c")
print(r1)
print(r2)
print(r3)
```

写出三行输出，并说明 `os.path.join` 遇到绝对路径参数时的规则。

### 2. `stem`/`suffix` 与多重扩展名

```python
from pathlib import Path

p = Path("2026-report.final.tar.gz")
print(p.name)
print(p.stem)
print(p.suffix)
print(p.suffixes)
```

写出四行输出，并解释为什么 `stem` 里仍然残留了部分扩展名。

### 3. `Path` 的相等与哈希

```python
from pathlib import Path

a = Path("data") / "2026" / "report.csv"
b = Path("data/2026/report.csv")
c = Path("data/./2026/report.csv")

print(a == b)
print(a == c)
print(len({a, b, c}))
```

预言三行输出，并说明为什么 `c` 的比较结果与前两个不同。

### 4. `relative_to` 抛异常的场景

```python
from pathlib import Path

base = Path("/srv/app/data")
target = Path("/srv/app/logs/app.log")

try:
    rel = target.relative_to(base)
    print(rel)
except ValueError as e:
    print("出错:", e)

print(target.is_relative_to(base))
```

写出输出，并说明为什么 `relative_to` 这里会走到 `except` 分支，而 `is_relative_to` 不会抛异常。

## 三、编程题

### 1. 安全的路径拼接器

编写函数 `safe_join(base, *parts)`：

- 使用 `Path` 拼接 `base` 与若干 `parts`；
- 拼接后调用 `resolve()` 得到绝对路径；
- 用 `is_relative_to()` 校验结果仍在 `base` 之下，不满足则抛 `ValueError("疑似路径穿越")`；
- 返回校验通过的 `Path` 对象。

### 2. 批量重命名工具

实现函数 `batch_rename(directory, pattern, new_suffix)`：

- 用 `Path(directory).glob(pattern)` 找出匹配的文件；
- 把每个文件的扩展名替换为 `new_suffix`（如 `.txt` → `.md`），文件名主体不变；
- 若目标文件名已存在，跳过并记录到返回的列表中，不覆盖已有文件；
- 返回 `(重命名成功的文件列表, 跳过的文件列表)`。

### 3. 目录大小统计器

编写函数 `dir_size(path)`：

- 使用 `Path(path).rglob("*")` 递归遍历所有子项；
- 只累加普通文件（`is_file()`）的 `stat().st_size`；
- 跳过符号链接指向的目标，不重复计入；
- 目录不存在时抛 `FileNotFoundError` 并给出清晰提示。

### 4. 跨平台路径展示器

实现函数 `describe_path(path)`，返回一个字典，包含以下键：

- `absolute`：绝对路径字符串；
- `posix`：无论平台如何都以 `/` 表示的字符串（用 `as_posix()`）；
- `parent`：父目录字符串；
- `name`、`stem`、`suffix`；
- `exists`、`is_file`、`is_dir`。

要求全程使用 `pathlib`，不得使用 `os.path`。

## 四、综合实践：静态资源服务器路径校验

你正在为一个简易静态文件服务器编写路径解析逻辑，用户请求会带来一个「相对路径」字符串（如 `img/logo.png` 或恶意的 `../../etc/passwd`），要求实现一套完整的路径处理流程：

1. 定义服务根目录 `ROOT = Path("static").resolve()`，作为唯一允许访问的范围；
2. 编写函数 `resolve_request(user_path)`：把 `ROOT` 与用户传入的相对路径拼接，并 `resolve()` 得到绝对路径；
3. 用 `is_relative_to()` 校验结果仍在 `ROOT` 内，越界时抛 `PermissionError("非法访问路径")`；
4. 若目标不存在，抛 `FileNotFoundError`；若目标是目录而非文件，尝试拼接 `index.html` 作为默认文件；
5. 根据文件的 `suffix` 判断 MIME 类型（至少支持 `.html`、`.css`、`.js`、`.png`、`.jpg` 几种），无法识别的返回 `application/octet-stream`；
6. 用 `stat().st_mtime` 生成一个简单的缓存标记（如格式化为字符串），并返回 `(内容字节, MIME 类型, 缓存标记)` 三元组；
7. 编写至少 3 组测试用例：正常访问、`../` 路径穿越尝试、访问不存在的文件，验证每种情况都被正确处理。
