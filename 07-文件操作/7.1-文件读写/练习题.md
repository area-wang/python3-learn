# 7.1 文件读写练习题

## 一、概念题

1. `open()` 的 `mode` 参数有哪几种基本取值？`'w'` 与 `'a'` 的关键区别是什么？
2. `read()`、`readline()`、`readlines()` 在返回值和内存占用上有哪些差异？为什么大文件推荐直接迭代文件对象？
3. 文本模式和二进制模式下，`encoding`、`newline`、`seek`、`buffering` 的行为分别有什么不同？
4. 不指定 `encoding` 时 Python 会如何决定编码？为什么中文乱码常由此引起？
5. `newline=None` 与 `newline=""` 在写入时对换行符的处理有什么差别？
6. `write()` 返回值的含义是什么？为什么 `writelines()` 不会自动添加换行符？
7. `'x'` 模式解决了什么问题？它和 `'w'` 模式的差别在哪里？
8. `flush()` 能否保证另一进程立即看到数据？为什么？
9. 文件未关闭可能带来哪些后果？
10. 列举至少四种文件操作中常见的异常及其触发场景。

## 二、判断代码输出

### 1. 读写指针切换

```python
# data.txt 内容：hello world
with open("data.txt", "w+", encoding="utf-8") as f:
    f.write("hello world")
    f.write(" again")
    f.seek(0)
    print(f.read(5))
    print(f.read())
```

写出输出，并解释为什么 `seek(0)` 之后能读到完整内容。

### 2. 缓冲与刷新

```python
import sys

with open("out.txt", "w", encoding="utf-8") as f:
    f.write("A")
    f.flush()
    f.write("B")
print("closed")
```

分析 `with` 退出时发生了什么，写出 `out.txt` 的最终内容和程序输出。

### 3. 文本与二进制

```python
with open("x.txt", "w", encoding="utf-8") as f:
    f.write("中文")

with open("x.txt", "rb") as f:
    print(len(f.read()))
```

写出输出，并说明为什么这个数字不等于 2。

### 4. 追加与只读

```python
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("123")

with open("a.txt", "a", encoding="utf-8") as f:
    f.write("456")
    f.seek(0)
    print(f.read())
```

预言输出；如果你的预测与实际不符，说明 `'a'` 模式下 `seek` 与读取的关系。

## 三、编程题

### 1. 行数统计器

编写函数 `count_lines(path, encoding="utf-8")`：

- 使用文件对象迭代逐行读取，不把整个文件读入内存；
- 返回总行数；
- 处理空文件返回 `0`；
- 文件不存在时抛 `FileNotFoundError` 并打印友好提示。

### 2. 首尾行查看器

实现 `peek(path, n_head=3, n_tail=3)`：

- 只用一次打开，先读前 `n_head` 行；
- 再读出剩余直到末尾并保留最后 `n_tail` 行；
- 大文件时不能把所有行同时存内存，只能保留必要窗口；
- 返回 `(head_lines, tail_lines)`。

### 3. 安全写入器

实现函数 `safe_write(path, content)`：

- 用 `'w'` 模式写入时如果目标已存在，要求先确认覆盖；
- 使用 `'x'` 模式提供「不允许覆盖」的调用方式 `safe_write(path, content, must_create=True)`；
- 对 `IsADirectoryError`、`PermissionError` 分别给出不同提示信息；
- 退出前确保文件已关闭。

### 4. 文件编码嗅探

编写 `read_any_encoding(path)`：

- 先以 `'rb'` 读出前若干字节；
- 判断是否为 UTF-8 BOM、UTF-16 BOM、或纯 UTF-8；
- 选择对应 `encoding` 再以文本模式读取返回；
- 无法识别时退回 `errors="replace"` 的 UTF-8 读取。

## 四、综合实践：日志文件分割与采样

给定一个可能上 GB 的日志文件 `app.log`，每行格式：

```text
2026-07-20 10:00:01 INFO  service_a started
2026-07-20 10:00:05 ERROR service_b crashed
```

要求：

1. 用一次打开逐行扫描，统计 `INFO`、`WARN`、`ERROR` 各级别的行数；
2. 把所有 `ERROR` 行写到 `errors.log`，其余写到 `others.log`；
3. 同时把每第 1000 行采样到 `sample.log`；
4. 全程不得把整个文件读入内存；
5. 使用「独占创建」写一个 `DONE` 标记文件，重复运行时检测到标记直接退出；
6. 异常情况下保证不会产生半截写出的输出文件（提示：先写临时文件再重命名）；
7. 思考：如果日志在另一个进程仍在写入，你的读取是否会读到不完整的行？如何检测？
