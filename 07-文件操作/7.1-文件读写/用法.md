# 7.1 文件读写

文件读写是 Python 与外部数据交互最基础的入口。核心入口是内置函数 `open()`，它返回一个文件对象，再通过文件对象的方法完成读写。理解 `open()` 的参数、文件模式、文本与二进制的差异，是掌握后续所有文件操作的前提。

## 1. `open()` 函数总览

```python
f = open(file, mode='r', buffering=-1, encoding=None,
         errors=None, newline=None, closefd=True, opener=None)
```

参数说明：

| 参数 | 说明 |
|---|---|
| `file` | 文件路径（`str`、`bytes`）或已打开的文件描述符（整数）。 |
| `mode` | 打开模式，默认 `'r'`（只读文本）。 |
| `buffering` | 缓冲策略。`-1` 表示使用默认；`0` 关闭缓冲（仅二进制可用）；`1` 行缓冲（仅文本可用）；`>1` 设置缓冲区字节数。 |
| `encoding` | 文本模式使用的编码，默认 `None`（使用平台默认，通常是 UTF-8 或 GBK）。 |
| `errors` | 编解码错误处理策略，如 `'strict'`（默认）、`'ignore'`、`'replace'`、`'backslashreplace'`、`'surrogateescape'`。 |
| `newline` | 文本模式下的换行符处理，见第 6 节。 |
| `closefd` | 当 `file` 是文件描述符时，决定 `close()` 是否同时关闭底层描述符。 |
| `opener` | 自定义打开器，用于通过非默认方式打开（如打开相对父目录的文件）。 |

记住：`open()` 成功后一定要关闭文件，最佳实践是使用 `with` 语句（见 7.2）。

## 2. 文件模式 `mode`

基本模式（六种，互斥选择其一）：

| 模式 | 含义 | 文件不存在 | 文件已存在 |
|---|---|---|---|
| `'r'` | 只读（默认） | 抛 `FileNotFoundError` | 从头读 |
| `'w'` | 只写（覆盖） | 创建 | 清空原内容 |
| `'a'` | 追加写 | 创建 | 在末尾追加 |
| `'x'` | 独占创建 | 创建 | 抛 `FileExistsError` |
| `'r+'` | 读写（不截断） | 抛 `FileNotFoundError` | 保留原内容，指针在开头 |
| `'U'` | 通用换行（Python 3.11 起废弃，已合并到 `'r'`） | — | — |

附加修饰符（与基本模式组合）：

- `'t'`：文本模式（默认），如 `'rt'` 等价于 `'r'`。
- `'b'`：二进制模式，如 `'rb'`、`'wb'`、`'ab'`、`'r+b'`。
- `'+'`：打开更新模式（读写），如 `'r+'`、`'w+'`、`'a+'`、`'x+'`。

```python
# 文本只读
f = open("data.txt", "r", encoding="utf-8")

# 二进制只读
f = open("data.bin", "rb")

# 独占创建，避免覆盖
try:
    f = open("lock.txt", "x", encoding="utf-8")
except FileExistsError:
    print("文件已存在，未覆盖")
```

`'w'` 与 `'a'` 的关键区别：

- `'w'` 打开即清空，原有内容丢失；
- `'a'` 打开不清空，所有写入都追加到文件末尾，且对 `'a'` 模式 `seek()` 无效（写入永远落到末尾）。
- `'a+'` 虽然可读可写，但读前仍需 `seek(0)`，写入仍会回到末尾。

## 3. 读取方法

### 3.1 `read(size=-1)`

一次性读取全部或指定大小。文本模式 `size` 是字符数，二进制模式是字节数。

```python
with open("poem.txt", encoding="utf-8") as f:
    text = f.read()         # 读全部
    head = f.read(10)       # 读前 10 个字符
```

`read()` 不传参时把整个文件加载进内存，大文件慎用。`read(0)` 返回空字符串但不移动指针（某些实现）。

### 3.2 `readline(size=-1)`

读取一行（包含行尾换行符 `\n`），到达文件末尾返回 `''`。

```python
with open("log.txt", encoding="utf-8") as f:
    first = f.readline()
    second = f.readline()
```

`size` 限制本行最多读取的字符数，超长行会被截断，下一次 `readline` 从截断处继续。

### 3.3 `readlines(hint=-1)`

读取所有行并返回列表，每行保留换行符。`hint` 控制总字节数的近似上限。

```python
with open("users.txt", encoding="utf-8") as f:
    lines = f.readlines()
    # ['alice,30\n', 'bob,25\n', ...]
```

注意 `readlines()` 会把整个文件加载为列表，大文件应改用逐行迭代。

### 3.4 文件对象本身可迭代

最推荐的逐行读法：

```python
with open("big.csv", encoding="utf-8") as f:
    for line in f:
        process(line.rstrip("\n"))
```

这种方式是惰性的，内存占用恒定，且内部有读缓冲优化。

## 4. 写入方法

### 4.1 `write(text)`

写入字符串，返回写入的字符数（文本）或字节数（二进制）。`write` **不会自动加换行**，需要手工拼接 `\n`。

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("hello\n")
    f.write("world\n")
```

### 4.2 `writelines(lines)`

写入一个可迭代对象中的每一项，**不会自动添加换行符**，名字容易误导。

```python
lines = ["alpha\n", "beta\n", "gamma\n"]
with open("out.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
```

### 4.3 `print` 写入文件

`print` 提供更方便的格式化与换行控制，且不需要手工拼 `\n`：

```python
with open("out.txt", "w", encoding="utf-8") as f:
    print("name:", "alice", file=f)
    print("score:", 95, file=f, sep=" → ", end=";\n")
```

## 5. 文本模式与二进制模式

| 维度 | 文本模式（`'t'`/默认） | 二进制模式（`'b'`） |
|---|---|---|
| 读写类型 | `str` | `bytes` |
| `encoding` 参数 | 生效 | 忽略 |
| `newline` 换行转换 | 生效 | 不转换，原样读写 `\r\n` |
| `seek` 任意位置 | 受限（只能定位到换行边界或文件头） | 任意字节偏移 |
| 缓冲策略 | 不能 `buffering=0` | 可以 `buffering=0`（无缓冲） |

文本模式默认会对平台换行符做归一化：读入时把 `\r\n`、`\r` 都转换为 `\n`，写出时把 `\n` 转回平台换行符。二进制模式则原样保留。

## 6. `newline` 参数

`newline` 控制文本模式下的换行符转换行为：

| `newline` 取值 | 读入行为 | 写出行为 |
|---|---|---|
| `None`（默认） | 所有 `\r\n`、`\r` 都转换为 `\n` | `\n` 转换为平台换行符（`\r\n` on Windows） |
| `''` | 通用换行生效但不转换 | `\n` 不转换 |
| `'\n'` | 只按 `\n` 分行 | `\n` 不转换 |
| `'\r\n'` 或 `'\r'` | 按指定字符分行 | `\n` 转换为该字符 |

```python
# 读取 Windows 换行的文件，统一成 \n
with open("win.txt", encoding="utf-8", newline=None) as f:
    text = f.read()

# 写出原始 \n，不做平台转换（生成 LF 文件）
with open("unix.txt", "w", encoding="utf-8", newline="") as f:
    f.write("line1\nline2\n")
```

跨平台处理文本时，明确指定 `newline=""` 能避免意外的换行符变化。

## 7. `encoding` 与 `errors`

不指定 `encoding` 会使用 `locale.getpreferredencoding(False)` 的结果，这在不同系统、不同语言环境下不同，是中文乱码的常见根源。

```python
# 推荐：显式指定编码
with open("中文.txt", "w", encoding="utf-8") as f:
    f.write("你好，世界")

# 容错读取：忽略无法解码的字节
with open("混合.txt", encoding="utf-8", errors="ignore") as f:
    text = f.read()
```

`errors` 常用取值：

- `'strict'`：默认，编解码失败抛 `UnicodeDecodeError`；
- `'ignore'`：忽略错误字节；
- `'replace'`：用 `�` 替换；
- `'backslashreplace'`：用十六进制转义替换；
- `'surrogateescape'`：保留原始字节可用于无损往返。

## 8. 缓冲 `buffering`

- `buffering=0`：无缓冲，每次写入立即落盘（仅二进制可用）；
- `buffering=1`：行缓冲，遇到 `\n` 刷新（仅文本可用）；
- `buffering>1`：设置缓冲区大小（字节）；
- `buffering=-1`：使用默认（通常 4096 或 8192 字节，交互式文本是行缓冲）。

```python
# 行缓冲：每写一行就 flush，便于实时查看日志
with open("log.txt", "w", encoding="utf-8", buffering=1) as f:
    f.write("step 1\n")   # 立即可见
```

## 9. 刷新与关闭

### 9.1 `flush()`

把缓冲区中的数据强制写入底层流，但**不会**刷新操作系统的页缓存，跨进程可见性仍可能延迟。

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("写一点")
    f.flush()        # 落盘
    f.write("再写一点")
    # with 退出时再 flush+close
```

### 9.2 `close()`

关闭文件并释放系统资源，同时会自动 `flush()`。未关闭的文件：

- 系统文件描述符表会泄漏，长时间运行的程序可能触达 `Too many open files`；
- 缓冲区数据可能永远不会落盘，进程异常退出时丢失；
- 在 Windows 上文件被独占，其他进程无法访问。

### 9.3 `detach()`

把 `BufferedReader` 与底层原始流分离，关闭文件对象不会关闭底层描述符，高级用法居多。

## 10. 其他常用方法

| 方法 | 作用 |
|---|---|
| `fileno()` | 返回底层文件描述符（整数），可用于 `os`/`select`/`fcntl` 操作 |
| `isatty()` | 判断是否连接到终端类设备 |
| `readable()` / `writable()` / `seekable()` | 判断是否可读/可写/可定位 |
| `truncate(size=None)` | 截断文件到指定大小，不传参则截断到当前指针位置 |
| `name` | 文件名/路径属性 |
| `mode` | 打开模式属性 |
| `closed` | 是否已关闭 |
| `close()` | 关闭文件 |

```python
with open("out.txt", "r+b") as f:
    print(f.fileno())
    print(f.readable(), f.writable(), f.seekable())
    f.truncate(0)   # 清空文件
```

## 11. 常见异常

| 异常 | 触发场景 |
|---|---|
| `FileNotFoundError` | `'r'`/`'r+'` 打开不存在的文件 |
| `FileExistsError` | `'x'` 模式打开已存在的文件 |
| `PermissionError` | 权限不足或路径是目录 |
| `IsADirectoryError` | 打开了一个目录 |
| `UnicodeDecodeError` | 文本模式解码失败且 `errors='strict'` |
| `ValueError` | 对已关闭文件操作，或二进制用了 `buffering=1` |
| `OSError` | 其他 I/O 错误的基类 |

## 12. 本节小结

1. `open()` 是文件操作总入口，理解 `mode`/`encoding`/`newline`/`buffering` 后基本能覆盖大多数场景；
2. 始终用 `with` 语句管理文件生命周期，避免资源泄漏；
3. 大文本用「文件对象迭代」逐行读，避免 `read()`/`readlines()` 把整个文件塞进内存；
4. 中文文件务必显式指定 `encoding="utf-8"`，不要依赖平台默认；
5. `'w'` 会清空、`'a'` 只追加、`'x'` 用于独占创建——按需选择避免误删数据；
6. 二进制读写返回 `bytes`，文本返回 `str`，二者不能混用，类型错配会直接报错。
