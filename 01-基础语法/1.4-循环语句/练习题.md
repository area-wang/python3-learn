## 第八部分：常见陷阱（⭐⭐⭐）

### 26. 修改正在遍历的列表
```python
# 预测输出或错误
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    if num % 2 == 0:
        numbers.remove(num)
print(numbers)
```

<details>
<summary>答案</summary>

```
[1, 3, 5]
```

**解释**：虽然结果看起来正确，但过程有问题。当删除元素时，列表索引会变化，可能跳过某些元素。

**正确做法**：
```python
# 方法1：遍历副本
numbers = [1, 2, 3, 4, 5]
for num in numbers[:]:
    if num % 2 == 0:
        numbers.remove(num)

# 方法2：列表推导式（推荐）
numbers = [num for num in numbers if num % 2 != 0]
```
</details>

### 30. 字典遍历时修改
```python
# 预测输出或错误
d = {"a": 1, "b": 2, "c": 3}
for key in d:
    if d[key] == 2:
        del d[key]
```

<details>
<summary>答案</summary>

**错误**：`RuntimeError: dictionary changed size during iteration`

**解释**：不能在遍历字典时修改其大小。

**正确做法**：
```python
# 方法1：先收集要删除的键
to_delete = [key for key, value in d.items() if value == 2]
for key in to_delete:
    del d[key]

# 方法2：字典推导式（推荐）
d = {key: value for key, value in d.items() if value != 2}
```
</details>

```python
    primes = []
    for num in range(2, limit):
        is_prime = True
        for i in range(2, int(num ** 0.5) + 1):

                is_prime = False
```

```python
    while b != 0:

    return a
```

```python
def print_diamond(n):
    # 上半部分（包括中间）
    for i in range(n // 2 + 1):

        stars = "*" * (2 * i + 1)
        print(spaces + stars)
    
    # 下半部分
    for i in range(n // 2 - 1, -1, -1):
        spaces = " " * (n // 2 - i)
        stars = "*" * (2 * i + 1)
        print(spaces + stars)
```

### 42. 杨辉三角
编写函数 `pascal_triangle(n)`，生成杨辉三角的前 n 行。

<details>
<summary>答案</summary>

```python
def pascal_triangle(n):
    triangle = []
    for i in range(n):
        row = [1] * (i + 1)
        for j in range(1, i):
            row[j] = triangle[i-1][j-1] + triangle[i-1][j]
        triangle.append(row)
    return triangle

# 测试
for row in pascal_triangle(5):

# 输出:

# [1, 4, 6, 4, 1]
```

### 44. 完全数
编写函数 `find_perfect_numbers(limit)`，找出小于 limit 的所有完全数。
（完全数：等于其所有真因子之和，如 6 = 1 + 2 + 3）

<details>
<summary>答案</summary>

```python
def find_perfect_numbers(limit):
    perfect = []
    for num in range(2, limit):
        divisors = []
        for i in range(1, num):
            if num % i == 0:
                divisors.append(i)
        if sum(divisors) == num:
            perfect.append(num)
    return perfect

# 测试
print(find_perfect_numbers(10000))
# [6, 28, 496, 8128]
```
</details>

### 45. 两数之和
编写函数 `two_sum(nums, target)`，找出数组中和为 target 的两个数的索引。

<details>
<summary>答案</summary>

```python
def two_sum(nums, target):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
    return None

# 更高效的方法（使用字典）
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return None

# 测试
```
