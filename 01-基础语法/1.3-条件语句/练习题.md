### 11. elif 执行顺序
```python
# 预测输出
score = 85
if score >= 60:
    print("及格")
elif score >= 70:
    print("中等")
elif score >= 80:
    print("良好")

    print("优秀")
```

<details>
<summary>答案</summary>

```

```

**解释**：第一个条件 `score >= 60` 为真，输出 "及格" 后退出整个 if-elif 结构。后面的条件都不会判断。

**正确做法**：应该从严格到宽松排序：
```python
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 70:
    print("中等")
elif score >= 60:
    print("及格")
```
</details>

### 15. 短路求值应用
```python
# 预测输出或错误
x = 0
if x != 0 and 10 / x > 1:
    print("A")

# 如果改成这样会怎么样？

    print("B")
```

<details>
<summary>答案</summary>

- 先计算 `10 / x`，除零错误

**教训**：利用短路求值避免错误，将可能出错的条件放在后面。
</details>

### 20. is vs ==
```python
# 预测输出
a = [1, 2, 3]
b = [1, 2, 3]

if a == b:
    print("A")
if a is b:
    print("B")

x = 256
y = 256
if x is y:
    print("C")

m = 257
n = 257
if m is n:
    print("D")
```

<details>
<summary>答案</summary>

```
A
C
```

**解释**：
- `a == b`：值相等，输出 "A"
- `a is b`：不是同一对象，不输出
- `x is y`：小整数（-5 到 256）被缓存，是同一对象，输出 "C"
- `m is n`：大整数不缓存，不是同一对象，不输出（某些环境可能为 True）

**关键点**：
- `==` 比较值
- `is` 比较身份（内存地址）
</details>

### 27. BMI 计算与分类

- 18.5-23.9: 正常

```python
def calculate_bmi(weight, height):

        return "Invalid input"

        category = "偏瘦"
    elif bmi < 24:

        category = "偏胖"

# 测试
print(calculate_bmi(70, 1.75))  # BMI: 22.86, 分类: 正常
```

### 28. 密码强度检查
编写函数 `check_password_strength(password)`，检查密码强度：
- 弱：长度 < 6
- 中：长度 >= 6 且包含数字和字母
- 强：长度 >= 8 且包含数字、字母和特殊字符

<details>
<summary>答案</summary>

```python
def check_password_strength(password):
    length = len(password)
    has_digit = any(c.isdigit() for c in password)
    has_alpha = any(c.isalpha() for c in password)
    has_special = any(not c.isalnum() for c in password)
    
    if length < 6:
        return "弱"
    elif length >= 8 and has_digit and has_alpha and has_special:
        return "强"
    elif length >= 6 and has_digit and has_alpha:
        return "中"
    else:
        return "弱"

# 测试
print(check_password_strength("123"))          # 弱
print(check_password_strength("abc123"))       # 中
print(check_password_strength("Abc123!@"))     # 强
print(check_password_strength("abcdefgh"))     # 弱（没有数字）
```
</details>

### 29. 最大值的多种写法
不使用 `max()` 函数，编写函数 `find_max(a, b, c)`，找出三个数中的最大值。
至少给出 3 种不同的实现方式。

<details>
<summary>答案</summary>

```python
# 方法1：传统 if-elif-else
def find_max_v1(a, b, c):
    if a >= b and a >= c:
        return a
    elif b >= a and b >= c:
        return b
    else:
        return c

# 方法2：嵌套三元表达式
def find_max_v2(a, b, c):
    return a if a >= b and a >= c else (b if b >= c else c)

# 方法3：两两比较
def find_max_v3(a, b, c):
    max_ab = a if a >= b else b
    max_abc = max_ab if max_ab >= c else c
    return max_abc

# 方法4：使用列表排序（虽然题目说不用 max，但可以用其他方法）
def find_max_v4(a, b, c):
    return sorted([a, b, c])[-1]

# 测试
print(find_max_v1(1, 5, 3))  # 5
print(find_max_v2(1, 5, 3))  # 5
print(find_max_v3(1, 5, 3))  # 5
print(find_max_v4(1, 5, 3))  # 5
```

### 32. 石头剪刀布
编写函数 `rock_paper_scissors(player1, player2)`，判断胜负：
- 返回 "Player 1 wins", "Player 2 wins", 或 "Tie"

<details>
<summary>答案</summary>

```python
def rock_paper_scissors(player1, player2):
    if player1 == player2:
        return "Tie"
    
    # Player 1 获胜的情况
    if (player1 == "rock" and player2 == "scissors") or \
       (player1 == "scissors" and player2 == "paper") or \
       (player1 == "paper" and player2 == "rock"):
        return "Player 1 wins"
    else:
        return "Player 2 wins"

# 测试
print(rock_paper_scissors("rock", "scissors"))  # Player 1 wins
print(rock_paper_scissors("rock", "paper"))     # Player 2 wins
print(rock_paper_scissors("rock", "rock"))      # Tie
```
</details>

### 33. 条件表达式优化
以下代码有性能问题，请优化：

```python
def process(data):
    if expensive_check1(data):
        if expensive_check2(data):
            if expensive_check3(data):
                return True
    return False
```

假设这些检查函数很耗时，如何优化？

<details>
<summary>答案</summary>

```python
# 优化：利用 and 短路求值
def process(data):
    return expensive_check1(data) and \
```
