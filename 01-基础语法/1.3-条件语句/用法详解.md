## 1. 条件语句基础

### 1.1 什么是条件语句
条件语句用于根据不同的条件执行不同的代码块。Python 使用缩进（通常是 4 个空格）来定义代码块。

```python
if 条件:
    # 条件为真时执行的代码
    pass
```

### 1.2 缩进规则
⚠️ **Python 的缩进非常重要**：
```python
# ✅ 正确：使用 4 个空格缩进
if True:
    print("正确")

# ❌ 错误：没有缩进
if True:
print("错误")  # IndentationError

# ❌ 错误：混用空格和制表符
if True:
    print("错误")  # 可能出问题
```

**最佳实践**：
- 使用 4 个空格缩进（不要用 Tab）
- 同一代码块的缩进必须一致
- 大多数编辑器可以配置 Tab 自动转为空格

## 2. if 语句

### 2.1 基本语法
```python
if 条件表达式:
    语句块
```

### 2.2 单条件判断
```python
age = 18

if age >= 18:
    print("你已成年")

# 输出: 你已成年
```

### 2.3 多条语句
```python
score = 85

if score >= 60:
    print("考试及格")
    print("分数是:", score)
    print("继续努力")
```

### 2.4 条件表达式
```python
# 比较运算符
x = 10
if x > 5:
    print("x 大于 5")

# 逻辑运算符
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("可以进入")

# 成员运算符
name = "Python"
if "P" in name:
    print("包含字母 P")
```

## 3. if-else 语句

### 3.1 基本语法
```python
if 条件表达式:
    语句块1
else:
    语句块2
```

### 3.2 二选一结构
```python
age = 16

if age >= 18:
    print("你已成年")
else:
    print("你未成年")

# 输出: 你未成年
```

### 3.3 实际应用示例
```python
# 判断奇偶数
num = 7
if num % 2 == 0:
    print(f"{num} 是偶数")
else:
    print(f"{num} 是奇数")

# 判断登录状态
is_logged_in = False
if is_logged_in:
    print("欢迎回来")
else:
    print("请先登录")
```

## 4. if-elif-else 语句

### 4.1 基本语法
```python
if 条件1:
    语句块1
elif 条件2:
    语句块2
elif 条件3:
    语句块3
else:
    语句块4
```

### 4.2 多条件判断
```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"成绩等级: {grade}")
# 输出: 成绩等级: B
```

### 4.3 执行顺序
⚠️ **重要**：条件从上到下依次判断，一旦某个条件为真，执行对应代码块后就退出整个 if-elif-else 结构。

```python
x = 95

# ✅ 正确：从高到低判断
if x >= 90:
    print("优秀")  # 执行这里
elif x >= 80:
    print("良好")  # 不会执行
elif x >= 60:
    print("及格")  # 不会执行

# ❌ 错误：顺序不当
if x >= 60:
    print("及格")  # 执行这里就退出了
elif x >= 80:
    print("良好")  # 永远不会执行
elif x >= 90:
    print("优秀")  # 永远不会执行
```

### 4.4 实际应用示例

#### 温度提示
```python
temperature = 28

if temperature >= 35:
    print("高温预警，注意防暑")
elif temperature >= 25:
    print("天气炎热")
elif temperature >= 15:
    print("温度适宜")
elif temperature >= 0:
    print("天气寒冷")
else:
    print("严寒，注意保暖")
```

#### BMI 计算器
```python
weight = 70  # kg
height = 1.75  # m
bmi = weight / (height ** 2)

if bmi < 18.5:
    category = "偏瘦"
elif bmi < 24:
    category = "正常"
elif bmi < 28:
    category = "偏胖"
else:
    category = "肥胖"

print(f"BMI: {bmi:.2f}, 分类: {category}")
```

## 5. 嵌套条件语句

### 5.1 基本概念
在条件语句内部再包含条件语句，称为嵌套条件语句。

### 5.2 基本示例
```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("可以进入")
    else:
        print("请先购票")
else:
    print("未成年不能进入")
```

### 5.3 避免过深嵌套
❌ **不推荐**：嵌套太深，难以阅读
```python
if condition1:
    if condition2:
        if condition3:
            if condition4:
                print("太深了")
```

✅ **推荐**：使用逻辑运算符简化
```python
if condition1 and condition2 and condition3 and condition4:
    print("清晰多了")
```

✅ **推荐**：提前返回（早返回模式）
```python
def check_user(age, has_ticket):
    if age < 18:
        return "未成年不能进入"
    
    if not has_ticket:
        return "请先购票"
    
    return "可以进入"
```

## 6. 三元表达式

### 6.1 基本语法
```python
值1 if 条件 else 值2
```

### 6.2 基本示例
```python
age = 20

# 传统写法
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 三元表达式
status = "成年" if age >= 18 else "未成年"
```

### 6.3 实际应用
```python
# 取最大值
a, b = 10, 20
max_value = a if a > b else b

# 判断奇偶
num = 7
parity = "奇数" if num % 2 == 1 else "偶数"

# 设置默认值
name = input("请输入姓名: ").strip()
name = name if name else "匿名用户"
```

### 6.4 嵌套三元表达式
⚠️ **可以嵌套，但不推荐过度使用**：

```python
score = 85

# ❌ 不推荐：难以阅读
grade = "A" if score >= 90 else "B" if score >= 80 else "C" if score >= 70 else "D" if score >= 60 else "F"

# ✅ 推荐：使用 if-elif-else
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
```

## 7. 布尔运算与短路求值

### 7.1 逻辑运算符
| 运算符 | 说明 | 示例 |
|--------|------|------|
| `and` | 逻辑与（且） | `x > 0 and x < 10` |
| `or` | 逻辑或（或） | `x < 0 or x > 10` |
| `not` | 逻辑非（非） | `not is_empty` |

### 7.2 and 运算符
```python
# 所有条件都为真，结果才为真
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("可以进入")
```

### 7.3 or 运算符
```python
# 只要有一个条件为真，结果就为真
is_vip = False
has_coupon = True

if is_vip or has_coupon:
    print("可以享受折扣")
```

### 7.4 短路求值（重要）
**短路求值**：一旦能确定结果，就不再计算后面的表达式。

```python
# and：如果第一个为 False，不再计算第二个
x = 0
if x != 0 and 10 / x > 1:  # x != 0 为 False，不会计算 10 / x
    print("不会执行")

# or：如果第一个为 True，不再计算第二个
if True or check():  # True，不会调用 check()
    print("会执行")

# 设置默认值
name = ""
display_name = name or "匿名用户"  # name 为空字符串（False），使用默认值
print(display_name)  # 匿名用户
```

## 8. 真值测试

### 8.1 假值（Falsy）
以下值在布尔上下文中被视为 `False`：

```python
# 数值零
if not 0:
    print("0 是 False")

if not 0.0:
    print("0.0 是 False")

# None
if not None:
    print("None 是 False")

# 空序列和集合
if not "":
    print("空字符串是 False")

if not []:
    print("空列表是 False")

if not ():
    print("空元组是 False")

if not {}:
    print("空字典是 False")
```

### 8.2 真值（Truthy）
除了假值以外的所有值都被视为 `True`：

```python
# 非零数值
if 1:
    print("非零数是 True")

# 非空序列
if "hello":
    print("非空字符串是 True")

if [0]:
    print("包含元素的列表是 True（即使元素是 0）")
```

### 8.3 真值测试的应用

#### 检查容器是否为空
```python
# ✅ 推荐：直接判断
my_list = []
if not my_list:
    print("列表为空")

# ❌ 不推荐：显式比较
if len(my_list) == 0:
    print("列表为空")
```

#### 检查 None
```python
# ✅ 推荐：使用 is
result = None
if result is None:
    print("result 是 None")

# ⚠️ 注意：不要混淆 None 和空容器
result = []
if not result:
    print("空列表，但不是 None")
```

## 9. 条件表达式的技巧

### 9.1 链式比较
```python
x = 5

# 传统写法
if x > 0 and x < 10:
    print("x 在 0 到 10 之间")

# 链式比较（推荐）
if 0 < x < 10:
    print("x 在 0 到 10 之间")

# 更多示例
age = 25
if 18 <= age <= 60:
    print("工作年龄")
```

### 9.2 in 和 not in
```python
# 检查成员
char = 'a'
if char in 'aeiou':
    print("是元音字母")

# 检查列表
status = "pending"
if status in ["pending", "processing"]:
    print("订单处理中")

# 检查字典键
user = {"name": "张三", "age": 25}
if "email" not in user:
    print("未设置邮箱")
```

### 9.3 多值匹配
```python
# 传统写法
status = "error"
if status == "error" or status == "failed" or status == "timeout":
    print("请求失败")

# ✅ 推荐：使用 in
if status in ("error", "failed", "timeout"):
    print("请求失败")
```

### 9.4 any() 和 all()
```python
# any()：只要有一个为 True，返回 True
numbers = [0, 0, 1, 0]
if any(numbers):
    print("至少有一个非零数")

# all()：所有都为 True，返回 True
scores = [85, 90, 78, 92]
if all(score >= 60 for score in scores):
    print("全部及格")
```

## 10. 常见错误与陷阱

### 10.1 赋值 vs 比较
```python
x = 10

# ❌ 错误：使用 = 而不是 ==
if x = 10:  # SyntaxError
    print("错误")

# ✅ 正确：使用 ==
if x == 10:
    print("正确")
```

### 10.2 浮点数比较
```python
# ⚠️ 浮点数精度问题
a = 0.1 + 0.2
if a == 0.3:
    print("不会执行")  # 因为 a = 0.30000000000000004

# ✅ 正确：使用容差比较
import math
if math.isclose(a, 0.3):
    print("会执行")
```

### 10.3 可变对象的比较
```python
# 列表比较
list1 = [1, 2, 3]
list2 = [1, 2, 3]

if list1 == list2:
    print("值相等")  # 会执行

if list1 is list2:
    print("是同一对象")  # 不会执行

# ⚠️ 注意：is 用于比较身份，== 用于比较值
```

### 10.4 空容器判断
```python
# ✅ 推荐：利用真值测试
my_list = []
if not my_list:
    print("列表为空")

# ❌ 不推荐：显式比较长度
if len(my_list) == 0:
    print("列表为空")
```

### 10.5 None 判断
```python
value = None

# ✅ 正确：使用 is
if value is None:
    print("value 是 None")

# ❌ 不推荐：使用 ==
if value == None:
    print("虽然能工作，但不推荐")
```

### 10.6 布尔值与 1/0 的混淆
```python
# Python 中 True == 1, False == 0
print(True == 1)   # True
print(False == 0)  # True

# ⚠️ 可能导致意外行为
my_list = [False, 0, "", None]
print(my_list.count(False))  # 2（False 和 0 都被计数）
```

### 10.7 逻辑运算符返回值
```python
# ⚠️ and 和 or 返回的是操作数，不是 True/False

# and 返回第一个假值或最后一个真值
result = 10 and 20
print(result)  # 20（不是 True）

# or 返回第一个真值或最后一个假值
result = 10 or 20
print(result)  # 10（不是 True）

# 实际应用：设置默认值
name = ""
display_name = name or "匿名用户"  # "匿名用户"
```

### 10.8 缩进错误
```python
# ❌ 常见错误：缩进不一致
age = 20
if age >= 18:
    print("成年")
  print("可以投票")  # IndentationError

# ✅ 正确：保持一致的缩进
if age >= 18:
    print("成年")
    print("可以投票")
```

### 10.9 忘记冒号
```python
# ❌ 常见错误：忘记冒号
if x > 10
    print("错误")  # SyntaxError

# ✅ 正确：记得加冒号
if x > 10:
    print("正确")
```

### 10.10 条件顺序问题
```python
x = 95

# ❌ 错误：条件顺序不当
if x >= 60:
    print("及格")  # 会执行这里
elif x >= 80:
    print("良好")  # 永远不会执行
elif x >= 90:
    print("优秀")  # 永远不会执行

# ✅ 正确：从严格到宽松排序
if x >= 90:
    print("优秀")
elif x >= 80:
    print("良好")
elif x >= 60:
    print("及格")
```

## 总结

**关键要点**：
1. Python 使用缩进定义代码块，通常使用 4 个空格
2. if-elif-else 按顺序判断，只执行第一个为真的代码块
3. 三元表达式适合简单的二选一逻辑
4. 利用短路求值可以优化性能和避免错误
5. 理解真值测试，简化代码
6. 使用链式比较和 in 运算符让代码更清晰

**最佳实践**：
- 使用 4 个空格缩进（不要用 Tab）
- 条件从严格到宽松排序
- 避免过深的嵌套，使用逻辑运算符或提前返回
- 利用真值测试简化空容器判断
- 使用 `is` 判断 None
- 使用 `==` 判断值相等
- 浮点数比较使用容差
- 三元表达式不要嵌套过深
