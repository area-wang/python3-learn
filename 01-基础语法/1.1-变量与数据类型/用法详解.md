## 1. 变量基础

### 1.1 什么是变量
变量是用于存储数据的容器。在 Python 中，变量不需要声明类型，直接赋值即可创建。

```python
# 创建变量
name = "张三"
age = 25
height = 1.75
is_student = True
```

### 1.2 变量的特点
- **动态类型**：变量类型可以随时改变
```python
x = 10        # x 是整数
x = "hello"   # 现在 x 是字符串
x = [1, 2, 3] # 现在 x 是列表
```

- **引用传递**：变量存储的是对象的引用（内存地址）
```python
a = [1, 2, 3]
b = a  # b 和 a 指向同一个列表对象
b.append(4)
print(a)  # 输出: [1, 2, 3, 4]
```

- **多重赋值**：可以同时给多个变量赋值
```python
# 同时赋值
x, y, z = 1, 2, 3

# 交换变量
a, b = 10, 20
a, b = b, a  # 交换后 a=20, b=10

# 链式赋值
x = y = z = 0  # x, y, z 都等于 0
```

### 1.3 变量的删除
使用 `del` 关键字删除变量：
```python
x = 10
del x
# print(x)  # 报错: NameError: name 'x' is not defined
```

### 1.4 查看变量类型
使用 `type()` 函数：
```python
x = 10
print(type(x))  # <class 'int'>

name = "Python"
print(type(name))  # <class 'str'>
```

## 2. 变量命名规则

### 2.1 命名规范
✅ **合法命名**：
```python
name = "张三"
age1 = 20
_private = "私有变量"
__magic__ = "魔法方法"
user_name = "李四"
MAX_SIZE = 100  # 常量建议全大写
```

❌ **非法命名**：
```python
# 1name = "错误"       # 不能以数字开头
# my-name = "错误"     # 不能包含连字符
# my name = "错误"     # 不能包含空格
# class = "错误"       # 不能使用关键字
```

### 2.2 命名约定
- **变量名**：小写字母，单词之间用下划线分隔（snake_case）
  ```python
  user_name = "张三"
  total_count = 100
  ```

- **常量**：全大写字母，单词之间用下划线分隔
  ```python
  MAX_SIZE = 1000
  PI = 3.14159
  ```

- **私有变量**：以单下划线开头（约定，不强制）
  ```python
  _internal_value = 10
  ```

- **特殊变量**：双下划线开头和结尾（不要自定义）
  ```python
  __name__  # 系统定义的特殊变量
  ```

### 2.3 Python 关键字
以下是不能用作变量名的关键字：
```python
False      await      else       import     pass
None       break      except     in         raise
True       class      finally    is         return
and        continue   for        lambda     try
as         def        from       nonlocal   while
assert     del        global     not        with
async      elif       if         or         yield
```

查看所有关键字：
```python
import keyword
print(keyword.kwlist)
```

## 3. 数据类型概览

Python 有以下内置数据类型：

### 3.1 数值类型
| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | `10`, `-5`, `0` |
| `float` | 浮点数 | `3.14`, `-0.5`, `2.0` |
| `complex` | 复数 | `3+4j`, `2-5j` |

```python
# 整数
age = 25
count = -10
big_num = 1_000_000  # 可以用下划线分隔，便于阅读

# 浮点数
pi = 3.14159
price = 19.99
scientific = 1.5e10  # 科学计数法: 1.5 × 10^10

# 复数
z = 3 + 4j
print(z.real)  # 实部: 3.0
print(z.imag)  # 虚部: 4.0
```

#### int 类型的常用方法

```python
# 1. bit_length() - 返回二进制表示的位数
x = 10
print(x.bit_length())  # 4 (二进制: 1010)

x = 255
print(x.bit_length())  # 8 (二进制: 11111111)

# 2. to_bytes() - 转换为字节
x = 1024
print(x.to_bytes(2, byteorder='big'))  # b'\x04\x00'
print(x.to_bytes(2, byteorder='little'))  # b'\x00\x04'

# 3. from_bytes() - 从字节创建整数（类方法）
bytes_data = b'\x04\x00'
print(int.from_bytes(bytes_data, byteorder='big'))  # 1024

# 4. bit_count() - 返回二进制中1的个数（Python 3.10+）
x = 15  # 二进制: 1111
print(x.bit_count())  # 4

x = 10  # 二进制: 1010
print(x.bit_count())  # 2

# 5. as_integer_ratio() - 返回分数形式（继承自 int）
# 注意：这个方法主要用于 float，对 int 返回 (x, 1)
x = 5
print(x.as_integer_ratio())  # (5, 1)
```

#### float 类型的常用方法

```python
# 1. is_integer() - 判断是否为整数值
x = 5.0
print(x.is_integer())  # True

x = 5.5
print(x.is_integer())  # False

# 2. as_integer_ratio() - 返回分数形式
x = 0.5
print(x.as_integer_ratio())  # (1, 2) 即 1/2

x = 0.75
print(x.as_integer_ratio())  # (3, 4) 即 3/4

# 3. hex() - 转换为十六进制字符串
x = 3.14
print(x.hex())  # '0x1.91eb851eb851fp+1'

# 4. fromhex() - 从十六进制创建浮点数（类方法）
print(float.fromhex('0x1.91eb851eb851fp+1'))  # 3.14
```

#### 数值类型的通用操作

```python
# 绝对值
print(abs(-10))  # 10
print(abs(-3.5))  # 3.5

# 幂运算
print(pow(2, 3))  # 8
print(pow(2, 3, 5))  # 3 (即 2^3 % 5)

# 四舍五入
print(round(3.14159, 2))  # 3.14
print(round(5.5))  # 6（注意：偶数舍入）
print(round(6.5))  # 6

# 向下取整、向上取整
import math
print(math.floor(3.9))  # 3
print(math.ceil(3.1))  # 4

# 最大值、最小值
print(max(1, 5, 3, 9, 2))  # 9
print(min(1, 5, 3, 9, 2))  # 1

# 求和
print(sum([1, 2, 3, 4, 5]))  # 15
```

## 4. 如何判断数据类型

### 4.1 使用 type() 函数
`type()` 返回对象的具体类型：
```python
x = 10
print(type(x))  # <class 'int'>
print(type(x) == int)  # True

# 判断类型
if type(x) == int:
    print("x 是整数")
```

**注意**：`type()` 不会识别继承关系：
```python
print(type(True) == bool)  # True
print(type(True) == int)   # False（虽然 bool 继承自 int）
```

### 4.2 使用 isinstance() 函数（推荐）
`isinstance()` 检查对象是否是指定类型或其子类的实例：
```python
x = 10
print(isinstance(x, int))     # True
print(isinstance(True, int))  # True（bool 是 int 的子类）
print(isinstance(True, bool)) # True

# 检查多个类型
x = 3.14
print(isinstance(x, (int, float)))  # True（x 是 int 或 float）
```

**isinstance() vs type() 对比**：
```python
# isinstance() 识别继承关系
print(isinstance(True, int))  # True
print(type(True) == int)      # False

# isinstance() 可以检查多个类型
print(isinstance(10, (int, float, str)))  # True
# type() 不支持这种用法
```

### 4.3 检查具体数据类型

#### 检查数值类型
```python
x = 10
print(isinstance(x, int))      # True
print(isinstance(3.14, float)) # True
print(isinstance(2+3j, complex)) # True

# 检查是否为数值（int 或 float）
import numbers
print(isinstance(10, numbers.Number))    # True
print(isinstance(3.14, numbers.Number))  # True
```

#### 检查字符串
```python
s = "hello"
print(isinstance(s, str))  # True
print(type(s) == str)      # True
```

#### 检查布尔值
```python
b = True
print(isinstance(b, bool))  # True
print(type(b) == bool)      # True

# ⚠️ 注意：bool 是 int 的子类
print(isinstance(True, int))  # True
```

#### 检查序列类型
```python
# 列表
lst = [1, 2, 3]
print(isinstance(lst, list))  # True

# 元组
tpl = (1, 2, 3)
print(isinstance(tpl, tuple))  # True

# 检查是否为序列
from collections.abc import Sequence
print(isinstance([1, 2], Sequence))    # True
print(isinstance((1, 2), Sequence))    # True
print(isinstance("hello", Sequence))   # True
```

#### 检查集合和字典
```python
s = {1, 2, 3}
print(isinstance(s, set))  # True

d = {"name": "张三"}
print(isinstance(d, dict))  # True
```

#### 检查 None
```python
x = None
print(x is None)           # True（推荐）
print(x == None)           # True（不推荐）
print(type(x) == type(None))  # True
```

### 4.4 使用内置函数判断特性

#### 检查是否可迭代
```python
from collections.abc import Iterable

print(isinstance([1, 2], Iterable))     # True
print(isinstance("hello", Iterable))    # True
print(isinstance(10, Iterable))         # False
```

#### 检查是否可调用
```python
def func():
    pass

print(callable(func))    # True
print(callable(len))     # True
print(callable(10))      # False
```

#### 检查是否有某个属性
```python
lst = [1, 2, 3]
print(hasattr(lst, 'append'))  # True
print(hasattr(lst, 'split'))   # False
```

### 4.5 类型判断最佳实践

#### ✅ 推荐做法
```python
# 1. 使用 isinstance() 而不是 type()
if isinstance(x, int):
    print("x 是整数")

# 2. 检查 None 使用 is
if x is None:
    print("x 是 None")

# 3. 检查多个类型
if isinstance(x, (int, float)):
    print("x 是数值")
```

#### ❌ 不推荐做法
```python
# 1. 不要用 type() 检查继承关系
if type(x) == int:  # 无法识别子类
    pass

# 2. 不要用 == 检查 None
if x == None:  # 应该用 is
    pass
```

## 5. 类型转换

### 5.1 自动类型转换（隐式转换）
```python
# 整数 + 浮点数 → 浮点数
x = 10 + 3.5  # 13.5 (float)

# 整数 * 布尔值 → 整数（True=1, False=0）
result = 5 * True  # 5
result = 5 * False  # 0
```

### 5.2 强制类型转换（显式转换）

#### 转为整数 `int()`
```python
# 浮点数转整数（截断小数部分）
x = int(3.9)  # 3（不是四舍五入）
x = int(-2.8)  # -2

# 字符串转整数
x = int("123")  # 123
x = int("0xFF", 16)  # 255（十六进制转换）
x = int("1010", 2)  # 10（二进制转换）

# 布尔值转整数
x = int(True)  # 1
x = int(False)  # 0

# ⚠️ 常见错误
# x = int("12.5")  # ValueError: 无法直接转换
# x = int("abc")   # ValueError: 非数字字符串
```

#### 转为浮点数 `float()`
```python
# 整数转浮点数
x = float(10)  # 10.0

# 字符串转浮点数
x = float("3.14")  # 3.14
x = float("1.5e2")  # 150.0（科学计数法）

# 布尔值转浮点数
x = float(True)  # 1.0

# ⚠️ 常见错误
# x = float("abc")  # ValueError
```

#### 转为字符串 `str()`
```python
# 任何类型都可以转为字符串
x = str(123)  # "123"
x = str(3.14)  # "3.14"
x = str(True)  # "True"
x = str(True)  # "True"
x = str([1, 2, 3])  # "[1, 2, 3]"
x = str(None)  # "None"
```

#### 转为布尔值 `bool()`
```python
# 以下值转换为 False
bool(0)  # False
bool(0.0)  # False
bool("")  # False（空字符串）
bool([])  # False（空列表）
bool({})  # False（空字典）
bool(())  # False（空元组）
bool(None)  # False
bool(set())  # False（空集合）

# 其他所有值都转换为 True
bool(1)  # True
bool(-1)  # True
bool("hello")  # True
bool([0])  # True（非空列表）
bool(" ")  # True（包含空格的字符串）
```

#### 容器类型转换
```python
# 列表 ↔ 元组 ↔ 集合
lst = [1, 2, 3, 3]
tpl = tuple(lst)  # (1, 2, 3, 3)
st = set(lst)  # {1, 2, 3}（去重）
lst2 = list(st)  # [1, 2, 3]

# 字符串 → 列表
# 字符串 → 列表
chars = list("hello")  # ['h', 'e', 'l', 'l', 'o']

# 字典键值转换
d = {"a": 1, "b": 2}
keys = list(d.keys())  # ['a', 'b']
values = list(d.values())  # [1, 2]
items = list(d.items())  # [('a', 1), ('b', 2)]
```

## 6. 变量作用域

### 6.1 作用域分类
Python 有四种作用域（LEGB 规则）：
1. **L (Local)**：局部作用域（函数内部）
2. **E (Enclosing)**：嵌套函数的外层函数作用域
3. **G (Global)**：全局作用域（模块级别）
4. **B (Built-in)**：内置作用域（Python 内置函数）

```python
# 全局变量
global_var = "全局"

def outer():
    # 外层函数变量
    enclosing_var = "外层"
    
    def inner():
        # 局部变量
        local_var = "局部"
        print(local_var)      # 局部
        print(enclosing_var)  # 外层
        print(global_var)     # 全局
        print(global_var)     # 全局
    
    inner()

outer()
```

### 6.2 global 关键字
在函数内修改全局变量需要使用 `global`：
```python
count = 0

def increment():
    global count  # 声明使用全局变量
    count += 1

increment()
print(count)  # 1
```

⚠️ **常见错误**：
```python
count = 0

def increment():
    # count += 1  # UnboundLocalError: 局部变量在赋值前被引用
    pass  # 因为 += 是先读后写，Python 认为 count 是局部变量
```

### 6.3 nonlocal 关键字
在嵌套函数中修改外层函数的变量：
```python
def outer():
    count = 0
    
    def inner():
        nonlocal count  # 声明使用外层函数的变量
        count += 1
    
    inner()
    print(count)  # 1

outer()
```

## 总结

**关键要点**：
1. Python 是动态类型语言，变量不需要声明类型
2. 变量存储的是对象的引用，不是值本身
3. 注意可变对象和不可变对象的区别
4. 类型转换要注意异常情况
5. 理解作用域规则（LEGB）
6. 小心浮点数精度、浅拷贝、可变默认参数等常见陷阱

**最佳实践**：
- 使用有意义的变量名
- 遵循命名规范（snake_case）
- 避免使用关键字和内置函数名
- 对 `None` 使用 `is` 而不是 `==`
- 需要精确计算时使用 `Decimal`
- 可变对象不要作为默认参数
