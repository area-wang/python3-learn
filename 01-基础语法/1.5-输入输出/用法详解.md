## 1. 输出基础 print()

### 1.1 什么是 print()
`print()` 函数用于将内容输出到控制台（屏幕）。

### 1.2 基本用法
```python
# 打印单个值
print("Hello, World!")

# 打印多个值（用空格分隔）
print("Python", 3, "is", "great")
# 输出: Python 3 is great

# 打印变量
name = "Alice"
age = 25
print(name, age)
# 输出: Alice 25
```

### 1.3 打印不同类型
```python
# 字符串
print("Hello")

# 数字
print(42)
print(3.14)

# 布尔值
print(True)

# 列表
print([1, 2, 3])

# 字典
print({"name": "Alice", "age": 25})

# None
print(None)
```

## 2. print() 参数详解

### 2.1 sep 参数（分隔符）
```python
# 默认用空格分隔
print("a", "b", "c")
# 输出: a b c

# 自定义分隔符
print("a", "b", "c", sep="-")
# 输出: a-b-c

print("2024", "01", "15", sep="/")
# 输出: 2024/01/15

# 无分隔符
print("a", "b", "c", sep="")
# 输出: abc
```

### 2.2 end 参数（结束符）
```python
# 默认换行
print("Hello")
print("World")
# 输出:
# Hello
# World

# 不换行
print("Hello", end=" ")
print("World")
# 输出: Hello World

# 自定义结束符
print("Python", end="!!!\n")
print("is great")
# 输出:
# Python!!!
# is great
```

### 2.3 file 参数（输出到文件）
```python
# 输出到文件
with open("output.txt", "w", encoding="utf-8") as f:
    print("Hello, File!", file=f)

# 输出到标准错误流
import sys
print("This is an error", file=sys.stderr)
```

### 2.4 flush 参数（立即刷新）
```python
import time

# flush=False（默认）：可能有缓冲
print("Loading", end="")
time.sleep(2)
print("Done")

# flush=True：立即输出
print("Loading", end="", flush=True)
time.sleep(2)
print("Done")
```

## 3. 格式化输出

### 3.1 % 格式化（旧式）
```python
# 字符串
name = "Alice"
print("Hello, %s" % name)
# 输出: Hello, Alice

# 整数
age = 25
print("Age: %d" % age)
# 输出: Age: 25

# 浮点数
pi = 3.14159
print("PI: %.2f" % pi)
# 输出: PI: 3.14

# 多个值
print("Name: %s, Age: %d" % (name, age))
# 输出: Name: Alice, Age: 25
```

**常用占位符**：
| 占位符 | 说明 | 示例 |
|--------|------|------|
| `%s` | 字符串 | `"Hello %s" % "World"` |
| `%d` | 整数 | `"Age: %d" % 25` |
| `%f` | 浮点数 | `"PI: %f" % 3.14` |
| `%.2f` | 保留 2 位小数 | `"PI: %.2f" % 3.14159` |
| `%x` | 十六进制 | `"Hex: %x" % 255` |
| `%%` | 百分号 | `"Score: 90%%"` |

### 3.2 str.format() 方法
```python
# 按位置
print("Hello, {}".format("World"))
# 输出: Hello, World

print("{} + {} = {}".format(1, 2, 3))
# 输出: 1 + 2 = 3

# 指定位置
print("{1} + {0} = {2}".format(1, 2, 3))
# 输出: 2 + 1 = 3

# 按名称
print("Name: {name}, Age: {age}".format(name="Alice", age=25))
# 输出: Name: Alice, Age: 25

# 格式化数字
pi = 3.14159
print("PI: {:.2f}".format(pi))
# 输出: PI: 3.14

# 对齐
print("{:<10}".format("left"))    # 左对齐
print("{:>10}".format("right"))   # 右对齐
print("{:^10}".format("center"))  # 居中
# 输出:
# left      
#      right
#   center  
```

### 3.3 f-string（推荐，Python 3.6+）
```python
# 基本用法
name = "Alice"
age = 25
print(f"Name: {name}, Age: {age}")
# 输出: Name: Alice, Age: 25

# 表达式
print(f"1 + 1 = {1 + 1}")
# 输出: 1 + 1 = 2

# 调用函数
print(f"Length: {len('hello')}")
# 输出: Length: 5

# 格式化数字
pi = 3.14159
print(f"PI: {pi:.2f}")
# 输出: PI: 3.14

# 对齐和填充
print(f"{'left':<10}")
print(f"{'right':>10}")
print(f"{'center':^10}")

# 千位分隔符
num = 1000000
print(f"{num:,}")
# 输出: 1,000,000

# 百分比
ratio = 0.85
print(f"Score: {ratio:.1%}")
# 输出: Score: 85.0%
```

### 3.4 格式化对齐与填充
```python
# 左对齐
print(f"{'Python':<10}|")
# 输出: Python    |

# 右对齐
print(f"{'Python':>10}|")
# 输出:     Python|

# 居中
print(f"{'Python':^10}|")
# 输出:   Python  |

# 填充字符
print(f"{'Python':*^10}|")
# 输出: **Python**|

# 数字对齐
for i in [1, 12, 123, 1234]:
    print(f"{i:>5}")
# 输出:
#     1
#    12
#   123
#  1234
```

### 3.5 格式化数字
```python
# 小数位数
pi = 3.14159
print(f"{pi:.2f}")  # 3.14
print(f"{pi:.4f}")  # 3.1416

# 千位分隔符
num = 1234567
print(f"{num:,}")  # 1,234,567

# 百分比
ratio = 0.856
print(f"{ratio:.2%}")  # 85.60%

# 科学计数法
big = 1234567890
print(f"{big:.2e}")  # 1.23e+09

# 二进制、八进制、十六进制
num = 255
print(f"Binary: {num:b}")   # Binary: 11111111
print(f"Octal: {num:o}")    # Octal: 377
print(f"Hex: {num:x}")      # Hex: ff
print(f"Hex: {num:X}")      # Hex: FF
```

## 4. 输入基础 input()

### 4.1 基本用法
```python
# 获取用户输入
name = input("请输入你的名字: ")
print(f"你好，{name}！")

# 注意：input() 总是返回字符串
age = input("请输入年龄: ")
print(type(age))  # <class 'str'>
```

### 4.2 类型转换
```python
# 转换为整数
age = int(input("请输入年龄: "))
print(f"明年你 {age + 1} 岁")

# 转换为浮点数
height = float(input("请输入身高(米): "))
print(f"你的身高是 {height} 米")

# 多个输入
numbers = input("请输入两个数字，用空格分隔: ").split()
a, b = int(numbers[0]), int(numbers[1])
print(f"{a} + {b} = {a + b}")

# 更简洁的写法
a, b = map(int, input("请输入两个数字: ").split())
print(f"{a} + {b} = {a + b}")
```

### 4.3 输入验证
```python
# 方法1：使用 while 循环
while True:
    try:
        age = int(input("请输入年龄: "))
        if age > 0:
            break
        else:
            print("年龄必须是正数")
    except ValueError:
        print("请输入有效的数字")

# 方法2：使用函数
def get_positive_int(prompt):
    while True:
        try:
            value = int(input(prompt))
            if value > 0:
                return value
            print("必须是正数")
        except ValueError:
            print("请输入有效的数字")

age = get_positive_int("请输入年龄: ")
```

## 5. 输入处理与验证

### 5.1 去除空白字符
```python
# 去除首尾空白
name = input("请输入姓名: ").strip()

# 去除左边空白
name = input("请输入姓名: ").lstrip()

# 去除右边空白
name = input("请输入姓名: ").rstrip()
```

### 5.2 大小写处理
```python
# 转小写
answer = input("是否继续？(Y/N): ").lower()
if answer == "y":
    print("继续")

# 转大写
code = input("请输入代码: ").upper()
```

### 5.3 分割输入
```python
# 按空格分割
words = input("请输入几个单词: ").split()
print(words)

# 按逗号分割
items = input("请输入项目（逗号分隔）: ").split(",")
print(items)

# 限制分割次数
a, b, rest = input("输入: ").split(maxsplit=2)
```

### 5.4 输入列表
```python
# 输入整数列表
numbers = list(map(int, input("请输入数字（空格分隔）: ").split()))
print(numbers)

# 输入多行
lines = []
print("请输入内容（输入空行结束）:")
while True:
    line = input()
    if not line:
        break
    lines.append(line)
print("你输入了:", lines)
```

### 5.5 输入验证函数
```python
def get_int(prompt, min_value=None, max_value=None):
    """获取整数输入，带范围验证"""
    while True:
        try:
            value = int(input(prompt))
            if min_value is not None and value < min_value:
                print(f"必须 >= {min_value}")
                continue
            if max_value is not None and value > max_value:
                print(f"必须 <= {max_value}")
                continue
            return value
        except ValueError:
            print("请输入有效的整数")

def get_choice(prompt, choices):
    """获取选项输入"""
    while True:
        choice = input(prompt).strip().lower()
        if choice in choices:
            return choice
        print(f"请输入: {', '.join(choices)}")

# 使用
age = get_int("请输入年龄(1-120): ", 1, 120)
answer = get_choice("是否继续？(y/n): ", ["y", "n"])
```

## 6. 文件输入输出

### 6.1 写入文件
```python
# 基本写入
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello, File!\n")
    f.write("Python is great\n")

# 使用 print 写入
with open("output.txt", "w", encoding="utf-8") as f:
    print("Hello, File!", file=f)
    print("Python is great", file=f)

# 追加模式
with open("output.txt", "a", encoding="utf-8") as f:
    f.write("Appended line\n")
```

### 6.2 读取文件
```python
# 读取整个文件
with open("input.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

# 按行读取
with open("input.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

# 读取所有行到列表
with open("input.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
    print(lines)
```

### 6.3 文件操作最佳实践
```python
# ✅ 推荐：使用 with 语句（自动关闭）
with open("file.txt", "r") as f:
    content = f.read()

# ❌ 不推荐：手动关闭
f = open("file.txt", "r")
content = f.read()
f.close()  # 容易忘记
```

## 7. 标准输入输出流

### 7.1 标准输入输出
```python
import sys

# 标准输出（stdout）
sys.stdout.write("Hello\n")

# 标准错误（stderr）
sys.stderr.write("Error message\n")

# 标准输入（stdin）
for line in sys.stdin:
    print(line.strip())
```

### 7.2 重定向输出
```python
import sys

# 保存原始 stdout
original_stdout = sys.stdout

# 重定向到文件
with open("log.txt", "w") as f:
    sys.stdout = f
    print("This goes to file")
    print("So does this")

# 恢复 stdout
sys.stdout = original_stdout
print("This goes to console")
```

## 8. 实用技巧

### 8.1 进度条
```python
import time

# 简单进度条
for i in range(101):
    print(f"\r进度: {i}%", end="", flush=True)
    time.sleep(0.05)
print()  # 换行

# 带符号的进度条
def progress_bar(current, total, width=50):
    percent = current / total
    filled = int(width * percent)
    bar = "█" * filled + "-" * (width - filled)
    print(f"\r[{bar}] {percent:.1%}", end="", flush=True)

for i in range(101):
    progress_bar(i, 100)
    time.sleep(0.05)
print()
```

## 9. 常见错误与陷阱

### 9.1 忘记类型转换
```python
# ❌ 错误：input() 返回字符串
age = input("请输入年龄: ")
# age = "25"（字符串）
print(age + 1)  # TypeError

# ✅ 正确：转换为整数
age = int(input("请输入年龄: "))
print(age + 1)  # 26
```

### 9.2 输入验证不足
```python
# ❌ 不安全：直接转换
age = int(input("请输入年龄: "))
# 如果输入 "abc"，会抛出 ValueError

# ✅ 安全：异常处理
try:
    age = int(input("请输入年龄: "))
except ValueError:
    print("请输入有效的数字")
    age = 0
```

### 9.3 字符串拼接 vs 格式化
```python
name = "Alice"
age = 25

# ❌ 不推荐：字符串拼接
print("Name: " + name + ", Age: " + str(age))

# ✅ 推荐：f-string
print(f"Name: {name}, Age: {age}")
```

### 9.4 print() 的 end 参数
```python
# 问题：不换行导致输出混乱
for i in range(5):
    print(i, end=" ")
# 输出: 0 1 2 3 4 

# 记得最后换行
for i in range(5):
    print(i, end=" ")
print()  # 换行
```

### 9.5 文件编码问题
```python
# ❌ 可能出错：未指定编码
with open("中文.txt", "w") as f:
    f.write("你好")

# ✅ 推荐：明确指定 UTF-8
with open("中文.txt", "w", encoding="utf-8") as f:
    f.write("你好")
```

### 9.6 格式化中的引号
```python
# ⚠️ 注意引号嵌套
name = "Alice"

# 错误
# print(f"She said "Hello, {name}"")  # SyntaxError

# 正确
print(f'She said "Hello, {name}"')
print(f"She said \"Hello, {name}\"")
```

### 9.7 分隔符问题
```python
# 输入: "1,2,3"
numbers = input("请输入数字（逗号分隔）: ").split(",")
# numbers = ["1", "2", "3"]（字符串列表）

# 记得转换类型
numbers = list(map(int, input("请输入数字: ").split(",")))
# numbers = [1, 2, 3]（整数列表）
```

## 总结

**关键要点**：
1. **print()**：输出到控制台
   - 参数：sep（分隔符）、end（结束符）、file（输出目标）、flush（立即刷新）
2. **格式化输出**：
   - % 格式化（旧式）
   - str.format()
   - f-string（推荐，Python 3.6+）
3. **input()**：获取用户输入（始终返回字符串）
4. **类型转换**：int(), float(), str()
5. **输入验证**：try-except、while 循环
6. **文件 I/O**：open(), read(), write()，使用 with 语句

**最佳实践**：
- 优先使用 f-string 进行格式化
- 始终验证用户输入
- 使用 .strip() 去除空白字符
- 文件操作使用 with 语句
- 明确指定文件编码（encoding="utf-8"）
- 使用有意义的提示信息
- 处理可能的异常（try-except）

**性能提示**：
- 大量输出使用 sys.stdout.write() 更快
- 文件操作使用缓冲提高效率
- 避免在循环中频繁打开文件
