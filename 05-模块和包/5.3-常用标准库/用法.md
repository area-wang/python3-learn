# 5.3 常用标准库

Python 标准库随 Python 一同提供，覆盖操作系统、路径、日期时间、数据序列化、文本处理、日志、并发、数据库等常见任务。学习标准库的关键不是背诵全部函数，而是知道“遇到某类问题应优先寻找哪个模块”。

## 1. 标准库使用原则

- 优先查找标准库是否已有可靠实现，不重复制造基础工具；
- 导入模块后通过命名空间调用，保持来源清晰；
- 注意标准库 API 也可能有平台差异和版本差异；
- 不要给自定义文件使用 `json.py`、`logging.py`、`typing.py` 等名称；
- 对安全敏感任务使用专用模块，例如令牌使用 `secrets` 而不是 `random`；
- 时间、路径、子进程等任务优先使用现代高层 API。

## 2. `pathlib`：面向对象的路径处理

`pathlib.Path` 通常比手工拼接字符串或直接使用大量 `os.path` 更清晰。

```python
from pathlib import Path

project_dir = Path(__file__).resolve().parent
data_file = project_dir / "data" / "users.json"

print(data_file.name)
print(data_file.suffix)
print(data_file.parent)
print(data_file.exists())
```

常用操作：

```python
from pathlib import Path

output_dir = Path("output")
output_dir.mkdir(parents=True, exist_ok=True)

report = output_dir / "report.txt"
report.write_text("学习 Python", encoding="utf-8")
content = report.read_text(encoding="utf-8")

for python_file in Path(".").rglob("*.py"):
    print(python_file)
```

注意：

- 相对路径仍然相对于当前工作目录；
- 需要相对当前源码文件定位时可基于 `Path(__file__).resolve().parent`；
- 包内资源应优先使用 `importlib.resources`，而不只是依赖 `__file__`；
- 文件不存在、权限不足等错误应明确处理。

## 3. `os`：操作系统接口

`os` 提供环境变量、进程信息和操作系统相关功能：

```python
import os

print(os.getcwd())
print(os.name)
print(os.getpid())

debug = os.getenv("APP_DEBUG", "false").lower() == "true"
```

设置环境变量只影响当前进程及其后续子进程：

```python
os.environ["APP_MODE"] = "development"
```

环境变量读取结果总是字符串。布尔值、整数、列表等需要显式解析和校验。

`os.walk()` 可以递归遍历目录，但简单路径遍历也可以使用 `Path.rglob()`。删除、重命名等操作要确认目标路径，避免误操作。

## 4. `sys`：解释器与运行环境

```python
import sys

print(sys.version)
print(sys.executable)
print(sys.platform)
print(sys.argv)
print(sys.path)
```

常见用途：

- `sys.argv`：读取简单命令行参数；复杂 CLI 推荐 `argparse`；
- `sys.exit(code)`：结束程序并返回退出码；
- `sys.stdin`、`sys.stdout`、`sys.stderr`：标准输入输出流；
- `sys.executable`：确认当前 Python 解释器；
- `sys.modules`：查看已导入模块缓存。

```python
import sys

if len(sys.argv) != 2:
    print("用法：python app.py <name>", file=sys.stderr)
    sys.exit(2)
```

退出码通常 `0` 表示成功，非零表示失败。不要使用 `os._exit()` 替代正常退出，除非明确理解它会跳过常规清理过程。

## 5. `argparse`：命令行参数解析

```python
import argparse

parser = argparse.ArgumentParser(description="批量问候用户")
parser.add_argument("name", help="用户名")
parser.add_argument("-n", "--count", type=int, default=1, help="重复次数")
parser.add_argument("--upper", action="store_true", help="转换为大写")
args = parser.parse_args()

message = f"Hello, {args.name}!"
if args.upper:
    message = message.upper()

for _ in range(args.count):
    print(message)
```

`argparse` 会生成帮助信息、检查基本类型并报告参数错误。复杂程序可以使用子命令：

```text
app user create
app user delete
app report export
```

解析参数与业务逻辑应分开，便于测试。

## 6. 日期和时间：`datetime`、`time`、`zoneinfo`

### 6.1 `datetime`

```python
from datetime import date, datetime, timedelta

today = date.today()
now = datetime.now()
tomorrow = today + timedelta(days=1)

text = now.strftime("%Y-%m-%d %H:%M:%S")
parsed = datetime.strptime("2026-07-18 10:30:00", "%Y-%m-%d %H:%M:%S")
```

### 6.2 时区

跨地区系统应优先使用带时区信息的时间：

```python
from datetime import datetime
from zoneinfo import ZoneInfo

shanghai = datetime.now(ZoneInfo("Asia/Shanghai"))
new_york = shanghai.astimezone(ZoneInfo("America/New_York"))
```

“朴素时间”不带时区信息，“感知时间”带有 `tzinfo`。两者混用容易产生错误。

### 6.3 `time`

测量经过时间应使用单调时钟：

```python
from time import perf_counter, sleep

start = perf_counter()
sleep(0.1)
elapsed = perf_counter() - start
print(elapsed)
```

不要使用墙上时钟计算性能耗时，因为系统时间可能被调整。

## 7. `json`：JSON 序列化

```python
import json

user = {"name": "小明", "age": 18, "active": True}

text = json.dumps(user, ensure_ascii=False, indent=2)
restored = json.loads(text)
```

文件读写：

```python
from pathlib import Path
import json

path = Path("user.json")

with path.open("w", encoding="utf-8") as file:
    json.dump(user, file, ensure_ascii=False, indent=2)

with path.open("r", encoding="utf-8") as file:
    loaded_user = json.load(file)
```

常见映射：

| Python | JSON |
|---|---|
| `dict` | object |
| `list`、`tuple` | array |
| `str` | string |
| `int`、`float` | number |
| `True`、`False` | true、false |
| `None` | null |

日期、集合、自定义对象等不能直接序列化，需要先转换或提供自定义编码逻辑。不要把 JSON 当作可执行代码，更不要使用 `eval()` 解析 JSON。

## 8. `csv`：表格文本

```python
import csv

rows = [
    {"name": "Alice", "score": 95},
    {"name": "Bob", "score": 88},
]

with open("scores.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "score"])
    writer.writeheader()
    writer.writerows(rows)
```

读取：

```python
with open("scores.csv", "r", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["name"], int(row["score"]))
```

CSV 字段读入后通常是字符串，需要按业务类型转换。`newline=""` 可以让 `csv` 模块正确处理换行细节。

## 9. `re`：正则表达式

```python
import re

pattern = re.compile(r"^[A-Za-z][A-Za-z0-9_]{2,15}$")

if pattern.fullmatch("python_user"):
    print("用户名格式正确")
```

常用函数：

- `re.search()`：在字符串中查找第一个匹配；
- `re.match()`：从字符串开头尝试匹配；
- `re.fullmatch()`：要求整个字符串匹配；
- `re.findall()`：返回全部非重叠匹配；
- `re.finditer()`：迭代返回匹配对象；
- `re.sub()`：替换匹配内容；
- `re.split()`：按模式分割。

建议使用原始字符串 `r"..."` 编写模式，减少反斜杠转义。复杂模式应使用命名分组、注释或拆分逻辑；正则并不适合解析任意复杂的嵌套语法。

## 10. 随机数：`random` 与 `secrets`

普通模拟和抽样使用 `random`：

```python
import random

print(random.randint(1, 6))
print(random.choice(["red", "green", "blue"]))
print(random.sample(range(1, 50), k=6))
```

密码重置令牌、验证码核心随机值等安全用途使用 `secrets`：

```python
import secrets

token = secrets.token_urlsafe(32)
code = "".join(secrets.choice("0123456789") for _ in range(6))
```

`random` 是确定性伪随机生成器，可以通过种子复现，不适合安全场景。

## 11. 数学与统计：`math`、`decimal`、`fractions`、`statistics`

```python
import math

print(math.sqrt(2))
print(math.ceil(3.2))
print(math.floor(3.8))
print(math.isclose(0.1 + 0.2, 0.3))
```

金额等需要十进制精确表达的场景可使用 `Decimal`，并优先从字符串构造：

```python
from decimal import Decimal, ROUND_HALF_UP

price = Decimal("19.90")
quantity = Decimal("3")
total = (price * quantity).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

分数：

```python
from fractions import Fraction

print(Fraction(1, 3) + Fraction(1, 6))  # 1/2
```

统计：

```python
from statistics import mean, median

scores = [70, 80, 90, 100]
print(mean(scores))
print(median(scores))
```

## 12. 高效容器：`collections`

### 12.1 `Counter`

```python
from collections import Counter

counts = Counter("mississippi")
print(counts.most_common(2))
```

### 12.2 `defaultdict`

```python
from collections import defaultdict

groups = defaultdict(list)
for name, department in [("Alice", "IT"), ("Bob", "HR")]:
    groups[department].append(name)
```

### 12.3 `deque`

```python
from collections import deque

queue = deque(["task1", "task2"])
queue.append("task3")
current = queue.popleft()
```

`deque` 适合两端高效添加和删除；列表更适合随机访问。

## 13. 迭代工具：`itertools` 与 `functools`

```python
from itertools import chain, islice

numbers = chain([1, 2], [3, 4])
print(list(numbers))

first_three = list(islice(range(100), 3))
```

```python
from functools import lru_cache, partial


@lru_cache(maxsize=128)
def fibonacci(number):
    if number < 2:
        return number
    return fibonacci(number - 1) + fibonacci(number - 2)


base_two = partial(int, base=2)
print(base_two("1010"))
```

缓存要求参数可哈希，还要考虑内存占用和缓存失效问题。不要缓存具有外部副作用或结果必须实时更新的函数。

## 14. 数据模型辅助：`dataclasses`、`enum`、`typing`

```python
from dataclasses import dataclass
from decimal import Decimal
from enum import Enum


class Status(Enum):
    PENDING = "pending"
    PAID = "paid"


@dataclass
class Order:
    order_id: str
    total: Decimal
    status: Status = Status.PENDING
```

`typing` 提供类型注解工具：

```python
from collections.abc import Iterable


def total(values: Iterable[float]) -> float:
    return sum(values)
```

类型注解主要服务于阅读、编辑器和静态检查，不会默认在运行时强制验证参数类型。

## 15. 日志：`logging`

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(name)s: %(message)s",
)

logger = logging.getLogger(__name__)

logger.info("应用启动")
logger.warning("缓存即将过期")
```

捕获异常并保留堆栈：

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    logger.exception("计算失败")
```

库代码通常只创建命名 logger，不应擅自调用 `basicConfig()` 改变整个应用的日志配置；日志级别、处理器和输出格式通常由应用入口决定。

## 16. 子进程：`subprocess`

```python
import subprocess

result = subprocess.run(
    ["python", "--version"],
    capture_output=True,
    text=True,
    check=True,
)

print(result.stdout or result.stderr)
```

建议：

- 参数使用列表，而不是拼接一整条命令字符串；
- 需要失败即抛异常时使用 `check=True`；
- 设置合理超时 `timeout=`；
- 谨慎使用 `shell=True`，尤其不要拼接不可信输入；
- 调用当前 Python 时可使用 `sys.executable`。

## 17. 临时文件与文件操作：`tempfile`、`shutil`

```python
from pathlib import Path
from tempfile import TemporaryDirectory
import shutil

with TemporaryDirectory() as temp_dir:
    temp_path = Path(temp_dir)
    source = temp_path / "source.txt"
    target = temp_path / "backup.txt"
    source.write_text("data", encoding="utf-8")
    shutil.copy2(source, target)
```

`tempfile` 会安全地创建临时位置；`shutil` 提供复制、移动、归档和目录树操作。删除目录树前应格外确认路径。

## 18. 哈希与编码：`hashlib`、`base64`

```python
import hashlib

digest = hashlib.sha256(b"hello").hexdigest()
print(digest)
```

哈希用于完整性校验、内容指纹等。密码存储不能简单使用一次 SHA-256，应使用专门的密码哈希算法和成熟方案。

```python
import base64

encoded = base64.b64encode("你好".encode("utf-8"))
decoded = base64.b64decode(encoded).decode("utf-8")
```

Base64 是编码，不是加密，不能保护敏感信息。

## 19. 标准库模块速查

| 任务 | 优先考虑 |
|---|---|
| 路径操作 | `pathlib` |
| 环境变量、系统接口 | `os` |
| 解释器信息、退出码 | `sys` |
| 命令行解析 | `argparse` |
| 日期时间 | `datetime`、`zoneinfo` |
| 性能计时、休眠 | `time` |
| JSON / CSV | `json`、`csv` |
| 正则匹配 | `re` |
| 普通随机 / 安全随机 | `random` / `secrets` |
| 数学、十进制、统计 | `math`、`decimal`、`statistics` |
| 计数、队列、默认映射 | `collections` |
| 迭代组合 | `itertools` |
| 缓存、函数适配 | `functools` |
| 日志 | `logging` |
| 子进程 | `subprocess` |
| 临时文件、复制归档 | `tempfile`、`shutil` |
| 包内资源 | `importlib.resources` |
| 已安装包元数据 | `importlib.metadata` |

## 20. 本节小结

1. 标准库是解决常见问题的首选工具箱，应先理解场景，再查阅具体 API。
2. 路径使用 `pathlib`，命令行使用 `argparse`，日志使用 `logging`，安全随机使用 `secrets`。
3. 时间处理要区分墙上时间、经过时间和时区；跨地区系统应使用带时区时间。
4. JSON、CSV 只负责格式转换，业务类型校验和异常处理仍需自行完成。
5. 子进程、路径删除、正则和序列化等功能必须考虑输入可信度、平台差异和失败情况。
6. 模块选择比函数背诵更重要；遇到问题时应能快速定位对应标准库。
