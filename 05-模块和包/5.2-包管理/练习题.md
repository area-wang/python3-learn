# 5.2 包管理练习题

## 一、概念题

1. 模块、导入包和发行包分别是什么？三者为什么不能混为一谈？
2. 普通包中的 `__init__.py` 有哪些作用？为什么它不宜执行耗时操作？
3. 绝对导入和相对导入各有什么优缺点？
4. `from ..models import User` 中两个点表示什么？
5. 为什么直接运行包内文件可能导致相对导入失败？
6. `python -m app.cli` 与 `python app/cli.py` 在模块定位和包上下文上有什么区别？
7. 仅执行 `import package` 时，是否会自动导入包中的全部子模块？
8. 什么是命名空间包？它适合哪些场景？
9. 为什么读取包内资源时推荐使用 `importlib.resources`？
10. `src` 布局主要解决什么问题？

## 三、编程题

### 1. 创建普通包

创建 `geometry` 包：

```text
geometry/
├── __init__.py
├── circle.py
├── rectangle.py
└── validators.py
```

要求：

- `circle.py` 实现周长和面积；
- `rectangle.py` 实现周长和面积；
- `validators.py` 统一检查长度是否为正数；
- 包内使用合理的绝对或相对导入；
- 在 `__init__.py` 中只重新导出最常用的两个函数；
- 使用 `__all__` 声明公开接口；
- 编写外部调用示例。

### 2. 为包增加命令入口

在上题基础上添加 `geometry/__main__.py`：

- 支持执行 `python -m geometry`；
- 提供圆形和矩形计算菜单；
- 交互逻辑与计算逻辑分离；
- 导入 `geometry` 时不得启动菜单。

### 3. 读取包内资源

创建包：


使用 `importlib.resources` 读取文本，不允许依赖当前工作目录。分别从项目根目录和其他目录运行，验证结果一致。

### 4. 重构过深结构

## 五、综合实践：图书管理包

设计一个 `library` 包，至少包含：

- `models`：图书、读者、借阅记录；
- `services`：借书、还书、查询；
- `storage`：内存存储实现；
- `exceptions`：领域异常；
- `cli`：命令行交互；
- `__main__.py`：模块入口。

要求：

1. 给出完整目录树；
2. 明确每个子包的职责；
3. 设计依赖方向，避免 `models` 反向依赖 `services`；
4. 只在顶层包重新导出最稳定的公共对象；
5. 使用 `python -m library` 启动程序；
6. 至少设计一个包内资源文件并正确读取；
7. 说明哪些名称属于公开 API，哪些属于内部实现。
