## 列表推导式

### 练习题

**题目 1：基础列表推导式**
1. 生成 1 到 20 所有整数的平方列表
2. 将字符串列表 `['hello', 'world', 'python']` 转换为大写
3. 从字符串 `"Python"` 生成字符列表 `['P', 'y', 't', 'h', 'o', 'n']`

**题目 2：带条件的列表推导式**
1. 从 `range(1, 101)` 中提取所有能被 3 整除的数
2. 从 `[-5, -3, 0, 2, 8, -1, 4]` 中提取所有正数
3. 从 `['apple', 'banana', 'kiwi', 'cherry', 'fig']` 中提取长度大于 4 的字符串

**题目 3：带 if-else 表达式**
1. 将 `[-2, 3, -1, 5, -4]` 中的负数替换为 0
2. 标记奇偶：`[1, 2, 3, 4, 5]` → `['odd', 'even', 'odd', 'even', 'odd']`
3. 把 60 分以上标记为 `'pass'`，否则 `'fail'`：`[55, 80, 90, 45, 70]`

**题目 4：陷阱题**
以下两段代码输出分别是什么？为什么不同？
```python
# 代码 A
a = [x if x > 0 for x in range(-3, 4)]

# 代码 B
b = [x for x in range(-3, 4) if x > 0]
```

## 字典推导式

### 练习题

**题目 1：基础字典推导式**
1. 生成数字 0-5 到其平方的映射：`{0:0, 1:1, 2:4, ...}`
2. 用 `['name', 'age', 'city']` 和 `['Alice', 25, 'Beijing']` 构造字典
3. 用字符串 `'hello'` 构造每个字符到出现次数的字典

**题目 2：反转字典**
1. 反转 `{'a': 1, 'b': 2, 'c': 3}` 得到 `{1: 'a', 2: 'b', 3: 'c'}`
2. 反转 `{'apple': 'fruit', 'carrot': 'vegetable'}` 得到值到键的映射

**题目 3：按值过滤**
1. 从 `{'a': 1, 'b': 3, 'c': 2, 'd': 5}` 中保留值大于 2 的项
2. 从 `{'abc': 1, 'hello': 2, 'hi': 3, 'world': 4}` 中保留键长度大于 3 的项

**题目 4：陷阱题**
以下代码输出是什么？为什么 `'a'` 丢失了？
```python
original = {'a': 1, 'b': 1, 'c': 2}
reversed_dict = {v: k for k, v in original.items()}
print(reversed_dict)
```

original = {'apple': 'fruit', 'carrot': 'vegetable'}
inverted = {v: k for k, v in original.items()}

d = {'abc': 1, 'hello': 2, 'hi': 3, 'world': 4}

print(filtered)  # {'hello': 2, 'world': 4}

# 题目 4
# 输出：{1: 'b', 2: 'c'}
# 原因：'a' 和 'b' 的值都是 1，反转时键 1 先映射到 'a'，再被 'b' 覆盖
# 修复：把值映射为列表
from collections import defaultdict
original = {'a': 1, 'b': 1, 'c': 2}
inverted = defaultdict(list)
for k, v in original.items():
    inverted[v].append(k)
print(dict(inverted))  # {1: ['a', 'b'], 2: ['c']}

**题目 3：for 与 if 混合**
对每个偶数 `x`（0-9）和每个奇数 `y`（0-9）生成 `(x, y)` 元组列表。

**题目 4：陷阱题**
以下代码输出是什么？期望得到 `[(0,0), (0,1), (0,2), (1,0), ...]`，实际顺序如何？为什么？
```python
result = [(x, y) for y in range(3) for x in range(3)]

```

<summary>点击查看答案</summary>

pairs = [(x, y) for x in [1, 2, 3] for y in ['a', 'b']]

# [(1,'a'), (1,'b'), (2,'a'), (2,'b'), (3,'a'), (3,'b')]

# 题目 2
result = [x for x in range(100) if x % 2 == 0 if x % 3 == 0]
print(result)  # [0, 6, 12, 18, ...]

# 等价写法
result = [x for x in range(100) if x % 2 == 0 and x % 3 == 0]
print(result)

# 题目 3
result = [(x, y) for x in range(10) if x % 2 == 0 for y in range(10) if y % 2 == 1]
print(result)
# [(0,1), (0,3), (0,5), (0,7), (0,9), (2,1), (2,3), ...]

# 题目 4
# 输出：[(0,0), (1,0), (2,0), (0,1), (1,1), (2,1), (0,2), (1,2), (2,2)]
# 原因：多重 for 从左到右是外层到内层，这里 y 在左是外层，x 在右是内层
# 所以 y 固定时遍历所有 x
# 修复：把 x 放在前面
result = [(x, y) for x in range(3) for y in range(3)]
print(result)
# [(0,0), (0,1), (0,2), (1,0), (1,1), (1,2), (2,0), (2,1), (2,2)]
```

# 修复：用元组（元组可哈希）
result = {(x, y) for x in range(2) for y in range(2)}
print(result)  # {(0,0), (0,1), (1,0), (1,1)}

# 题目 6
# 输出 5
# walrus 运算符 := 在推导式内赋值会修改外部变量
counter = 0
result = [(counter := counter + 1) for _ in range(5)]
print(counter)  # 5
print(result)  # [1, 2, 3, 4, 5]
```

## 总结

通过这些练习题，你应该能够：

1. 熟练掌握列表、字典、集合推导式与生成器表达式
2. 理解多重循环与多个 if 的执行顺序
3. 避开元组陷阱、作用域、生成器一次性等常见陷阱
4. 用 walrus 运算符在推导式中赋值与提取
5. 用推导式处理嵌套、展平、转置等结构变换
6. 在性能与可读性之间正确取舍

### 学习建议

1. **循序渐进**：从基础列表推导式开始，逐步挑战综合题
2. **动手实践**：每道题都自己运行验证
3. **对比写法**：同一问题用推导式、for 循环、map/filter 多种写法
4. **注意陷阱**：元组陷阱、生成器一次性、字典反转丢值等
5. **性能意识**：大数据集优先用生成器表达式
6. **可读性优先**：复杂逻辑果断用显式循环

### 常见模式总结

1. **过滤 + 映射**：`[f(x) for x in iter if cond(x)]`
2. **笛卡尔积**：`[(a, b) for a in A for b in B]`
3. **展平**：`[x for sub in nested for x in sub]`
4. **转置**：`[[row[i] for row in matrix] for i in range(n)]`
5. **反转字典**：`{v: k for k, v in d.items()}`
6. **条件计数**：`sum(1 for x in iter if cond(x))`
7. **聚合短路**：`any(...)` / `all(...)`
8. **walrus 提取**：`[y for x in iter if (y := f(x)) > 0]`

继续练习，你会越来越熟练！
