## String 基础

String（字符串）是 Python 中用于表示文本数据的核心数据类型，它是一个有序的、不可变的 Unicode 字符序列。

**特点：**
- **不可变性（immutable）**：字符串一旦创建，其内容不能被修改；所有"修改"操作都会返回新字符串对象
- **Unicode 支持**：Python 3 的字符串原生支持 Unicode，可以表示世界上几乎所有的文字
- **有序序列**：字符按顺序排列，支持索引和切片访问
- **可迭代**：字符串是可迭代对象，可以用 for 循环逐字符遍历
- **不可变带来的好处**：可以作为字典的键、集合的元素；多变量引用同一字符串时安全无副作用

**内存结构：**
- Python 3 中字符串以紧凑的柔性数组方式存储字符码点
- CPython 对短字符串进行"驻留"（intern），相同字面量共享同一对象以节省内存
- 时间复杂度：索引访问 O(1)，len() O(1)，拼接 `s + t` O(n+m)，`in` 子串搜索平均 O(n)

```python
# 字符串是不可变的
s = "hello"
print(type(s))   # <class 'str'>
print(len(s))     # 5

# "修改" 实际上是创建新字符串
s = "hello"
s[0] = "H"        # TypeError: 'str' object does not support item assignment

# 正确做法：生成新字符串
s = "H" + s[1:]
print(s)          # Hello

# 字符串驻留（intern）：相同字面量共享对象
a = "hello"
b = "hello"
print(a is b)     # True - 短字符串字面量被驻留

# 但动态构造的字符串不一定驻留
c = "hel" + "lo"
print(a is c)     # True - 编译期常量折叠
d = "".join(["h","e","l","l","o"])
print(a is d)     # False - 运行期拼接不一定驻留

# 手动驻留
e = sys.intern(d)
print(a is e)     # True
```

**字符串、字节串（bytes）、字节列表的关系：**
```python
s = "中文"                 # str: Unicode 文本
b = s.encode("utf-8")      # bytes: 字节序列
print(type(b))             # <class 'bytes'>
print(b)                   # b'\xe4\xb8\xad\xe6\x96\x87'
print(list(b))             # [228, 184, 173, 230, 150, 135]
print(b.decode("utf-8"))   # 中文
```

## 创建字符串

### 1. 使用引号创建

**语法：** `str_name = 'text'` 或 `str_name = "text"`

**特点：**
- 单引号 `'...'` 和双引号 `"..."` 完全等价
- 字符串本身包含单引号时，用双引号包裹更方便（反之亦然）
- 引号必须成对使用

```python
# 单引号
s1 = 'hello'
print(s1)  # hello

# 双引号
s2 = "world"
print(s2)  # world

# 字符串中包含单引号 → 用双引号包裹
s3 = "It's a book"
print(s3)  # It's a book

# 字符串中包含双引号 → 用单引号包裹
s4 = 'He said "hello"'
print(s4)  # He said "hello"

# 空字符串
empty1 = ''
empty2 = ""
print(len(empty1), len(empty2))  # 0 0
print(bool(empty1))              # False（空字符串为假值）
```

### 2. 使用三引号创建多行字符串

**语法：** `str_name = '''text'''` 或 `str_name = """text"""`

**特点：**
- 三引号字符串可以跨多行，保留换行符
- 常用于文档字符串（docstring）和多行文本
- 三引号内可以自由使用单/双引号而不需转义

```python
# 三引号多行字符串
poem = """静夜思
床前明月光
疑是地上霜"""
print(poem)
# 静夜思
# 床前明月光
# 疑是地上霜

# 三引号内自由使用引号
quote = '''他说："Python 是一门 '优雅' 的语言。"'''
print(quote)  # 他说："Python 是一门 '优雅' 的语言。"

# 注意：行首的缩进也会被保留
s = """
    缩进的内容
    """
print(repr(s))  # '\n    缩进的内容\n    '

# 文档字符串（docstring）
def greet(name):
    """返回问候语
    
    参数:
        name: 名字
    返回:
        问候字符串
    """
    return f"Hello, {name}"

print(greet.__doc__)
```

### 3. 转义字符

反斜杠 `\` 用于在字符串中插入特殊字符。

| 转义序列 | 含义 |
|---------|------|
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\n` | 换行 |
| `\r` | 回车 |
| `\t` | 水平制表符 |
| `\v` | 垂直制表符 |
| `\b` | 退格 |
| `\f` | 换页 |
| `\0` | 空字符（Null） |
| `\a` | 响铃 |
| `\xHH` | 两位十六进制 Unicode 字符 |
| `\uHHHH` | 四位十六进制 Unicode 字符 |
| `\UHHHHHHHH` | 八位十六进制 Unicode 字符 |
| `\ooo` | 八进制字符 |

```python
# 换行与制表
print("第一行\n第二行")     # 第一行 [换行] 第二行
print("A\tB\tC")            # A    B    C
print("姓名\t年龄\n张三\t20")

# 引号转义
print('It\'s a book')       # It's a book
print("He said \"hi\"")     # He said "hi"

# 反斜杠本身需要转义（Windows 路径）
path = "C:\\Users\\Admin\\Desktop"
print(path)  # C:\Users\Admin\Desktop

# 十六进制 \x
print("\x41")          # A （0x41 = 65 = 'A'）
print("\x4e2d")        # 错误：\x 只支持两位 → 实际只识别 \x4e = 'N'，'2d' 作为字面量

# Unicode \u（四位）和 \U（八位）
print("中")        # 中
print("é")        # é
print("\U0001f600")    # 😀

# 八进制 \ooo
print("\101")          # A （0o101 = 65）
```

**常见错误：**
```python
# 反斜杠末尾陷阱：行尾的反斜杠表示续行
s = "abc\
def"
print(s)  # abcdef（没有换行）

# Windows 路径中的 \U 被当成 Unicode 转义
# path = "C:\Users\name"  # SyntaxWarning / UnicodeDecodeError
# 正确写法：
path = "C:\\Users\\name"
path = r"C:\Users\name"  # 原始字符串
```

### 4. 原始字符串 r''

**语法：** `r'text'` 或 `R'text'`

**特点：**
- 反斜杠不被当作转义字符，按字面量处理
- 常用于正则表达式、Windows 路径
- 原始字符串**不能以单个反斜杠结尾**（仍会转义其后的引号）

```python
# 普通字符串 vs 原始字符串
print("C:\\new\\folder")   # C:\new\folder
print(r"C:\new\folder")    # C:\new\folder

# 正则表达式
import re
pattern = r"\d+\.\d+"      # 匹配数字.数字
print(re.findall(pattern, "价格 12.34 元"))  # ['12.34']

# 原始字符串内的引号仍需注意
s = r"It\'s ok"
print(s)  # It\'s ok  （反斜杠被保留）

# 原始字符串不能以单反斜杠结尾
# s = r"abc\"  # SyntaxError
# 变通：
s = r"abc" + "\\"
print(s)  # abc\
```

### 5. 使用 str() 构造函数

**语法：** `str(object='', encoding='utf-8', errors='strict')`

**参数：**
- `object`：要转换为字符串的对象
- `encoding`（仅用于 bytes/bytearray）：指定编码
- `errors`（仅用于 bytes/bytearray）：错误处理策略

**返回值：** 字符串对象

```python
# 从数字创建
print(str(123))      # '123'
print(str(3.14))     # '3.14'
print(str(True))     # 'True'
print(str(None))     # 'None'

# 从列表创建（调用其 __str__）
print(str([1, 2, 3]))   # '[1, 2, 3]'
print(str({'a': 1}))    # "{'a': 1}"

# 从 bytes 解码
b = b'hello'
print(str(b, encoding='utf-8'))  # hello

# 定义 __str__ 的自定义类
class Person:
    def __init__(self, name):
        self.name = name
    def __str__(self):
        return f"Person({self.name})"

print(str(Person("Alice")))  # Person(Alice)
```

### 6. 使用 join 从可迭代对象创建

```python
# 从字符列表拼接
chars = ['h', 'e', 'l', 'l', 'o']
s = "".join(chars)
print(s)  # hello

# 带分隔符拼接
words = ["Python", "is", "fun"]
print(" ".join(words))   # Python is fun
print("-".join(words))   # Python-is-fun
print(",".join(words))   # Python,is,fun
```

## 访问与切片

### 1. 索引访问

**语法：** `str[index]`

**参数：**
- `index`：整数
  - 正索引：从 0 开始，0 表示第一个字符
  - 负索引：从 -1 开始，-1 表示最后一个字符

**返回值：** 长度为 1 的字符串

**异常：**
- `IndexError`：索引超出范围

**时间复杂度：** O(1)

```python
s = "Python"

# 正向索引
print(s[0])   # 'P'
print(s[1])   # 'y'
print(s[5])   # 'n'

# 负向索引
print(s[-1])  # 'n' - 最后一个
print(s[-2])  # 'o' - 倒数第二个
print(s[-6])  # 'P' - 倒数第六个

# 索引越界
try:
    print(s[10])   # IndexError: string index out of range
except IndexError as e:
    print(f"错误: {e}")

try:
    print(s[-10])
except IndexError as e:
    print(f"错误: {e}")

# 字符串不可变：不能通过索引赋值
# s[0] = 'p'  # TypeError
```

**索引对应关系：**
```
字符串: P  y  t  h  o  n
正索引: 0  1  2  3  4  5
负索引:-6 -5 -4 -3 -2 -1
```

### 2. 切片访问

**语法：** `str[start:stop:step]`

**参数：**
- `start`（可选）：起始索引（包含），默认 0
- `stop`（可选）：结束索引（不包含），默认字符串长度
- `step`（可选）：步长，默认 1；负数表示反向

**返回值：** 新字符串（切片总是返回新对象）

**特点：**
- 切片**不会引发 IndexError**，越界会自动调整
- 支持 `start > stop` 的"空切片"

**时间复杂度：** O(k)，k 为切片长度

```python
s = "0123456789"

# 基本切片 [start:stop]
print(s[2:5])     # '234' - 索引 2 到 4
print(s[0:3])     # '012'

# 省略 start
print(s[:5])      # '01234' - 前 5 个字符
print(s[:])       # '0123456789' - 完整副本

# 省略 stop
print(s[5:])      # '56789'
print(s[7:])      # '789'

# 步长
print(s[::2])     # '02468' - 每隔一个字符
print(s[1::2])    # '13579' - 奇数位置
print(s[2:8:2])   # '246'

# 负步长（反向）
print(s[::-1])    # '9876543210' - 反转字符串
print(s[::-2])    # '97531'
print(s[8:2:-1])  # '876543'
print(s[5::-1])   # '543210'

# 负索引切片
print(s[-5:-2])   # '567'
print(s[-5:])     # '56789'
print(s[:-3])     # '0123456'

# 越界切片不报错
print(s[5:100])   # '56789' - 自动截断
print(s[-100:3])  # '012'
print(s[100:200]) # '' - 空字符串

# 空切片
print(s[5:2])     # '' - start > stop（正步长时）
print(s[5:5])     # ''
```

**切片常用模式：**
```python
s = "hello world"

# 复制
copy = s[:]

# 反转
rev = s[::-1]

# 取前 n 个
first_n = s[:n]

# 取后 n 个
last_n = s[-n:]

# 删除前 n 个
without_first = s[n:]

# 删除后 n 个
without_last = s[:-n]

# 每隔 k 个取一个
every_k = s[::k]
```

### 3. 切片反转字符串

```python
s = "abcdef"
print(s[::-1])  # fedcba

# 与 reversed() 对比
print("".join(reversed(s)))  # fedcba
```

### 4. 切片越界不报错的原理

切片的 start/stop 会被 `slice.indices(length)` 方法映射到有效范围，超出部分自动截断为 0 或 length，因此永远不会抛出 IndexError。

```python
sl = slice(5, 100, 1)
print(sl.indices(10))  # (5, 10, 1) - stop 被截断到 10

# 这也是 s[100:200] 返回空字符串的原因
sl = slice(100, 200, 1)
print(sl.indices(10))  # (10, 10, 1) - start=stop=10 → 空
```

## 字符串运算

### 1. + 拼接

**语法：** `str1 + str2`

**返回值：** 新字符串

**时间复杂度：** O(n+m)，需要复制两个字符串

```python
a = "Hello"
b = " World"
print(a + b)   # Hello World

# 多个拼接
print("a" + "b" + "c")  # abc

# 错误：不能与非字符串拼接
try:
    print("age: " + 25)   # TypeError
except TypeError as e:
    print(f"错误: {e}")

# 正确：先转换
print("age: " + str(25))  # age: 25
```

### 2. * 重复

**语法：** `str * n` 或 `n * str`

**返回值：** 新字符串

**时间复杂度：** O(n*len)

```python
print("ab" * 3)   # ababab
print(3 * "ab")   # ababab
print("-" * 30)   # ------------------------------
print("=" * 20)

# 0 或负数 → 空字符串
print("ab" * 0)    # ''
print("ab" * -1)   # ''
```

### 3. in / not in 成员检查

**语法：** `sub in s` 或 `sub not in s`

**返回值：** 布尔值

**时间复杂度：** 平均 O(n)，最坏 O(n*m)

**特点：**
- 检查的是子串（不仅是单字符）
- 大小写敏感

```python
s = "hello world"

print("hello" in s)       # True
print("world" in s)       # True
print("Hello" in s)       # False - 大小写敏感
print("xyz" not in s)     # True

# 单字符检查
print("h" in s)           # True
print("z" in s)           # False

# 用于条件判断
keyword = "python"
if keyword in "I love python":
    print("包含关键词")
```

### 4. len() 长度

**语法：** `len(s)`

**返回值：** 字符数（整数）

**时间复杂度：** O(1)

```python
print(len("hello"))   # 5
print(len(""))        # 0
print(len("中文"))    # 2 - 字符数，不是字节数
print(len("😀😀"))    # 2 - emoji 也算 1 个字符
```

### 5. 比较运算符

按字典序（Unicode 码点）逐字符比较。

```python
print("apple" == "apple")   # True
print("apple" != "banana")  # True
print("apple" < "banana")   # True
print("apple" < "apricot")  # True
print("abc" < "abcd")       # True - 前缀相同，短的更小

# 大小写：大写字母码点 < 小写字母
print("Apple" < "apple")    # True - 'A'(65) < 'a'(97)
print("Z" < "a")            # True

# max/min
print(max("hello"))   # 'o'
print(min("hello"))   # 'h'
```

## 字符串方法详解

字符串方法都返回新字符串（因为字符串不可变），原字符串不会被修改。

### 一、大小写转换

#### 1. upper() / lower()

**语法：** `s.upper()` / `s.lower()`

**返回值：** 全大写 / 全小写的新字符串

**时间复杂度：** O(n)

```python
s = "Hello World 123 中文"

print(s.upper())   # HELLO WORLD 123 中文
print(s.lower())   # hello world 123 中文

# 中文不受影响
print("你好".upper())   # 你好

# 大小写不敏感比较
a, b = "Hello", "hello"
print(a == b)              # False
print(a.lower() == b.lower())  # True
```

#### 2. capitalize()

首字母大写，其余小写。

```python
print("hello world".capitalize())   # 'Hello world'
print("HELLO".capitalize())         # 'Hello'
print("中文 hello".capitalize())    # '中文 hello' - 首字符非字母，原样
```

#### 3. title()

每个单词首字母大写。

```python
print("hello world".title())        # 'Hello World'
print("i love python".title())      # 'I Love Python'

# 陷阱：撇号后的字母也会被大写
print("don't stop".title())         # "Don'T Stop"
```

#### 4. swapcase()

大小写互换。

```python
print("Hello World".swapcase())   # 'hELLO wORLD'
print("PyThOn".swapcase())        # 'pYtHoN'
```

#### 5. casefold()

**语法：** `s.casefold()`

**返回值：** 折叠后的小写字符串

**特点：**
- 比 lower() 更激进，专为大小写不敏感比较设计
- 处理德语 ß 等特殊字符：`"ß".casefold() == "ss"`

```python
# 德语 ß
s = "straße"
print(s.lower())     # 'straße' - lower 不变
print(s.casefold())  # 'strasse' - casefold 展开为 ss

# 大小写不敏感比较的最佳实践
a, b = "STRASSE", "straße"
print(a.lower() == b.lower())              # False
print(a.casefold() == b.casefold())        # True
```

### 二、查找

#### 1. find() / rfind()

**语法：** `s.find(sub[, start[, stop]])` / `s.rfind(sub[, start[, stop]])`

**参数：**
- `sub`：要查找的子串
- `start`（可选）：起始位置，默认 0
- `stop`（可选）：结束位置，默认字符串长度

**返回值：** 找到的最低/最高索引；未找到返回 **-1**（不抛异常）

**时间复杂度：** O(n)

```python
s = "hello world hello"

print(s.find("hello"))   # 0 - 第一个
print(s.find("world"))   # 6
print(s.find("hello", 1))  # 12 - 从索引 1 开始找
print(s.find("xyz"))     # -1 - 未找到

print(s.rfind("hello"))  # 12 - 最后一个
print(s.rfind("o"))      # 14 - 最后一个 'o'

# 与 index() 对比：未找到时 find 返回 -1，index 抛 ValueError
```

#### 2. index() / rindex()

与 find/rfind 相同，但未找到时抛出 `ValueError`。

```python
s = "hello world"
print(s.index("world"))   # 6

try:
    print(s.index("xyz"))  # ValueError: substring not found
except ValueError as e:
    print(f"错误: {e}")

# 安全用法：先 in 检查
sub = "world"
if sub in s:
    print(s.index(sub))
```

#### 3. count()

**语法：** `s.count(sub[, start[, stop]])`

**返回值：** 子串出现次数（不重叠），未找到返回 0

**时间复杂度：** O(n)

```python
s = "hello world hello"
print(s.count("hello"))   # 2
print(s.count("l"))       # 4
print(s.count("x"))       # 0
print(s.count("o", 0, 5)) # 0 - 只在前 5 个字符中查找

# 不重叠计数
print("aaaa".count("aa"))  # 2 - 不重叠
```

#### 4. startswith() / endswith()

**语法：** `s.startswith(prefix[, start[, stop]])` / `s.endswith(suffix[, start[, stop]])`

**参数：** `prefix`/`suffix` 可以是字符串或字符串元组（任一匹配即 True）

**返回值：** 布尔值

```python
s = "hello world"

print(s.startswith("hello"))   # True
print(s.startswith("world"))   # False
print(s.startswith("world", 6))  # True - 从索引 6 开始
print(s.endswith("world"))      # True
print(s.endswith("hello", 0, 5))  # True

# 元组前缀：任一匹配即 True
filename = "image.PNG"
print(filename.endswith((".png", ".jpg", ".jpeg")))  # True

url = "https://example.com"
print(url.startswith(("http://", "https://")))  # True
```

### 三、替换

#### 1. replace()

**语法：** `s.replace(old, new[, count])`

**参数：**
- `old`：要被替换的子串
- `new`：替换成的新子串
- `count`（可选）：最多替换次数，默认全部

**返回值：** 新字符串

**时间复杂度：** O(n)

```python
s = "hello world"

print(s.replace("world", "Python"))   # hello Python
print(s.replace("l", "L"))            # heLLo worLd
print(s.replace("l", "L", 2))         # heLLo world - 只替换 2 个

# 删除子串（替换为空）
print("hello world".replace(" ", ""))  # helloworld

# replace 不支持正则，需要正则用 re.sub
import re
print(re.sub(r"\d+", "#", "a1b22c333"))  # a#b#c#
```

#### 2. expandtabs()

**语法：** `s.expandtabs(tabsize=8)`

**返回值：** 将制表符 `\t` 替换为空格的新字符串

```python
s = "a\tb\tc"
print(s)                # a	b	c（含制表符）
print(s.expandtabs())   # a       b       c（默认 8 字符宽）
print(s.expandtabs(4))  # a   b   c
print(repr(s.expandtabs(4)))  # 'a   b   c'

# 用于对齐表格
print("Name\tAge\tCity".expandtabs(10))
print("Alice\t20\tNYC".expandtabs(10))
```

### 四、分割与合并

#### 1. split() / rsplit()

**语法：** `s.split(sep=None, maxsplit=-1)` / `s.rsplit(sep=None, maxsplit=-1)`

**参数：**
- `sep`：分隔符。`None`（默认）时按任意空白字符分割，并自动去除空字符串
- `maxsplit`：最大分割次数，-1 表示不限制

**返回值：** 字符串列表

**特点：**
- `sep=None`：连续空白被视为单个分隔符，且首尾空白被忽略
- `sep=" "`：精确按单个空格分割，连续空格会产生空字符串
- rsplit 从右侧开始分割（仅在指定 maxsplit 时有区别）

```python
# 默认按空白分割
print("hello world python".split())        # ['hello', 'world', 'python']
print("  hello   world  ".split())         # ['hello', 'world'] - 去除首尾和多余空白
print("a,b,c".split(","))                  # ['a', 'b', 'c']

# maxsplit 限制次数
print("a,b,c,d".split(",", 2))             # ['a', 'b', 'c,d']
print("a,b,c,d".rsplit(",", 2))            # ['a,b', 'c', 'd'] - 从右分割

# 精确空格分割（注意区别）
print("hello  world".split(" "))           # ['hello', '', 'world'] - 连续空格产生空串
print("hello  world".split())              # ['hello', 'world']

# 分割行
print("a\nb\nc".split("\n"))               # ['a', 'b', 'c']
print("a\nb\nc".splitlines())              # ['a', 'b', 'c']

# 空字符串
print("".split())       # []
print("".split(","))    # [''] - 指定 sep 时空串返回 ['']
```

#### 2. splitlines()

**语法：** `s.splitlines([keepends])`

**参数：** `keepends`（可选）：是否保留行尾换行符，默认 False

**返回值：** 行列表

**特点：**
- 识别各种换行符：`\n`, `\r`, `\r\n`, `\v`, `\f`, `\x1c` 等
- 不像 split("\n")，最后一个空行不会被保留为空字符串

```python
text = "a\nb\nc"
print(text.splitlines())         # ['a', 'b', 'c']
print(text.splitlines(True))     # ['a\n', 'b\n', 'c']

text = "a\r\nb\rc"
print(text.splitlines())         # ['a', 'b', 'c'] - 自动识别多种换行

# 与 split("\n") 的区别
print("a\nb\n".split("\n"))      # ['a', 'b', ''] - 末尾有空串
print("a\nb\n".splitlines())     # ['a', 'b']     - 无末尾空串
```

#### 3. partition() / rpartition()

**语法：** `s.partition(sep)` / `s.rpartition(sep)`

**返回值：** 三元组 `(前部分, 分隔符, 后部分)`

**特点：**
- 总是返回 3 个元素的元组
- 未找到分隔符：partition 返回 `("原字符串", "", "")`；rpartition 返回 `("", "", "原字符串")`

```python
print("hello world".partition(" "))    # ('hello', ' ', 'world')
print("hello world".rpartition(" "))   # ('hello', ' ', 'world')

# 多个分隔符：partition 取第一个，rpartition 取最后一个
print("a.b.c".partition("."))    # ('a', '.', 'b.c')
print("a.b.c".rpartition("."))   # ('a.b', '.', 'c')

# 未找到
print("hello".partition(" "))    # ('hello', '', '')
print("hello".rpartition(" "))   # ('', '', 'hello')

# 常用于解析 key=value
key, _, value = "name=Alice".partition("=")
print(key, value)   # name Alice
```

#### 4. join()

**语法：** `sep.join(iterable)`

**参数：** `iterable`：元素必须是字符串的可迭代对象

**返回值：** 用 sep 连接后的新字符串

**时间复杂度：** O(n)（远快于 `+` 循环拼接）

```python
print(",".join(["a", "b", "c"]))   # a,b,c
print(" ".join(["Python", "is", "fun"]))  # Python is fun
print("".join(["h", "e", "l", "l", "o"]))  # hello
print("-".join("abc"))             # a-b-c - 字符串本身也是可迭代的

# 错误：元素必须都是字符串
try:
    print(",".join([1, 2, 3]))     # TypeError
except TypeError as e:
    print(f"错误: {e}")

# 正确：先转换
print(",".join(str(x) for x in [1, 2, 3]))  # 1,2,3

# 路径拼接
import os
print(os.path.join("folder", "sub", "file.txt"))  # folder/sub/file.txt
```

### 五、去除

#### 1. strip() / lstrip() / rstrip()

**语法：**
- `s.strip([chars])`
- `s.lstrip([chars])`
- `s.rstrip([chars])`

**参数：** `chars`（可选）：要去除的字符集合（字符串形式），默认去除空白字符

**返回值：** 新字符串

**特点：**
- `chars` 是字符集合，不是前缀/后缀：会去除所有出现在 chars 中的字符
- 从两端/左端/右端连续去除，遇到不在 chars 中的字符停止

```python
# 默认去除空白
print("  hello  ".strip())    # 'hello'
print("  hello  ".lstrip())   # 'hello  '
print("  hello  ".rstrip())   # '  hello'

# 去除指定字符集
print("xxxhelloxxx".strip("x"))    # 'hello'
print("abchelloba".strip("abc"))   # 'hello' - 'a','b','c' 都被去除
print("##hello##".strip("#"))      # 'hello'

# 陷阱：chars 是字符集不是前缀
print("abcabc".strip("abc"))   # '' - 全部被去除
print("hello".strip("he"))     # 'llo' - 'h','e' 都在集合中

# 去除多种字符
print("  \t\nhello \n".strip())    # 'hello'

# 实用：去除引号
s = '"hello"'
print(s.strip('"'))   # hello
```

### 六、对齐填充

#### 1. center() / ljust() / rjust()

**语法：**
- `s.center(width[, fillchar])`
- `s.ljust(width[, fillchar])`
- `s.rjust(width[, fillchar])`

**参数：**
- `width`：总宽度。若小于字符串长度，返回原字符串
- `fillchar`（可选）：填充字符，默认空格，必须是单个字符

**返回值：** 新字符串

```python
print("hello".center(11))       # '   hello   '
print("hello".center(11, "*"))  # '***hello***'
print("hello".ljust(10, "-"))   # 'hello-----'
print("hello".rjust(10, "-"))   # '-----hello'

# width < len：原样返回
print("hello".center(3))  # 'hello'

# 制表对齐
for name, score in [("Alice", 95), ("Bob", 100)]:
    print(name.ljust(10), str(score).rjust(5))
# Alice        95
# Bob         100
```

#### 2. zfill()

**语法：** `s.zfill(width)`

**返回值：** 左侧填充 0 到指定宽度的字符串

**特点：** 若字符串以符号（`+`/`-`）开头，0 填在符号之后

```python
print("42".zfill(5))      # '00042'
print("-42".zfill(5))     # '-0042' - 0 在符号后
print("+42".zfill(5))     # '+0042'
print("hello".zfill(10))  # '00000hello'

# 用于编号补零
for i in range(1, 4):
    print(f"ID-{str(i).zfill(3)}")  # ID-001 ID-002 ID-003
```

### 七、判断方法

返回布尔值，用于判断字符串的字符组成特征。

| 方法 | 含义 |
|------|------|
| `isalpha()` | 是否全为字母 |
| `isdigit()` | 是否全为数字（不含小数点、负号） |
| `isalnum()` | 是否全为字母或数字 |
| `isspace()` | 是否全为空白字符 |
| `isupper()` | 是否全大写（含字母） |
| `islower()` | 是否全小写（含字母） |
| `istitle()` | 是否标题形式（每个单词首字母大写） |
| `isnumeric()` | 是否全为数值字符（含罗马数字、分数等） |
| `isdecimal()` | 是否全为十进制数字字符 |
| `isidentifier()` | 是否合法标识符 |
| `isprintable()` | 是否全为可打印字符 |

```python
print("hello".isalpha())      # True
print("hello123".isalpha())   # False
print("123".isdigit())        # True
print("12.3".isdigit())       # False - 含小数点
print("hello123".isalnum())   # True
print("   ".isspace())        # True
print("\t\n".isspace())       # True
print("HELLO".isupper())      # True
print("Hello".islower())      # False
print("Hello World".istitle())  # True

# 中文也是字母
print("中文".isalpha())      # True
print("中文123".isalnum())   # True

# 用户输入校验
user_input = "12345"
print(user_input.isdigit())  # True - 可安全转 int
```

**isnumeric / isdigit / isdecimal 的区别（重要）：**

| 字符 | isdecimal | isdigit | isnumeric |
|------|-----------|---------|-----------|
| `"123"` | True | True | True |
| `"²"`（上标 2） | False | True | True |
| `"½"`（分数） | False | False | True |
| `"Ⅳ"`（罗马数字） | False | False | True |
| `"-1"` | False | False | False |

```python
print("123".isdecimal(), "123".isdigit(), "123".isnumeric())   # True True True
print("²".isdecimal(), "²".isdigit(), "²".isnumeric())         # False True True
print("½".isdecimal(), "½".isdigit(), "½".isnumeric())         # False False True

# 转换 int 时只有 decimal 风格最安全
print(int("123"))   # 123
# int("²")  # ValueError
```

### 八、格式化方法

详见 [字符串格式化](#字符串格式化) 一节。

```python
print("{} {}".format("Hello", "World"))      # Hello World
```

```python
data = {"name": "Alice", "age": 20}

from collections import defaultdict

print("{name} from {city}".format_map(d))  # Alice from 未知

```

## 字符串格式化

Python 提供三种字符串格式化方式，推荐使用 f-string（Python 3.6+）。

### 1. f-string（推荐）

**语法：** `f'text {expression:format_spec}'`

**特点：**
- 在字符串前加 `f` 或 `F`
- `{}` 内可放任意 Python 表达式
- 支持格式说明符 `:` 后接格式规范
- 性能最好

#### 变量与表达式

```python
name = "Alice"
age = 20
print(f"Hello, {name}!")            # Hello, Alice!
print(f"{name} is {age} years old") # Alice is 20 years old

# 表达式
print(f"{1 + 2 * 3}")              # 7
print(f"{len(name)}")              # 5
print(f"{name.upper()}")           # ALICE
print(f"{[x**2 for x in range(3)]}")  # [0, 1, 4]

# 调用函数
print(f"{'hello'.title()}")        # Hello
```

#### 格式说明符

**语法：** `{value:[[fill]align][sign][#][0][width][,][.precision][type]}`

- `fill`：填充字符
- `align`：`<` 左对齐、`>` 右对齐、`^` 居中、`=` 符号位后填充
- `sign`：`+` 总显示符号、`-` 仅负数显示（默认）、` ` 正数加空格
- `#`：显示进制前缀（0x, 0o, 0b）
- `0`：数值前补零
- `width`：最小宽度
- `,`：千分位分隔符
- `.precision`：精度（小数位数或字符串截断长度）
- `type`：类型码（d, f, e, x, o, b, s, % 等）

```python
# 宽度与对齐
print(f"{42:10}")       # '        42' - 默认右对齐
print(f"{42:<10}")      # '42        ' - 左对齐
print(f"{42:>10}")      # '        42' - 右对齐
print(f"{42:^10}")      # '    42    ' - 居中
print(f"{42:_>10}")     # '________42' - 用 _ 填充

# 符号
print(f"{5:+}")         # '+5'
print(f"{5:-}")         # '5'
print(f"{5: }")         # ' 5'
print(f"{-5:+}")        # '-5'

# 补零
print(f"{42:05}")       # '00042'
print(f"{42:010}")      # '0000000042'

# 千分位
print(f"{1234567:,}")   # '1,234,567'
print(f"{1234567:_}")   # '1_234_567'（下划线分组）

# 精度
print(f"{3.14159:.2f}")  # '3.14'
print(f"{3.14159:.4f}")  # '3.1416'
print(f"{12345.6789:.2f}")  # '12345.68'

# 字符串截断
print(f"{'hello world':.5}")  # 'hello' - 截断到 5 字符
print(f"{'hello':10.3}")      # 'hel       ' - 宽度10，截断3

# 进制
n = 255
print(f"{n:b}")     # '11111111' - 二进制
print(f"{n:o}")     # '377' - 八进制
print(f"{n:x}")     # 'ff' - 十六进制小写
print(f"{n:X}")     # 'FF' - 十六进制大写
print(f"{n:#x}")    # '0xff' - 带前缀
print(f"{n:#b}")    # '0b11111111'

# 百分比
print(f"{0.75:.0%}")   # '75%'
print(f"{0.756:.1%}")  # '75.6%'
print(f"{1/3:.2%}")    # '33.33%'

# 科学计数法
print(f"{1234567:.2e}")   # '1.23e+06'
print(f"{0.000123:.2e}")  # '1.23e-04'

# 日期格式化
from datetime import datetime
now = datetime.now()
print(f"{now:%Y-%m-%d}")            # 2026-06-29
print(f"{now:%Y-%m-%d %H:%M:%S}")   # 2026-06-29 14:30:00
print(f"{now:%Y年%m月%d日}")         # 2026年06月29日
```

#### 嵌套与变量在格式中

```python
width = 10
precision = 3
value = 3.14159
print(f"{value:{width}.{precision}f}")  # '     3.142'

# 嵌套字段
align = ">"
print(f"{42:{align}{width}}")   # '        42'

# ! 转换：!r 调 repr, !s 调 str, !a 调 ascii
name = "Alice"
print(f"{name!r}")     # 'Alice' - 带引号
print(f"{name!s}")     # Alice
```

#### f-string 中的引号

Python 3.12+ 允许 f-string 内使用与外层相同的引号；早期版本需使用不同引号。

```python
# Python 3.12+
# print(f"{'hello'}")  # 3.12+ 合法

# 3.11 及更早：内外引号需不同
print(f"{'hello'}")    # 内单外双 → 合法（所有版本）
print(f"{'hello'.upper()}")  # HELLO
```

### 2. str.format()

**语法：** `"{}".format(args)`

**特点：**
- 比 f-string 早，兼容性好
- 占位符 `{}` 可带字段名或索引

```python
# 位置参数
print("{} + {} = {}".format(1, 2, 3))         # 1 + 2 = 3
print("{0} {0} {1}".format("a", "b"))         # a a b

# 命名参数
print("{name} is {age}".format(name="Alice", age=20))

# 访问属性和元素
class Point:
    def __init__(self):
        self.x = 3
        self.y = 4
p = Point()
print("{0.x}, {0.y}".format(p))   # 3, 4
print("{[0]}".format([10, 20]))   # 10

# 格式说明符与 f-string 相同
print("{:.2f}".format(3.14159))   # 3.14
print("{:>10}".format("hi"))      # '        hi'
```

### 3. % 占位符（老式）

```python
print("Name: %s" % "Alice")               # Name: Alice
print("Age: %d" % 20)                     # Age: 20
print("Pi: %.2f" % 3.14159)               # Pi: 3.14
print("%5d" % 42)                         # '   42'
print("%-5d|" % 42)                       # '42   |'
print("%05d" % 42)                        # '00042'
print("%e" % 1234567)                     # '1.234567e+06'
print("Hex: %#x" % 255)                   # Hex: 0xff
```

### 4. 三种方式对比

| 特性 | f-string | str.format | % 格式化 |
|------|----------|------------|---------|
| 可读性 | 最好 | 好 | 一般 |
| 性能 | 最快 | 中等 | 较慢 |
| 表达式支持 | 任意 | 受限 | 不支持 |
| 引入版本 | 3.6 | 2.6 | 早期 |
| 国际化（i18n） | 不便 | 适合 | 适合 |

```python
name, age = "Alice", 20

# f-string
print(f"{name} is {age}")

# format
print("{} is {}".format(name, age))

# %
print("%s is %d" % (name, age))
```

## 编码与解码

### 1. encode() 编码

**语法：** `s.encode(encoding='utf-8', errors='strict')`

**参数：**
- `encoding`：编码名称，常用 `utf-8`、`gbk`、`ascii`、`latin-1`
- `errors`：错误处理策略
  - `strict`（默认）：抛 UnicodeEncodeError
  - `ignore`：忽略无法编码的字符
  - `replace`：替换为 `?`
  - `backslashreplace`：替换为 `\xHH` 转义
  - `xmlcharrefreplace`：替换为 XML 字符引用

**返回值：** bytes 对象

```python
s = "中文"

# UTF-8 编码（变长，每个中文 3 字节）
b = s.encode("utf-8")
print(b)           # b'\xe4\xb8\xad\xe6\x96\x87'
print(len(b))      # 6

# GBK 编码（每个中文 2 字节）
b_gbk = s.encode("gbk")
print(b_gbk)       # b'\xd6\xd0\xce\xc4'
print(len(b_gbk))   # 4

# ASCII 无法编码中文
try:
    s.encode("ascii")  # UnicodeEncodeError
except UnicodeEncodeError as e:
    print(f"错误: {e}")

# errors 处理
print(s.encode("ascii", errors="ignore"))          # b''
print(s.encode("ascii", errors="replace"))         # b'??'
print(s.encode("ascii", errors="xmlcharrefreplace"))  # b'&#20013;&#25991;'
```

### 2. decode() 解码

**语法：** `b.decode(encoding='utf-8', errors='strict')`

**返回值：** 字符串

```python
b = b'\xe4\xb8\xad\xe6\x96\x87'
print(b.decode("utf-8"))   # 中文

# 错误的编码会导致乱码或异常
try:
    print(b.decode("gbk"))  # 乱码或 UnicodeDecodeError
except UnicodeDecodeError as e:
    print(f"错误: {e}")

# errors 处理
bad_bytes = b'\xe4\xb8\xff'  # 非法 UTF-8
print(bad_bytes.decode("utf-8", errors="replace"))   # '中'
print(bad_bytes.decode("utf-8", errors="ignore"))    # '中'
```

### 3. bytes 与 str 的区别

| 特性 | str | bytes |
|------|-----|-------|
| 类型 | 文本（Unicode） | 字节序列 |
| 字面量 | `'...'` | `b'...'` |
| 元素 | 字符（str） | 整数（0-255） |
| 用途 | 处理文本 | 网络传输、文件 I/O |

```python
s = "ABC"
b = b"ABC"

print(type(s))   # <class 'str'>
print(type(b))   # <class 'bytes'>

# bytes 的元素是整数
print(b[0])      # 65
print(s[0])      # 'A'

# 互相转换
print(s.encode("ascii"))   # b'ABC'
print(b.decode("ascii"))   # 'ABC'

# bytes 不能直接和 str 拼接
try:
    s + b    # TypeError
except TypeError as e:
    print(f"错误: {e}")
```

### 4. chr() 和 ord()

**语法：**
- `ord(c)`：单字符 → Unicode 码点（整数）
- `chr(i)`：整数 → 对应 Unicode 字符

```python
print(ord('A'))      # 65
print(ord('a'))      # 97
print(ord('0'))      # 48
print(ord('中'))     # 20013

print(chr(65))       # 'A'
print(chr(97))       # 'a'
print(chr(20013))    # '中'
print(chr(128512))   # 😀

# 大小写转换的底层原理
c = 'a'
print(chr(ord(c) - 32))   # 'A'

# 遍历字母表
import string
print(string.ascii_uppercase)   # ABCDEFGHIJKLMNOPQRSTUVWXYZ
print([chr(i) for i in range(65, 91)])  # ['A', 'B', ..., 'Z']
```

### 5. 常见编码

| 编码 | 特点 |
|------|------|
| ASCII | 7 位，128 个字符，仅英文 |
| Latin-1 (ISO-8859-1) | 8 位，256 个字符，西欧语言 |
| UTF-8 | 变长（1-4 字节），兼容 ASCII，互联网主流 |
| UTF-16 | 定长 2 或 4 字节 |
| GBK | 中文编码，每个汉字 2 字节 |
| GB2312 | GBK 子集，简体中文 |

```python
# 同一文本不同编码的字节数
text = "Hello, 中文"
print(len(text.encode("utf-8")))    # 13 (7 ASCII + 2*3)
print(len(text.encode("gbk")))      # 11 (7 ASCII + 2*2)
print(len(text.encode("utf-16")))   # 14 (2 BOM + 7*2)
```

## 模板字符串 Template

`string.Template` 提供简单的占位符替换，比 `%` 和 `format` 更安全（适合处理用户提供的模板）。

**语法：** `Template("text $name or ${name}").substitute(mapping)`

```python
from string import Template

# 基本用法
t = Template("Hello, $name!")
print(t.substitute(name="Alice"))   # Hello, Alice!

# ${name} 形式（避免歧义）
t = Template("Hello, ${name}!")
print(t.substitute(name="Alice"))

# 多个变量
t = Template("$name is $age years old")
print(t.substitute(name="Alice", age=20))  # Alice is 20 years old

# 从字典
data = {"name": "Alice", "age": 20}
print(t.substitute(data))

# safe_substitute：缺少变量不报错
t = Template("$a and $b")
print(t.safe_substitute({"a": 1}))   # '1 and $b' - b 保留
# t.substitute({"a": 1})  # KeyError - substitute 会报错

# $$ 表示字面的 $
t = Template("Price: $$100")
print(t.substitute())   # Price: $100
```

**适用场景：**
- 用户提供的模板字符串（避免注入风险）
- 国际化（i18n）模板
- 配置文件变量替换

## 常用技巧

### 1. 反转字符串

```python
# 方法1：切片（最快）
s = "hello"
print(s[::-1])   # olleh

# 方法2：reversed + join
print("".join(reversed(s)))   # olleh

# 方法3：循环
result = ""
for c in s:
    result = c + result
print(result)   # olleh

# 方法4：递归
def reverse(s):
    return s[::-1] if len(s) <= 1 else reverse(s[1:]) + s[0]
```

### 2. 去重保序

```python
s = "abacabad"

# 方法1：dict.fromkeys（Python 3.7+ 保序）
print("".join(dict.fromkeys(s)))   # abcd

# 方法2：循环
seen = set()
result = "".join(c for c in s if not (c in seen or seen.add(c)))
print(result)   # abcd
```

```python
def is_palindrome(s):
```

### 5. 驼峰转换

```python
    parts = s.split("_")
```

### 6. 判断子序列

判断 s 是否为 t 的子序列（字符顺序出现，不要求连续）。

```python
def is_subsequence(s, t):
    it = iter(t)
    return all(c in it for c in s)

print(is_subsequence("abc", "ahbgdc"))   # True
print(is_subsequence("axc", "ahbgdc"))   # False

# 双指针法
def is_subsequence2(s, t):
    i = j = 0
    while i < len(s) and j < len(t):
        if s[i] == t[j]:
            i += 1
        j += 1
    return i == len(s)
```

### 10. 字符串加密（凯撒密码）

```python
def caesar(text, shift):
    result = []
    for c in text:
        if c.isupper():
            result.append(chr((ord(c) - 65 + shift) % 26 + 65))
        elif c.islower():
            result.append(chr((ord(c) - 97 + shift) % 26 + 97))
        else:
            result.append(c)
    return "".join(result)

print(caesar("Hello", 3))   # Khoor
print(caesar("Khoor", -3))  # Hello
```

## 性能分析

### 时间复杂度总结

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `s[i]` | O(1) | 索引访问 |
| `len(s)` | O(1) | 长度（缓存） |
| `s + t` | O(n+m) | 拼接，复制两串 |
| `s * k` | O(n*k) | 重复 |
| `s in t` | 平均 O(n) | 子串搜索 |
| `s.find()` | O(n) | 查找 |
| `s.replace()` | O(n) | 替换 |
| `s.split()` | O(n) | 分割 |
| `sep.join()` | O(n) | 合并 |
| `s.strip()` | O(n) | 去除 |
| `s[i:j]` | O(j-i) | 切片 |
| `s.upper()` | O(n) | 大小写转换 |

### 1. 字符串拼接陷阱

**问题：** 在循环中使用 `+` 拼接字符串效率极低。

```python
# 不推荐：每次 + 都创建新字符串，总复杂度 O(n²)
result = ""
for i in range(10000):
    result += str(i)

# 推荐：用 join，一次性分配
result = "".join(str(i) for i in range(10000))

# 推荐：写入列表再 join
parts = []
for i in range(10000):
    parts.append(str(i))
result = "".join(parts)
```

**原理：** 字符串不可变，`a + b` 需要分配新空间并复制 a 和 b。循环中每次 `+=` 都会复制累积的所有内容。

### 2. intern（字符串驻留）

CPython 会自动驻留：
- 短字符串字面量
- 仅含字母、数字、下划线的标识符样式的字符串

```python
import sys

# 手动驻留（用于大量重复字符串的场景）
a = sys.intern("very_long_string_" * 1)
b = sys.intern("very_long_string_" * 1)
print(a is b)   # True - 共享对象

# 适用场景：从文件/网络读取的大量重复字符串
# intern 后可以加速 == 比较和 in 查找
```

### 3. f-string vs format vs %

```python
import timeit

name, age = "Alice", 20

# f-string 最快
t1 = timeit.timeit(lambda: f"{name} is {age}", number=1000000)

# format 中等
t2 = timeit.timeit(lambda: "{} is {}".format(name, age), number=1000000)

# % 较慢
t3 = timeit.timeit(lambda: "%s is %d" % (name, age), number=1000000)

# 通常 t1 < t2 < t3
```

**结论：**
- 性能要求高且 Python 3.6+：用 f-string
- 需要模板复用或 i18n：用 format 或 Template
- 简单场景：三者皆可，可读性优先

### 4. 成员检查的优化

```python
# 单字符检查：用 in 字符串
vowels = "aeiou"
print("a" in vowels)   # O(n) 但 n 很小

# 多字符检查大量数据：用 set
vowel_set = set("aeiou")
for c in "hello":
    if c in vowel_set:   # O(1)
        print(c)
```

## 常见错误

### 1. 索引越界

```python
s = "hello"
try:
    print(s[10])   # IndexError
except IndexError as e:
    print(f"错误: {e}")

# 解决：先检查长度
if len(s) > 10:
    print(s[10])
```

### 2. 不可变导致"修改"无效

```python
s = "hello"
s.replace("h", "H")   # 返回新字符串，但没接收
print(s)   # hello - 原字符串未变

# 正确：接收返回值
s = s.replace("h", "H")
print(s)   # Hello
```

### 3. 编码错误 UnicodeDecodeError

```python
# 用错误编码解码
b = b'\xe4\xb8\xad'   # UTF-8 编码的"中"
try:
    print(b.decode("gbk"))   # UnicodeDecodeError 或乱码
except UnicodeDecodeError as e:
    print(f"错误: {e}")

# 解决：使用正确编码，或 errors 参数
print(b.decode("utf-8"))                    # 中
print(b.decode("gbk", errors="replace"))    # 锟? （乱码但不报错）
```

### 4. 反斜杠转义陷阱

```python
# Windows 路径
# path = "C:\new\folder"   # \n 被当作换行！
# print(path)  # C:
# ew\folder

# 解决方法1：双反斜杠
path = "C:\\new\\folder"

# 解决方法2：原始字符串
path = r"C:\new\folder"

# 解决方法3：正斜杠（Python 接受）
path = "C:/new/folder"
```

### 5. isnumeric / isdigit / isdecimal 区别

```python
# 误用 isdigit 判断能否转 int
s = "²"
print(s.isdigit())   # True - 但 int(s) 会失败
# int(s)   # ValueError

# 正确：用 isdecimal
print(s.isdecimal())   # False
# 或直接 try
try:
    n = int(s)
except ValueError:
    n = 0
```

### 6. split 的空串陷阱

```python
# 空字符串 split
print("".split(","))     # [''] - 注意返回 [''] 而非 []
print("".split())        # []   - 默认 sep 返回 []

# 连续分隔符
print("a,,b".split(","))  # ['a', '', 'b']
print("a,,b".split())     # ['a,,b'] - 默认按空白
```

### 7. strip 的字符集误解

```python
# 误以为 strip("abc") 是去除前缀 "abc"
print("abcHelloabc".strip("abc"))   # 'Hello' - 实际去除 a/b/c 任意组合
print("cabHello".strip("abc"))      # 'Hello'

# 只想去掉固定前缀/后缀：用 removeprefix/removesuffix（Python 3.9+）
print("abcHello".removeprefix("abc"))   # Hello
print("Helloabc".removesuffix("abc"))   # Hello
```

### 8. 大小写敏感比较

```python

# 不区分大小写比较

```

```python
age = 20
# print("Age: " + age)   # TypeError

print(f"Age: {age}")        # Age: 20  （推荐）
```

## 总结

### 核心要点

1. **字符串特性**
   - 不可变、Unicode、有序、可迭代
   - 索引访问 O(1)，长度 O(1)
   - 所有"修改"操作返回新字符串

2. **常用方法分类**
   - 大小写：`upper`/`lower`/`capitalize`/`title`/`swapcase`/`casefold`
   - 查找：`find`/`rfind`/`index`/`rindex`/`count`/`startswith`/`endswith`
   - 替换：`replace`/`expandtabs`
   - 分割合并：`split`/`rsplit`/`splitlines`/`partition`/`rpartition`/`join`
   - 去除：`strip`/`lstrip`/`rstrip`
   - 对齐：`center`/`ljust`/`rjust`/`zfill`
   - 判断：`isalpha`/`isdigit`/`isalnum`/`isspace`/`isnumeric`/`isdecimal` 等
   - 格式化：`format`/`format_map`

3. **格式化方式**
   - f-string（推荐，最快最可读）
   - str.format()
   - % 占位符（老式）
   - string.Template（用户模板）

4. **编码**
   - str 是 Unicode 文本，bytes 是字节序列
   - encode/decode 在两者间转换
   - 推荐 UTF-8 作为通用编码
   - chr/ord 在字符与码点间转换

5. **性能**
   - 循环拼接用 join，不要用 +=
   - f-string 性能最好
   - 大量重复字符串可 intern

6. **常见陷阱**
   - 不可变导致方法返回值被忽略
   - 反斜杠转义（Windows 路径）
   - 编码不一致导致 UnicodeDecodeError
   - isdigit/isnumeric/isdecimal 的差异
   - strip 是字符集而非前缀

### 何时使用字符串

**适合：**
- 文本数据处理
- 用户输入、配置文件
- 日志、消息、模板

**不适合：**
- 二进制数据（用 bytes）
- 频繁修改的大文本（用 io.StringIO 或 list + join）
- 数值计算（转换为 int/float）
