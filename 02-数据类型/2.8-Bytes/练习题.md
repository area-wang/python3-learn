## 创建 bytes

### 练习题

**题目 1：基础创建**
1. 使用字面量创建 `b'Hello'`
2. 使用 `bytes()` 创建空字节串
3. 使用 `bytes(5)` 创建什么？输出并解释
4. 使用 `bytes([65, 66, 67])` 创建字节串

**题目 2：从字符串创建**
1. 将 `'Hello'` 用 UTF-8 编码为 bytes（两种方式）
2. 将 `'中文'` 分别用 UTF-8 和 GBK 编码，比较字节数
3. 尝试 `bytes('hello')` 不指定 encoding，会发生什么？

**题目 3：从可迭代对象创建**
1. 用 `range(65, 91)` 创建包含所有大写字母的 bytes
2. 用列表 `[0, 255, 128, 64]` 创建 bytes
3. 尝试用 `[256]` 创建，会发生什么？

**题目 4：陷阱题**
以下代码输出是什么？解释原因。
```python
b1 = b'123'
b2 = bytes([1, 2, 3])
print(b1 == b2)
print(b1[0], b2[0])
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
b1 = b'Hello'
print(b1)  # b'Hello'

empty = bytes()
print(empty)  # b''

b_zeros = bytes(5)
print(b_zeros)  # b'\x00\x00\x00\x00\x00' - 5 个零字节

b_abc = bytes([65, 66, 67])
print(b_abc)  # b'ABC'

# 题目 2
# 方式1：encode
b1 = 'Hello'.encode('utf-8')
# 方式2：bytes 构造
b2 = bytes('Hello', 'utf-8')
print(b1, b2, b1 == b2)  # b'Hello' b'Hello' True

b_utf8 = '中文'.encode('utf-8')
b_gbk = '中文'.encode('gbk')
print(len(b_utf8), len(b_gbk))  # 6 4（UTF-8 每字 3 字节，GBK 每字 2 字节）

try:
    bytes('hello')  # TypeError
except TypeError as e:
    print(f"错误: {e}")  # string argument without an encoding

# 题目 3
b_upper = bytes(range(65, 91))
print(b_upper)  # b'ABCDEFGHIJKLMNOPQRSTUVWXYZ'

b_mix = bytes([0, 255, 128, 64])
print(b_mix)  # b'\x00\xff\x80@'

try:
    bytes([256])  # 256 > 255
except ValueError as e:
    print(f"错误: {e}")  # bytes must be in range(0, 256)

# 题目 4
b1 = b'123'
b2 = bytes([1, 2, 3])
print(b1 == b2)  # False
# b'123' 的字节是 [49, 50, 51]（ASCII '1','2','3'）
# bytes([1, 2, 3]) 的字节是 [1, 2, 3]
# 两者完全不同！
print(b1[0], b2[0])  # 49 1
# b1[0] 是 '1' 的 ASCII 值 49，b2[0] 是整数 1
```

**题目 2：切片访问**

1. 获取前 5 个字节
2. 获取最后 5 个字节
3. 反转整个字节串
4. `b[0:1]` 和 `b[0]` 的区别是什么？

**题目 3：陷阱题 - 索引类型**
以下代码哪里有错？如何修复？
```python
b = b'Hello'
first_char = b[0]
print(first_char.upper())  # 期望输出 'H'
```

**题目 4：实战应用**
编写函数，接收 bytes，返回每个字节的整数值列表。例如 `b'AB'` -> `[65, 66]`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
b = b'Hello'
print(type(b[0]))  # <class 'int'>
print(b[0])   # 72
print(b[-1])  # 111
print(b[0] == b'H')  # False
# b[0] 是 int 72，b'H' 是 bytes b'H'，类型不同，不相等
# 但 72 == ord('H')，所以 chr(b[0]) == 'H'

# 题目 2
b = b'Hello World'
print(b[:5])     # b'Hello'
print(b[-5:])    # b'World'
print(b[::-1])   # b'dlroW olleH'

# b[0:1] 返回 bytes b'H'，b[0] 返回 int 72
print(b[0:1], type(b[0:1]))  # b'H' <class 'bytes'>
print(b[0], type(b[0]))      # 72 <class 'int'>

# 题目 3
b = b'Hello'
first_char = b[0]  # 这是 int 72
# first_char.upper()  # AttributeError: 'int' object has no attribute 'upper'
# 修复方式1：用切片取单字节 bytes
first_char = b[0:1]  # b'H'
print(first_char.upper())  # b'H'
# 修复方式2：转字符
print(chr(b[0]))  # 'H'

# 题目 4
def bytes_to_int_list(b):
    return list(b)

print(bytes_to_int_list(b'AB'))  # [65, 66]

# 或用推导式
def bytes_to_int_list_v2(b):
    return [byte for byte in b]

print(bytes_to_int_list_v2(b'Hello'))  # [72, 101, 108, 108, 111]
```
</details>

## bytearray 可变字节

### 练习题

**题目 1：基础操作**
1. 创建 `bytearray(b'hello')`
2. 将第一个字节改为大写 'H' 的值
3. 追加字节 `33`（'!'）
4. 在索引 5 处插入空格 `32`

**题目 2：bytes vs bytearray**
1. 演示 bytes 不可变（修改会报错）
2. 演示 bytearray 可变
3. bytes 和 bytearray 哪个可哈希？哪个能做字典键？

**题目 3：可变方法**
给定 `ba = bytearray(b'ABCABC')`
1. 删除第一个 'A'（值 65）
2. 反转 ba
3. 弹出最后一个字节并打印
4. 清空 ba

**题目 4：实战应用 - 动态构建**
使用 bytearray 高效构建一个 1000 字节的递增序列（0,1,2,...,255,0,1,...），最后转为 bytes。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
ba = bytearray(b'hello')
ba[0] = ord('H')  # 72
ba.append(33)     # '!'
ba.insert(5, 32)  # 空格
print(ba)  # bytearray(b'Hello !')

# 题目 2
b = b'hello'
try:
    b[0] = 72  # TypeError
except TypeError as e:
    print(f"bytes 错误: {e}")

ba = bytearray(b'hello')
ba[0] = 72
print(ba)  # bytearray(b'Hello')

# bytes 可哈希，bytearray 不可哈希
d = {b'key': 'value'}  # 可以
print(d[b'key'])  # value
try:
    {bytearray(b'key'): 'v'}  # TypeError
except TypeError as e:
    print(f"bytearray 错误: {e}")

# 题目 3
ba = bytearray(b'ABCABC')
ba.remove(65)  # 删除第一个 65 ('A')
print(ba)  # bytearray(b'BCABC')

ba.reverse()
print(ba)  # bytearray(b'CBACB')

last = ba.pop()
print(last)  # 67 ('C')
print(ba)   # bytearray(b'CBAC')

ba.clear()
print(ba)  # bytearray(b'')

# 题目 4
ba = bytearray()
for i in range(1000):
    ba.append(i % 256)
result = bytes(ba)
print(len(result))  # 1000
print(result[:5])   # b'\x00\x01\x02\x03\x04'
print(result[-1])   # 231（999 % 256 = 231）
```
</details>

## 编码与解码

### 练习题

**题目 1：基础编解码**
1. 将 `'Hello, 世界'` 用 UTF-8 编码为 bytes
2. 将得到的 bytes 解码回字符串
3. 验证往返是否无损

**题目 2：不同编码对比**
1. 将 `'中文'` 分别用 UTF-8、GBK、UTF-16 编码，打印字节数和字节内容
2. 用 UTF-8 编码的 bytes，能用 GBK 正确解码吗？为什么？

**题目 3：ASCII 限制**
1. `'Hello'.encode('ascii')` 成功吗？
2. `'café'.encode('ascii')` 成功吗？为什么？
3. `'café'.encode('latin-1')` 成功吗？字节数是多少？

**题目 4：陷阱题 - 编码不匹配**
以下代码输出是什么？解释。
```python
s = '中文'
b = s.encode('utf-8')
print(b.decode('gbk'))
```

**题目 5：实战应用**
编写函数 `safe_decode(b)`，尝试用 UTF-8 解码 bytes，失败则尝试 GBK，都失败返回 None。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
s = 'Hello, 世界'
b = s.encode('utf-8')
print(b)  # b'Hello, \xe4\xb8\x96\xe7\x95\x8c'
decoded = b.decode('utf-8')
print(decoded)  # Hello, 世界
print(decoded == s)  # True - 无损往返

# 题目 2
s = '中文'
b_utf8 = s.encode('utf-8')
b_gbk = s.encode('gbk')
b_utf16 = s.encode('utf-16')
print(len(b_utf8), b_utf8)    # 6 b'\xe4\xb8\xad\xe6\x96\x87'
print(len(b_gbk), b_gbk)      # 4 b'\xd6\xd0\xce\xc4'
print(len(b_utf16), b_utf16)  # 6 b'\xff\xfe-NV}'（含 BOM）

# 不能正确解码：UTF-8 字节用 GBK 解会乱码或报错
b = s.encode('utf-8')
try:
    print(b.decode('gbk'))  # 乱码：娴腑姳 等
except UnicodeDecodeError as e:
    print(f"错误: {e}")

# 题目 3
print('Hello'.encode('ascii'))  # b'Hello' - 成功
try:
    'café'.encode('ascii')  # UnicodeEncodeError
except UnicodeEncodeError as e:
    print(f"ASCII 错误: {e}")  # 'é' 非 ASCII

b = 'café'.encode('latin-1')
print(b, len(b))  # b'caf\xe9' 4 - latin-1 单字节编码

# 题目 4
s = '中文'
b = s.encode('utf-8')  # b'\xe4\xb8\xad\xe6\x96\x87'
# 用 GBK 解码：GBK 是双字节，\xe4\xb8 解为某字，\xad\xe6 解为某字，\x96\x87 解为某字
# 结果是乱码（不会报错，因为恰好 6 字节 = 3 个 GBK 字符）
print(b.decode('gbk'))  # 漢郑鏂（乱码）
# 教训：编码和解码必须用相同编码

# 题目 5
def safe_decode(b):
    for encoding in ['utf-8', 'gbk', 'latin-1']:
        try:
            return b.decode(encoding)
        except UnicodeDecodeError:
            continue
    return None

print(safe_decode('中文'.encode('utf-8')))  # 中文
print(safe_decode('中文'.encode('gbk')))    # 中文
print(safe_decode(b'\xff\xfe'))             # 通常 latin-1 能解码任意字节
```
</details>

2. 用 `errors='replace'` 编码 `'café中文'`（ASCII），输出什么？

1. 用 `errors='backslashreplace'` 编码 `'café'`（ASCII）
2. 用 `errors='xmlcharrefreplace'` 编码 `'café中文'`（ASCII）

**题目 5：陷阱题**
以下代码输出是什么？
```python
b = b'hello \xff world'
print(b.decode('utf-8', errors='ignore'))
print(len(b.decode('utf-8', errors='ignore')))
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
try:
    b'\xff'.decode('utf-8')  # UnicodeDecodeError
except UnicodeDecodeError as e:
    print(f"解码错误: {e}")

try:
    '中文'.encode('ascii')  # UnicodeEncodeError
except UnicodeEncodeError as e:
    print(f"编码错误: {e}")

# 题目 2
print(b'caf\xe9'.decode('utf-8', errors='ignore'))  # caf（\xe9 被丢弃）

print('café中文'.encode('ascii', errors='ignore'))  # b'caf'（é 和中文被丢弃）

# 题目 3
print(b'caf\xe9'.decode('utf-8', errors='replace'))  # caf（替换符）

print('café中文'.encode('ascii', errors='replace'))  # b'caf???'（é->? 中->? 文->?）

# 题目 4
print('café'.encode('ascii', errors='backslashreplace'))
# b'caf\\xe9'

print('café中文'.encode('ascii', errors='xmlcharrefreplace'))
# b'caf&#233;&#20013;&#25991;'

# 题目 5
b = b'hello \xff world'
# \xff 在 UTF-8 中非法，ignore 会丢弃它
result = b.decode('utf-8', errors='ignore')
print(result)        # 'hello  world'（\xff 丢失，留下两个空格）
print(len(result))   # 12（原 13 字节 - 1 个非法字节 = 12 字符）
# 注意：b 是 13 字节，丢弃 1 个后是 12 字符
```
</details>

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
print(b'\x00\x01\xff'.hex())  # '0001ffaa' 实际 '0001ff'
print(b'Hello'.hex())  # '48656c6c6f'
print(b'\xab\xcd'.hex(' '))  # 'ab cd'

print(bytes.fromhex('48 65 6c 6c 6f'))  # b'Hello'

    bytes.fromhex('xyz')  # ValueError

    print(f"错误: {e}")

try:
    bytes.fromhex('abc')  # 奇数长度
except ValueError as e:
    print(f"错误: {e}")  # non-hexagonal number ... / odd-length string

# 题目 3
s = 'Hello'
hex_str = s.encode('utf-8').hex()
print(hex_str)  # '48656c6c6f'
restored = bytes.fromhex(hex_str).decode('utf-8')
print(restored)  # Hello
print(restored == s)  # True

b = b'\xde\xad\xbe\xef'
hex_str = b.hex()
print(hex_str)  # 'deadbeef'
restored = bytes.fromhex(hex_str)
print(restored == b)  # True

# 题目 4
import binascii
h = binascii.hexlify(b'Hello')
print(h, type(h))  # b'48656c6c6f' <class 'bytes'>
b = binascii.unhexlify(h)
print(b)  # b'Hello'

# 区别：hexlify 返回 bytes，.hex() 返回 str
print(type(binascii.hexlify(b'Hello')))  # <class 'bytes'>
print(type(b'Hello'.hex()))              # <class 'str'>

# 题目 5
mac_str = 'aabbccddeeff'
mac_bytes = bytes.fromhex(mac_str)
print(mac_bytes.hex(':'))  # 'aa:bb:cc:dd:ee:ff'
print(mac_bytes.hex('-'))  # 'aa-bb-cc-dd-ee-ff'

# 反向：从 'aa:bb:cc:dd:ee:ff' 解析
formatted = 'aa:bb:cc:dd:ee:ff'
clean = formatted.replace(':', '')
mac_bytes2 = bytes.fromhex(clean)
print(mac_bytes2.hex())  # 'aabbccddeeff'
```

<details>
<summary>点击查看答案</summary>

```python

    if len(b) < 8:
```

```python
    positions = []

        for bit in range(8):
            if byte & (1 << bit):
                positions.append(i * 8 + bit)
    return positions

def leb128_encode(n):
    result = bytearray()
    while True:
        byte = n & 0x7f
        n >>= 7
        if n != 0:
            byte |= 0x80  # 还有后续
        result.append(byte)
        if n == 0:
            break
    return bytes(result)

def leb128_decode(data):
    result = 0
    shift = 0
    for byte in data:
        result |= (byte & 0x7f) << shift
        if byte & 0x80 == 0:
            break
        shift += 7
    return result

# 题目 5：字典序列化
import struct

def serialize(obj):
    result = bytearray()
    for key, value in obj.items():
        # 键：2 字节长度 + UTF-8 字节
        key_bytes = str(key).encode('utf-8')
        result += struct.pack('>H', len(key_bytes))
        result += key_bytes
        # 值类型 + 数据
        if isinstance(value, int):
            result += b'I'
            value_bytes = str(value).encode('utf-8')
            result += struct.pack('>H', len(value_bytes))
            result += value_bytes
        elif isinstance(value, str):
            result += b'S'
            value_bytes = value.encode('utf-8')
            result += struct.pack('>H', len(value_bytes))
            result += value_bytes
        else:
            raise TypeError(f"不支持的类型: {type(value)}")
    return bytes(result)

def deserialize(data):
    obj = {}
    pos = 0
    while pos < len(data):
        # 读键
        key_len = struct.unpack('>H', data[pos:pos+2])[0]
        pos += 2
        key = data[pos:pos+key_len].decode('utf-8')
        pos += key_len
        # 读值类型
        type_tag = data[pos:pos+1]
        pos += 1
        # 读值
        value_len = struct.unpack('>H', data[pos:pos+2])[0]
        pos += 2
        value_bytes = data[pos:pos+value_len]
        pos += value_len
        if type_tag == b'I':
            value = int(value_bytes.decode('utf-8'))
        else:
            value = value_bytes.decode('utf-8')
        obj[key] = value
    return obj

# 测试

print(serialized.hex())
restored = deserialize(serialized)
print(restored)  # {'name': 'Alice', 'age': 30, 'city': 'Beijing'}
print(restored == data)  # True
```

1. **理解本质**：bytes 是 0-255 整数序列，str 是 Unicode 字符序列
2. **注意类型**：索引返回 int，切片返回 bytes，方法参数必须是 bytes
3. **编解码匹配**：encode 和 decode 必须用相同编码
4. **善用 errors**：处理来源不明数据时用 errors='replace' 容错
5. **性能意识**：拼接用 join，构建用 bytearray，大文件分块读
6. **二进制思维**：理解字节序、位运算、struct 格式

### 常见模式总结

1. **编解码**：str <-> bytes 通过 encode/decode
2. **十六进制**：bytes <-> hex str 通过 hex/fromhex
3. **数字互转**：int <-> bytes 通过 from_bytes/to_bytes
4. **结构化数据**：用 struct.pack/unpack
5. **二进制 IO**：用 'rb'/'wb' 模式
6. **文件类型**：通过魔数（头部字节）判断
7. **加密哈希**：处理原始 bytes，不涉及编码
