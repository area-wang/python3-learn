## Bytes 基础

Bytes（字节串）是 Python 中用于表示**二进制数据**的不可变序列。它是处理文件、网络通信、加密数据等场景的核心数据类型。

**特点：**
- **不可变性**：bytes 对象一旦创建就不能修改（immutable），类似 tuple
- **字节序列**：每个元素是 0-255 范围内的整数（一个字节 = 8 bit = 0~255）
- **有序性**：元素按顺序排列，支持索引与切片
- **二进制安全**：可以存储任意二进制数据，包括图片、音视频、加密内容
- **与 str 的区别**：str 是 Unicode 文本序列（人类可读），bytes 是字节序列（机器可读）

**bytes 与 str 的核心区别：**

| 特性 | str（字符串） | bytes（字节串） |
|------|--------------|----------------|
| 元素类型 | Unicode 字符（码点） | 0-255 整数（字节） |
| 可变性 | 不可变 | 不可变（bytearray 可变） |
| 字面量 | `'hello'`, `"hi"` | `b'hello'`, `b"hi"` |
| 编码 | 已解码的文本 | 编码后的二进制 |
| 典型场景 | 文本处理 | 文件/网络/加密 |

**内存结构：**
- bytes 在内存中是连续的字节数组，每个字节占 1 字节
- 是一个紧凑、高效的二进制存储结构
- 时间复杂度：访问 O(1)，拼接 O(n)，搜索 O(n)

**ASCII 显示规则：**
- bytes 在显示时，可打印 ASCII 字符（32-126）显示为对应字符
- 不可打印字节以 `\xNN`（十六进制）或转义符（如 `\n`、`\t`）显示

```python
# 可打印 ASCII 字符直接显示为字符
b1 = b'Hello'
print(b1)        # b'Hello'
print(type(b1))  # <class 'bytes'>

# 不可打印字节以 \x 形式显示
b2 = b'\x00\x01\x02\xff'
print(b2)        # b'\x00\x01\x02\xff'

# 常见转义符
b3 = b'line1\nline2\ttab'
print(b3)        # b'line1\nline2\ttab'
print(len(b3))   # 14（\n 和 \t 各算 1 个字节）

# 每个元素是 0-255 的整数
b = b'AB'
print(b[0])      # 65 - 不是 'A'，而是整数 65
print(b[1])      # 66

# 验证类型
print(type(b'x'))     # <class 'bytes'>
print(type('x'))      # <class 'str'>
```

**字节值范围说明：**
```python
# 每个字节 0-255
b = bytes([0, 65, 255, 128])
print(b)  # b'\x00A\xff\x80'

# 超出范围的值会报错
try:
    bytes([256])  # 256 > 255
except ValueError as e:
    print(f"错误: {e}")  # bytes must be in range(0, 256)
```

## 创建 bytes

### 1. 使用 b'' 字面量

**语法：** `b'内容'` 或 `b"内容"`

**特点：**
- 最直观的创建方式
- 字面量中只能使用 ASCII 字符（0-127）
- 非 ASCII 字符必须用 `\x`、`\u` 等转义
- 可以使用单引号、双引号、三引号

**返回值：** bytes 对象

**时间复杂度：** O(n)

```python
# 基本创建
b1 = b'hello'
print(b1)           # b'hello'
print(type(b1))     # <class 'bytes'>
print(len(b1))      # 5

# 双引号
b2 = b"world"
print(b2)           # b'world'

# 三引号（多行）
b3 = b'''line1
line2'''
print(b3)           # b'line1\nline2'

# 空字节串
empty = b''
print(empty)        # b''
print(len(empty))   # 0

# 包含数字的 bytes（注意：是 ASCII 字符，不是数字）
b4 = b'123'
print(b4)           # b'123'
print(b4[0])        # 49 - ASCII 码 '1' 的值

# 包含转义字符
b5 = b'\x41\x42\x43'  # \x41 = 'A', \x42 = 'B', \x43 = 'C'
print(b5)           # b'ABC'

# 非 ASCII 字符直接写在字面量中会报错
try:
    b = b'中文'  # SyntaxError
except SyntaxError as e:
    print(f"错误: {e}")
```

### 2. 使用 bytes() 构造函数

**语法：** `bytes([source[, encoding[, errors]]])`

**参数：**
- 不传参数：创建空 bytes
- `source` 为整数：创建该长度的全零字节串
- `source` 为可迭代整数：每个整数 0-255，创建对应字节串
- `source` 为 str：必须同时指定 `encoding`（和可选 `errors`）
- `source` 为 bytes/bytearray：返回其副本

**返回值：** 新的 bytes 对象

**时间复杂度：** O(n)

```python
# 1. 创建空 bytes
empty = bytes()
print(empty)  # b''

# 2. 从整数创建（指定长度的全零字节串）
b1 = bytes(5)
print(b1)  # b'\x00\x00\x00\x00\x00'
print(len(b1))  # 5

# 3. 从可迭代整数创建
b2 = bytes([65, 66, 67, 97, 98])
print(b2)  # b'ABCab'
print(list(b2))  # [65, 66, 67, 97, 98]

# 从元组创建
b3 = bytes((72, 101, 108, 108, 111))
print(b3)  # b'Hello'

# 从 range 创建
b4 = bytes(range(65, 68))  # A, B, C
print(b4)  # b'ABC'

# 4. 从字符串创建（必须指定 encoding）
b5 = bytes('hello', 'utf-8')
print(b5)  # b'hello'

b6 = bytes('中文', 'utf-8')
print(b6)  # b'\xe4\xb8\xad\xe6\x96\x87'（6 个字节）

b7 = bytes('中文', 'gbk')
print(b7)  # b'\xd6\xd0\xce\xc4'（4 个字节）

# 5. 从 bytes/bytearray 创建副本
original = b'python'
copy = bytes(original)
print(copy)  # b'python'
print(copy is original)  # False - 新对象

ba = bytearray(b'hello')
b8 = bytes(ba)
print(b8)  # b'hello'
print(type(b8))  # <class 'bytes'>
```

**常见错误：**
```python
# 字符串不指定 encoding 会报错
try:
    bytes('hello')  # TypeError
except TypeError as e:
    print(f"错误: {e}")  # string argument without an encoding

# 整数超出范围
try:
    bytes([300])  # 300 > 255
except ValueError as e:
    print(f"错误: {e}")

# 负数
try:
    bytes([-1])
except ValueError as e:
    print(f"错误: {e}")  # bytes must be in range(0, 256)
```

### 3. 通过字符串编码创建

**语法：** `'字符串'.encode(encoding='utf-8')`

这是创建 bytes 最常用的方式之一，详见[编码与解码](#编码与解码)。

```python
# encode 等价于 bytes(str, encoding)
s = 'Hello, 世界'
b1 = s.encode('utf-8')
b2 = bytes(s, 'utf-8')
print(b1 == b2)  # True
print(b1)        # b'Hello, \xe4\xb8\x96\xe7\x95\x8c'
```

## bytearray 可变字节序列

bytearray 是 bytes 的可变版本，类似 list 之于 tuple。它支持原地的添加、删除、修改操作。

### 1. 创建 bytearray

**语法：** `bytearray([source[, encoding[, errors]]])`

**参数：** 与 `bytes()` 相同

**返回值：** bytearray 对象

```python
# 空 bytearray
ba1 = bytearray()
print(ba1)  # bytearray(b'')
print(type(ba1))  # <class 'bytearray'>

# 指定长度（全零）
ba2 = bytearray(5)
print(ba2)  # bytearray(b'\x00\x00\x00\x00\x00')

# 从可迭代整数
ba3 = bytearray([65, 66, 67])
print(ba3)  # bytearray(b'ABC')

# 从字符串
ba4 = bytearray('hello', 'utf-8')
print(ba4)  # bytearray(b'hello')

# 从 bytes
ba5 = bytearray(b'python')
print(ba5)  # bytearray(b'python')
```

### 2. bytearray 与 bytes 的区别

| 特性 | bytes | bytearray |
|------|-------|-----------|
| 可变性 | 不可变 | 可变 |
| 字面量 | `b'...'` | 无字面量 |
| 哈希 | 可哈希（可作字典键） | 不可哈希 |
| 方法 | 只读方法 | 含修改方法 |
| 用途 | 存储/传输 | 构建/修改 |

```python
# bytes 不可变
b = b'hello'
try:
    b[0] = 72  # 'H'
except TypeError as e:
    print(f"错误: {e}")  # 'bytes' object does not support item assignment

# bytearray 可变
ba = bytearray(b'hello')
ba[0] = 72  # 修改第一个字节
print(ba)  # bytearray(b'Hello')

# 哈希性差异
print(hash(b'key'))  # 可以哈希
try:
    hash(bytearray(b'key'))  # 不可哈希
except TypeError as e:
    print(f"错误: {e}")  # unhashable type: 'bytearray'
```

### 3. bytearray 的可变方法

#### append() - 追加一个字节

```python
ba = bytearray(b'ABC')
ba.append(97)  # 追加 'a'（ASCII 97）
print(ba)  # bytearray(b'ABCa')

# 注意：只能追加 0-255 的整数
try:
    ba.append(256)
except ValueError as e:
    print(f"错误: {e}")
```

#### extend() - 扩展多个字节

```python
ba = bytearray(b'AB')
ba.extend(b'CD')
print(ba)  # bytearray(b'ABCD')

ba.extend([101, 102])  # 'e', 'f'
print(ba)  # bytearray(b'ABCDef')

ba.extend(b'\xff\x00')
print(ba)  # bytearray(b'ABCDef\xff\x00')
```

#### insert() - 插入字节

```python
ba = bytearray(b'AC')
ba.insert(1, 66)  # 在索引 1 插入 'B'
print(ba)  # bytearray(b'ABC')
```

#### pop() - 弹出并返回

```python
ba = bytearray(b'ABCD')
last = ba.pop()       # 默认弹出末尾
print(last)  # 68
print(ba)    # bytearray(b'ABC')

first = ba.pop(0)
print(first)  # 65
print(ba)     # bytearray(b'BC')
```

#### remove() - 删除指定字节值

```python
ba = bytearray(b'ABAC')
ba.remove(65)  # 删除第一个值为 65 ('A') 的字节
print(ba)  # bytearray(b'BAC')
```

#### reverse() - 原地反转

```python
ba = bytearray(b'ABCD')
ba.reverse()
print(ba)  # bytearray(b'DCBA')
```

#### clear() - 清空

```python
ba = bytearray(b'hello')
ba.clear()
print(ba)  # bytearray(b'')
```

```python
# 综合示例：动态构建字节序列
ba = bytearray()
for ch in 'Hello':
    ba.append(ord(ch))
print(ba)  # bytearray(b'Hello')

# 修改某个字节
ba[0] = ord('h')
print(ba)  # bytearray(b'hello')

# 切片赋值（类似 list）
ba[1:4] = b'ELP'
print(ba)  # bytearray(b'hELPo')
```

## 访问与切片

### 1. 索引访问（返回 int 而非 bytes）

**语法：** `bytes[index]`

**返回值：** 0-255 的整数（**注意：不是单元素 bytes！**）

**异常：** `IndexError` - 索引越界

**时间复杂度：** O(1)

```python
b = b'Hello'

# 正向索引
print(b[0])   # 72 - 'H' 的 ASCII 值（整数！）
print(b[1])   # 101 - 'e'
print(b[4])   # 111 - 'o'

# 负向索引
print(b[-1])  # 111 - 最后一个
print(b[-5])  # 72 - 第一个

# 类型验证：索引返回 int
print(type(b[0]))  # <class 'int'>

# 转换为字符
print(chr(b[0]))  # 'H'

# 索引越界
try:
    print(b[10])
except IndexError as e:
    print(f"错误: {e}")  # index out of range
```

**关键陷阱：** `b'Hello'[0]` 返回 `72`（int），不是 `b'H'`（bytes）！这与 str 不同（`'Hello'[0]` 返回 `'H'`）。

```python
# str vs bytes 索引对比
s = 'Hello'
b = b'Hello'

print(s[0])   # 'H' - str 返回字符
print(b[0])   # 72  - bytes 返回整数

print(type(s[0]))  # <class 'str'>
print(type(b[0]))  # <class 'int'>
```

### 2. 切片访问（返回 bytes）

**语法：** `bytes[start:stop:step]`

**返回值：** 新的 bytes 对象

**特点：**
- 切片总是返回 bytes（即使只切一个元素）
- 切片不会引发 IndexError，自动调整范围
- 支持负索引和负步长

**时间复杂度：** O(k)，k 为切片长度

```python
b = b'Hello World'

# 基本切片
print(b[0:5])   # b'Hello'
print(b[6:])    # b'World'
print(b[:5])    # b'Hello'
print(b[:])     # b'Hello World' - 完整副本

# 单元素切片 vs 索引
print(b[0])     # 72 - 整数
print(b[0:1])   # b'H' - bytes
print(type(b[0:1]))  # <class 'bytes'>

# 步长切片
print(b[::2])   # b'HloWrd' - 每隔一个
print(b[::-1])  # b'dlroW olleH' - 反转

# 负索引切片
print(b[-5:])   # b'World'
print(b[:-6])   # b'Hello'
```

### 3. 切片赋值（仅 bytearray）

bytes 不可变，不能切片赋值；bytearray 可以。

```python
# bytes 不能切片赋值
b = b'hello'
try:
    b[1:3] = b'XY'
except TypeError as e:
    print(f"错误: {e}")  # 'bytes' object does not support item assignment

# bytearray 可以
ba = bytearray(b'hello')
ba[1:3] = b'XY'
print(ba)  # bytearray(b'hXYlo')
```

## bytes 运算

### 1. + 运算符 - 连接

**语法：** `bytes1 + bytes2`

**返回值：** 新的 bytes 对象

**时间复杂度：** O(n + m)

```python
b1 = b'Hello'
b2 = b' World'
result = b1 + b2
print(result)  # b'Hello World'
print(b1)      # b'Hello' - 原对象不变

# 不能与 str 直接相加
try:
    b'Hello' + ' World'  # TypeError
except TypeError as e:
    print(f"错误: {e}")  # can't concat bytes to str
```

### 2. * 运算符 - 重复

**语法：** `bytes * n`

**返回值：** 新的 bytes 对象

```python
b = b'AB'
print(b * 3)   # b'ABABAB'
print(3 * b)   # b'ABABAB'
print(b * 0)   # b''
print(b * -1)  # b'' - 负数视为 0
```

### 3. in / not in - 成员检查

**语法：** `sub in bytes`

**返回值：** 布尔值

**时间复杂度：** O(n*m) 最坏

**特点：** 可以检查子字节串或单个整数

```python
b = b'Hello World'

# 检查子字节串
print(b'Hello' in b)      # True
print(b'World' in b)      # True
print(b'Python' in b)     # False
print(b'Python' not in b) # True

# 检查单个字节（整数）
print(72 in b)   # True - 'H' 的值
print(100 in b)  # False

# 注意：检查字符字符串会报错
try:
    'H' in b  # TypeError
except TypeError as e:
    print(f"错误: {e}")  # a bytes-like object is required, not 'str'
```

### 4. len() - 长度

**语法：** `len(bytes)`

**返回值：** 字节数（整数）

**时间复杂度：** O(1)

```python
b = b'Hello'
print(len(b))  # 5

# 注意：字节数 != 字符数（对非 ASCII）
b_chinese = '中文'.encode('utf-8')
print(b_chinese)       # b'\xe4\xb8\xad\xe6\x96\x87'
print(len(b_chinese))  # 6 - 字节数
print(len('中文'))      # 2 - 字符数
```

### 5. 比较运算

```python
# 字节序逐字节比较
print(b'abc' == b'abc')  # True
print(b'abc' != b'abd')  # True
print(b'abc' < b'abd')   # True
print(b'ab' < b'abc')    # True（短的更小）

# bytes 与 bytearray 比较
print(b'abc' == bytearray(b'abc'))  # True - 值相等
```

## 编码与解码

编码（encode）与解码（decode）是 bytes 与 str 之间转换的核心操作，也是最容易出错的地方。

### 1. str.encode() - 字符串编码为 bytes

**语法：** `str.encode(encoding='utf-8', errors='strict')`

**参数：**
- `encoding`：编码名称，默认 `'utf-8'`
- `errors`：错误处理方案，默认 `'strict'`

**返回值：** bytes 对象

```python
# 默认 UTF-8 编码
s = 'Hello'
b = s.encode()
print(b)  # b'Hello'

# 显式指定 UTF-8
b = 'Hello'.encode('utf-8')
print(b)  # b'Hello'

# 中文编码（UTF-8：每个汉字 3 字节）
b = '中文'.encode('utf-8')
print(b)  # b'\xe4\xb8\xad\xe6\x96\x87'
print(len(b))  # 6

# GBK 编码（每个汉字 2 字节）
b = '中文'.encode('gbk')
print(b)  # b'\xd6\xd0\xce\xc4'
print(len(b))  # 4

# ASCII 编码（不能编码非 ASCII 字符）
b = 'Hello'.encode('ascii')
print(b)  # b'Hello'

# ASCII 编码中文会报错
try:
    '中文'.encode('ascii')  # UnicodeEncodeError
except UnicodeEncodeError as e:
    print(f"错误: {e}")

# Latin-1（ISO-8859-1）：单字节编码，0-255 全覆盖
b = 'café'.encode('latin-1')
print(b)  # b'caf\xe9'
```

### 2. bytes.decode() - bytes 解码为字符串

**语法：** `bytes.decode(encoding='utf-8', errors='strict')`

**参数：**
- `encoding`：编码名称，默认 `'utf-8'`
- `errors`：错误处理方案，默认 `'strict'`

**返回值：** str 对象

```python
# UTF-8 解码
b = b'Hello'
s = b.decode('utf-8')
print(s)  # Hello

# 默认 UTF-8
s = b.decode()
print(s)  # Hello

# 中文 bytes 解码
b = b'\xe4\xb8\xad\xe6\x96\x87'
s = b.decode('utf-8')
print(s)  # 中文

# GBK bytes 解码
b = b'\xd6\xd0\xce\xc4'
s = b.decode('gbk')
print(s)  # 中文
```

### 3. 常见编码

| 编码 | 说明 | 字节宽度 |
|------|------|---------|
| `utf-8` | 变长编码，互联网标准 | 1-4 字节/字符 |
| `gbk` / `gb2312` | 简体中文编码 | 1-2 字节/字符 |
| `big5` | 繁体中文编码 | 1-2 字节/字符 |
| `ascii` | 美国标准，0-127 | 1 字节/字符 |
| `latin-1` / `iso-8859-1` | 西欧语言，0-255 | 1 字节/字符 |
| `utf-16` | 定长 2 字节（+BOM） | 2 字节/字符 |
| `utf-32` | 定长 4 字节 | 4 字节/字符 |

```python
s = '中文A'

# UTF-8
print(s.encode('utf-8'))   # b'\xe4\xb8\xad\xe6\x96\x87A'（7 字节）
# GBK
print(s.encode('gbk'))     # b'\xd6\xd0\xce\xc4A'（5 字节）
# UTF-16
print(s.encode('utf-16'))  # b'\xff\xfe-N\x96YA'（含 BOM）
# ASCII（'A' 可以，中文不行）
print('A'.encode('ascii')) # b'A'

# 编码与解码的可逆性
b = s.encode('utf-8')
assert b.decode('utf-8') == s  # True - 用相同编码往返无损
```

## 编码错误处理

当编码/解码遇到无法处理的字符时，`errors` 参数决定如何处理。

### errors 参数取值

| 取值 | 说明 |
|------|------|
| `strict`（默认） | 抛出 UnicodeError |
| `ignore` | 忽略无法处理的字符 |
| `replace` | 用 `?`（编码）或 `�`（解码）替换 |
| `backslashreplace` | 用 `\xNN`、`\uNNNN` 等转义替换 |
| `xmlcharrefreplace` | 用 XML 字符引用 `&#NNN;` 替换 |
| `namereplace` | 用 `\N{名称}` 替换 |

### 1. strict（默认）

```python
# 解码时遇到非法字节
b = b'\xff\xfe'  # 不是合法 UTF-8
try:
    b.decode('utf-8')  # UnicodeDecodeError
except UnicodeDecodeError as e:
    print(f"错误: {e}")

# 编码时遇到无法编码的字符
try:
    '中文'.encode('ascii')  # UnicodeEncodeError
except UnicodeEncodeError as e:
    print(f"错误: {e}")
```

### 2. ignore - 忽略

```python
# 解码忽略非法字节
b = b'caf\xe9'  # \xe9 在 UTF-8 中是非法续接
s = b.decode('utf-8', errors='ignore')
print(s)  # caf（非法字节被丢弃）

# 编码忽略无法编码的字符
s = 'café中文'
b = s.encode('ascii', errors='ignore')
print(b)  # b'caf'（é 和中文被丢弃）
```

### 3. replace - 替换

```python
# 解码替换非法字节为
b = b'caf\xe9'
s = b.decode('utf-8', errors='replace')
print(s)  # caf（非法字节变为替换符 U+FFFD）

# 编码替换无法编码的字符为 ?
s = 'café中文'
b = s.encode('ascii', errors='replace')
print(b)  # b'caf???'（é→?，中→?，文→?）
```

### 4. backslashreplace - 反斜杠转义

```python
# 编码时用 \x 转义
s = 'café中文'
b = s.encode('ascii', errors='backslashreplace')
print(b)  # b'caf\\xe3\\x80\\x90...'(实际为 b'caf\\xe9\\xe4\\xb8\\xad\\xe6\\x96\\x87')

# 解码时用 \udcXX 转义非法字节
b = b'caf\xe9'
s = b.decode('utf-8', errors='backslashreplace')
print(s)  # caf\\udce9
```

### 5. xmlcharrefreplace - XML 字符引用

```python
s = 'café中文'
b = s.encode('ascii', errors='xmlcharrefreplace')
print(b)  # b'caf&#233;&#20013;&#25991;'
```

### 编码不匹配的典型错误

```python
# 用 GBK 解码 UTF-8 编码的字节 - 乱码或报错
b = '中文'.encode('utf-8')
try:
    s = b.decode('gbk')  # 可能乱码或 UnicodeDecodeError
    print(s)  # 乱码：娴腑姳 等
except UnicodeDecodeError as e:
    print(f"错误: {e}")

# 安全解码：用 replace 处理
b = '中文'.encode('utf-8')
s = b.decode('gbk', errors='replace')
print(s)  # 乱码但不报错

# 推荐做法：用 errors='ignore' 或 'replace' 容错
with open('unknown_encoding.txt', 'rb') as f:
    data = f.read()
text = data.decode('utf-8', errors='replace')  # 安全
```

## bytes 方法详解

bytes 的方法大多与 str 类似，但操作的是字节而非字符。

### 1. find() / rfind() - 查找子字节串

**语法：** `bytes.find(sub[, start[, end]])`

**返回值：** 找到返回起始索引，未找到返回 -1

**时间复杂度：** O(n)

```python
b = b'Hello World Hello'

print(b.find(b'Hello'))      # 0
print(b.find(b'World'))      # 6
print(b.find(b'Python'))     # -1
print(b.find(b'Hello', 1))   # 12 - 从索引 1 开始找
print(b.find(b'Hello', 0, 5))  # 0 - 在范围 [0,5) 内找

# rfind 从右找
print(b.rfind(b'Hello'))     # 12

# 注意：查找的是 bytes，不是 str
try:
    b.find('Hello')  # TypeError
except TypeError as e:
    print(f"错误: {e}")
```

### 2. index() / rindex() - 类似 find 但找不到报错

```python
b = b'Hello World'
print(b.index(b'World'))  # 6

try:
    b.index(b'Python')  # ValueError
except ValueError as e:
    print(f"错误: {e}")
```

### 3. count() - 统计出现次数

```python
b = b'Hello World Hello'
print(b.count(b'Hello'))  # 2
print(b.count(b'l'))      # 5
print(b.count(b'Python')) # 0
print(b.count(b'l', 0, 5))  # 2 - 在范围内统计
```

### 4. split() / rsplit() - 分割

**语法：** `bytes.split(sep=None, maxsplit=-1)`

**返回值：** bytes 列表

```python
b = b'apple,banana,orange'
parts = b.split(b',')
print(parts)  # [b'apple', b'banana', b'orange']

# 限制分割次数
parts = b.split(b',', 1)
print(parts)  # [b'apple', b'banana,orange']

# 不传 sep：按空白分割
b = b'  hello   world  python  '
print(b.split())  # [b'hello', b'world', b'python']

# rsplit 从右分割
b = b'a.b.c.d'
print(b.rsplit(b'.', 1))  # [b'a.b.c', b'd']
```

### 5. join() - 连接

**语法：** `sep.join(iterable_of_bytes)`

```python
parts = [b'apple', b'banana', b'orange']
result = b','.join(parts)
print(result)  # b'apple,banana,orange'

# 用空字节串连接
result = b''.join([b'Hello', b' ', b'World'])
print(result)  # b'Hello World'

# 必须都是 bytes
try:
    b','.join(['a', 'b'])  # TypeError
except TypeError as e:
    print(f"错误: {e}")
```

### 6. replace() - 替换

**语法：** `bytes.replace(old, new[, count])`

```python
b = b'Hello World Hello'
print(b.replace(b'Hello', b'Hi'))  # b'Hi World Hi'
print(b.replace(b'Hello', b'Hi', 1))  # b'Hi World Hello' - 只替换 1 次
print(b.replace(b'o', b'0'))  # b'Hell0 W0rld Hell0'
```

### 7. startswith() / endswith() - 前缀后缀检查

```python
b = b'Hello World'
print(b.startswith(b'Hello'))  # True
print(b.startswith(b'World'))  # False
print(b.endswith(b'World'))    # True
print(b.endswith(b'Hello'))    # False

# 支持元组多个前缀
print(b.startswith((b'Hello', b'Hi')))  # True
print(b.endswith((b'World', b'!')))     # True

# 指定范围
print(b.startswith(b'World', 6))  # True - 从索引 6 开始
```

### 8. strip() / lstrip() / rstrip() - 去除边缘字节

```python
b = b'  Hello World  '
print(b.strip())   # b'Hello World'
print(b.lstrip())  # b'Hello World  '
print(b.rstrip())  # b'  Hello World'

# 指定要去除的字节
b = b'xxHelloxxx'
print(b.strip(b'x'))  # b'Hello'

b = b'\x00\x00data\x00\x00'
print(b.strip(b'\x00'))  # b'data'
```

### 9. upper() / lower() / title() / capitalize() - 大小写转换

```python
b = b'Hello World'
print(b.upper())      # b'HELLO WORLD'
print(b.lower())      # b'hello world'
print(b.title())      # b'Hello World'
print(b.capitalize()) # b'Hello world'

# 只对 ASCII 字母有效
b = b'caf\xc3\xa9'  # 'café' 的 UTF-8
print(b.upper())  # b'CAF\xc3\xa9'（非 ASCII 不变）
```

### 10. partition() / rpartition() - 分割为三部分

```python
b = b'Hello World'
print(b.partition(b' '))   # (b'Hello', b' ', b'World')
print(b.rpartition(b' '))  # (b'Hello', b' ', b'World')

# 找不到分隔符
b = b'HelloWorld'
print(b.partition(b' '))  # (b'HelloWorld', b'', b'')
print(b.rpartition(b' '))  # (b'', b'', b'HelloWorld')
```

### 11. translate() / maketrans() - 字节映射

```python
# maketrans 创建映射表（0-256 长度的 bytes）
# 将 b'a'->b'A', b'b'->b'B'
table = bytes.maketrans(b'ab', b'AB')
b = b'abcabc'
print(b.translate(table))  # b'ABcABc'

# 第三个参数指定要删除的字节
table = bytes.maketrans(b'ab', b'AB', b'c')
print(b.translate(table))  # b'ABAB' - 'c' 被删除

# 删除所有空格
b = b'  Hello  World  '
print(b.translate(None, b' '))  # b'HelloWorld'
```

### 12. center() / ljust() / rjust() / zfill() - 对齐填充

```python
b = b'Hi'
print(b.center(10, b'-'))  # b'----Hi----'
print(b.ljust(10, b'-'))   # b'Hi--------'
print(b.rjust(10, b'-'))   # b'--------Hi'
print(b.zfill(10))         # b'00000000Hi'（用 0 填充）
```

### 13. expandtabs() - 制表符展开

```python
b = b'a\tb\tc'
print(b.expandtabs(4))  # b'a   b   c'（每个 \t 展开为对齐到 4 的倍数）
```

### 14. splitlines() - 按行分割

```python
b = b'line1\nline2\r\nline3'
print(b.splitlines())       # [b'line1', b'line2', b'line3']
print(b.splitlines(True))   # 保留换行符 [b'line1\n', b'line2\r\n', b'line3']
```

### 15. isdigit() / isalpha() / isspace() 等 - 类型判断

```python
print(b'123'.isdigit())    # True
print(b'abc'.isalpha())    # True
print(b'   '.isspace())    # True
print(b'Hello'.isalpha())  # True
print(b'abc123'.isalnum()) # True
print(b'HELLO'.isupper())  # True
print(b'hello'.islower())  # True

# 空字节串
print(b''.isalpha())  # False
print(b''.isspace())  # False
```

## 十六进制操作

十六进制（hex）是 bytes 最常见的文本表示形式，常用于显示二进制数据、加密哈希、MAC 地址等。

### 1. bytes.hex() - 转为十六进制字符串

**语法：** `bytes.hex([sep[, bytes_per_sep]])`

**参数：**
- `sep`（可选）：分隔符
- `bytes_per_sep`（可选）：每几个字节加分隔符

**返回值：** str（十六进制字符串）

```python
b = b'\x00\x01\xff\xaa'
print(b.hex())  # '0001ffaa'

# 加分隔符
print(b.hex(' '))          # '00 01 ff aa'
print(b.hex(':'))          # '00:01:ff:aa'
print(b.hex('-'))          # '00-01-ff-aa'

# bytes_per_sep：从右往左每 N 字节加分隔符
print(b.hex(':', 1))  # '00:01:ff:aa'
print(b.hex(':', 2))  # '0001:ffaa'（每 2 字节一组）
print(b.hex('-', -2))  # '00-01-ffaa'（负数表示从左往右）

# 实际应用：MAC 地址格式化
mac = bytes.fromhex('aabbccddeeff')
print(mac.hex(':'))  # 'aa:bb:cc:dd:ee:ff'

# 哈希值显示
import hashlib
h = hashlib.md5(b'hello').digest()
print(h.hex())  # 5d41402abc4b2a76b9719d911017c592
```

### 2. bytes.fromhex() - 从十六进制字符串创建

**语法：** `bytes.fromhex(string)`

**参数：** 十六进制字符串（可含空格）

**返回值：** bytes 对象

```python
b = bytes.fromhex('48656c6c6f')
print(b)  # b'Hello'

# 含空格
b = bytes.fromhex('48 65 6c 6c 6f')
print(b)  # b'Hello'

# 大小写均可
b = bytes.fromhex('ABCDEF')
print(b)  # b'\xab\xcd\xef'

# 非法字符报错
try:
    bytes.fromhex('xyz')  # ValueError
except ValueError as e:
    print(f"错误: {e}")

# 奇数长度报错
try:
    bytes.fromhex('abc')  # 奇数个字符
except ValueError as e:
    print(f"错误: {e}")
```

### 3. binascii 模块

`binascii` 模块提供底层十六进制转换函数。

```python
import binascii

# hexlify: bytes -> hex bytes
b = b'Hello'
h = binascii.hexlify(b)
print(h)  # b'48656c6c6f'
print(type(h))  # <class 'bytes'>

# unhexlify: hex bytes -> bytes
b2 = binascii.unhexlify(h)
print(b2)  # b'Hello'

# 带分隔符
h = binascii.hexlify(b, b'-')
print(h)  # b'48-65-6c-6c-6f'

# hexlify vs .hex()
# hexlify 返回 bytes，.hex() 返回 str
print(type(binascii.hexlify(b)))  # <class 'bytes'>
print(type(b.hex()))              # <class 'str'>
```

**互转示例：**
```python
# bytes <-> hex str 往返
original = b'\xde\xad\xbe\xef'
hex_str = original.hex()
restored = bytes.fromhex(hex_str)
assert restored == original  # True
```

## bytes 与数字互转

### 1. int.from_bytes() - 字节转整数

**语法：** `int.from_bytes(bytes, byteorder, *, signed=False)`

**参数：**
- `bytes`：字节序列
- `byteorder`：字节序，`'big'`（大端）或 `'little'`（小端）
- `signed`：是否为有符号整数，默认 False

**返回值：** 整数

```python
# 大端序（高位在前，人类阅读顺序）
b = b'\x00\x01'
print(int.from_bytes(b, 'big'))  # 1

b = b'\x01\x00'
print(int.from_bytes(b, 'big'))  # 256

# 小端序（低位在前，x86 内存顺序）
b = b'\x01\x00'
print(int.from_bytes(b, 'little'))  # 1

b = b'\x00\x01'
print(int.from_bytes(b, 'little'))  # 256

# 大数
b = b'\x01\x02\x03\x04'
print(int.from_bytes(b, 'big'))     # 16909060
print(int.from_bytes(b, 'little'))  # 67305985

# 有符号
b = b'\xff'
print(int.from_bytes(b, 'big', signed=True))    # -1
print(int.from_bytes(b, 'big', signed=False))   # 255

b = b'\xff\xff'
print(int.from_bytes(b, 'big', signed=True))    # -1
```

### 2. int.to_bytes() - 整数转字节

**语法：** `int.to_bytes(length, byteorder, *, signed=False)`

**参数：**
- `length`：字节数
- `byteorder`：`'big'` 或 `'little'`
- `signed`：是否有符号

**返回值：** bytes

```python
# 大端序
print((256).to_bytes(2, 'big'))   # b'\x01\x00'
print((1).to_bytes(2, 'big'))     # b'\x00\x01'
print((255).to_bytes(1, 'big'))   # b'\xff'

# 小端序
print((256).to_bytes(2, 'little'))  # b'\x00\x01'
print((1).to_bytes(2, 'little'))    # b'\x01\x00'

# 有符号
print((-1).to_bytes(1, 'big', signed=True))    # b'\xff'
print((-1).to_bytes(2, 'big', signed=True))    # b'\xff\xff'

# 长度不足会报错
try:
    (256).to_bytes(1, 'big')  # 256 需要 2 字节
except OverflowError as e:
    print(f"错误: {e}")  # int too big to convert

# 自动计算所需长度
n = 123456789
length = (n.bit_length() + 7) // 8
b = n.to_bytes(length, 'big')
print(b)  # b'\x07[\xcd\x15'
print(int.from_bytes(b, 'big'))  # 123456789
```

### 3. 字节序（Endianness）说明

| 字节序 | 说明 | 典型场景 |
|--------|------|---------|
| `big`（大端） | 高位字节在前 | 网络协议、Java、人类阅读 |
| `little`（小端） | 低位字节在前 | x86/AMD64 CPU、文件格式 |

```python
n = 0x12345678

# 大端：12 34 56 78
print(n.to_bytes(4, 'big'))  # b'\x124Vx'（即 \x12\x34\x56\x78）

# 小端：78 56 34 12
print(n.to_bytes(4, 'little'))  # b'xV4\x12'（即 \x78\x56\x34\x12）

# 网络字节序通常是大端
import socket
# socket.htonl: 主机序 -> 网络序（大端）
```

### 4. struct 模块 - 结构化打包/解包

`struct` 模块用于处理 C 风格的二进制数据结构。

**语法：**
- `struct.pack(format, *values)`：打包为 bytes
- `struct.unpack(format, buffer)`：解包为元组

**格式字符：**

| 字符 | C 类型 | Python | 大小 |
|------|--------|--------|------|
| `b`/`B` | signed/unsigned char | int | 1 |
| `h`/`H` | short | int | 2 |
| `i`/`I` | int | int | 4 |
| `l`/`L` | long | int | 4 |
| `q`/`Q` | long long | int | 8 |
| `f` | float | float | 4 |
| `d` | double | float | 8 |
| `s` | char[] | bytes | 1 |

**前缀：** `<` 小端，`>` 大端，`!` 网络序（大端），`=` 本机序

```python
import struct

# 打包一个整数和一个浮点数（小端）
b = struct.pack('<if', 42, 3.14)
print(b)  # b'*\x00\x00\x00\xc3\xf5H@'
print(len(b))  # 8（4 + 4）

# 解包
values = struct.unpack('<if', b)
print(values)  # (42, 3.140000104904175)

# 大端打包
b = struct.pack('>i', 12345)
print(b)  # b'09'
print(struct.unpack('>i', b))  # (12345,)

# 打包字符串（需指定长度）
b = struct.pack('<10s', b'hello')
print(b)  # b'hello\x00\x00\x00\x00\x00'（不足补零）
print(struct.unpack('<10s', b))  # (b'hello\x00\x00\x00\x00\x00',)

# calcsize 计算大小
print(struct.calcsize('<if'))  # 8
print(struct.calcsize('>HHH'))  # 6

# 多字段结构
header = struct.pack('>HHI', 1, 2, 100)  # 2 + 2 + 4 = 8 字节
ver, type_, length = struct.unpack('>HHI', header)
print(ver, type_, length)  # 1 2 100

# unpack_from 从指定偏移解包
data = b'\x00\x00\x01\x00\x02\x00\x03\x00'
val = struct.unpack_from('>H', data, offset=2)
print(val)  # (1,)
```

## Base64 等编码

Base64 是将二进制数据用 64 个可打印 ASCII 字符表示的编码方式，常用于邮件、URL、数据传输。

### base64 模块

```python
import base64

# 1. 标准 Base64
data = b'Hello, World!'
encoded = base64.b64encode(data)
print(encoded)  # b'SGVsbG8sIFdvcmxkIQ=='
print(type(encoded))  # <class 'bytes'>

decoded = base64.b64decode(encoded)
print(decoded)  # b'Hello, World!'

# 2. URL 安全 Base64（- 替换 +，_ 替换 /）
encoded = base64.urlsafe_b64encode(b'ab??')
print(encoded)  # b'YWI-_w==' 等

# 3. Base32
encoded = base64.b32encode(b'Hello')
print(encoded)  # b'JBSWY3DP'
print(base64.b32decode(encoded))  # b'Hello'

# 4. Base16（即十六进制）
encoded = base64.b16encode(b'Hi')
print(encoded)  # b'4869'
print(base64.b16decode(encoded))  # b'Hi'

# 5. ASCII 编码（每个字节 1 字符）
encoded = base64.a85encode(b'Hello')
print(encoded)  # b'87cURD]I'
print(base64.a85decode(encoded))  # b'Hello'

# 处理字符串
s = '中文数据'
b = s.encode('utf-8')
encoded = base64.b64encode(b).decode('ascii')  # 转 str 便于传输
print(encoded)  # 5Lit2KjmkYvmlbAxMjM=

# 解码还原
decoded = base64.b64decode(encoded.encode('ascii')).decode('utf-8')
print(decoded)  # 中文数据
```

### 其他编码

```python
# binascii 也提供 base64
import binascii

# b2a_base64
b = b'Hello'
encoded = binascii.b2a_base64(b)
print(encoded)  # b'SGVsbG8=\n'（带换行）

# a2b_base64
decoded = binascii.a2b_base64(encoded)
print(decoded)  # b'Hello'

# uuencode（老式编码）
encoded = binascii.b2a_uu(b'Hello')
print(encoded)  # b'\\x68\x45\x6c\x6c\x6f\x00\n' 等格式
```

## bytes 与文件

二进制文件读写是 bytes 最常见的应用场景。与文本模式不同，二进制模式不进行编码转换。

### 1. 二进制读取

```python
# 写入二进制文件
with open('data.bin', 'wb') as f:
    f.write(b'Hello, Binary World!')
    f.write(b'\x00\x01\x02\xff')

# 读取二进制文件
with open('data.bin', 'rb') as f:
    data = f.read()
    print(data)  # b'Hello, Binary World!\x00\x01\x02\xff'
    print(type(data))  # <class 'bytes'>

# 分块读取（大文件）
with open('data.bin', 'rb') as f:
    while True:
        chunk = f.read(4)  # 每次读 4 字节
        if not chunk:
            break
        print(chunk)

# 按行读取（遇到 \n 分割）
with open('data.bin', 'rb') as f:
    for line in f:
        print(line)

# 读取指定字节数
with open('data.bin', 'rb') as f:
    first_5 = f.read(5)
    print(first_5)  # b'Hello'
    
    # seek 移动指针
    f.seek(0)  # 回到开头
    f.seek(7)  # 跳到第 7 字节
    print(f.read(6))  # b'Binary'
    
    # tell 当前位置
    print(f.tell())
```

### 2. 二进制写入

```python
# 写入 bytes
with open('out.bin', 'wb') as f:
    f.write(b'Hello')
    f.write(b' ')
    f.write(b'World')

# 写入 bytearray
with open('out.bin', 'wb') as f:
    f.write(bytearray([65, 66, 67]))

# writelines 写入列表
with open('out.bin', 'wb') as f:
    f.writelines([b'line1\n', b'line2\n', b'line3\n'])

# 追加模式
with open('out.bin', 'ab') as f:
    f.write(b'appended')
```

### 3. 文本 vs 二进制模式对比

```python
# 文本模式：自动编码/解码，返回 str
with open('text.txt', 'w', encoding='utf-8') as f:
    f.write('中文文本')

with open('text.txt', 'r', encoding='utf-8') as f:
    content = f.read()
    print(type(content))  # <class 'str'>
    print(content)  # 中文文本

# 二进制模式：不编码，返回 bytes
with open('text.txt', 'wb') as f:
    f.write('中文文本'.encode('utf-8'))

with open('text.txt', 'rb') as f:
    content = f.read()
    print(type(content))  # <class 'bytes'>
    print(content)  # b'\xe4\xb8\xad...'
    print(content.decode('utf-8'))  # 中文文本
```

### 4. 实际应用：复制图片

```python
# 复制二进制文件（图片、音视频等）
def copy_binary(src_path, dst_path, chunk_size=8192):
    with open(src_path, 'rb') as src, open(dst_path, 'wb') as dst:
        while True:
            chunk = src.read(chunk_size)
            if not chunk:
                break
            dst.write(chunk)

# 读取图片头部判断类型（魔数）
def get_image_type(path):
    with open(path, 'rb') as f:
        header = f.read(8)
    
    if header.startswith(b'\xff\xd8\xff'):
        return 'JPEG'
    elif header.startswith(b'\x89PNG\r\n\x1a\n'):
        return 'PNG'
    elif header.startswith(b'GIF87a') or header.startswith(b'GIF89a'):
        return 'GIF'
    return 'Unknown'
```

## bytes 字面量进阶

bytes 字面量支持多种转义，混合 ASCII 字符与十六进制。

### 1. \x 转义

```python
# \xNN：十六进制字节
b = b'\x41'  # = 'A' (65)
print(b)  # b'A'

b = b'\x48\x65\x6c\x6c\x6f'  # 'Hello'
print(b)  # b'Hello'

# \x 后必须跟 2 位十六进制
b = b'\xff'  # 255
print(b)  # b'\xff'

# 混合 ASCII 与 \x
b = b'AB\x00CD'
print(b)  # b'AB\x00CD'
print(list(b))  # [65, 66, 0, 67, 68]
```

### 2. 常用转义符

| 转义 | 含义 | ASCII 值 |
|------|------|---------|
| `\n` | 换行 | 10 |
| `\r` | 回车 | 13 |
| `\t` | 制表符 | 9 |
| `\\` | 反斜杠 | 92 |
| `\'` | 单引号 | 39 |
| `\"` | 双引号 | 34 |
| `\0` | 空字节 | 0 |
| `\xNN` | 十六进制字节 | NN |
| `\r\n` | Windows 换行 | 13 10 |

```python
b = b'line1\nline2'
print(b)  # b'line1\nline2'
print(len(b))  # 11（\n 算 1 字节）

b = b'tab\there'
print(b)  # b'tab\there'

# Windows 换行
b = b'line1\r\nline2'
print(b)  # b'line1\r\nline2'
print(len(b))  # 12（\r\n 算 2 字节）

# 转义反斜杠
b = b'C:\\path\\to\\file'
print(b)  # b'C:\\path\\to\\file'

# \0 空字节
b = b'data\x00more'
print(b)  # b'data\x00more'
print(b.split(b'\x00'))  # [b'data', b'more']
```

### 3. 非 ASCII 字符的处理

bytes 字面量中**不能直接写非 ASCII 字符**，必须用转义或编码。

```python
# 错误：直接写中文
# b = b'中文'  # SyntaxError

# 正确方式1：用 \x 转义（UTF-8 编码）
b = b'\xe4\xb8\xad'  # '中' 的 UTF-8 编码
print(b.decode('utf-8'))  # 中

# 正确方式2：先写字符串再编码
b = '中文'.encode('utf-8')
print(b)  # b'\xe4\xb8\xad\xe6\x96\x87'

# 正确方式3：bytes() 构造
b = bytes('中文', 'utf-8')
```

### 4. raw bytes 字面量 br''

```python
# r 前缀：禁用转义
b1 = b'\n'  # 1 字节（换行符）
b2 = rb'\n'  # 2 字节（反斜杠 + n）
print(b1, len(b1))  # b'\n' 1
print(b2, len(b2))  # b'\\n' 2

# 常用于正则表达式
import re
pattern = rb'\d+'  # 匹配数字的 raw bytes
print(re.findall(pattern, b'abc123def456'))  # [b'123', b'456']

# br 与 rb 等价
print(br'\n' == rb'\n')  # True
```

## 性能分析

### 时间复杂度总结

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `b[i]` | O(1) | 索引访问（返回 int） |
| `b[i:j]` | O(k) | 切片，k 为切片长度 |
| `len(b)` | O(1) | 获取长度 |
| `b1 + b2` | O(n+m) | 连接（创建新对象） |
| `b * n` | O(n*k) | 重复 |
| `sub in b` | O(n*m) | 子串搜索 |
| `b.find(sub)` | O(n) | 查找 |
| `b.split(sep)` | O(n) | 分割 |
| `b.replace()` | O(n) | 替换 |
| `b.hex()` | O(n) | 转十六进制 |
| `bytes.fromhex()` | O(n) | 从十六进制 |
| `b.encode/decode` | O(n) | 编解码 |

### 性能优化建议

#### 1. 拼接 bytes 用 join 而非 +

```python
# 不推荐：多次 + 创建中间对象
parts = [b'a', b'b', b'c', b'd']
result = b''
for p in parts:
    result += p  # 每次创建新对象，O(n²)

# 推荐：用 join
result = b''.join(parts)  # O(n)
```

#### 2. 构建大 bytes 用 bytearray

```python
# 不推荐：bytes 不可变，每次拼接都创建新对象
b = b''
for i in range(1000):
    b += bytes([i])  # 低效

# 推荐：bytearray 可变
ba = bytearray()
for i in range(1000):
    ba.append(i)
b = bytes(ba)  # 最后转换
```

#### 3. 内存视图避免复制

```python
# memoryview 不复制数据，零开销切片
b = b'x' * 1000000
mv = memoryview(b)
chunk = mv[100:200]  # 不复制，共享内存
print(len(chunk))  # 100

# 修改 bytearray 通过 memoryview
ba = bytearray(b'hello')
mv = memoryview(ba)
mv[0] = 72  # 'H'
print(ba)  # bytearray(b'Hello')
```

#### 4. 大文件分块处理

```python
# 不要一次性读入大文件
# 不推荐
# data = open('big.bin', 'rb').read()  # 占满内存

# 推荐：分块
with open('big.bin', 'rb') as f:
    for chunk in iter(lambda: f.read(8192), b''):
        process(chunk)
```

#### 5. 编解码缓存

```python
# 重复编解码的结果可缓存
_cache = {}
def cached_decode(b, encoding='utf-8'):
    if (b, encoding) not in _cache:
        _cache[(b, encoding)] = b.decode(encoding)
    return _cache[(b, encoding)]
```

def file_type(path):
    with open(path, 'rb') as f:
        magic = f.read(4)
    
    signatures = {
        b'\xff\xd8\xff': 'JPEG',
        b'\x89PNG': 'PNG',
        b'GIF8': 'GIF',
        b'PK\x03\x04': 'ZIP',
        b'%PDF': 'PDF',
        b'\x1f\x8b': 'GZIP',

    for sig, name in signatures.items():

### 6. 字节填充

```python
# PKCS7 填充（加密常用）
def pkcs7_pad(data, block_size=16):
    pad_len = block_size - (len(data) % block_size)
    return data + bytes([pad_len]) * pad_len

def pkcs7_unpad(data):
    pad_len = data[-1]
    return data[:-pad_len]

b = b'Hello'
padded = pkcs7_pad(b)
print(padded)  # b'Hello\x0b\x0b\x0b...(共 16 字节)'
print(pkcs7_unpad(padded))  # b'Hello'
```

def find_all(data, pattern):
    positions = []
    start = 0
    while True:
        idx = data.find(pattern, start)
        if idx == -1:
            break
        positions.append(idx)
        start = idx + 1
    return positions

## 常见错误

### 1. 索引返回 int 而非 bytes

```python
b = b'Hello'

# 错误：以为索引返回单字节 bytes
# result = b[0].upper()  # AttributeError: 'int' object has no attribute 'upper'

# 正确：索引返回 int
print(b[0])  # 72

# 想获取单字节 bytes，用切片
print(b[0:1])  # b'H'

# 转 int 为字符
print(chr(b[0]))  # 'H'
```

### 2. 编码解码不匹配

```python
# 用错误编码解码导致乱码或报错
b = '中文'.encode('utf-8')

# 错误：用 GBK 解码 UTF-8 字节
try:
    s = b.decode('gbk')  # 可能 UnicodeDecodeError 或乱码
except UnicodeDecodeError as e:
    print(f"错误: {e}")

# 正确：用相同编码
s = b.decode('utf-8')
print(s)  # 中文
```

### 3. 不可变修改报错

```python
b = b'Hello'

# 错误：bytes 不可变
try:
    b[0] = 104  # TypeError
except TypeError as e:
    print(f"错误: {e}")

# 正确：用 bytearray
ba = bytearray(b'Hello')
ba[0] = 104
print(ba)  # bytearray(b'hello')

# 或创建新 bytes
b = b'hello' + b' world'
```

### 4. b'' 只能包含 ASCII 字面量

```python
# 错误：bytes 字面量含非 ASCII 字符
# b = b'中文'  # SyntaxError: bytes can only contain ASCII literal characters

# 正确：用编码
b = '中文'.encode('utf-8')
# 或
b = b'\xe4\xb8\xad\xe6\x96\x87'  # 直接写 UTF-8 字节
```

### 5. bytes 与 str 混用

```python
b = b'Hello'
s = 'Hello'

# 错误：bytes + str
try:
    result = b + s  # TypeError
except TypeError as e:
    print(f"错误: {e}")

# 正确：统一类型
result = b + s.encode('utf-8')  # 都是 bytes
# 或
result = b.decode('utf-8') + s  # 都是 str

# 错误：用 str 查找 bytes
try:
    b.find('l')  # TypeError
except TypeError as e:
    print(f"错误: {e}")

# 正确
b.find(b'l')
```

### 6. hex() 与 fromhex() 混淆返回类型

```python
b = b'\xab\xcd'

# hex() 返回 str（不是 bytes）
h = b.hex()
print(type(h))  # <class 'str'>
print(h)  # 'abcd'

# fromhex() 接收 str
b2 = bytes.fromhex(h)
print(b2)  # b'\xab\xcd'

# 错误：把 bytes 传给 fromhex
try:
    bytes.fromhex(b'abcd')  # 实际上 fromhex 也接受 bytes-like，但语义混乱
except TypeError as e:
    print(f"错误: {e}")
```

### 7. 整数转字节长度不足

```python
# 错误：数字太大，指定长度不够
try:
    (256).to_bytes(1, 'big')  # OverflowError
except OverflowError as e:
    print(f"错误: {e}")

# 正确：指定足够长度
print((256).to_bytes(2, 'big'))  # b'\x01\x00'

# 自动计算长度
n = 12345
length = (n.bit_length() + 7) // 8
print(n.to_bytes(length, 'big'))
```

### 8. 二进制文件用文本模式读写

```python
# 错误：用文本模式读二进制文件，可能损坏数据
# with open('image.jpg', 'r') as f:  # 可能 UnicodeDecodeError
#     data = f.read()

# 正确：用二进制模式
with open('image.jpg', 'rb') as f:
    data = f.read()
```

### 9. 忘记 errors 参数导致崩溃

```python
# 处理来源不明的文本时，缺少 errors 处理会崩溃
unknown_data = b'\xff\xfe\x00data'

# 错误：默认 strict 会抛异常
try:
    unknown_data.decode('utf-8')
except UnicodeDecodeError as e:
    print(f"错误: {e}")

# 正确：用 errors 容错
s = unknown_data.decode('utf-8', errors='replace')
print(s)  # 含替换字符
```

### 10. 混淆 bytes 与 bytearray 的可哈希性

```python
# bytes 可哈希，可作字典键
d = {b'key': 'value'}
print(d[b'key'])  # value

# bytearray 不可哈希，不能作键
ba = bytearray(b'key')
try:
    d = {ba: 'value'}  # TypeError
except TypeError as e:
    print(f"错误: {e}")  # unhashable type: 'bytearray'
```

## 总结

### 核心要点

1. **bytes 本质**
   - 不可变的 0-255 整数序列
   - 每个元素是 int，不是字符
   - 二进制数据的标准容器

2. **bytes vs str**
   - str 是文本（Unicode），bytes 是二进制
   - 通过 encode/decode 互转
   - 字面量 `b'...'` 只能含 ASCII

3. **bytearray**
   - bytes 的可变版本
   - 支持 append/extend/insert/pop 等修改方法
   - 不可哈希

4. **编码与解码**
   - 必须用相同编码往返
   - errors 参数处理非法数据
   - 常见编码：UTF-8、GBK、ASCII、Latin-1

5. **数字互转**
   - `int.from_bytes` / `int.to_bytes`
   - struct 模块处理结构化数据
   - 注意字节序 big/little

6. **常见陷阱**
   - 索引返回 int 不是 bytes
   - bytes 不可变
   - 编码解码要匹配
   - 字面量只能 ASCII

### 何时使用 bytes

**适合使用 bytes：**
- 读写二进制文件（图片、音视频、压缩包）
- 网络通信协议
- 加密/哈希运算
- 处理原始二进制数据

**不适合使用 bytes：**
- 处理文本（用 str）
- 需要可变字节序列（用 bytearray）
- 需要哈希（bytearray 不行，用 bytes）
