## Number 基础

Python 中的 Number（数字）用于存储数值。Python 3 支持三种不同的数值类型：`int`（整数）、`float`（浮点数）和 `complex`（复数）。此外 `bool`（布尔值）是 `int` 的子类，也属于数字类型家族。

**特点：**
- **不可变性**：所有数字类型都是不可变对象（immutable），修改值会创建新对象
- **任意精度整数**：`int` 不存在溢出问题，可以表示任意大小的整数
- **统一类型体系**：`int`、`float`、`complex`、`bool` 都属于 `numbers.Number` 抽象基类
- **自动类型提升**：运算时遵循 `int → float → complex` 的提升规则

**三种数值类型：**

| 类型 | 描述 | 示例 |
|------|------|------|
| `int` | 整数，无大小限制 | `10`, `-5`, `0b1010` |
| `float` | 浮点数，IEEE 754 双精度 | `3.14`, `-0.5`, `1e10` |
| `complex` | 复数，实部 + 虚部 | `3+4j`, `1j` |

**内存与不可变性：**

```python
# 数字是不可变对象
a = 10
b = 10
print(a is b)  # True - 小整数被缓存（-5 到 256）

# 修改"值"实际上是创建新对象
x = 5
print(id(x))  # 某个内存地址
x = x + 1     # 创建新的 int 对象
print(id(x))  # 不同的内存地址

# 缓存范围
print(256 is 256)    # True
print(257 is 257)    # 在交互式下可能 False，此处由编译器常量折叠可能为 True
# 大整数不被缓存
a = 1000
b = 1000
print(a is b)  # 可能 False - 不在小整数缓存范围内

# 类型层次
import numbers
print(isinstance(5, numbers.Number))     # True
print(isinstance(3.14, numbers.Number))  # True
print(isinstance(True, numbers.Number))  # True
print(isinstance(3+4j, numbers.Number))  # True

# isinstance 类型检查
print(isinstance(5, int))        # True
print(isinstance(5, float))      # False
print(isinstance(True, int))     # True - 布尔是 int 的子类
print(isinstance(True, bool))    # True
```

**类型提升规则：**

```python
# int + int = int
print(type(3 + 5))        # <class 'int'>

# int + float = float
print(type(3 + 5.0))      # <class 'float'>

# int/float + complex = complex
print(type(3 + 4j))       # <class 'complex'>
print(type(3.0 + 4j))     # <class 'complex'>

# 除法总是返回 float（即使整除）
print(type(6 / 2))        # <class 'float'> - 结果 3.0
print(type(6 // 2))       # <class 'int'> - 整除返回 int
```

## int 整数

`int` 是 Python 的整数类型，与 C/Java 不同，Python 的 `int` 没有固定大小限制，可以表示任意精度的整数。

### 1. 整数的创建

**语法：** 直接书写数字字面量，或使用 `int()` 构造函数。

**特点：**
- 任意精度，无溢出
- 支持四种进制表示
- 支持下划线分隔（Python 3.6+），提高可读性
- 小整数缓存范围：`[-5, 256]`

```python
# 十进制整数
a = 100
b = -50
c = 0
print(type(a))  # <class 'int'>

# 任意大整数（不会溢出）
big = 10 ** 100  # googol
print(big)       # 100 位的大整数
print(len(str(big)))  # 101

# 下划线分隔（Python 3.6+），提高可读性
population = 7_800_000_000
print(population)  # 7800000000

binary = 0b1111_0000_1111
print(binary)  # 3855

credit_card = 1234_5678_9012_3456
print(credit_card)  # 1234567890123456

# 正负号
positive = +42
negative = -42
print(positive, negative)  # 42 -42

# int() 构造函数
a = int()         # 0
b = int(3.14)     # 3 - 截断小数部分
c = int(-3.9)     # -3 - 向 0 截断
d = int("42")     # 42 - 从字符串解析
e = int("  42  ") # 42 - 自动去除空白
print(a, b, c, d, e)
```

### 2. 进制表示

Python 支持四种进制表示整数：

| 进制 | 前缀 | 示例 | 十进制值 |
|------|------|------|---------|
| 二进制 | `0b` 或 `0B` | `0b1010` | 10 |
| 八进制 | `0o` 或 `0O` | `0o12` | 10 |
| 十进制 | 无 | `10` | 10 |
| 十六进制 | `0x` 或 `0X` | `0xA` | 10 |

```python
# 二进制（前缀 0b）
print(0b1010)    # 10
print(0b1111)    # 15
print(0B1010)    # 10 - 大写 B 也可以

# 八进制（前缀 0o）
print(0o12)      # 10
print(0o777)     # 511
print(0O12)      # 10 - 大写 O 也可以

# 十六进制（前缀 0x）
print(0xA)       # 10
print(0xFF)      # 255
print(0xDEAD)    # 57005
print(0Xa)       # 10 - 大写 X 也可以

# 不同进制表示同一个值
print(0b1111 == 0o17 == 15 == 0xF)  # True

# 带下划线的进制
print(0b_1111_0000)  # 240
print(0x_FF_FF)      # 65535
```

### 3. 进制转换

Python 提供三个内置函数将整数转换为不同进制的字符串表示。

**函数：** `bin()`, `oct()`, `hex()`

**参数：** 一个整数

**返回值：** 带前缀的字符串

```python
n = 255

# 转二进制字符串（带 0b 前缀）
print(bin(n))    # '0b11111111'
print(type(bin(n)))  # <class 'str'>

# 转八进制字符串（带 0o 前缀）
print(oct(n))    # '0o377'

# 转十六进制字符串（带 0x 前缀）
print(hex(n))    # '0xff'

# 去掉前缀
print(bin(n)[2:])   # '11111111'
print(oct(n)[2:])   # '377'
print(hex(n)[2:])   # 'ff'

# format() 函数也可以做进制转换
print(format(n, 'b'))   # '11111111' - 二进制，无前缀
print(format(n, 'o'))   # '377' - 八进制
print(format(n, 'x'))   # 'ff' - 小写十六进制
print(format(n, 'X'))   # 'FF' - 大写十六进制
print(format(n, '#x'))  # '0xff' - 带前缀

# f-string 进制转换
print(f"{n:b}")   # '11111111'
print(f"{n:#b}")  # '0b11111111'
print(f"{n:x}")   # 'ff'

# 任意进制转换（自定义函数）
def to_base(n, base):
    """将整数 n 转换为 base 进制字符串"""
    if n == 0:
        return '0'
    digits = '0123456789abcdefghijklmnopqrstuvwxyz'
    result = ''
    while n > 0:
        result = digits[n % base] + result
        n //= base
    return result

print(to_base(255, 16))  # 'ff'
print(to_base(255, 2))   # '11111111'
print(to_base(255, 8))   # '377'
print(to_base(255, 36))  # '73'

# int() 从字符串解析任意进制
print(int('ff', 16))     # 255
print(int('11111111', 2))  # 255
print(int('377', 8))     # 255
print(int('73', 36))     # 255
```

### 4. 位运算

Python 支持完整的位运算操作。注意：Python 的整数是任意精度的，负数使用"无穷位"的二补码表示，因此对负数的位运算结果可能与 C 语言不同。

| 运算符 | 名称 | 说明 |
|--------|------|------|
| `&` | 按位与 | 两位都为 1 才为 1 |
| `\|` | 按位或 | 任一位为 1 即为 1 |
| `^` | 按位异或 | 两位不同为 1 |
| `~` | 按位取反 | 一元运算，`~x == -x-1` |
| `<<` | 左移 | 低位补 0，相当于乘 2^n |
| `>>` | 右移 | 高位补符号位，相当于除 2^n |

```python
a = 0b1100  # 12
b = 0b1010  # 10

# 按位与
print(a & b)       # 8  (0b1000)
print(bin(a & b))  # '0b1000'

# 按位或
print(a | b)       # 14 (0b1110)
print(bin(a | b))  # '0b1110'

# 按位异或
print(a ^ b)       # 6  (0b0110)
print(bin(a ^ b))  # '0b0110'

# 按位取反（注意：~x == -x-1）
print(~a)   # -13
print(~0)   # -1
print(~-1)  # 0

# 左移（相当于乘以 2^n）
print(1 << 4)    # 16
print(5 << 2)    # 20

# 右移（相当于整除 2^n）
print(16 >> 2)   # 4
print(20 >> 2)   # 5
print(-16 >> 2)  # -4 - 算术右移，保留符号

# 常见位运算技巧
# 判断奇偶
n = 7
print(n & 1)  # 1 - 奇数
n = 8
print(n & 1)  # 0 - 偶数

# 交换两个数（不用临时变量）
x, y = 3, 5
x ^= y
y ^= x
x ^= y
print(x, y)  # 5 3

# 快速乘除 2
print(5 << 1)   # 10 - 5 * 2
print(5 >> 1)   # 2  - 5 // 2

# 获取某一位
n = 0b1011  # 11
print((n >> 0) & 1)  # 1 - 第 0 位
print((n >> 1) & 1)  # 1 - 第 1 位
print((n >> 2) & 1)  # 0 - 第 2 位
print((n >> 3) & 1)  # 1 - 第 3 位

# 设置某一位为 1
n = 0b1000  # 8
n |= (1 << 0)  # 设置第 0 位
print(bin(n))  # '0b1001'

# 清除某一位
n = 0b1011  # 11
n &= ~(1 << 1)  # 清除第 1 位
print(bin(n))  # '0b1001'

# 异或的常见用法：找出唯一不同的数
# 数组中除一个数外其他都出现两次，找出该数
nums = [4, 1, 2, 1, 2]
result = 0
for num in nums:
    result ^= num
print(result)  # 4

# 统计二进制中 1 的个数
n = 0b11011  # 27
print(bin(n).count('1'))  # 4
# 或使用 int.bit_count()（Python 3.10+）
print(n.bit_count())  # 4
```

### 5. int 的常用方法

```python
n = 255

# bit_length() - 二进制位数（不含符号）
print(n.bit_length())  # 8
print(0.bit_length())  # 0
print(1.bit_length())  # 1
print(-1.bit_length()) # 1

# bit_count() - 二进制中 1 的个数（Python 3.10+）
print(255.bit_count())  # 8
print(7.bit_count())    # 3

# to_bytes() - 转换为字节
print((255).to_bytes(2, 'big'))     # b'\x00\xff' - 大端
print((255).to_bytes(2, 'little'))  # b'\xff\x00' - 小端
print((1024).to_bytes(4, 'big'))    # b'\x00\x00\x04\x00'

# from_bytes() - 从字节创建整数
print(int.from_bytes(b'\x00\xff', 'big'))      # 255
print(int.from_bytes(b'\x00\x00\x04\x00', 'big'))  # 1024

# as_integer_ratio() - 转为分数（int 时分母为 1）
print((5).as_integer_ratio())  # (5, 1)
```

## float 浮点数

`float` 是 Python 的浮点数类型，基于 IEEE 754 双精度（64 位）浮点数标准，提供约 15-17 位有效十进制数字的精度。

### 1. 浮点数的创建

**特点：**
- IEEE 754 双精度，约 15-17 位有效数字
- 支持科学计数法
- 范围约 `±1.8 × 10^308`
- 存在精度问题（如 `0.1 + 0.2 != 0.3`）

```python
# 基本浮点数
a = 3.14
b = -0.5
c = 0.0
print(type(a))  # <class 'float'>

# 整数除法返回浮点数
print(6 / 2)   # 3.0
print(type(6 / 2))  # <class 'float'>

# 科学计数法
print(1e3)     # 1000.0
print(1.5e3)   # 1500.0
print(1e-3)    # 0.001
print(6.022e23)  # 阿伏伽德罗常数

# float() 构造函数
print(float())      # 0.0
print(float(3))     # 3.0 - int 转 float
print(float("3.14"))  # 3.14
print(float("1e10"))  # 10000000000.0
print(float("inf"))   # inf - 无穷大
print(float("-inf"))  # -inf
print(float("nan"))   # nan - 非数字

# 从字符串解析（自动处理空白和前缀符号）
print(float("  -3.14  "))  # -3.14
print(float("+1.5"))       # 1.5

# 特殊值：无穷大与 NaN
inf = float('inf')
neg_inf = float('-inf')
nan = float('nan')

print(inf)       # inf
print(inf > 1e308)  # True
print(inf + 1)   # inf
print(inf - inf) # nan
print(nan == nan)  # False - NaN 不等于自身
print(nan != nan)  # True
```

### 2. IEEE 754 与精度问题

浮点数在计算机中用二进制表示，许多十进制小数无法精确表示，导致精度问题。

```python
# 经典精度问题
print(0.1 + 0.2)         # 0.30000000000000004
print(0.1 + 0.2 == 0.3)  # False

# 看似相等的数实际不等
print(0.1 + 0.1 + 0.1 == 0.3)  # False

# 显示更多小数位
print(f"{0.1 + 0.2:.20f}")  # 0.30000000000000004441
print(f"{0.1:.20f}")        # 0.10000000000000000555
print(f"{0.2:.20f}")        # 0.20000000000000001110

# 大数精度丢失
print(0.1 + 1e20 - 1e20)  # 0.0 - 大数"吞掉"小数

# 浮点数比较陷阱
a = 0.1 + 0.2
b = 0.3
print(a == b)  # False

# 正确做法：使用 math.isclose
import math
print(math.isclose(a, b))  # True
print(math.isclose(a, b, rel_tol=1e-9))  # True

# 或使用 Decimal
from decimal import Decimal
print(Decimal('0.1') + Decimal('0.2') == Decimal('0.3'))  # True
```

### 3. Decimal 模块对比

`decimal` 模块提供高精度的十进制浮点运算，适合财务、货币计算。

```python
from decimal import Decimal, getcontext

# 创建 Decimal（推荐用字符串，避免 float 精度问题）
a = Decimal('0.1')
b = Decimal('0.2')
print(a + b)            # 0.3
print(a + b == Decimal('0.3'))  # True

# 用 float 创建 Decimal 会保留 float 的精度问题
print(Decimal(0.1))     # 0.1000000000000000055511151231257827021181583404541015625

# 设置精度
getcontext().prec = 6
print(Decimal('1') / Decimal('7'))  # 0.142857

# 大数计算
getcontext().prec = 50
print(Decimal(2).sqrt())  # 1.4142135623730950488016887242096980785696718753769

# 货币计算示例
price = Decimal('19.99')
tax_rate = Decimal('0.08')
total = price + price * tax_rate
print(total)  # 21.5892
print(total.quantize(Decimal('0.01')))  # 21.59 - 保留两位小数

# float 与 Decimal 性能对比
# float 快但精度有限，Decimal 慢但精确
```

### 4. float 常用方法

```python
# is_integer() - 判断浮点数是否为整数
print(3.0.is_integer())   # True
print(3.5.is_integer())   # False
print(-2.0.is_integer())  # True

# as_integer_ratio() - 返回分子分母元组
print(0.5.as_integer_ratio())   # (1, 2)
print(0.75.as_integer_ratio())  # (3, 4)
print(1.5.as_integer_ratio())   # (3, 2)

# hex() - 十六进制表示
print(3.14.hex())  # '0x1.91eb851eb851fp+1'
print(float.fromhex('0x1.0p0'))  # 1.0

# 判断特殊值
import math
print(math.isinf(float('inf')))  # True
print(math.isnan(float('nan')))  # True
print(math.isfinite(3.14))       # True
print(math.isfinite(float('inf')))  # False
```

## complex 复数

`complex` 是 Python 的复数类型，由实部（real）和虚部（imag）组成，虚部用 `j` 表示（数学上通常是 `i`，工程学用 `j`）。

**特点：**
- 实部和虚部都是 `float` 类型
- 字面量语法：`real + imag j`
- 支持所有算术运算
- 内置复数运算函数较少，复杂运算用 `cmath` 模块

### 1. 创建复数

```python
# 字面量
a = 3 + 4j
b = 1j        # 纯虚数
c = 5 + 0j    # 实部为 5
d = -2 - 3j   # 实部 -2，虚部 -3

print(type(a))  # <class 'complex'>
print(a)        # (3+4j)

# complex() 构造函数
z1 = complex(3, 4)   # (3+4j)
z2 = complex(5)      # (5+0j) - 只有实部
z3 = complex(0, 1)   # 1j - 只有虚部
z4 = complex('3+4j') # (3+4j) - 从字符串解析
z5 = complex('1j')   # 1j

print(z1, z2, z3, z4, z5)

# 从字符串解析（字符串中不能有空格）
try:
    complex('3 + 4j')  # ValueError
except ValueError as e:
    print(f"错误: {e}")
```

### 2. 复数的属性

```python
z = 3 + 4j

# .real - 实部
print(z.real)      # 3.0
print(type(z.real))  # <class 'float'>

# .imag - 虚部
print(z.imag)      # 4.0
print(type(z.imag))  # <class 'float'>

# .conjugate() - 共轭复数
print(z.conjugate())  # (3-4j)

# abs() - 模（绝对值）
print(abs(z))  # 5.0 - sqrt(3**2 + 4**2)

# 复数没有 < > 比较，只能比较相等
print((3+4j) == (3+4j))  # True
print((3+4j) == 3+4j)    # True
try:
    (3+4j) < (5+6j)  # TypeError
except TypeError as e:
    print(f"错误: {e}")
```

### 3. 复数运算

```python
a = 3 + 4j
b = 1 - 2j

# 加减乘除
print(a + b)  # (4+2j)
print(a - b)  # (2+6j)
print(a * b)  # (11-2j) - (3+4j)(1-2j) = 3-6j+4j-8j² = 11-2j
print(a / b)  # (-1+2j)

# 共轭
print(a.conjugate())  # (3-4j)

# 模
print(abs(a))  # 5.0

# 幂运算
print(a ** 2)  # (-7+24j)
print(a ** 0.5)  # 复数平方根

# 使用 cmath 模块
import cmath

z = 3 + 4j
print(cmath.phase(z))    # 0.9272952180016122 - 相位角（弧度）
print(cmath.polar(z))    # (5.0, 0.927...) - 极坐标 (模, 相位)
print(cmath.rect(5, 0.9272952180016122))  # (3.000...+4j) - 极坐标转笛卡尔

# 复数的指数和对数（欧拉公式）
print(cmath.exp(1j * cmath.pi))  # (-1+1.2246467991473532e-16j) ≈ -1
print(cmath.log(z))
print(cmath.sqrt(-1))  # 1j - 负数平方根
```

## 数值运算符

Python 提供了丰富的数值运算符。

### 1. 算术运算符

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `+` | 加法 | `3 + 5` → `8` |
| `-` | 减法 | `5 - 3` → `2` |
| `*` | 乘法 | `3 * 5` → `15` |
| `/` | 真除法 | `7 / 2` → `3.5` |
| `//` | 整除（地板除） | `7 // 2` → `3` |
| `%` | 取模 | `7 % 3` → `1` |
| `**` | 幂运算 | `2 ** 3` → `8` |

```python
# 加减乘除
print(3 + 5)    # 8
print(5 - 3)    # 2
print(3 * 5)    # 15
print(7 / 2)    # 3.5 - 真除法，总是返回 float
print(7.0 / 2)  # 3.5

# 整除 //（地板除，向负无穷取整）
print(7 // 2)    # 3
print(-7 // 2)   # -4 - 向下取整（不是 -3）
print(7 // -2)   # -4
print(7.0 // 2)  # 3.0 - 如果有 float，返回 float
print(-7 // 2)   # -4

# 取模 %（结果的符号与除数相同）
print(7 % 3)     # 1
print(-7 % 3)    # 2 - 注意：是 2，不是 -1
print(7 % -3)    # -2
print(-7 % -3)   # -1

# 整除与取模的关系：(a // b) * b + (a % b) == a
a, b = 7, 3
print((a // b) * b + (a % b))  # 7
a, b = -7, 3
print((a // b) * b + (a % b))  # -7

# 幂运算 **
print(2 ** 3)    # 8
print(2 ** 0.5)  # 1.4142135623730951 - 平方根
print(2 ** -1)   # 0.5
print((-8) ** (1/3))  # 复数？实际返回 1.732...+1j（因为 1/3 是 float）
print((-8) ** 2)  # 64
print(4 ** 3 ** 2)  # 262144 - 右结合，相当于 4 ** (3 ** 2) = 4 ** 9
```

### 3. 运算符优先级（从高到低）

```
**              幂运算（右结合）
+x, -x, ~x      一元正负、按位取反
*, /, //, %     乘、除、整除、取模
+, -            加、减
<<, >>          位移
&               按位与
^               按位异或
|               按位或
比较运算符
not, and, or    逻辑（最低）
```

```python
# 优先级示例

print((2 + 3) * 4)    # 20 - 括号优先
print(2 ** 3 ** 2)    # 512 - 右结合，相当于 2 ** 9
print(-2 ** 2)        # -4 - ** 优先于一元负号，相当于 -(2**2)
print((-2) ** 2)      # 4
print(2 * 3 ** 2)     # 18 - ** 优先于 *
print(~5 + 1)         # -5 - ~5 是 -6，再加 1

# 建议使用括号明确优先级，提高可读性
result = (a + b) * (c + d)
```

## 常用内置函数

### 1. abs() - 绝对值

**语法：** `abs(x)`

**返回值：** 数字的绝对值，类型与输入相同（复数返回模）

```python

```

### 2. round() - 四舍五入

**语法：** `round(number[, ndigits])`

**参数：**
- `number`：数值
- `ndigits`（可选）：小数位数，默认 None 返回整数

**返回值：** 浮点数（指定 ndigits）或整数（不指定）

**特点：** 使用银行家舍入（banker's rounding），四舍六入五成双

```python
# 不指定 ndigits，返回整数
print(round(3.4))   # 3
print(round(3.6))   # 4
print(round(2.5))   # 2 - 银行家舍入，五成双
print(round(3.5))   # 4
print(round(4.5))   # 4 - 五成双（4 是偶数）
print(round(5.5))   # 6

# 指定小数位数
print(round(3.14159, 2))  # 3.14
print(round(3.14159, 3))  # 3.142
print(round(3.14159, 0))  # 3.0 - 返回 float
print(round(3.14159, -1)) # 0.0 - 负数表示小数点左边

print(round(1234.5, -2))  # 1200.0
print(round(1250, -2))    # 1200 - 银行家舍入

# 浮点精度问题
print(round(2.675, 2))  # 2.67 - 实际 2.67499999...

# 实现传统四舍五入（五入）
from decimal import Decimal, ROUND_HALF_UP
def round_half_up(n, digits=0):
    d = Decimal(str(n))
    return float(d.quantize(Decimal('1.' + '0'*digits) if digits > 0 else Decimal('1'), rounding=ROUND_HALF_UP))

print(round_half_up(2.5))   # 3
print(round_half_up(4.5))   # 5
print(round_half_up(2.675, 2))  # 2.68
```

### 3. pow() - 幂运算

**语法：** `pow(base, exp[, mod])`

**参数：**
- `base`：底数
- `exp`：指数
- `mod`（可选）：取模

**返回值：** base ** exp，或 (base ** exp) % mod

```python
print(pow(2, 3))    # 8
print(pow(2, 0.5))  # 1.4142135623730951
print(pow(2, -1))   # 0.5
print(pow(2, 10))   # 1024

# 三参数形式：高效模幂运算
print(pow(2, 10, 100))  # 24 - 2^10 % 100
print(pow(3, 100, 7))   # 4 - 高效计算大数模幂

# pow 与 ** 的区别：pow 三参数版本更高效
# pow(a, b, m) 比 (a ** b) % m 高效得多（不会先算大数）

# 负指数
print(pow(2, -2))  # 0.25

# 复数
print(pow(2+3j, 2))  # (-5+12j)
```

### 4. max() 和 min() - 最大最小值

**语法：** `max(arg1, arg2, ...[, key=func])` 或 `max(iterable[, key=func])`

**参数：**
- 多个位置参数，或一个可迭代对象
- `key`（可选）：比较键函数

**返回值：** 最大或最小的元素

**异常：** `ValueError`（空序列）

```python
print(max(3, 1, 4, 1, 5))   # 5
print(min(3, 1, 4, 1, 5))   # 1

print(max([3, 1, 4, 1, 5]))  # 5
print(min([3, 1, 4, 1, 5]))  # 1

# 使用 key
print(max(1, 2, 3, key=lambda x: -x))  # 1 - 取最小的
print(max([-3, -1, -4], key=abs))      # -4 - 绝对值最大

# 字符串
print(max('abc', 'abd'))  # 'abd'
print(min(['apple', 'banana', 'cherry'], key=len))  # 'apple'

# 空序列报错
try:
    max([])
except ValueError as e:
    print(f"错误: {e}")

# 提供默认值（仅可迭代对象形式）
print(max([], default=0))  # 0
```

## random 模块

`random` 模块用于生成伪随机数。注意：基于 Mersenne Twister 算法，**不安全**，不能用于加密。加密用途请使用 `secrets` 模块。

### 1. 基本随机函数

```python
import random

# random() - [0.0, 1.0) 之间的随机浮点数
print(random.random())  # 例如 0.3744042661957246

# uniform(a, b) - [a, b] 之间的随机浮点数
print(random.uniform(1, 10))  # 例如 4.7269182381293945

# randint(a, b) - [a, b] 之间的随机整数（包含两端）
print(random.randint(1, 100))  # 例如 42

# randrange(start, stop[, step]) - 范围内随机整数
print(random.randrange(10))        # 0-9
print(random.randrange(1, 10))     # 1-9
print(random.randrange(0, 10, 2))  # 0,2,4,6,8 中的随机一个
```

### 2. 序列随机

```python
import random

# choice(seq) - 从序列中随机选一个
fruits = ['apple', 'banana', 'orange']
print(random.choice(fruits))  # 随机一个水果
print(random.choice('hello'))  # 随机一个字符

# choices(population, weights=None, k=1) - 有放回随机选 k 个（Python 3.6+）
print(random.choices(fruits, k=3))  # 例如 ['apple', 'banana', 'apple']
# 带权重
print(random.choices(fruits, weights=[1, 2, 3], k=5))  # banana 出现概率是 apple 的 2 倍

    """判断 n 是否为质数"""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    for i in range(3, int(math.sqrt(n)) + 1, 2):
        if n % i == 0:
            return False
    return True

print(is_prime(21))  # False
print(is_prime(97))  # True

def to_base(n, base):
    if n == 0:

    digits = '0123456789abcdefghijklmnopqrstuvwxyz'

        n //= base
    return sign + result

count = 0
count += (5 > 3)  # count += True → count = 1
print(count)  # 1

# 字符串 'True' 不能直接转 int
try:
    int("True")  # ValueError
except ValueError as e:
    print(f"错误: {e}")
```

## 总结

### 核心要点

1. **数值类型**
   - `int`：任意精度整数
   - `float`：IEEE 754 双精度浮点
   - `complex`：复数
   - `bool`：是 `int` 的子类

2. **运算符**
   - 算术：`+ - * / // % **`
   - 位运算：`& | ^ ~ << >>`
   - 注意 `/` 总是返回 float，`//` 是地板除

3. **类型转换**
   - `int()` 向 0 截断
   - `float()` 转浮点
   - `int(str, base)` 解析指定进制
   - `round()` 银行家舍入

4. **精度处理**
   - 浮点比较用 `math.isclose`
   - 精确十进制用 `Decimal`
   - 精确分数用 `Fraction`

5. **常用模块**
   - `math`：数学函数与常量
   - `random`：伪随机数（不安全）
   - `decimal`：高精度十进制
   - `fractions`：分数
   - `cmath`：复数运算

### 最佳实践

- 涉及浮点比较时永远使用 `math.isclose` 而非 `==`
- 财务、货币计算使用 `Decimal` 而非 `float`
- 大数模幂用 `pow(a, b, m)` 三参数形式
- 累加浮点用 `math.fsum` 提高精度
- 加密场景用 `secrets` 模块而非 `random`
- 使用 f-string 进行数值格式化输出

### 何时使用哪种类型

| 需求 | 类型 | 说明 |
|------|------|------|
| 通用整数运算 | `int` | 无溢出 |
| 科学计算、统计 | `float` | 速度快 |
| 货币财务 | `Decimal` | 精确十进制 |
| 精确分数 | `Fraction` | 无精度损失 |
| 信号、电气 | `complex` | 复数支持 |
| 逻辑判断 | `bool` | True/False |
| 大整数 ID | `int` | 任意精度 |
