# 题目 1
# Falsy（假值）：
# 数值：0, 0.0, -0, 0j 都是 Falsy
# 字符串：只有 '' 是 Falsy，' ', '0', 'False' 都是 Truthy
# 列表：只有 [] 是 Falsy，[0], [False], [None] 都是 Truthy
# 字典/集合：只有 {} 和 set() 是 Falsy，{'a': 0}, {None} 都是 Truthy

print(bool(0), bool(0.0), bool(-0), bool(0j))  # False False False False
print(bool(''), bool(' '), bool('0'), bool('False'))  # False True True True
print(bool([]), bool([0]), bool([False]), bool([None]))  # False True True True
print(bool({}), bool({'a': 0}), bool(set()), bool({None}))  # False True False True

# 题目 2
def check_data(data):
    # 判断空列表
    if isinstance(data, list):
        if data:
            print(f"元素个数: {len(data)}")
        else:
            print("空")
    # 判断 None
    elif data is None:
        print("无数据")
    # 判断非空字符串
    elif isinstance(data, str):
        if data:
            print(f"字符串长度: {len(data)}")
        else:
            print("空字符串")

check_data([])           # 空
check_data([1, 2, 3])    # 元素个数: 3
check_data(None)         # 无数据
check_data("hello")      # 字符串长度: 5
check_data("")           # 空字符串

# 题目 3
class Stack:
    def __init__(self):
        self.items = []
    
    def push(self, item):
        self.items.append(item)
    
    def pop(self):
        if not self:
            raise IndexError("pop from empty stack")
        return self.items.pop()
    
    def __bool__(self):
        return len(self.items) > 0  # 栈为空时返回 False

s = Stack()
print(bool(s))  # False - 空栈
s.push(1)
s.push(2)
print(bool(s))  # True - 非空栈
print(s.pop())  # 2
print(s.pop())  # 1
print(bool(s))  # False - 又空了

# 题目 4
# bug：if x 会把 0 当作假值，导致 process(0) 走入 "无数据" 分支
# 修复：用 is None 判断是否传入了值
def process(x=None):
    if x is not None:  # 修复：只判断是否为 None
        return f"处理 {x}"
    return "无数据"

print(process(5))  # 处理 5
print(process(0))  # 处理 0 - 修复后正确
print(process())   # 无数据

## 总结

通过这些练习题，你应该能够：

1. 熟练掌握布尔值的创建和转换
2. 理解真值测试规则（Truthy/Falsy）
3. 熟练使用 `and`、`or`、`not` 逻辑运算符及其短路特性
4. 掌握比较运算符和链式比较
5. 区分 `is` 和 `==`、逻辑运算和位运算
6. 识别并避免常见陷阱
7. 应用布尔运算解决实际问题

### 学习建议

1. **理解原理**：布尔类型是 `int` 的子类，这是很多陷阱的根源
2. **动手实践**：每道题都要自己运行验证
3. **关注陷阱**：特别留意 `is` vs `==`、`and/or` 返回对象、`0`/`False` 混淆
4. **Pythonic 写法**：用 `if x:` 代替 `if x == True:`，用 `if x is None:` 判断 `None`
5. **短路求值**：理解并利用短路特性编写简洁代码

### 常见陷阱速查

1. **`True == 1`**：布尔值等于整数，但 `1 is not True`
2. **`and/or` 返回对象**：不是布尔值，必要时用 `bool()` 转换
3. **`0` 是假值**：判断是否传入了值用 `is None`，不要用 `if x:`
4. **字典键冲突**：`1` 和 `True` 是同一个键
5. **链式比较语义**：`a != b != c` 不表示三个数互不相同
6. **`is` vs `==`**：判断 `None` 用 `is`，比较值用 `==`
7. **`bool('False')` 是 `True`**：非空字符串都是真值

继续练习，你会越来越熟练！
