## Bool 基础

Bool（布尔）是 Python 中表示逻辑真值的数据类型，只有两个取值：`True`（真）和 `False`（假）。布尔类型是 Python 中最基础也是最重要的类型之一，广泛应用于条件判断、循环控制、逻辑运算等场景。

**特点：**
- **只有两个值**：`True` 和 `False`（注意首字母大写）
- **是 int 的子类**：`bool` 类型继承自 `int`，这是 Python 的一个重要特性
- **True 等于 1，False 等于 0**：在数值运算中可以当作整数使用
- **不可变类型**：布尔值是不可变对象（immutable）
- **单例模式**：Python 中所有 `True` 都是同一个对象，所有 `False` 都是同一个对象

**内存结构：**
- `True` 和 `False` 在 Python 启动时就创建为单例对象
- 所有返回 `True` 的表达式都引用同一个对象
- `bool` 类型是 `int` 类型的子类，在内存中以整数形式存储

### 1. 基本概念

```python
# 布尔类型的两个字面量
t = True
f = False

print(type(t))   # <class 'bool'>
print(type(f))   # <class 'bool'>
print(t)         # True
print(f)         # False
```

### 2. bool 是 int 的子类

这是 Python 布尔类型最特殊的一点。`bool` 继承自 `int`，这意味着布尔值本质上就是整数的子类，可以被当作整数使用。

```python
# isinstance 检查
print(isinstance(True, bool))  # True
print(isinstance(True, int))   # True - True 也是 int 的实例！
print(isinstance(False, int))  # True

# 类型继承关系
print(issubclass(bool, int))   # True - bool 是 int 的子类

# 类继承链
print(True.__class__)              # <class 'bool'>
print(True.__class__.__bases__)    # (<class 'int'>,)
```

### 3. True == 1，False == 0

由于 `bool` 是 `int` 的子类，`True` 等价于 `1`，`False` 等价于 `0`。

```python
# 值相等
print(True == 1)   # True
print(False == 0)  # True

# 但类型不同
print(type(True))  # <class 'bool'>
print(type(1))     # <class 'int'>

# 数值运算中作为整数使用
print(True + True)     # 2
print(True + 1)        # 2
print(False + False)   # 0
print(True * 5)        # 5
print(False * 5)       # 0
print(True - False)    # 1
print(sum([True, False, True, True]))  # 3 - 统计 True 的个数
```

### 4. 单例特性

Python 中 `True` 和 `False` 都是单例对象，所有引用 `True` 的变量都指向同一个内存地址。

```python
a = True
b = 1 == 1  # 计算结果也是 True
c = 10 > 5  # 也是 True

# 它们都是同一个对象
print(a is b)  # True
print(a is c)  # True
print(a is True)  # True

# id 完全相同
print(id(a), id(b), id(True))  # 三个值完全相同
```

### 5. 注意大小写

`True` 和 `False` 必须首字母大写，全小写或全大写都会被当作变量名而非布尔字面量。

```python
# 正确写法
x = True
y = False

# 错误写法（这些是变量名，不是布尔值！）
# true = 100  # 这只是定义了一个名为 true 的变量
# TRUE = 100  # 同上

# 验证
print(True)   # True（布尔字面量）
print(type(True))  # <class 'bool'>

# true 未定义会报错
try:
    print(true)  # NameError: name 'true' is not defined
except NameError as e:
    print(f"错误: {e}")
```

## 创建布尔值

### 1. 使用字面量

**语法：** 直接使用 `True` 或 `False`

**特点：**
- 最直接的方式
- 创建的是单例对象
- 首字母必须大写

```python
# 直接使用字面量
is_active = True
is_empty = False

print(is_active)  # True
print(is_empty)   # False
print(type(is_active))  # <class 'bool'>
```

### 2. 使用比较运算

比较运算的结果就是布尔值。

**返回值：** 布尔值（`True` 或 `False`）

```python
# 数值比较
print(3 > 2)        # True
print(3 < 2)        # False
print(3 == 3)       # True
print(3 != 4)       # True
print(3 >= 3)       # True
print(3 <= 2)       # False

# 字符串比较
print('hello' == 'hello')  # True
print('abc' < 'abd')       # True - 按字典序比较
print('abc' == 'abc')      # True

# 列表比较
print([1, 2, 3] == [1, 2, 3])  # True
print([1, 2] == [1, 2, 3])     # False

# 成员运算（in / not in）
print(3 in [1, 2, 3])          # True
print('a' in 'apple')          # True
print('x' not in 'apple')      # True

# 身份运算（is / is not）
a = [1, 2, 3]
b = [1, 2, 3]
c = a
print(a is c)   # True - 同一个对象
print(a is b)   # False - 不同对象
print(a is not b)  # True
```

### 3. 使用 bool() 转换函数

**语法：** `bool([x])`

**参数：**
- `x`（可选）：任意 Python 对象
- 如果不提供参数，返回 `False`

**返回值：** 布尔值（`True` 或 `False`）

**特点：**
- 根据对象的真值规则转换
- 空对象、"零值"对象转换为 `False`
- 非空对象转换为 `True`

```python
# 数值类型
print(bool(0))      # False
print(bool(1))      # True
print(bool(-1))     # True - 负数也是 True
print(bool(0.0))    # False
print(bool(3.14))   # True
print(bool(0j))     # False - 复数 0
print(bool(1+2j))   # True

# 字符串
print(bool(''))         # False - 空字符串
print(bool('hello'))    # True
print(bool(' '))        # True - 包含空格的字符串非空
print(bool('0'))        # True - 字符串 '0' 不是空字符串！

# 容器类型
print(bool([]))         # False - 空列表
print(bool([1, 2]))     # True
print(bool(()))         # False - 空元组
print(bool((1,)))       # True
print(bool({}))         # False - 空字典
print(bool({'a': 1}))   # True
print(bool(set()))      # False - 空集合
print(bool({1, 2}))     # True

# None
print(bool(None))   # False

# 不提供参数
print(bool())   # False
```

### 4. 使用逻辑运算

逻辑运算符 `and`、`or`、`not` 的结果可能是布尔值，也可能是参与运算的对象本身。

```python
# and 运算
print(3 > 2 and 5 > 3)   # True
print(3 > 2 and 5 < 3)   # False
print(True and True)     # True

# or 运算
print(3 > 2 or 5 < 3)    # True
print(3 < 2 or 5 < 3)    # False

# not 运算
print(not True)          # False
print(not False)         # True
print(not 0)             # True
print(not 'hello')       # False
```

## 真值测试

Python 中任何对象都可以进行真值测试（truth value testing），用于 `if`、`while`、`and`、`or`、`not` 等需要布尔值的场合。这是 Python 一个非常强大的特性。

### 1. Falsy（假值）规则

以下对象在真值测试中被视为 `False`：

**语法：** 在布尔上下文中自动调用 `bool()` 转换

**Falsy 对象列表：**
- `False` 本身
- `None`
- 任何数值类型的零：`0`、`0.0`、`0j`、`Decimal(0)`、`Fraction(0, 1)`
- 空序列：`''`、`[]`、`()`
- 空映射：`{}`
- 空集合：`set()`、`frozenset()`
- 自定义对象：`__bool__()` 返回 `False` 或 `__len__()` 返回 `0`

```python
# 数值零
print(bool(0))       # False
print(bool(0.0))     # False
print(bool(0j))      # False
print(bool(0.0 + 0j))  # False

# 空序列
print(bool(''))      # False - 空字符串
print(bool([]))      # False - 空列表
print(bool(()))      # False - 空元组
print(bool(b''))     # False - 空 bytes
print(bool(range(0)))  # False - 空 range

# 空映射和集合
print(bool({}))      # False - 空字典
print(bool(set()))   # False - 空集合
print(bool(frozenset()))  # False

# None
print(bool(None))    # False

# 在条件判断中使用
def check_value(x):
    if x:
        return "真值"
    else:
        return "假值"

print(check_value(0))       # 假值
print(check_value(''))      # 假值
print(check_value([]))      # 假值
print(check_value(None))    # 假值
print(check_value(1))       # 真值
print(check_value('hello')) # 真值
```

### 2. Truthy（真值）规则

除上述 Falsy 对象外，所有其他对象都被视为 `True`。

```python
# 非零数值
print(bool(1))       # True
print(bool(-1))      # True - 负数也是 True
print(bool(0.001))   # True
print(bool(3.14))    # True

# 非空序列
print(bool('a'))     # True
print(bool(' '))     # True - 包含空格
print(bool('0'))     # True - 字符串 '0' 不是数值零
print(bool([0]))     # True - 包含 0 的列表
print(bool([None]))  # True - 包含 None 的列表
print(bool((False,)))  # True

# 非空映射和集合
print(bool({'a': 1}))  # True
print(bool({1, 2}))    # True

# 真值在 if 中的应用
user_input = '0'
if user_input:  # 字符串 '0' 是真值
    print("输入非空")  # 会执行

empty_list = []
if not empty_list:  # not [] = not False = True
    print("列表为空")  # 会执行
```

### 3. 自定义对象的真值

自定义类可以通过定义 `__bool__()` 或 `__len__()` 方法控制对象的真值。

**优先级：**
1. 先调用 `__bool__()`，如果定义了则使用其返回值
2. 如果没有 `__bool__()`，则调用 `__len__()`，返回 0 视为 False，非 0 视为 True
3. 如果两者都没有定义，则对象默认为 True

```python
# 方法1：定义 __bool__()
class MyObject:
    def __init__(self, value):
        self.value = value
    
    def __bool__(self):
        return self.value > 0  # value > 0 时为 True

obj1 = MyObject(5)
obj2 = MyObject(-3)
obj3 = MyObject(0)
print(bool(obj1))  # True
print(bool(obj2))  # False
print(bool(obj3))  # False

# 方法2：定义 __len__()（当没有 __bool__ 时生效）
class Container:
    def __init__(self, items):
        self.items = items
    
    def __len__(self):
        return len(self.items)  # 长度为 0 时为 False

c1 = Container([1, 2, 3])
c2 = Container([])
print(bool(c1))  # True
print(bool(c2))  # False

# 优先级演示：同时定义 __bool__ 和 __len__
class Both:
    def __bool__(self):
        return False  # __bool__ 优先
    
    def __len__(self):
        return 100  # 这个会被忽略

obj = Both()
print(bool(obj))  # False - __bool__ 优先

# 没有定义任何方法的类默认为 True
class Default:
    pass

print(bool(Default()))  # True
```

### 4. 真值测试在控制流中的应用

```python
# 判断列表是否为空（推荐方式）
my_list = [1, 2, 3]
if my_list:  # 比 if len(my_list) > 0 更 Pythonic
    print("列表非空")

# 判断字符串是否为空
name = ""
if not name:
    print("名字为空")

# 判断 None
value = None
if value is None:  # 判断 None 用 is 更好
    print("值为 None")

# 默认值技巧
def greet(name=None):
    name = name or 'Guest'  # 如果 name 是假值，使用 'Guest'
    print(f"Hello, {name}")

greet()         # Hello, Guest
greet('Alice')  # Hello, Alice
greet('')       # Hello, Guest - 空字符串也是假值，注意这个陷阱
```

## 逻辑运算符

Python 有三个逻辑运算符：`and`、`or`、`not`。

### 1. and 运算符

**语法：** `x and y`

**特点：**
- 短路求值：如果 `x` 为假，直接返回 `x`，不再计算 `y`
- 返回值是参与运算的对象，而不是布尔值（除非参与运算的就是布尔值）
- 只有两个操作数都为真时，才返回最后一个（最右侧）的真值对象
- 如果有任何一个为假，返回第一个为假的对象

**返回值：** 
- 如果 `x` 为假，返回 `x`
- 如果 `x` 为真，返回 `y`

```python
# 基本用法
print(True and True)    # True
print(True and False)   # False
print(False and True)   # False
print(False and False)  # False

# 短路求值
def side_effect():
    print("函数被调用了！")
    return True

# 第一个为 False，第二个不会执行
result = False and side_effect()  # 不会打印 "函数被调用了！"
print(result)  # False

# 第一个为 True，第二个会执行
result = True and side_effect()  # 会打印 "函数被调用了！"
print(result)  # True

# 返回的是对象本身，不是布尔值
print(1 and 2)        # 2 - 返回最后一个真值
print(0 and 2)        # 0 - 返回第一个假值
print(2 and 0)        # 0 - x 为真，返回 y（0）
print('' and 'hello')  # '' - 空字符串是假值
print('a' and 'b')     # 'b' - 都为真，返回最后一个
print([1] and [2])     # [2]
print([] and [2])      # [] - 空列表是假值

# 多个 and 连用
print(1 and 2 and 3)      # 3 - 全为真，返回最后一个
print(1 and 0 and 3)      # 0 - 遇到第一个假值就返回
print('a' and 'b' and '')  # '' - 最后一个是假值
```

### 2. or 运算符

**语法：** `x or y`

**特点：**
- 短路求值：如果 `x` 为真，直接返回 `x`，不再计算 `y`
- 返回值是参与运算的对象
- 只要有一个为真，返回第一个为真的对象
- 两个都为假时，返回最后一个（最右侧的）假值对象

**返回值：**
- 如果 `x` 为真，返回 `x`
- 如果 `x` 为假，返回 `y`

```python
# 基本用法
print(True or True)    # True
print(True or False)   # True
print(False or True)   # True
print(False or False)  # False

# 短路求值
def side_effect():
    print("函数被调用了！")
    return False

# 第一个为 True，第二个不会执行
result = True or side_effect()  # 不会打印
print(result)  # True

# 第一个为 False，第二个会执行
result = False or side_effect()  # 会打印
print(result)  # False

# 返回的是对象本身
print(1 or 2)         # 1 - 第一个为真，返回它
print(0 or 2)         # 2 - 第一个为假，返回第二个
print(0 or '')        # '' - 都为假，返回最后一个
print('a' or 'b')      # 'a' - 第一个为真
print('' or 'b')       # 'b' - 第一个为假
print([] or [2])       # [2]
print([1] or [2])      # [1]

# 多个 or 连用
print(1 or 2 or 3)     # 1 - 返回第一个真值
print(0 or '' or 3)    # 3 - 前两个为假，返回最后一个
print(0 or '' or [])   # [] - 全为假，返回最后一个
```

### 3. not 运算符

**语法：** `not x`

**特点：**
- 一元运算符，只有一个操作数
- 返回值是真正的布尔值（`True` 或 `False`）
- 对真值返回 `False`，对假值返回 `True`

**返回值：** 布尔值

```python
# 基本用法
print(not True)    # False
print(not False)   # True

# 对各种对象取反
print(not 0)       # True
print(not 1)       # False
print(not '')      # True
print(not 'hello') # False
print(not [])      # True
print(not [1])     # False
print(not None)    # True

# not 的优先级高于 and/or
print(not True and False)  # False - 等价于 (not True) and False = False and False
print(not (True and False))  # True

# 双重否定
print(not not True)   # True
print(not not 0)      # False
print(not not 'hello')  # True

# not 返回布尔值，与 and/or 不同
print(type(not 1))    # <class 'bool'>
print(type(1 and 2))  # <class 'int'> - and 返回对象本身
```

### 4. 短路求值的实际应用

短路求值是 Python 中一个非常有用的特性，可以用来避免错误、提供默认值等。

```python
# 应用1：避免除零错误
a = 0
if a != 0 and 10 / a > 1:  # 短路：a==0 时不会计算 10/a
    print("条件成立")

# 应用2：提供默认值
name = None
display_name = name or '匿名用户'  # name 为 None（假值），使用 '匿名用户'
print(display_name)  # 匿名用户

name = 'Alice'
display_name = name or '匿名用户'  # name 为真值，使用 name
print(display_name)  # Alice

# 应用3：条件赋值
config = {}
timeout = config.get('timeout') or 30  # 如果没有配置，使用默认值 30
print(timeout)  # 30

# 应用4：避免属性访问错误
class User:
    def __init__(self, name=None):
        self.name = name

user = None
# 错误方式：user.name 会报 AttributeError
# print(user.name)
# 正确方式：短路求值
name = user and user.name  # user 为 None，直接返回 None
print(name)  # None

user = User('Alice')
name = user and user.name  # user 为真，返回 user.name
print(name)  # Alice

# 应用5：链式默认值
value = None
result = value or [] or 'default'  # 依次尝试
print(result)  # 'default'
```

### 5. 逻辑运算符的优先级

优先级从高到低：`not` > `and` > `or`

```python
# not 优先级最高
print(not True and False)  # 等价于 (not True) and False = False
print(not (True and False))  # True

# and 优先级高于 or
print(True or False and False)  # 等价于 True or (False and False) = True
print((True or False) and False)  # False

# 复杂表达式建议使用括号
result = (a > 0 and a < 10) or (b > 0 and b < 10)  # 比 a > 0 and a < 10 or ... 更清晰
```

## 比较运算符

Python 提供了丰富的比较运算符，所有比较运算的结果都是布尔值。

### 1. 基本比较运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `==` | 等于 | `3 == 3` → `True` |
| `!=` | 不等于 | `3 != 4` → `True` |
| `>` | 大于 | `3 > 2` → `True` |
| `<` | 小于 | `3 < 2` → `False` |
| `>=` | 大于等于 | `3 >= 3` → `True` |
| `<=` | 小于等于 | `3 <= 2` → `False` |

**返回值：** 布尔值

```python
# 数值比较
print(3 == 3)   # True
print(3 != 4)   # True
print(3 > 2)    # True
print(3 < 2)    # False
print(3 >= 3)   # True
print(3 <= 2)   # False

# 字符串比较（按字典序，逐字符比较 Unicode 码点）
print('apple' == 'apple')  # True
print('apple' < 'banana')  # True - 'a' < 'b'
print('apple' < 'apricot') # True - 第三个字符 'p' < 'r'
print('abc' < 'abcd')      # True - 前缀相同，短的更小
print('ABC' < 'abc')       # True - 大写字母码点小于小写

# 列表比较（逐元素比较）
print([1, 2, 3] == [1, 2, 3])  # True
print([1, 2, 3] < [1, 2, 4])   # True
print([1, 2] < [1, 2, 3])      # True - 前缀相同，短的更小
print([1, 2, 3] != [1, 2, 4])  # True

# 元组、集合也可以比较
print((1, 2) == (1, 2))   # True
print((1, 2) < (1, 3))    # True

# 不同类型比较（== 和 !=）
print(1 == 1.0)        # True - 数值相等
print(1 == True)       # True - True 等于 1
print(0 == False)      # True - False 等于 0
print('1' == 1)        # False - 类型不同
print([1, 2] == (1, 2))  # False - 类型不同
```

### 2. 链式比较

Python 支持链式比较，可以同时比较多个值，这是 Python 一个独特的语法糖。

**语法：** `a < b < c` 等价于 `a < b and b < c`

**特点：**
- `b` 只会被计算一次（如果是函数调用，更高效）
- 等价于多个 `and` 连接的比较
- 可以混合使用不同的比较运算符

```python
# 数值范围判断
x = 5
print(1 < x < 10)     # True - 等价于 1 < x and x < 10
print(1 < x < 3)      # False
print(10 < x < 20)    # False

# 等号在链式比较中
x = 5
print(1 <= x <= 10)   # True
print(5 == x == 5)    # True - 等价于 5 == x and x == 5

# 混合运算符
x = 5
print(1 < x != 6)     # True - 等价于 1 < x and x != 6
print(1 < x > 3)      # True - 等价于 1 < x and x > 3

# 字符串链式比较
s = 'm'
print('a' < s < 'z')  # True - s 在 a 到 z 之间

# 链式比较中变量只计算一次
def get_value():
    print("调用了一次")
    return 5

# 链式比较：get_value 只调用一次
print(1 < get_value() < 10)  # 调用了一次，True

# 等价的非链式写法：get_value 调用两次
# value = get_value()
# print(1 < value and value < 10)

# 链式比较的陷阱
a = 1
b = 2
c = 1
print(a < b > c)   # True - 等价于 a < b and b > c，即 1 < 2 and 2 > 1
# 注意：这并不表示 a < b 且 b > c 且 a 和 c 的关系
```

### 3. is 与 == 的区别

这是 Python 中最容易混淆的地方。

**`==`（等于）：** 比较两个对象的**值**是否相等
**`is`（身份运算）：** 比较两个对象是否是**同一个对象**（内存地址是否相同，即 `id()` 是否相同）

```python
# == 比较值
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True - 值相等
print(a is b)  # False - 不是同一个对象
print(id(a), id(b))  # 不同的内存地址

# 同一个对象
c = a
print(a is c)  # True - c 引用 a
print(a == c)  # True

# 小整数缓存（-5 到 256）
x = 256
y = 256
print(x is y)  # True - 小整数被缓存，是同一个对象

x = 257
y = 257
print(x is y)  # 在交互式环境中可能 False，在脚本中可能 True（编译器优化）

# 字符串 intern 机制
s1 = 'hello'
s2 = 'hello'
print(s1 is s2)  # True - 短字符串被 intern

# None 的判断：应该用 is
x = None
print(x == None)   # True - 但不推荐
print(x is None)   # True - 推荐方式

# True 和 False 的判断：应该用 is 或直接判断
x = True
print(x == True)   # True
print(x is True)   # True - 更明确

# is 的常见用途
if x is None:   # 判断 None
    pass
if x is True:   # 判断是否真的是 True（而不是 1）
    pass
```

## 布尔运算与位运算区别

Python 中 `and`/`or`/`not` 是逻辑运算符，而 `&`/`|`/`~`/`^` 是位运算符，两者经常被混淆。

### 1. and 与 & 的区别

**`and`（逻辑与）：**
- 短路求值
- 返回参与运算的对象之一
- 用于布尔逻辑判断

**`&`（按位与）：**
- 不会短路，两个操作数都会计算
- 对整数执行按位与运算
- 对布尔值执行按位与运算（结果还是布尔值，但会计算两边）
- 优先级高于 `and`

```python
# 对布尔值的区别
print(True and False)  # False - 短路，返回 False
print(True & False)    # False - 按位与

# 短路 vs 不短路
def side_effect():
    print("调用了！")
    return True

# and 短路
result = False and side_effect()  # 不会打印
# & 不短路
result = False & side_effect()  # 会打印 "调用了！"

# 对整数的区别
print(5 and 3)   # 3 - 返回最后一个真值
print(5 & 3)     # 1 - 按位与：101 & 011 = 001

# 在 NumPy/Pandas 中 & 用于元素级运算
# 注意：在这些库中必须用 & 而不能用 and
```

### 2. or 与 | 的区别

```python
# 对布尔值
print(True or False)  # True - 短路，返回 True
print(True | False)   # True - 按位或

# 短路 vs 不短路
def side_effect():
    print("调用了！")
    return False

# or 短路
result = True or side_effect()  # 不会打印
# | 不短路
result = True | side_effect()  # 会打印

# 对整数
print(5 or 3)   # 5 - 返回第一个真值
print(5 | 3)    # 7 - 按位或：101 | 011 = 111
```

### 3. not 与 ~ 的区别

```python
# not 返回布尔值
print(not True)   # False
print(not 0)      # True

# ~ 是按位取反，对整数有效
print(~True)   # -2 - ~x = -x - 1
print(~1)      # -2
print(~0)      # -1
print(~False)  # -1
```

### 4. 优先级差异

位运算符的优先级高于比较运算符，逻辑运算符的优先级低于比较运算符。

```python
# 逻辑运算符：比较 > not > and > or
print(1 < 2 and 3 > 2)  # True - 先比较再 and

# 位运算符优先级更高
# 错误示例：
# print(1 < 2 & 3 > 2)  # 等价于 1 < (2 & 3) > 2 = 1 < 2 > 2 = False
# 在 Pandas/NumPy 中需要加括号：
# mask = (df['a'] > 1) & (df['b'] < 10)
```

### 5. 使用场景对比

```python
# 场景1：普通条件判断，用 and/or
age = 25
if age >= 18 and age <= 60:
    print("适龄")

# 场景2：NumPy/Pandas 元素级运算，用 &/|
import numpy as np
arr = np.array([1, 2, 3, 4, 5])
mask = (arr > 2) & (arr < 5)  # 数组级的按位与，等价于元素级逻辑与
print(mask)  # [False False True True False]
# 注意：这里不能用 and，因为 and 不能处理数组

# 场景3：位运算（标志位）
READ = 1    # 001
WRITE = 2   # 010
EXEC = 4    # 100

permission = READ | WRITE  # 011 - 同时有读和写权限
print(bool(permission & READ))   # True - 检查是否有读权限
print(bool(permission & EXEC))   # False - 没有执行权限
```

### 3. 从字符串解析布尔值

Python 没有内置的 `strtobool`，但可以用多种方式实现。

```python
# 方法1：显式比较
def str_to_bool(s):
    return s.lower() == 'true'

print(str_to_bool('True'))   # True
print(str_to_bool('false'))  # False
print(str_to_bool(''))       # False - 注意：空字符串返回 False
print(str_to_bool('abc'))    # False - 任何非 'true' 的字符串都返回 False

# 方法2：使用 ast.literal_eval（更严格）
from ast import literal_eval
print(literal_eval('True'))   # True
print(literal_eval('False'))  # False
# literal_eval('hello')  # ValueError - 严格解析

# 方法3：使用 distutils（已弃用，不推荐）
# from distutils.util import strtobool

# 方法4：自定义映射
def parse_bool(s):
    mapping = {'true': True, 'false': False, 'yes': True, 'no': False,
               '1': True, '0': False, 'on': True, 'off': False}
    s = s.lower().strip()
    if s in mapping:
        return mapping[s]
    raise ValueError(f"无法解析: {s}")

print(parse_bool('yes'))  # True
print(parse_bool('NO'))   # False
print(parse_bool('1'))    # True

# 注意陷阱：bool('False') 是 True！
print(bool('False'))  # True - 非空字符串都是真值
# 这就是为什么不能用 bool() 来从字符串解析布尔值
```

## 常用技巧

### 1. 短路赋值默认值

```python
# 使用 or 提供默认值
def get_name(name):
    return name or 'Anonymous'

print(get_name('Alice'))  # Alice
print(get_name(''))       # Anonymous
print(get_name(None))     # Anonymous

# 链式默认值
def get_config(env_value, default1, default2):
    return env_value or default1 or default2

# 使用 and 进行条件链
# 只在前一个条件成立时才检查下一个
user = {'name': 'Alice', 'age': 25}
# 错误：user['name'] 可能 KeyError
# result = user['name'].startswith('A')
# 正确：用 and 短路
result = 'name' in user and user['name'].startswith('A')
print(result)  # True
```

### 2. 条件表达式（三元运算符）

**语法：** `x if condition else y`

```python
# 基本用法
age = 20
status = '成年' if age >= 18 else '未成年'
print(status)  # 成年

# 嵌套条件表达式（不推荐过度嵌套）
score = 85
grade = 'A' if score >= 90 else 'B' if score >= 80 else 'C'
print(grade)  # B

# 在列表推导式中使用
numbers = [1, -2, 3, -4, 5]
labels = ['正' if x > 0 else '负' for x in numbers]
print(labels)  # ['正', '负', '正', '负', '正']

# 在函数参数中使用
def greet(name=None):
    print(f"Hello, {name if name else 'Guest'}")

greet()         # Hello, Guest
greet('Alice')  # Hello, Alice

# 条件表达式 vs and/or 技巧
# x if condition else y 比 (condition and x) or y 更清晰，推荐使用条件表达式
```

### 3. 用 bool 过滤

```python
# 过滤掉假值
data = [0, 1, '', 'hello', None, [], [1], False, True]
filtered = list(filter(None, data))  # None 表示过滤假值
print(filtered)  # [1, 'hello', [1], True]

# 使用列表推导式过滤
data = [0, 1, 2, 0, 3, 0, 4]
non_zero = [x for x in data if x]  # 过滤掉 0
print(non_zero)  # [1, 2, 3, 4]

# 用 bool() 转换列表

# 统计真值个数
```

### 4. all() 和 any()

**`all(iterable)`：** 所有元素为真返回 `True`，空可迭代对象返回 `True`
**`any(iterable)`**：任一元素为真返回 `True`，空可迭代对象返回 `False`

```python
# all - 所有为真
print(all([True, True, True]))   # True
print(all([True, False, True]))  # False
print(all([]))                   # True - 空可迭代对象
print(all([1, 2, 3]))            # True - 非零数字都是真值
print(all([1, 0, 3]))            # False - 0 是假值
print(all(['', 'a']))            # False - 空字符串是假值

# any - 任一为真
print(any([False, False, True]))  # True
print(any([False, False, False])) # False
print(any([]))                    # False - 空可迭代对象
print(any([0, 0, 1]))             # True
print(any([0, 0, 0]))             # False

# 实际应用：检查所有元素是否满足条件
numbers = [2, 4, 6, 8, 10]
print(all(x % 2 == 0 for x in numbers))  # True - 全是偶数

# 检查是否有任何元素满足条件
numbers = [1, 3, 5, 7, 8]
print(any(x % 2 == 0 for x in numbers))  # True - 有偶数

# 短路求值
# all 遇到第一个假值就停止
def check(x):
    print(f"检查 {x}")
    return x > 0

print(all(check(x) for x in [1, 2, -3, 4]))  # 检查 1, 2, -3 然后停止
# any 遇到第一个真值就停止
print(any(check(x) for x in [-1, 0, 3, 4]))  # 检查 -1, 0, 3 然后停止
```


## 常见陷阱

### 1. is 与 == 比较 True 的陷阱

```python
# 由于 True == 1，所以 == 会把 1 当作 True
print(1 == True)   # True
print(1.0 == True)  # True

# 但 is 不会
print(1 is True)   # False - 1 不是 True 对象
print(1.0 is True)  # False

# 陷阱示例
def process(flag):
    if flag == True:  # 危险：1 也会进入这个分支
        return "真"
    return "假"

print(process(True))  # 真
print(process(1))     # 真 - 不是预期的！可能 1 应该被当作数值处理
print(process(2))     # 假 - 2 != True

# 正确方式
def process_v2(flag):
    if flag is True:  # 严格判断
        return "真"
    return "假"

print(process_v2(True))  # 真
print(process_v2(1))     # 假 - 现在正确了
```

### 2. 链式比较的语义陷阱

```python
# 链式比较不是数学上的传递
a = 1
b = 2
c = 3
print(a < b < c)  # True - 1 < 2 < 3

# 但要注意：a < b > c 不表示 a 和 c 的关系
a = 1
b = 5
c = 2
print(a < b > c)  # True - 等价于 a < b and b > c，即 1 < 5 and 5 > 2
# 这并不意味着 a > c（实际上 1 < 2）

# 陷阱：判断三个数是否相等
a, b, c = 1, 1, 1
print(a == b == c)  # True - 正确
# 但如果想要判断 a 等于 b 且 b 等于 c，这就是正确写法

# 判断三个数是否都不相等（错误写法）
a, b, c = 1, 2, 3
print(a != b != c)  # True，但这并不保证 a != c
a, b, c = 1, 2, 1
print(a != b != c)  # True - 但 a == c！这是陷阱
# 正确写法
print(a != b and a != c and b != c)  # False
```

### 3. and/or 返回对象而非布尔值

```python
# and 返回对象本身
result = 1 and 2
print(result)        # 2 - 不是 True！
print(result == 2)   # True
print(result is True)  # False

# or 返回对象本身
result = 0 or 'hello'
print(result)        # 'hello' - 不是 True！

# 陷阱：在需要严格布尔值的场合
def is_valid(x):
    return x and len(x) > 0  # 危险：可能返回非布尔值

result = is_valid('hello')
print(result)  # True - 这次返回布尔值
result = is_valid([1])
print(result)  # True
result = is_valid([])
print(result)  # [] - 返回空列表，不是 False！
# if result:  # 这里能用，因为 [] 是假值
#     pass
# 但如果直接比较 result == False 就会出错
print(result == False)  # False - [] 不等于 False

# 正确方式：显式转换为布尔值
def is_valid_v2(x):
    return bool(x and len(x) > 0)
result = is_valid_v2([])
print(result)  # False - 现在是真正的布尔值
```

### 4. 布尔值与整数混合运算

```python
# True 当作 1，False 当作 0
print(True + True)    # 2
print(True * 5)       # 5
print(False * 100)    # 0

# 陷阱：意外地用布尔值做算术
flags = [True, False, True, True]
total = sum(flags)  # 3 - 这是统计 True 的个数，没问题

# 但如果本意是统计数值
numbers = [1, 2, 3]
# 错误：如果 numbers 中混入了布尔值
mixed = [1, 2, True, 3, False]
print(sum(mixed))  # 7 - True 当作 1，False 当作 0，结果被影响

# 陷阱：用 1 和 True 作为字典键
d = {1: 'one', True: 'true'}
print(d)  # {1: 'true'} - True 和 1 是同一个键！后赋值的覆盖了
print(d[1])   # 'true'
print(d[True])  # 'true' - 同一个键

# 集合中
s = {1, True, 0, False}
print(s)  # {0, 1} 或 {False, True} - 只有 2 个元素，因为 1==True, 0==False
print(len(s))  # 2
```

### 5. 0 的判断陷阱

```python
# 0 == False
print(0 == False)  # True
print(0.0 == False)  # True

# 陷阱：判断变量是否为 0
x = 0
if x == False:  # 危险：0 会被当作 False
    print("x 是 False")  # 会执行，但 x 实际是整数 0
if x == 0:  # 正确
    print("x 是 0")

# 陷阱：判断变量是否为真值
x = 0
if x:  # 0 是假值
    print("真")  # 不执行
# 这通常是我们想要的，但如果 x 本应是数值 0 呢？

# 严格判断
def is_zero(x):
    return x == 0 and type(x) in (int, float)

print(is_zero(0))      # True
print(is_zero(False))  # False - False == 0 但类型不对
print(is_zero(0.0))    # True
```

### 6. 空字符串判断陷阱

```python
# 空字符串是假值
print(bool(''))  # False

# 但字符串 '0'、'False'、'None' 都是真值！
print(bool('0'))      # True
print(bool('False'))  # True
print(bool('None'))   # True
print(bool(' '))      # True - 包含空格

# 陷阱：从用户输入判断
user_input = input("请输入 (y/n): ")  # 假设输入 ''
if user_input:  # 空输入是假值
    print("有输入")
else:
    print("无输入")  # 执行

# 但如果用户输入 'n' 表示否
user_input = 'n'
if user_input:  # 'n' 是真值，会执行
    print("确认")  # 执行，但用户意图是"否"
# 应该明确判断
if user_input.lower() in ('y', 'yes'):
    print("确认")
```

### 7. 短路求值的副作用陷阱

```python
# 短路可能跳过重要的副作用
def log_and_check(x):
    print(f"检查 {x}")
    return x > 0

# 使用 and 时，如果第一个为假，第二个不执行
values = [0, 5, -3, 2]
for v in values:
    if v and log_and_check(v):  # v=0 时不会调用 log_and_check
        print(f"{v} 有效")
# 输出：
# 检查 5
# 5 有效
# 检查 -3
# 检查 2
# 2 有效
# 注意：0 没有被检查！

# 如果希望总是检查，用 &
for v in values:
    if bool(v) & log_and_check(v):  # 不会短路，但要注意优先级
        print(f"{v} 有效")

# 或者显式判断
for v in values:
    if v != 0 and log_and_check(v):
        print(f"{v} 有效")
```

### 8. 链式比较中函数只调用一次

```python
# 链式比较：函数只调用一次
import random

def get_random():
    return random.randint(1, 100)

# 链式比较
# 1 < get_random() < 50 中 get_random() 只调用一次
# 等价于
# temp = get_random()
# 1 < temp and temp < 50

# 如果写成两个比较，会调用两次
# 1 < get_random() and get_random() < 50  # 调用两次，可能两次值不同

# 陷阱示例
def f():
    print("调用")
    return 5

# 链式比较
result = 1 < f() < 10  # 调用一次
# 非链式
# result = 1 < f() and f() < 10  # 调用两次，结果可能不一致
```

## 常见错误

### 1. 大小写错误

```python
# 错误：使用小写的 true/false
# x = true  # NameError: name 'true' is not defined
# y = false  # NameError

# 正确：首字母大写
x = True
y = False
```

### 2. 用 == 比较 None

```python
# 不推荐
x = None
if x == None:  # 能用但不推荐
    pass

# 推荐
if x is None:  # 推荐
    pass

# 原因：== 可能被自定义类重载，行为不可预测
class Weird:
    def __eq__(self, other):
        return True  # 与任何东西比较都返回 True

w = Weird()
print(w == None)  # True - 但 w 不是 None！
print(w is None)  # False - 正确
```

### 3. 用 if x == True 代替 if x

```python
# 不推荐
x = True
if x == True:  # 啰嗦，且有陷阱
    pass

# 推荐
if x:  # 简洁
    pass

# 但要注意：if x 会把 1、[1] 等也当作真
# 如果需要严格判断是否为 True
if x is True:  # 严格
    pass
```

### 4. 混淆 and/or 与 &/|

```python
# 在 NumPy/Pandas 中混淆会导致错误
import numpy as np
arr = np.array([True, False, True])

# 正确：用 & 做元素级运算
print(arr & np.array([True, True, False]))  # [ True False False]

# 错误：用 and 会报错
# print(arr and np.array([True, True, False]))  # ValueError

# 普通逻辑判断中错误使用 &
a = 5
# 错误：位运算优先级高于比较
# if a > 1 & a < 10:  # 等价于 a > (1 & a) < 10，逻辑错误
#     pass
# 正确：加括号或用 and
if a > 1 and a < 10:
    pass
if (a > 1) & (a < 10):  # 也可以，但通常用 and
    pass
```

### 5. 布尔值作为字典键的冲突

```python
# 陷阱：1 和 True 是同一个键
d = {1: '整数', True: '布尔'}
print(d)  # {1: '布尔'} - 后赋值的覆盖

# 同样 0 和 False
d = {0: '整数', False: '布尔'}
print(d)  # {0: '布尔'}

# 避免方法：不要混用 1/True 或 0/False 作为键
# 如果需要区分，用字符串
d = {'1': '整数', 'True': '布尔'}
```

### 6. 误以为 and/or 返回布尔值

```python
# 误解：以为 and 返回布尔值
result = 'hello' and 'world'
print(result)  # 'world' - 不是 True！

# 在条件表达式中通常没问题
if 'hello' and 'world':
    print("都为真")  # 执行

# 但在需要布尔值的场合
def check(x):
    return x and True  # 可能返回 x 而不是 True

print(check('hello'))  # True - 这次返回 True
print(check(0))        # 0 - 返回 0 而不是 False！
print(check(0) == False)  # False - 0 != False（实际上 0 == False 是 True...）
# 等等，0 == False 是 True，所以这里实际是 True
# 但类型不同
print(type(check(0)))  # <class 'int'>，不是 bool

# 正确方式
def check_v2(x):
    return bool(x)  # 显式转换
print(check_v2(0))  # False
print(type(check_v2(0)))  # <class 'bool'>
```

### 7. 在布尔上下文中误用 falsy 值

```python
# 陷阱：0 被当作假值
def process_number(x):
    if x:  # 0 会被当作假值
        return f"处理 {x}"
    return "没有数字"

print(process_number(5))  # 处理 5
print(process_number(0))  # 没有数字 - 但 0 是有效的数字！

# 正确方式：显式判断 None
def process_number_v2(x):
    if x is not None:  # 只判断是否为 None
        return f"处理 {x}"
    return "没有数字"

print(process_number_v2(0))  # 处理 0 - 正确

# 或者用哨兵值
def process_number_v3(x=None):
    if x is None:
        return "没有数字"
    return f"处理 {x}"
```

### 8. not 与 in 的优先级

```python
# not in 是一个整体运算符
print('a' not in 'abc')  # False - 'a' 不在 'abc' 中？错，'a' 在里面

# not in 优先级
x = 'a'
# 错误理解：not x in 'abc' 
# 正确理解：(not x) in 'abc' 还是 not (x in 'abc')?
# 答案：not (x in 'abc')，因为 not in 是整体
print(not x in 'abc')  # False - 等价于 not (x in 'abc')
print(x not in 'abc')  # False - 同上，更清晰的写法
```

## 总结

### 核心要点

1. **布尔类型特性**
   - 只有两个值：`True` 和 `False`
   - `bool` 是 `int` 的子类，`True == 1`，`False == 0`
   - `True` 和 `False` 是单例对象

2. **真值测试规则**
   - Falsy：`False`、`None`、`0`、`0.0`、`''`、`[]`、`()`、`{}`、`set()` 等空容器
   - 其余对象都是 Truthy
   - 自定义对象通过 `__bool__()` 或 `__len__()` 控制

3. **逻辑运算符**
   - `and`：短路求值，返回对象本身
   - `or`：短路求值，返回对象本身
   - `not`：返回真正的布尔值
   - 优先级：`not` > `and` > `or`

4. **比较运算符**
   - `==` 比较值，`is` 比较身份（内存地址）
   - 支持链式比较 `a < b < c`
   - 判断 `None` 用 `is None`

5. **位运算与逻辑运算**
   - `&`/`|` 不会短路，对整数做位运算
   - `and`/`or` 会短路，返回对象本身
   - 在 NumPy/Pandas 中用 `&`/`|` 做元素级运算

### 最佳实践

- 判断空容器用 `if not container:`
- 判断 `None` 用 `if x is None:`
- 判断布尔值用 `if x:` 或 `if x is True:`
- 提供默认值用 `x or default`
- 避免用 `if x == True:`，用 `if x:` 或 `if x is True:`
- 链式比较用 `a < x < b` 而不是 `a < x and x < b`
- 不要混用 `1`/`True` 和 `0`/`False` 作为字典键

### 常见陷阱速查

| 陷阱 | 错误写法 | 正确写法 |
|------|---------|---------|
| 判断 None | `if x == None:` | `if x is None:` |
| 判断 True | `if x == True:` | `if x:` 或 `if x is True:` |
| 判断空容器 | `if len(x) == 0:` | `if not x:` |
| 范围判断 | `if a < x and x < b:` | `if a < x < b:` |
| 默认值 | `if x is None: x = default` | `x = x or default` |
| 严格布尔判断 | `if x == True:` | `if x is True:` |
