# 02-数据类型

Python中的核心数据结构，掌握它们是Python编程的基础。

## 📑 目录

### 基本数据类型

#### [2.1-Number（数字）](./2.1-Number/)
**数值类型**
- int（整数）
- float（浮点数）
- complex（复数）
- 数值运算和转换

#### [2.2-String（字符串）](./2.2-String/)
**不可变序列，文本处理的基础**
- 不可变类型
- 支持索引和切片
- 丰富的字符串方法
- 格式化输出

#### [2.3-Bool（布尔）](./2.3-Bool/)
**逻辑类型**
- True和False
- 逻辑运算
- 真值测试

### 容器类型

#### [2.4-List（列表）](./2.4-List/)
**可变序列类型，最常用的数据结构**
- 支持动态增删改查
- 有序可索引
- 可包含任意类型元素

#### [2.5-Tuple（元组）](./2.5-Tuple/)
**不可变序列类型**
- 一旦创建不可修改
- 性能优于List
- 常用于数据保护和函数返回值

#### [2.6-Set（集合）](./2.6-Set/)
**无序不重复元素集**
- 自动去重
- 支持集合运算（并集、交集、差集）
- 查找效率高

#### [2.7-Dict（字典）](./2.7-Dict/)
**键值对存储结构**
- 通过键快速访问值
- 键必须唯一且不可变
- Python 3.7+ 保持插入顺序

### 其他类型

#### [2.8-Bytes（字节串）](./2.8-Bytes/)
**二进制数据类型**
- 不可变字节序列
- 用于二进制数据处理
- 编码与解码

#### [2.9-推导式](./2.9-推导式/)
**高效创建数据结构**
- 列表推导式
- 字典推导式
- 集合推导式
- 生成器表达式

## 🎯 学习重点

1. **选择合适的数据类型**：根据需求选择合适的数据类型
2. **理解可变性**：可变类型（List、Set、Dict）vs 不可变类型（Number、String、Tuple）
3. **掌握常用操作**：增删改查、切片、推导式
4. **性能考虑**：不同数据类型的时间复杂度

## 📊 对比总结

| 特性 | List | Tuple | Set | Dict |
|------|------|-------|-----|------|
| 可变性 | 可变 | 不可变 | 可变 | 可变 |
| 有序性 | 有序 | 有序 | 无序 | 有序(3.7+) |
| 重复性 | 可重复 | 可重复 | 不可重复 | 键不可重复 |
| 索引 | 支持 | 支持 | 不支持 | 键访问 |
| 用途 | 通用序列 | 数据保护 | 去重/集合运算 | 映射关系 |
