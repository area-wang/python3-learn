# 8.1 迭代器

迭代器（Iterator）是 Python 中 `for` 循环、推导式、`*` 解包等一切「遍历」行为背后的统一机制。理解迭代器协议，不仅能写出自定义的可遍历对象，还能看懂 `itertools` 这类高效处理惰性序列的工具，是后续学习生成器（8.2）的基础。

## 1. 可迭代对象与迭代器

Python 里有两个容易混淆的概念：

| 概念 | 定义 | 判断方式 |
|---|---|---|
| 可迭代对象（Iterable） | 实现了 `__iter__` 方法，能通过 `iter()` 产出一个迭代器 | `isinstance(obj, collections.abc.Iterable)` |
| 迭代器（Iterator） | 实现了 `__iter__` 和 `__next__` 方法，每次 `next()` 产出下一个值，耗尽后抛 `StopIteration` | `isinstance(obj, collections.abc.Iterator)` |

关键关系：**迭代器一定是可迭代对象（它的 `__iter__` 返回自身），但可迭代对象不一定是迭代器**。

```python
lst = [1, 2, 3]
print(hasattr(lst, "__iter__"))   # True，list 是可迭代对象
print(hasattr(lst, "__next__"))   # False，list 本身不是迭代器

it = iter(lst)
print(hasattr(it, "__iter__"))    # True
print(hasattr(it, "__next__"))    # True，list_iterator 才是迭代器
```

`list`、`dict`、`str`、`set`、文件对象都是可迭代对象，但真正驱动遍历的是它们各自 `iter()` 之后返回的迭代器对象。

## 2. 迭代器协议：`__iter__` 与 `__next__`

迭代器协议只有两条规则：

1. `__iter__(self)` 返回迭代器本身（`return self`）；
2. `__next__(self)` 返回序列中的下一个值，没有更多值时抛出 `StopIteration`。

```python
class CountUp:
    """从 start 数到 end（含）的迭代器"""

    def __init__(self, start, end):
        self.current = start
        self.end = end

    def __iter__(self):
        return self

    def __next__(self):
        if self.current > self.end:
            raise StopIteration
        value = self.current
        self.current += 1
        return value


counter = CountUp(1, 3)
print(next(counter))   # 1
print(next(counter))   # 2
print(next(counter))   # 3
print(next(counter))   # 抛出 StopIteration
```

在 `for` 循环中使用时，`StopIteration` 会被自动捕获，不需要手动处理：

```python
for n in CountUp(1, 3):
    print(n)   # 1 2 3
```

## 3. `StopIteration` 的语义

`StopIteration` 不是错误，而是「迭代结束」的信号。它只应该在 `__next__` 内部主动 `raise`，交给调用方（`for`、`next()` 带默认值等）捕获。

```python
it = iter([1, 2])
print(next(it))            # 1
print(next(it))            # 2
print(next(it, "没有了"))   # 没有了，next() 的第二个参数提供默认值，避免异常
```

一个重要细节：Python 3.7 起（PEP 479），如果在**生成器函数内部**未捕获地让 `StopIteration` 向外传播，会被转换成 `RuntimeError`，以防止它被外层 `for` 循环误当作正常结束吞掉。自定义的普通迭代器类不受此限制，但生成器（见 8.2）需要留意。

## 4. `for` 循环的工作原理（脱糖）

`for item in obj:` 本质上是下面代码的语法糖：

```python
_iterator = iter(obj)
while True:
    try:
        item = next(_iterator)
    except StopIteration:
        break
    # 循环体
    print(item)
```

理解这一点后，就能明白为什么：

- `obj` 只需要可迭代（实现 `__iter__`），`for` 会先调用 `iter(obj)` 拿到迭代器；
- 同一个可迭代对象可以同时开启多个独立的 `for` 循环（每次 `iter()` 都产出一个新的迭代器，各自维护自己的进度）；
- 但如果直接对一个「迭代器」做 `for`，由于其 `__iter__` 返回自身，多次遍历会共享同一个进度，第二次遍历将得不到任何元素。

```python
nums = [1, 2, 3]
for a in nums:
    for b in nums:      # 每次都是全新的迭代器，互不影响
        pass

it = iter(nums)
for a in it:
    print(a)            # 1 2 3
for a in it:
    print(a)            # 什么都不打印，it 已耗尽
```

## 5. `iter()` 的两种用法

`iter()` 内置函数有两种调用形式：

| 形式 | 说明 |
|---|---|
| `iter(iterable)` | 对可迭代对象取迭代器，等价于调用 `iterable.__iter__()` |
| `iter(callable, sentinel)` | 反复调用 `callable()`，直到返回值等于 `sentinel` 时停止（不含哨兵值本身） |

第二种形式在读取「直到某个哨兵为止」的数据流时非常实用：

```python
import functools

with open("data.txt", encoding="utf-8") as f:
    # 等价于反复调用 f.readline()，直到读到空字符串为止
    for line in iter(f.readline, ""):
        process(line)


# 模拟从队列里取数据，直到取到 None 停止
def make_reader(values):
    values = iter(values)
    return functools.partial(next, values, None)


reader = make_reader([1, 2, 3])
for x in iter(reader, None):
    print(x)   # 1 2 3
```

## 6. 自定义迭代器类：分离可迭代对象与迭代器

当一个对象需要**支持多次独立遍历**时，应该把「可迭代对象」和「迭代器」拆成两个类：可迭代对象的 `__iter__` 每次都返回一个全新的迭代器实例。

```python
class Fibonacci:
    """可迭代对象：每次 iter() 都产生一个从头开始的新迭代器"""

    def __init__(self, limit):
        self.limit = limit

    def __iter__(self):
        return FibonacciIterator(self.limit)


class FibonacciIterator:
    """真正持有遍历状态的迭代器"""

    def __init__(self, limit):
        self.limit = limit
        self.a, self.b = 0, 1
        self.count = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.count >= self.limit:
            raise StopIteration
        value = self.a
        self.a, self.b = self.b, self.a + self.b
        self.count += 1
        return value


fib = Fibonacci(5)
print(list(fib))   # [0, 1, 1, 2, 3]
print(list(fib))   # [0, 1, 1, 2, 3]，可以重复遍历，因为每次都拿到新迭代器
```

如果嫌拆两个类麻烦，也可以用生成器函数代替 `__iter__` 的实现（见 8.2），效果等价且更简洁：

```python
class FibonacciGen:
    def __init__(self, limit):
        self.limit = limit

    def __iter__(self):
        a, b, count = 0, 1, 0
        while count < self.limit:
            yield a
            a, b = b, a + b
            count += 1
```

生成器本质上也是一种迭代器（同时实现了 `__iter__` 和 `__next__`），只是由解释器自动生成，8.2 会详细展开。

## 7. 迭代器耗尽与常见误区

迭代器是**一次性、只能前进**的：一旦 `next()` 用尽，无法回退或重置，只能重新 `iter()` 一个新的（如果来源支持的话）。

```python
data = [1, 2, 3]
it = iter(data)
total_first_pass = sum(it)     # 3+2+1，消耗掉 it
total_second_pass = sum(it)    # 0，it 已耗尽，没有元素可加
```

常见误区：

- 把生成器/迭代器当作列表反复使用，第二次遍历得到空结果；
- 对迭代器调用 `len()`：迭代器不支持 `len()`（除非专门实现），因为总长度可能未知或无限；
- 认为 `for x in some_iterator` 结束后 `some_iterator` 可以复用——实际上它已经耗尽。

## 8. `itertools`：迭代器工具箱

标准库 `itertools` 提供了大量惰性、内存友好的迭代器组合工具，无需一次性生成完整序列。以下是最常用的一批：

| 函数 | 作用 |
|---|---|
| `count(start=0, step=1)` | 从 `start` 开始，按 `step` 无限递增 |
| `cycle(iterable)` | 无限循环重复某个可迭代对象的元素 |
| `repeat(elem, times=None)` | 重复 `elem`，`times` 为 `None` 时无限重复 |
| `chain(*iterables)` | 把多个可迭代对象串联成一个 |
| `islice(iterable, start, stop, step)` | 对（可能无限的）迭代器做切片，惰性求值 |
| `zip_longest(*iterables, fillvalue=None)` | 按最长的可迭代对象对齐，缺失处用 `fillvalue` 填充 |
| `groupby(iterable, key=None)` | 对**已排序**的连续相同 key 的元素分组 |
| `tee(iterable, n=2)` | 把一个迭代器复制成 `n` 个独立、互不干扰的迭代器 |
| `pairwise(iterable)` | 3.10+，产出相邻元素对 `(a0,a1), (a1,a2), ...` |

```python
from itertools import count, cycle, repeat, chain, islice, zip_longest, groupby, tee, pairwise

# count + islice：无限计数器，只取前 5 个
print(list(islice(count(10, 2), 5)))          # [10, 12, 14, 16, 18]

# cycle：无限循环，配合 islice 限制数量
print(list(islice(cycle("AB"), 5)))           # ['A', 'B', 'A', 'B', 'A']

# repeat：常用于给 map 提供固定参数
print(list(map(pow, range(3), repeat(2))))    # [0, 1, 4]，即 0**2,1**2,2**2

# chain：多个来源当作一个整体遍历
print(list(chain([1, 2], (3, 4), "56")))      # [1, 2, 3, 4, '5', '6']

# zip_longest：长度不同时用 fillvalue 补齐
print(list(zip_longest([1, 2, 3], ["a", "b"], fillvalue="-")))
# [(1, 'a'), (2, 'b'), (3, '-')]

# groupby：只对相邻且相同的 key 分组，用前需要先按 key 排序
data = sorted(["apple", "avocado", "banana", "blueberry", "cherry"], key=lambda s: s[0])
for key, group in groupby(data, key=lambda s: s[0]):
    print(key, list(group))
# a ['apple', 'avocado']
# b ['banana', 'blueberry']
# c ['cherry']

# tee：从一个迭代器派生出多个独立副本，各自维护自己的进度
original = iter([1, 2, 3])
copy1, copy2 = tee(original, 2)
print(next(copy1))     # 1
print(list(copy2))     # [1, 2, 3]，copy2 不受 copy1 消费的影响

# pairwise：相邻元素配对，常用于计算差值、检测相邻关系
print(list(pairwise([1, 3, 6, 10])))   # [(1, 3), (3, 6), (6, 10)]
```

使用 `itertools` 时要注意：

- `count`、`cycle`、`repeat(elem)`（不传 `times`）都会产生**无限**迭代器，必须搭配 `islice` 或显式 `break` 使用，否则会死循环；
- `tee` 产生的多个迭代器共享底层缓冲区，若某个副本大幅落后其他副本，缓冲区会持续增长占用内存，不适合长期错峰消费；
- `groupby` 只按「相邻相同」分组，不会像 `dict` 一样自动把所有相同 key 的元素聚在一起，使用前几乎总是需要先 `sorted(..., key=...)`。

## 9. 本节小结

1. 可迭代对象实现 `__iter__`，迭代器额外实现 `__next__`；迭代器的 `__iter__` 返回自身，因此迭代器本身也是可迭代对象；
2. `for` 循环等价于先 `iter(obj)` 拿到迭代器，再反复 `next()` 直到捕获 `StopIteration`；
3. 自定义可重复遍历的对象时，应让「容器类」的 `__iter__` 每次返回一个全新的「迭代器类」实例，避免共享遍历状态；
4. 迭代器是一次性的，耗尽后无法重置，只能重新获取新的迭代器；
5. `iter(callable, sentinel)` 可以把「反复调用直到遇到哨兵值」的模式转成迭代器，常用于读取流式数据；
6. 生成器（8.2）本质上也是一种迭代器，由解释器自动实现 `__iter__`/`__next__`，写法更简洁；
7. `itertools` 提供了 `chain`、`islice`、`cycle`、`count`、`repeat`、`zip_longest`、`groupby`、`tee`、`pairwise` 等惰性组合工具，能在不占用额外内存的前提下处理甚至无限的序列，使用无限迭代器时务必搭配 `islice` 等方式限制范围。
