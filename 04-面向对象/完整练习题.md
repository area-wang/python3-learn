## 基础综合题

### 题目 1：学生成绩类

定义 `Student(name, scores)`：

- `scores` 是成绩列表，创建时复制一份，避免外部列表影响对象
- `add_score(score)` 添加成绩，成绩必须在 0 到 100
- `average` 只读属性，返回平均分；没有成绩时返回 0
- `is_passed()` 平均分大于等于 60
- `__repr__` 返回 `Student(name='Alice', average=90.0)` 风格

### 题目 2：银行账户

定义 `BankAccount(owner, balance=0)`：

- 余额不能为负
- `deposit(amount)`、`withdraw(amount)`
- `balance` 只读
- `transfer_to(other, amount)` 转账给另一个账户
- `__str__` 返回用户友好文本

### 题目 3：购物车

定义 `Product(name, price)` 和 `ShoppingCart`：

- 商品价格不能为负
- 购物车内部保存商品和数量
- `add(product, quantity=1)`
- `remove(product)`
- `total` 只读属性
- 支持 `len(cart)` 返回商品种类数
- 支持迭代购物车条目

<details>
<summary>参考答案</summary>

```python
class Student:
    def __init__(self, name, scores):
        self.name = name
        self._scores = []
        for score in scores:
            self.add_score(score)

    def add_score(self, score):
        if not 0 <= score <= 100:
            raise ValueError("成绩必须在 0 到 100 之间")
        self._scores.append(score)

    @property
    def scores(self):
        return tuple(self._scores)

    @property
    def average(self):
        return sum(self._scores) / len(self._scores) if self._scores else 0

    def is_passed(self):
        return self.average >= 60

    def __repr__(self):
        return f"Student(name={self.name!r}, average={self.average:.1f})"


class BankAccount:
    def __init__(self, owner, balance=0):
        if balance < 0:
            raise ValueError("余额不能为负")
        self.owner = owner
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("金额必须为正")
        self._balance += amount

    def withdraw(self, amount):
        if amount <= 0 or amount > self._balance:
            raise ValueError("金额非法")
        self._balance -= amount

    def transfer_to(self, other, amount):
        self.withdraw(amount)
        other.deposit(amount)

    def __str__(self):
        return f"{self.owner}: {self.balance:.2f}"


class Product:
    def __init__(self, name, price):
        if price < 0:
            raise ValueError("价格不能为负")
        self.name = name
        self.price = price

    def __repr__(self):
        return f"Product({self.name!r}, {self.price!r})"


class ShoppingCart:
    def __init__(self):
        self._items = {}

    def add(self, product, quantity=1):
        if quantity <= 0:
            raise ValueError("数量必须为正")
        self._items[product] = self._items.get(product, 0) + quantity

    def remove(self, product):
        if product not in self._items:
            raise ValueError("商品不存在")
        del self._items[product]

    @property
    def total(self):
        return sum(product.price * quantity for product, quantity in self._items.items())

    def __len__(self):
        return len(self._items)

    def __iter__(self):
        return iter(self._items.items())
```

</details>

### 题目 4：图形系统

定义抽象基类 `Shape`：

- 抽象方法 `area()`
- 抽象方法 `perimeter()`

实现：

- `Rectangle(width, height)`
- `Circle(radius)`
- `Triangle(a, b, c)`，使用海伦公式计算面积

再写函数：

- `total_area(shapes)`
- `largest_shape(shapes)`，返回面积最大的图形

### 题目 5：通知系统

定义统一接口：

- `EmailNotifier.send(to, message)`
- `SMSNotifier.send(to, message)`
- `ConsoleNotifier.send(to, message)`

写 `send_batch(notifier, users, message)`，不判断 notifier 类型。

### 题目 6：支付策略

定义：

- `Payment.pay(amount)`
- `AliPay`
- `WeChatPay`
- `BankCardPay`

写 `checkout(amount, payment)`，通过多态完成支付。

<details>
<summary>参考答案</summary>

```python
from abc import ABC, abstractmethod
import math


class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

    @abstractmethod
    def perimeter(self):
        pass


class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)


class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return math.pi * self.radius ** 2

    def perimeter(self):
        return 2 * math.pi * self.radius


class Triangle(Shape):
    def __init__(self, a, b, c):
        if a + b <= c or a + c <= b or b + c <= a:
            raise ValueError("不是合法三角形")
        self.a = a
        self.b = b
        self.c = c

    def perimeter(self):
        return self.a + self.b + self.c

    def area(self):
        s = self.perimeter() / 2
        return math.sqrt(s * (s - self.a) * (s - self.b) * (s - self.c))


def total_area(shapes):
    return sum(shape.area() for shape in shapes)


def largest_shape(shapes):
    return max(shapes, key=lambda shape: shape.area())


class EmailNotifier:
    def send(self, to, message):
        return f"Email to {to}: {message}"


class SMSNotifier:
    def send(self, to, message):
        return f"SMS to {to}: {message}"


class ConsoleNotifier:
    def send(self, to, message):
        return f"Console to {to}: {message}"


def send_batch(notifier, users, message):
    return [notifier.send(user, message) for user in users]


class Payment:
    def pay(self, amount):
        raise NotImplementedError


class AliPay(Payment):
    def pay(self, amount):
        return f"支付宝支付 {amount}"


class WeChatPay(Payment):
    def pay(self, amount):
        return f"微信支付 {amount}"


class BankCardPay(Payment):
    def pay(self, amount):
        return f"银行卡支付 {amount}"


def checkout(amount, payment):
    return payment.pay(amount)
```

</details>

## 魔法方法综合题

### 题目 7：分数类

定义 `Fraction(numerator, denominator)`：

- 分母不能为 0
- 自动约分
- `__repr__` 返回 `Fraction(1, 2)`
- `__str__` 返回 `"1/2"`
- 支持 `+`、`-`、`*`、`/`
- 支持 `==`

### 题目 8：历史记录容器

定义 `History`：

- `add(item)` 添加记录
- `len(history)`
- `history[i]`
- `item in history`
- 支持迭代
- `last` 只读属性返回最后一条，没有记录返回 `None`

<details>
<summary>参考答案</summary>

```python
import math


class Fraction:
    def __init__(self, numerator, denominator):
        if denominator == 0:
            raise ValueError("分母不能为 0")
        if denominator < 0:
            numerator = -numerator
            denominator = -denominator
        gcd = math.gcd(numerator, denominator)
        self.numerator = numerator // gcd
        self.denominator = denominator // gcd

    def __repr__(self):
        return f"Fraction({self.numerator}, {self.denominator})"

    def __str__(self):
        return f"{self.numerator}/{self.denominator}"

    def __eq__(self, other):
        if not isinstance(other, Fraction):
            return NotImplemented
        return (self.numerator, self.denominator) == (other.numerator, other.denominator)

    def __add__(self, other):
        if not isinstance(other, Fraction):
            return NotImplemented
        return Fraction(
            self.numerator * other.denominator + other.numerator * self.denominator,
            self.denominator * other.denominator,
        )

    def __sub__(self, other):
        if not isinstance(other, Fraction):
            return NotImplemented
        return Fraction(
            self.numerator * other.denominator - other.numerator * self.denominator,
            self.denominator * other.denominator,
        )

    def __mul__(self, other):
        if not isinstance(other, Fraction):
            return NotImplemented
        return Fraction(self.numerator * other.numerator, self.denominator * other.denominator)

    def __truediv__(self, other):
        if not isinstance(other, Fraction):
            return NotImplemented
        return Fraction(self.numerator * other.denominator, self.denominator * other.numerator)


class History:
    def __init__(self):
        self._items = []

    def add(self, item):
        self._items.append(item)

    @property
    def last(self):
        return self._items[-1] if self._items else None

    def __len__(self):
        return len(self._items)

    def __getitem__(self, index):
        return self._items[index]

    def __contains__(self, item):
        return item in self._items

    def __iter__(self):
        return iter(self._items)
```

</details>

## 高级特性综合题

### 题目 9：数据类订单

使用 `dataclass` 定义：

- `Product(name, price)`
- `OrderItem(product, quantity)`
- `Order(items)`，`items` 使用 `field(default_factory=list)`

要求：

- 价格不能为负
- 数量必须为正
- `Order.total` 返回总价

### 题目 10：字段描述符

实现描述符：

- `PositiveNumber`
- `NonEmptyString`

用它们定义 `Book(title, price, stock)`。

### 题目 11：插件注册

使用 `__init_subclass__` 实现导出器注册：

- `Exporter.registry`
- `CSVExporter(Exporter, name="csv")`
- `JSONExporter(Exporter, name="json")`
- `get_exporter(name)` 返回对应导出器类

<details>
<summary>参考答案</summary>

```python
from dataclasses import dataclass, field


@dataclass(frozen=True)
class Product:
    name: str
    price: float

    def __post_init__(self):
        if self.price < 0:
            raise ValueError("价格不能为负")


@dataclass
class OrderItem:
    product: Product
    quantity: int

    def __post_init__(self):
        if self.quantity <= 0:
            raise ValueError("数量必须为正")


@dataclass
class Order:
    items: list[OrderItem] = field(default_factory=list)

    @property
    def total(self):
        return sum(item.product.price * item.quantity for item in self.items)


class PositiveNumber:
    def __set_name__(self, owner, name):
        self.storage_name = "_" + name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value):
        if value <= 0:
            raise ValueError("必须为正数")
        setattr(instance, self.storage_name, value)


class NonEmptyString:
    def __set_name__(self, owner, name):
        self.storage_name = "_" + name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value):
        if not isinstance(value, str) or not value:
            raise ValueError("必须是非空字符串")
        setattr(instance, self.storage_name, value)


class Book:
    title = NonEmptyString()
    price = PositiveNumber()
    stock = PositiveNumber()

    def __init__(self, title, price, stock):
        self.title = title
        self.price = price
        self.stock = stock


class Exporter:
    registry = {}

    def __init_subclass__(cls, name=None, **kwargs):
        super().__init_subclass__(**kwargs)
        if name:
            Exporter.registry[name] = cls


class CSVExporter(Exporter, name="csv"):
    pass


class JSONExporter(Exporter, name="json"):
    pass


def get_exporter(name):
    return Exporter.registry[name]
```

</details>

## 进阶挑战

### 挑战 1：小型 ORM 模型

实现一个最小 ORM 风格系统：

- 字段描述符 `StringField`、`IntegerField`
- `Model.to_dict()`
- `Model.from_dict(data)` 类方法
- 子类 `User(Model)` 定义字段 `name`、`age`
- 字段校验失败时抛出 `ValueError`

### 挑战 2：命令行命令注册器

实现：

- `Command.registry`
- 每个子类必须定义 `name`
- 子类自动注册
- `Command.run(*args)` 为抽象接口
- `execute(name, *args)` 根据名字找到命令并执行

### 挑战 3：可扩展折扣系统

实现：

- `Discount` 抽象基类
- `NoDiscount`
- `PercentDiscount`
- `FullReductionDiscount`
- `CompositeDiscount`，可以组合多个折扣策略
- `Order.checkout(discount)` 使用多态计算最终金额

这些挑战没有唯一答案。重点是保持接口统一、状态封装、职责清晰，并尽量减少类型判断。
