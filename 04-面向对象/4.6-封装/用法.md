## 封装的概念

封装是把数据和操作数据的方法放在一起，并隐藏不希望外部依赖的实现细节。

```python
class BankAccount:
    def __init__(self, balance=0):
        if balance < 0:
            raise ValueError("余额不能为负")
        self._balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("金额必须为正")
        self._balance += amount

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("金额必须为正")
        if amount > self._balance:
            raise ValueError("余额不足")
        self._balance -= amount

    @property
    def balance(self):
        return self._balance
```

外部通过 `deposit`、`withdraw` 操作余额，而不是随意修改 `_balance`。

## 公开接口与内部实现

公开接口是类承诺给外部使用的部分；内部实现是类自己管理的细节。

```python
class UserService:
    def register(self, username, password):
        self._validate_username(username)
        hashed = self._hash_password(password)
        return {"username": username, "password": hashed}

    def _validate_username(self, username):
        if not username:
            raise ValueError("用户名不能为空")

    def _hash_password(self, password):
        return f"hashed:{password}"
```

`register` 是公开接口；`_validate_username` 和 `_hash_password` 是内部辅助方法。

## 单下划线约定

单下划线 `_name` 表示“内部使用，不建议外部直接访问”。这只是约定，不会阻止访问。

```python
class Config:
    def __init__(self):
        self._loaded = False

c = Config()
print(c._loaded)  # 可以访问，但不推荐
```

Python 社区更重视约定和可读性，而不是强制私有。

## 双下划线名称改写

双下划线 `__name` 会触发名称改写：类内部的 `__name` 会变成 `_ClassName__name`。

```python
class User:
    def __init__(self, name):
        self.__name = name

u = User("Alice")
# print(u.__name)  # AttributeError
print(u._User__name)  # Alice，不推荐这样访问
```

名称改写主要用于避免子类意外覆盖父类内部属性。

```python
class Base:
    def __init__(self):
        self.__token = "base"

class Child(Base):
    def __init__(self):
        super().__init__()
        self.__token = "child"

c = Child()
print(c.__dict__)
# {'_Base__token': 'base', '_Child__token': 'child'}
```

双下划线不是安全加密，不要把它当权限控制。

## `@property` 与受控访问

封装常用 property 控制外部读写。

```python
class Age:
    def __init__(self, value):
        self.value = value

    @property
    def value(self):
        return self._value

    @value.setter
    def value(self, value):
        if not 0 <= value <= 150:
            raise ValueError("年龄不合理")
        self._value = value
```

只读属性：

```python
class Order:
    def __init__(self, items):
        self._items = list(items)

    @property
    def total(self):
        return sum(price for _, price in self._items)
```

## 不变式

不变式是对象生命周期中始终应该成立的规则。例如账户余额不能为负、库存不能为负、日期必须合法。

```python
class Inventory:
    def __init__(self, stock):
        if stock < 0:
            raise ValueError("库存不能为负")
        self._stock = stock

    def remove(self, count):
        if count <= 0:
            raise ValueError("数量必须为正")
        if count > self._stock:
            raise ValueError("库存不足")
        self._stock -= count

    @property
    def stock(self):
        return self._stock
```

封装的价值之一，就是所有状态修改都经过校验入口，保证不变式不被破坏。

## 封装集合与可变对象

如果直接返回内部列表，外部可以绕过类的方法修改内部状态。

```python
class Team:
    def __init__(self):
        self._members = []

    @property
    def members(self):
        return self._members  # 风险：外部可以 append
```

更稳妥的写法是返回副本或只读视图。

```python
class Team:
    def __init__(self):
        self._members = []

    def add_member(self, name):
        if not name:
            raise ValueError("成员名不能为空")
        self._members.append(name)

    @property
    def members(self):
        return tuple(self._members)

t = Team()
t.add_member("Alice")
print(t.members)
```

## 常见错误与最佳实践

### 1. 所有属性都写 getter/setter

Python 不需要像 Java 那样机械写 getter/setter。普通公开属性可以直接访问，需要校验时再引入 property。

### 2. 把双下划线当安全机制

`__name` 只是改名，仍可通过 `_ClassName__name` 访问。

### 3. 公开内部可变对象

返回内部列表、字典时要谨慎，必要时返回副本。

### 4. 方法绕过校验直接改状态

类内部也应尽量通过统一入口维护不变式。

### 5. 公开接口频繁变化

外部依赖公开接口。内部实现可以重构，公开接口要保持稳定。

---

## 小结

- 封装是隐藏实现细节，暴露稳定接口。
- 单下划线表示内部约定，双下划线触发名称改写。
- property 可用于受控读写和校验。
- 封装要保护对象不变式。
- 对内部可变集合要谨慎暴露。
