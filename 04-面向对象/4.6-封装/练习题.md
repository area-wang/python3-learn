## 公开接口

### 练习题

**题目 1：账户封装**

定义 `BankAccount`，外部只能通过 `deposit`、`withdraw` 修改余额，通过只读属性 `balance` 查看余额。

**题目 2：注册服务**

定义 `UserService.register(username, password)`，内部用 `_validate_username` 和 `_hash_password` 辅助。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class BankAccount:
    def __init__(self, balance=0):
        if balance < 0:
            raise ValueError("余额不能为负")
        self._balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("金额必须为正")
        self._balance += amount

    def withdraw(self, amount):
        if amount <= 0 or amount > self._balance:
            raise ValueError("金额非法")
        self._balance -= amount

    @property
    def balance(self):
        return self._balance

class UserService:
    def register(self, username, password):
        self._validate_username(username)
        return {"username": username, "password": self._hash_password(password)}

    def _validate_username(self, username):
        if not username:
            raise ValueError("用户名不能为空")

    def _hash_password(self, password):
        return f"hashed:{password}"
```

## 下划线约定

### 练习题

**题目 1：单下划线**

定义类 `Config`，内部属性 `_loaded`，说明为什么外部不应依赖它。

**题目 2：双下划线**

定义 `User.__token`，打印对象的 `__dict__`，观察实际属性名。

**题目 3：名称改写**

父类和子类都定义 `self.__value`，观察 `__dict__` 中有几个字段。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Config:
    def __init__(self):
        self._loaded = False

# _loaded 只是内部约定，类作者可能随时改名或改变含义。

class User:
    def __init__(self, token):
        self.__token = token

u = User("abc")
print(u.__dict__)  # {'_User__token': 'abc'}

class Base:
    def __init__(self):
        self.__value = "base"

class Child(Base):
    def __init__(self):
        super().__init__()
        self.__value = "child"

c = Child()
print(c.__dict__)  # {'_Base__value': 'base', '_Child__value': 'child'}
```

## 受控属性

### 练习题

**题目 1：年龄校验**

定义 `Person.age`，年龄必须在 0 到 150 之间。

**题目 2：库存校验**

定义 `Product.stock`，库存不能为负。

**题目 3：只读总价**

定义 `Order`，保存商品列表，提供只读属性 `total`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Person:
    def __init__(self, age):
        self.age = age

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if not 0 <= value <= 150:
            raise ValueError("年龄不合理")
        self._age = value

class Product:
    def __init__(self, stock):
        self.stock = stock

    @property
    def stock(self):
        return self._stock

    @stock.setter
    def stock(self, value):
        if value < 0:
            raise ValueError("库存不能为负")
        self._stock = value

class Order:
    def __init__(self):
        self._items = []

    def add_item(self, name, price):
        self._items.append((name, price))

    @property
    def total(self):
        return sum(price for _, price in self._items)
```

## 保护不变式

### 练习题

**题目 1：库存移除**

定义 `Inventory.remove(count)`，不能让库存变成负数。

**题目 2：不可直接修改成员列表**

定义 `Team`，内部用 `_members` 保存列表，`members` 返回元组，添加成员必须走 `add_member`。

**题目 3：陷阱分析**

下面写法有什么风险？

```python
class Team:
    def __init__(self):
        self._members = []

    @property
    def members(self):
        return self._members
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Inventory:
    def __init__(self, stock):
        if stock < 0:
            raise ValueError("库存不能为负")
        self._stock = stock

    def remove(self, count):
        if count <= 0 or count > self._stock:
            raise ValueError("数量非法")
        self._stock -= count

    @property
    def stock(self):
        return self._stock

class Team:
    def __init__(self):
        self._members = []

    def add_member(self, name):
        if not name:
            raise ValueError("成员名不能为空")
        self._members.append(name)

    @property
    def members(self):
        return tuple(self._members)

# 题目 3
# members 返回内部列表，外部可以 team.members.append("")，
# 绕过 add_member 的校验逻辑，破坏封装。
```

## 综合练习

### 综合题：课程报名系统

定义 `Course(name, capacity)`：

- `capacity` 必须大于 0
- 内部 `_students` 保存报名学生
- `enroll(student)` 报名，满员时抛异常，重复报名时抛异常
- `drop(student)` 退课，不存在时抛异常
- `students` 返回元组，不暴露内部列表
- `available_slots` 只读属性返回剩余名额

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Course:
    def __init__(self, name, capacity):
        if capacity <= 0:
            raise ValueError("容量必须为正")
        self.name = name
        self._capacity = capacity
        self._students = []

    def enroll(self, student):
        if student in self._students:
            raise ValueError("不能重复报名")
        if len(self._students) >= self._capacity:
            raise ValueError("课程已满")
        self._students.append(student)

    def drop(self, student):
        if student not in self._students:
            raise ValueError("学生未报名")
        self._students.remove(student)

    @property
    def students(self):
        return tuple(self._students)

    @property
    def available_slots(self):
        return self._capacity - len(self._students)

course = Course("Python", 2)
course.enroll("Alice")
print(course.students)
print(course.available_slots)
```

</details>
