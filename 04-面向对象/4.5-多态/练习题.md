## 基础多态

### 练习题

**题目 1：动物叫声**

定义 `Dog.speak()`、`Cat.speak()`、`Cow.speak()`，再写函数 `make_sound(animal)` 调用 `animal.speak()`。

**题目 2：形状面积**

定义 `Rectangle.area()` 和 `Circle.area()`，写 `total_area(shapes)` 计算总面积。

**题目 3：统一发送接口**

定义 `EmailSender.send(to, content)` 和 `SMSSender.send(to, content)`，写 `notify(sender, user, message)`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Dog:
    def speak(self):
        return "汪"

class Cat:
    def speak(self):
        return "喵"

class Cow:
    def speak(self):
        return "哞"

def make_sound(animal):
    return animal.speak()

print(make_sound(Dog()))
print(make_sound(Cat()))

class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

class Circle:
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14159 * self.radius ** 2

def total_area(shapes):
    return sum(shape.area() for shape in shapes)

print(total_area([Rectangle(3, 4), Circle(2)]))

class EmailSender:
    def send(self, to, content):
        return f"Email to {to}: {content}"

class SMSSender:
    def send(self, to, content):
        return f"SMS to {to}: {content}"

def notify(sender, user, message):
    return sender.send(user, message)

print(notify(EmailSender(), "Alice", "hello"))
```

## 鸭子类型

### 练习题

**题目 1：可写对象**

定义 `ConsoleWriter.write(text)` 和 `ListWriter.write(text)`，写函数 `write_all(writer, lines)`，逐行写入。

**题目 2：可迭代对象**

写函数 `sum_even(items)`，只要求 `items` 可迭代，返回其中偶数和。用列表、元组、生成器测试。

**题目 3：文件风格对象**

写函数 `copy_text(reader, writer)`，要求 `reader` 有 `read()`，`writer` 有 `write(text)`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class ConsoleWriter:
    def write(self, text):
        print(text)

class ListWriter:
    def __init__(self):
        self.lines = []

    def write(self, text):
        self.lines.append(text)

def write_all(writer, lines):
    for line in lines:
        writer.write(line)

lw = ListWriter()
write_all(lw, ["a", "b"])
print(lw.lines)

def sum_even(items):
    return sum(x for x in items if x % 2 == 0)

print(sum_even([1, 2, 3, 4]))
print(sum_even((2, 4, 5)))
print(sum_even(x for x in range(6)))

class Reader:
    def read(self):
        return "hello"

class Writer:
    def __init__(self):
        self.text = ""

    def write(self, text):
        self.text += text

def copy_text(reader, writer):
    writer.write(reader.read())

w = Writer()
copy_text(Reader(), w)
print(w.text)
```

## 抽象基类

### 练习题

**题目 1：支付抽象类**

用 `ABC` 定义 `Payment.pay(amount)`，实现 `AliPay` 和 `BankCardPay`。

**题目 2：存储抽象类**

定义 `Storage.save(key, value)` 和 `Storage.load(key)` 两个抽象方法，实现 `MemoryStorage`。

**题目 3：抽象类实例化**

尝试实例化未实现抽象方法的子类，说明会发生什么。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
from abc import ABC, abstractmethod

class Payment(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

class AliPay(Payment):
    def pay(self, amount):
        return f"支付宝支付 {amount}"

class BankCardPay(Payment):
    def pay(self, amount):
        return f"银行卡支付 {amount}"

print(AliPay().pay(100))

class Storage(ABC):
    @abstractmethod
    def save(self, key, value):
        pass

    @abstractmethod
    def load(self, key):
        pass

class MemoryStorage(Storage):
    def __init__(self):
        self.data = {}

    def save(self, key, value):
        self.data[key] = value

    def load(self, key):
        return self.data.get(key)

s = MemoryStorage()
s.save("name", "Alice")
print(s.load("name"))

# 未实现抽象方法的子类不能实例化，会抛 TypeError。
```

## 类型判断重构

### 练习题

**题目 1：重构面积函数**

```python
def area(shape):
    if shape["type"] == "rect":
        return shape["width"] * shape["height"]
    if shape["type"] == "circle":
        return 3.14159 * shape["radius"] ** 2
```

**题目 2：折扣策略**

定义 `NoDiscount`、`RateDiscount`、`FullReduction`，都实现 `apply(amount)`，写 `checkout(amount, discount)`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

class Circle:
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14159 * self.radius ** 2

def area(shape):
    return shape.area()

class NoDiscount:
    def apply(self, amount):
        return amount

class RateDiscount:
    def __init__(self, rate):
        self.rate = rate

    def apply(self, amount):
        return amount * (1 - self.rate)

class FullReduction:
    def __init__(self, threshold, reduction):
        self.threshold = threshold
        self.reduction = reduction

    def apply(self, amount):
        return amount - self.reduction if amount >= self.threshold else amount

def checkout(amount, discount):
    return discount.apply(amount)

print(checkout(200, NoDiscount()))
print(checkout(200, RateDiscount(0.1)))
print(checkout(200, FullReduction(100, 20)))
```

## 综合练习

### 综合题：导出器系统

实现一个数据导出系统：

- `CSVExporter.export(rows)` 输出 CSV 风格字符串
- `JSONExporter.export(rows)` 输出 JSON 字符串
- `TextExporter.export(rows)` 输出简单文本
- `export_data(exporter, rows)` 不判断类型，只调用 `exporter.export(rows)`

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
import json

class CSVExporter:
    def export(self, rows):
        if not rows:
            return ""
        headers = rows[0].keys()
        lines = [",".join(headers)]
        for row in rows:
            lines.append(",".join(str(row[h]) for h in headers))
        return "\n".join(lines)

class JSONExporter:
    def export(self, rows):
        return json.dumps(rows, ensure_ascii=False)

class TextExporter:
    def export(self, rows):
        return "\n".join(str(row) for row in rows)

def export_data(exporter, rows):
    return exporter.export(rows)

rows = [{"name": "Alice", "age": 20}, {"name": "Bob", "age": 22}]
print(export_data(CSVExporter(), rows))
print(export_data(JSONExporter(), rows))
print(export_data(TextExporter(), rows))
```

</details>
