# 04-面向对象

面向对象编程（Object-Oriented Programming，OOP）是 Python 组织复杂程序的重要方式。它把数据和行为封装到对象中，用类描述对象的结构，用继承和多态复用与扩展能力。

## 学习建议

1. 先掌握“类是模板，对象是实例”这个基本模型。
2. 写类时优先关注对象应该承担的职责，而不是机械地把函数放进类里。
3. 属性负责保存状态，方法负责表达行为；状态越少，类越容易测试。
4. 继承要谨慎使用：能组合就不要强行继承。
5. 魔法方法和元类很强大，但应服务于可读性，不要为了炫技而使用。
