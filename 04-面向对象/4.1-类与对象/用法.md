## 类与对象的基本概念

**类（class）** 是对象的模板，用来描述一类事物有哪些数据和行为。

**对象（object / instance）** 是类创建出来的具体实例，每个对象可以有自己的状态。

```python
class Student:
    pass

stu1 = Student()
stu2 = Student()

print(type(stu1))       # <class '__main__.Student'>
print(stu1 is stu2)     # False，不同对象
```

可以把类理解为“设计图”，对象理解为“按设计图造出来的实体”。类本身也是对象，只不过它的类型通常是 `type`。

```python
print(type(Student))    # <class 'type'>
```

## 定义类 class

### 1. 基本语法

```python
class 类名:
    类体
```

类名推荐使用 **大驼峰命名法（PascalCase）**。

```python
class User:
    pass

class BankAccount:
    pass
```

类体不能为空。如果暂时没有内容，可以使用 `pass` 或 `...` 占位。

```python
class Todo:
    pass

class Stub:
    ...
```

### 2. 类的文档字符串

类的第一条语句如果是字符串，它就是类的 docstring。

```python
class Product:
    """商品对象，保存商品名称和价格。"""

print(Product.__doc__)  # 商品对象，保存商品名称和价格。
help(Product)
```

### 3. 类体执行时机

类体在执行到 `class` 语句时立即执行，执行完成后生成类对象，并把类名绑定到该类对象。

```python
class Demo:
    print("class body running")
    x = 10

print(Demo.x)
```

输出：

```text
class body running
10
```

## 创建对象

调用类名就会创建对象：

```python
class Dog:
    pass

dog = Dog()
print(dog)
```

对象默认可以动态添加属性：

```python
dog.name = "旺财"
dog.age = 3

print(dog.name)
print(dog.age)
print(dog.__dict__)   # {'name': '旺财', 'age': 3}
```

不推荐在外部随意给对象加属性，因为对象结构会变得不稳定。更常见的做法是在 `__init__` 中统一初始化。

## self 的含义

`self` 表示“当前对象本身”。实例方法被对象调用时，Python 会自动把调用者作为第一个参数传进去。

```python
class Person:
    def say_hello(self):
        print("hello")

p = Person()
p.say_hello()          # 自动传入 p
Person.say_hello(p)    # 与上一行等价
```

`self` 不是关键字，但强烈建议按约定使用 `self`，不要改成 `this`、`me` 等名字。

```python
class Counter:
    def increment(self):
        self.count += 1
```

`self.xxx` 通常表示对象自己的属性；不写 `self`，只是方法内部的局部变量。

```python
class User:
    def set_name(self, name):
        self.name = name    # 对象属性
        label = name        # 局部变量，方法结束后消失
```

## `__init__` 初始化方法

`__init__` 在对象创建完成后自动调用，用于初始化对象状态。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

stu = Student("Alice", 95)
print(stu.name, stu.score)
```

### 1. `__init__` 不是构造器本身

严格来说，`__new__` 负责创建对象，`__init__` 负责初始化对象。初学阶段大多数场景只需要掌握 `__init__`。

```python
class Example:
    def __new__(cls, *args, **kwargs):
        print("__new__ create object")
        return super().__new__(cls)

    def __init__(self):
        print("__init__ initialize object")

Example()
```

### 2. `__init__` 必须返回 None

```python
class Bad:
    def __init__(self):
        # return 123  # TypeError: __init__() should return None
        pass
```

### 3. 默认参数

```python
class Book:
    def __init__(self, title, author="未知"):
        self.title = title
        self.author = author

book = Book("Python 入门")
print(book.title, book.author)
```

### 4. 参数校验

```python
class Rectangle:
    def __init__(self, width, height):
        if width <= 0 or height <= 0:
            raise ValueError("宽和高必须为正数")
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height
```

## 对象的状态与行为

属性表示对象的**状态**，方法表示对象的**行为**。

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款金额必须为正数")
        self.balance += amount

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("取款金额必须为正数")
        if amount > self.balance:
            raise ValueError("余额不足")
        self.balance -= amount

account = BankAccount("Alice", 100)
account.deposit(50)
account.withdraw(30)
print(account.balance)  # 120
```

一个好类通常具有清晰的职责：`BankAccount` 管理账户余额，不负责打印菜单、读取输入或保存文件。

## 对象身份、类型和值

Python 中每个对象都有：

- 身份：`id(obj)`，对象的唯一标识
- 类型：`type(obj)`，对象所属的类
- 值：对象保存的数据状态

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p1 = Point(1, 2)
p2 = Point(1, 2)

print(id(p1), id(p2))
print(type(p1))
print(p1 == p2)   # 默认比较身份，False
print(p1 is p2)   # False
```

如果希望对象按值比较，需要在后续章节学习 `__eq__` 或使用 `dataclass`。

## 对象生命周期

对象生命周期大致分为：

1. 创建对象：调用类名，底层先执行 `__new__`
2. 初始化对象：执行 `__init__`
3. 使用对象：访问属性、调用方法
4. 销毁对象：引用计数归零后被垃圾回收

```python
class Trace:
    def __init__(self, name):
        self.name = name
        print(self.name, "created")

    def __del__(self):
        print(self.name, "deleted")

t = Trace("A")
del t
```

`__del__` 的执行时机不要用于核心业务逻辑，因为不同 Python 实现和循环引用场景下可能不稳定。需要释放文件、网络连接等资源时，优先使用上下文管理器。

## 类命名与文件组织

### 命名建议

| 对象 | 推荐风格 | 示例 |
|---|---|---|
| 类名 | PascalCase | `UserProfile` |
| 方法名 | snake_case | `get_total_price` |
| 属性名 | snake_case | `created_at` |
| 常量 | UPPER_CASE | `MAX_RETRY` |

### 文件组织建议

简单学习脚本可以一个文件放多个类；真实项目中按职责拆分。

```text
shop/
  models.py      # Product、Order
  services.py    # OrderService
  storage.py     # 数据保存
```

## 常见错误与最佳实践

### 1. 忘记 self

```python
class User:
    # def set_name(name):     # 错误：少了 self
    #     self.name = name
    def set_name(self, name):
        self.name = name
```

### 2. 把局部变量误当属性

```python
class User:
    def __init__(self, name):
        name = name       # 无意义，只是局部变量

u = User("Alice")
# print(u.name)          # AttributeError
```

正确写法：

```python
class User:
    def __init__(self, name):
        self.name = name
```

### 3. 在类里放无关职责

不要让一个类同时负责输入、计算、展示、持久化。类越“全能”，越难维护。

### 4. 优先让对象始终处于有效状态

对象创建后应尽量是可用的，不要创建半成品对象。

```python
class Email:
    def __init__(self, address):
        if "@" not in address:
            raise ValueError("邮箱格式错误")
        self.address = address
```

### 5. 不要滥用类

只有数据和行为确实需要绑定时才写类。简单的纯计算逻辑，用函数更清楚。

## 小结

- 类是模板，对象是实例。
- 调用类名会创建对象。
- `self` 表示当前对象。
- `__init__` 用于初始化对象属性，不能返回非 `None`。
- 属性保存状态，方法表达行为。
- 写类时应关注职责清晰、对象状态有效、接口稳定。
