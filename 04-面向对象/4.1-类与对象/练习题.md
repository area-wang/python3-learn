## 类定义与对象创建

### 练习题

**题目 1：最小类**

定义一个空类 `Person`，创建两个对象 `p1`、`p2`，打印：

1. `type(p1)`
2. `p1 is p2`
3. `type(Person)`

**题目 2：动态属性**

定义类 `Dog`，创建对象后给它添加 `name`、`age` 两个属性，并打印 `dog.__dict__`。

**题目 3：类文档**

定义类 `Product`，写 docstring `"商品类"`，打印 `Product.__doc__`。

```python
# 题目 1
class Person:
```

### 参考答案

```python
# 题目 1
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_passed(self):
        return self.score >= 60

    def show(self):
        print(f"{self.name}: {self.score}")

s = Student("Alice", 88)
print(s.is_passed())  # True
s.show()

# 题目 2
class Rectangle:
    def __init__(self, width, height):
        if width <= 0 or height <= 0:
            raise ValueError("宽高必须为正数")
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

r = Rectangle(3, 4)
print(r.area())       # 12
print(r.perimeter())  # 14

# 题目 3
class Book:
    def __init__(self, title, author="未知", price=0):

        self.author = author
        self.price = price

print(Book("Python").__dict__)
print(Book("Python", "Guido").__dict__)
print(Book("Python", "Guido", 99).__dict__)

# 题目 4
# __init__ 只能返回 None。对象创建由 __new__ 完成，__init__ 只负责初始化。
# 返回 123 会触发 TypeError。
```

## 对象状态与行为

### 练习题

**题目 1：银行账户**

定义 `BankAccount(owner, balance=0)`：

- `deposit(amount)` 存款，金额必须大于 0
- `withdraw(amount)` 取款，金额必须大于 0 且不能超过余额
- `get_balance()` 返回余额

**题目 2：购物车**

定义 `ShoppingCart`：

- 初始化一个空列表 `items`
- `add_item(name, price, quantity=1)` 添加商品
- `total()` 计算总价
- `clear()` 清空购物车

**题目 3：对象身份**

创建两个内容相同的 `Point(1, 2)`，比较 `p1 is p2` 和 `p1 == p2`，解释结果。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款金额必须大于 0")
        self.balance += amount

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("取款金额必须大于 0")
        if amount > self.balance:
            raise ValueError("余额不足")
        self.balance -= amount

    def get_balance(self):
        return self.balance

account = BankAccount("Alice", 100)
account.deposit(50)
account.withdraw(20)
print(account.get_balance())  # 130

# 题目 2
class ShoppingCart:
    def __init__(self):
        self.items = []

    def add_item(self, name, price, quantity=1):
        if price < 0 or quantity <= 0:
            raise ValueError("价格不能为负，数量必须为正")
        self.items.append({"name": name, "price": price, "quantity": quantity})

    def total(self):
        return sum(item["price"] * item["quantity"] for item in self.items)

    def clear(self):
        self.items.clear()

cart = ShoppingCart()
cart.add_item("书", 50, 2)
cart.add_item("笔", 3, 5)
print(cart.total())  # 115
cart.clear()
print(cart.total())  # 0

# 题目 3
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p1 = Point(1, 2)
p2 = Point(1, 2)
print(p1 is p2)  # False，不同对象
print(p1 == p2)  # False，默认比较身份，不按属性值比较
```

## 陷阱题

**题目 1：忘记 self**

```python
class A:
    def hello():
        print("hi")

A().hello()
```

输出什么？为什么？

**题目 2：共享可变默认参数**

下面代码有什么问题？

```python
class Team:
    def __init__(self, members=[]):
        self.members = members

t1 = Team()
t2 = Team()
t1.members.append("Alice")
print(t2.members)
```

**题目 3：类体执行**

下面代码输出什么？

```python
class Demo:
    print("A")
    x = 1

print("B")
print(Demo.x)
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
# TypeError: A.hello() takes 0 positional arguments but 1 was given
# 通过对象调用实例方法时，Python 会自动传入当前对象作为第一个参数。
# 修复：
class A:
    def hello(self):
        print("hi")

A().hello()

# 题目 2
# 输出 ['Alice']。members=[] 在函数定义时只创建一次，
# 两个 Team() 共用同一个默认列表。
class Team:
    def __init__(self, members=None):
        self.members = [] if members is None else list(members)

t1 = Team()
t2 = Team()
t1.members.append("Alice")
print(t2.members)  # []

# 题目 3
# 输出：
# A
# B
# 1
# class 语句执行时会立即执行类体，生成类对象后才继续执行后续代码。
```

</details>

## 综合练习

### 综合题 1：图书管理对象

定义 `Book` 类，包含 `title`、`author`、`price`、`stock`。要求：

- 创建时校验 `price >= 0`、`stock >= 0`
- `sell(count)` 表示卖出 count 本，库存不足抛出异常
- `restock(count)` 增加库存
- `value()` 返回当前库存总价值

### 综合题 2：待办事项

定义 `TodoItem(title)`：

- 初始 `done = False`
- `mark_done()` 标记完成
- `mark_undone()` 标记未完成
- `rename(title)` 修改标题，空标题抛出异常
- `status()` 返回 `"已完成"` 或 `"未完成"`

### 综合题 3：温度对象

定义 `Temperature(celsius)`：

- 摄氏度不能低于 -273.15
- `to_fahrenheit()` 返回华氏度
- `to_kelvin()` 返回开尔文
- `is_freezing()` 判断是否低于等于 0 摄氏度

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Book:
    def __init__(self, title, author, price, stock):
        if price < 0:
            raise ValueError("价格不能为负")
        if stock < 0:
            raise ValueError("库存不能为负")
        self.title = title
        self.author = author
        self.price = price
        self.stock = stock

    def sell(self, count):
        if count <= 0:
            raise ValueError("销售数量必须为正")
        if count > self.stock:
            raise ValueError("库存不足")
        self.stock -= count

    def restock(self, count):
        if count <= 0:
            raise ValueError("入库数量必须为正")
        self.stock += count

    def value(self):
        return self.price * self.stock


class TodoItem:
    def __init__(self, title):
        if not title:
            raise ValueError("标题不能为空")
        self.title = title
        self.done = False

    def mark_done(self):
        self.done = True

    def mark_undone(self):
        self.done = False

    def rename(self, title):
        if not title:
            raise ValueError("标题不能为空")
        self.title = title

    def status(self):
        return "已完成" if self.done else "未完成"


class Temperature:
    def __init__(self, celsius):
        if celsius < -273.15:
            raise ValueError("温度不能低于绝对零度")
        self.celsius = celsius

    def to_fahrenheit(self):
        return self.celsius * 9 / 5 + 32

    def to_kelvin(self):
        return self.celsius + 273.15

    def is_freezing(self):
        return self.celsius <= 0

book = Book("Python", "Alice", 80, 10)
book.sell(2)
print(book.stock, book.value())  # 8 640

todo = TodoItem("学习 OOP")
todo.mark_done()
print(todo.status())             # 已完成

temp = Temperature(0)
print(temp.to_fahrenheit())      # 32.0
print(temp.to_kelvin())          # 273.15
print(temp.is_freezing())        # True
```

</details>
