## `dataclass`

### 练习题

**题目 1：坐标点**

用 `@dataclass` 定义 `Point(x, y)`，验证自动生成的 `__repr__` 和 `__eq__`。

**题目 2：团队成员**

定义 `Team(name, members)`，`members` 使用 `field(default_factory=list)`。

**题目 3：不可变金额**

定义 `Money(amount, currency="CNY")`，使用 `frozen=True`。

**题目 4：排序学生**

定义可排序的 `Student(score, name)`，按 `score` 排序。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
from dataclasses import dataclass, field

@dataclass
class Point:
    x: int
    y: int

print(Point(1, 2))
print(Point(1, 2) == Point(1, 2))

@dataclass
class Team:
    name: str
    members: list[str] = field(default_factory=list)

t1 = Team("A")
t2 = Team("B")
t1.members.append("Alice")
print(t1.members)
print(t2.members)

@dataclass(frozen=True)
class Money:
    amount: float
    currency: str = "CNY"

print(Money(10))

@dataclass(order=True)
class Student:
    score: int
    name: str

print(sorted([Student(90, "A"), Student(80, "B")]))
```

## `__slots__`

### 练习题

**题目 1：限制属性**

定义 `Point`，`__slots__ = ("x", "y")`，尝试给 `z` 赋值，说明结果。

**题目 2：检查 `__dict__`**

比较普通类实例和 slots 类实例是否有 `__dict__`。

**题目 3：适用场景**

列举两个适合使用 `__slots__` 的场景和两个不适合的场景。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
# p.z = 3  # AttributeError: 'Point' object has no attribute 'z'
print(hasattr(p, "__dict__"))  # False

class Normal:
    pass

n = Normal()
print(hasattr(n, "__dict__"))  # True

# 适合：大量小对象；属性固定的数据结构。
# 不适合：需要动态添加属性；依赖 __dict__ 的调试或序列化工具。
```

## 描述符

### 练习题

**题目 1：正数描述符**

实现 `Positive`，用于校验 `Product.price` 和 `Product.stock` 都必须大于 0。

**题目 2：字符串非空描述符**

实现 `NonEmptyString`，用于校验 `User.name` 不能为空字符串。

**题目 3：解释 `__set_name__`**

说明 `__set_name__(self, owner, name)` 中 `owner` 和 `name` 分别是什么。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Positive:
    def __set_name__(self, owner, name):
        self.storage_name = "_" + name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value):
        if value <= 0:
            raise ValueError("必须大于 0")
        setattr(instance, self.storage_name, value)

class Product:
    price = Positive()
    stock = Positive()

    def __init__(self, price, stock):
        self.price = price
        self.stock = stock

class NonEmptyString:
    def __set_name__(self, owner, name):
        self.storage_name = "_" + name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value):
        if not isinstance(value, str) or not value:
            raise ValueError("必须是非空字符串")
        setattr(instance, self.storage_name, value)

class User:
    name = NonEmptyString()

    def __init__(self, name):
        self.name = name

# __set_name__ 在类创建时调用。
# owner 是拥有该描述符的类，例如 Product。
# name 是描述符绑定到类上的属性名，例如 "price"。
```

## 类装饰器与子类注册

### 练习题

**题目 1：自动 repr**

写类装饰器 `add_repr`，为类添加基于 `__dict__` 的 `__repr__`。

**题目 2：插件注册**

用 `__init_subclass__` 实现插件自动注册：`class CsvPlugin(Plugin, name="csv")`。

**题目 3：子类检查**

定义父类 `Command`，要求所有子类必须定义类属性 `name`，否则抛异常。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
def add_repr(cls):
    def __repr__(self):
        attrs = ", ".join(f"{k}={v!r}" for k, v in self.__dict__.items())
        return f"{cls.__name__}({attrs})"
    cls.__repr__ = __repr__
    return cls

@add_repr
class User:
    def __init__(self, name):
        self.name = name

print(User("Alice"))

class Plugin:
    registry = {}

    def __init_subclass__(cls, name=None, **kwargs):
        super().__init_subclass__(**kwargs)
        if name:
            Plugin.registry[name] = cls

class CsvPlugin(Plugin, name="csv"):
    pass

print(Plugin.registry)

class Command:
    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        if not hasattr(cls, "name"):
            raise TypeError("Command 子类必须定义 name")

class HelloCommand(Command):
    name = "hello"
```

## 元类与动态类

### 练习题

**题目 1：动态创建类**

使用 `type` 创建 `User` 类，类属性 `role = "guest"`，实例属性 `name`。

**题目 2：元类修改属性名**

定义元类，把非魔法类属性名改成大写。

**题目 3：何时不用元类**

说明为什么普通业务代码通常不优先选择元类。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
User = type(
    "User",
    (),
    {
        "role": "guest",
        "__init__": lambda self, name: setattr(self, "name", name),
    },
)

u = User("Alice")
print(u.name, u.role)

class UpperAttrMeta(type):
    def __new__(mcls, name, bases, namespace):
        new_namespace = {}
        for key, value in namespace.items():
            if key.startswith("__"):
                new_namespace[key] = value
            else:
                new_namespace[key.upper()] = value
        return super().__new__(mcls, name, bases, new_namespace)

class Demo(metaclass=UpperAttrMeta):
    value = 10

print(Demo.VALUE)

# 元类改变类创建机制，理解和调试成本高。
# 多数需求可用普通类、dataclass、描述符、类装饰器或 __init_subclass__ 解决。
```

## 综合练习

### 综合题：轻量模型系统

实现一个简化模型系统：

- 描述符 `Positive` 校验正数
- 描述符 `NonEmptyString` 校验非空字符串
- `Model` 父类提供 `to_dict()`
- 使用 `__init_subclass__` 自动把子类按类名注册到 `Model.registry`
- 定义 `Product(Model)`，字段 `name`、`price`、`stock`
- `Product` 使用 `@dataclass` 或普通类均可

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Positive:
    def __set_name__(self, owner, name):
        self.storage_name = "_" + name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value):
        if value <= 0:
            raise ValueError("必须大于 0")
        setattr(instance, self.storage_name, value)


class NonEmptyString:
    def __set_name__(self, owner, name):
        self.storage_name = "_" + name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value):
        if not isinstance(value, str) or not value:
            raise ValueError("必须是非空字符串")
        setattr(instance, self.storage_name, value)


class Model:
    registry = {}

    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        Model.registry[cls.__name__] = cls

    def to_dict(self):
        return {
            key.lstrip("_"): value
            for key, value in self.__dict__.items()
        }


class Product(Model):
    name = NonEmptyString()
    price = Positive()
    stock = Positive()

    def __init__(self, name, price, stock):
        self.name = name
        self.price = price
        self.stock = stock


p = Product("Book", 50, 10)
print(p.to_dict())
print(Model.registry)
```

</details>
