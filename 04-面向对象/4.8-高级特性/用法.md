## `dataclass`

`dataclass` 可以自动生成 `__init__`、`__repr__`、`__eq__` 等方法，适合以数据为主的类。

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(1, 2)
print(p)              # Point(x=1, y=2)
print(p == Point(1, 2))  # True
```

### 默认值

```python
@dataclass
class User:
    name: str
    age: int = 0
```

有默认值的字段必须放在无默认值字段之后。

### 可变默认值

可变默认值要用 `field(default_factory=...)`。

```python
from dataclasses import field

@dataclass
class Team:
    name: str
    members: list[str] = field(default_factory=list)
```

### 冻结对象

```python
@dataclass(frozen=True)
class Money:
    amount: float
    currency: str = "CNY"

m = Money(10)
# m.amount = 20  # FrozenInstanceError
```

### 排序

```python
@dataclass(order=True)
class Student:
    score: int
    name: str

print(sorted([Student(90, "A"), Student(80, "B")]))
```

## `__slots__`

`__slots__` 可以限制实例允许的属性，并减少每个实例的内存开销。

```python
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
# p.z = 3  # AttributeError
```

使用 `__slots__` 后，普通实例默认没有 `__dict__`。

```python
print(hasattr(p, "__dict__"))  # False
```

适合大量小对象、属性固定的场景。不适合需要动态属性的对象。

## 描述符 descriptor

描述符是实现了 `__get__`、`__set__`、`__delete__` 中任意方法的对象。`property` 本身就是描述符。

```python
class Positive:
    def __set_name__(self, owner, name):
        self.name = "_" + name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return getattr(instance, self.name)

    def __set__(self, instance, value):
        if value <= 0:
            raise ValueError("必须为正数")
        setattr(instance, self.name, value)

class Product:
    price = Positive()
    stock = Positive()

    def __init__(self, price, stock):
        self.price = price
        self.stock = stock

p = Product(10, 3)
print(p.price)
```

描述符适合复用属性校验逻辑。例如多个字段都要求正数时，比每个字段写一套 property 更简洁。

## 类装饰器

类装饰器接收类对象，返回类对象或替代对象。

```python
def add_repr(cls):
    def __repr__(self):
        attrs = ", ".join(f"{k}={v!r}" for k, v in self.__dict__.items())
        return f"{cls.__name__}({attrs})"
    cls.__repr__ = __repr__
    return cls

@add_repr
class User:
    def __init__(self, name):
        self.name = name

print(User("Alice"))
```

类装饰器适合批量增强类，例如注册插件、补充方法、添加校验。

## `__init_subclass__`

当一个类被继承时，父类的 `__init_subclass__` 会自动执行。

```python
class Plugin:
    registry = {}

    def __init_subclass__(cls, name=None, **kwargs):
        super().__init_subclass__(**kwargs)
        if name:
            Plugin.registry[name] = cls

class CsvPlugin(Plugin, name="csv"):
    pass

print(Plugin.registry)
```

它常用于自动注册子类、检查子类是否定义某些属性。

## 元类 metaclass

元类是“创建类的类”。普通类默认由 `type` 创建。

```python
class User:
    pass

print(type(User))  # <class 'type'>
```

自定义元类可以控制类创建过程。

```python
class UpperAttrMeta(type):
    def __new__(mcls, name, bases, namespace):
        new_namespace = {}
        for key, value in namespace.items():
            if key.startswith("__"):
                new_namespace[key] = value
            else:
                new_namespace[key.upper()] = value
        return super().__new__(mcls, name, bases, new_namespace)

class Demo(metaclass=UpperAttrMeta):
    value = 10

print(Demo.VALUE)
```

元类非常强大，但也会增加理解成本。大多数场景优先考虑类装饰器、描述符、`__init_subclass__`。

## 动态创建类

`type(name, bases, namespace)` 可以动态创建类。

```python
User = type(
    "User",
    (),
    {
        "role": "guest",
        "__init__": lambda self, name: setattr(self, "name", name),
    },
)

u = User("Alice")
print(u.name, u.role)
```

动态创建类适合框架、ORM、序列化系统等元编程场景，普通业务代码较少需要。

## 高级特性选择建议

| 需求 | 优先选择 |
|---|---|
| 数据类，自动生成初始化和显示 | `@dataclass` |
| 限制属性、减少大量实例内存 | `__slots__` |
| 多个属性复用同样校验 | 描述符 |
| 批量增强类但不改变类创建底层 | 类装饰器 |
| 子类自动注册或检查 | `__init_subclass__` |
| 深度控制类创建过程 | 元类 |

实践建议：

1. 能用普通类就不用高级特性。
2. 能用 `dataclass` 就不要手写重复样板代码。
3. 能用类装饰器或 `__init_subclass__`，就不要急着写元类。
4. 描述符适合复用字段逻辑，不适合简单的一两个属性。
5. 高级特性必须让代码更清晰，否则就是负担。

---

## 小结

- `dataclass` 用于数据对象，减少样板代码。
- `__slots__` 限制属性并降低内存占用。
- 描述符控制属性访问，是 `property` 的底层协议。
- 类装饰器和 `__init_subclass__` 可用于注册和增强类。
- 元类控制类创建过程，强大但应少用。
