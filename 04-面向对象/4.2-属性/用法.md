## 属性的概念

属性是绑定在对象或类上的名字，用来保存状态或配置。

```python
class User:
    pass

u = User()
u.name = "Alice"       # 实例属性
User.category = "普通用户"  # 类属性
```

Python 属性本质上是命名空间中的键值绑定。普通实例通常用 `obj.__dict__` 保存实例属性，类用 `Class.__dict__` 保存类属性。

---

## 实例属性

实例属性属于某个具体对象，不同对象之间互不影响。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

s1 = Student("Alice", 90)
s2 = Student("Bob", 80)

s1.score = 95
print(s1.score)  # 95
print(s2.score)  # 80
```

### 常见创建方式

```python
class Person:
    def __init__(self, name):
        self.name = name       # 推荐：初始化时创建

    def set_age(self, age):
        self.age = age         # 可以，但对象早期没有 age 属性

p = Person("Alice")
p.city = "Beijing"            # 外部动态添加，学习阶段可用，项目中少用
```

统一在 `__init__` 中声明属性，能让对象结构更稳定。

## 类属性

类属性属于类对象，所有实例都可以访问。

```python
class Employee:
    company = "ACME"

    def __init__(self, name):
        self.name = name

e1 = Employee("Alice")
e2 = Employee("Bob")

print(e1.company)       # ACME
print(e2.company)       # ACME
print(Employee.company) # ACME
```

适合放在类属性里的内容：

- 所有对象共享的常量
- 默认配置
- 对象计数器
- 不随单个实例变化的元信息

```python
class User:
    count = 0

    def __init__(self, name):
        self.name = name
        User.count += 1

User("A")
User("B")
print(User.count)  # 2
```

## 属性查找顺序

访问 `obj.attr` 时，大致顺序是：

1. 数据描述符（后续高级特性）
2. 实例属性 `obj.__dict__`
3. 类属性和父类属性
4. 非数据描述符
5. 找不到则触发 `AttributeError`

初学可先记住：实例属性优先于同名普通类属性。

```python
class Demo:
    x = 1

d = Demo()
print(d.x)      # 1，来自类属性

d.x = 2         # 创建实例属性 x，遮蔽类属性
print(d.x)      # 2
print(Demo.x)   # 1
print(d.__dict__)  # {'x': 2}
```

如果想修改类属性，应通过类名修改。

```python
Demo.x = 100
print(Demo.x)
```

## 动态属性

Python 默认允许运行时添加、修改、删除属性。

```python
class Config:
    pass

cfg = Config()
cfg.host = "localhost"
cfg.port = 5432
print(cfg.__dict__)

del cfg.port
print(hasattr(cfg, "port"))  # False
```

动态属性灵活，但也会带来拼写错误难发现的问题。

```python
user = User("Alice")
user.nmae = "Bob"   # 拼错了，不会修改 name，而是新建 nmae
```

需要限制属性时，可使用 `__slots__`，见 4.8。

## `@property` 属性

`@property` 可以把方法包装成像属性一样访问的接口。

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def area(self):
        return 3.14159 * self.radius ** 2

c = Circle(2)
print(c.area)   # 12.56636，不需要写 c.area()
```

### 1. 只读属性

只定义 getter，不定义 setter，就是只读属性。

```python
class Order:
    def __init__(self, price, quantity):
        self.price = price
        self.quantity = quantity

    @property
    def total(self):
        return self.price * self.quantity

order = Order(10, 3)
print(order.total)
# order.total = 100  # AttributeError
```

### 2. 属性校验

通常用私有存储字段配合 property。

```python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price      # 调用 setter

    @property
    def price(self):
        return self._price

    @price.setter
    def price(self, value):
        if value < 0:
            raise ValueError("价格不能为负")
        self._price = value

p = Product("Book", 50)
p.price = 80
print(p.price)
```

### 3. 删除器

```python
class Session:
    def __init__(self, token):
        self._token = token

    @property
    def token(self):
        return self._token

    @token.deleter
    def token(self):
        self._token = None

s = Session("abc")
del s.token
print(s.token)  # None
```

### 4. 什么时候使用 property

适合：

- 对外表现为属性，但内部需要计算
- 赋值时需要校验
- 想保持接口不变，把公开字段改成受控访问

不适合：

- 计算非常昂贵且使用者以为只是普通属性
- 修改属性时产生明显副作用，例如写数据库、发网络请求

## 属性删除与检测

```python
class User:
    def __init__(self, name):
        self.name = name

u = User("Alice")

print(hasattr(u, "name"))       # True
print(getattr(u, "name"))       # Alice
print(getattr(u, "age", 0))     # 0，默认值
setattr(u, "age", 20)
print(u.age)
delattr(u, "age")
```

这些函数适合在属性名来自字符串时使用。

```python
field = "name"
print(getattr(u, field))
```

## 可变类属性陷阱

类属性如果是可变对象，所有实例会共享它。

```python
class Team:
    members = []

    def add(self, name):
        self.members.append(name)

t1 = Team()
t2 = Team()
t1.add("Alice")
print(t2.members)  # ['Alice']
```

如果每个对象都需要独立列表，应在 `__init__` 中创建实例属性。

```python
class Team:
    def __init__(self):
        self.members = []

    def add(self, name):
        self.members.append(name)
```

可变类属性不是不能用，而是要明确它是“共享状态”。

---

## 属性设计最佳实践

1. 实例自己的状态放实例属性。
2. 所有对象共享的常量或配置放类属性。
3. 可变对象通常不要作为类属性，除非就是要共享。
4. 属性命名用名词或名词短语，如 `name`、`created_at`。
5. 不要把复杂动作伪装成属性，动作应写成方法。
6. 需要校验或计算时使用 `@property`。
7. 对外公开属性前，先想清楚它是否应该允许被任意修改。

---

## 小结

- 实例属性属于对象，类属性属于类。
- `obj.attr` 会先查实例属性，再查类属性。
- 给对象同名赋值通常会创建或修改实例属性，不会修改类属性。
- `@property` 可以让方法以属性形式暴露，并支持校验。
- 避免无意共享可变类属性。
