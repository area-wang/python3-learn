## 实例属性

### 练习题

**题目 1：用户对象**

定义 `User(name, age)`，把 `name`、`age` 保存为实例属性，并打印 `user.__dict__`。

**题目 2：修改属性**

创建两个 `Student` 对象，修改其中一个的 `score`，验证另一个不受影响。

**题目 3：动态属性**

定义空类 `Config`，创建对象后动态添加 `host`、`port`，再用 `getattr` 读取。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

user = User("Alice", 20)
print(user.__dict__)

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

s1 = Student("A", 90)
s2 = Student("B", 80)
s1.score = 95
print(s1.score)  # 95
print(s2.score)  # 80

class Config:
    pass

cfg = Config()
cfg.host = "localhost"
cfg.port = 3306
print(getattr(cfg, "host"))
print(getattr(cfg, "port"))
```

## 类属性

### 练习题

**题目 1：学校名称**

定义 `Student.school = "Python Academy"`，所有学生实例都能访问该属性。

**题目 2：对象计数器**

定义 `User.count`，每创建一个 `User` 对象，计数加 1。

**题目 3：类属性修改**

解释下面代码输出：

```python
class A:
    x = 1

a1 = A()
a2 = A()
a1.x = 2
A.x = 3
print(a1.x)
print(a2.x)
print(A.x)
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Student:
    school = "Python Academy"

    def __init__(self, name):
        self.name = name

print(Student("Alice").school)
print(Student("Bob").school)

class User:
    count = 0

    def __init__(self, name):
        self.name = name
        User.count += 1

User("A")
User("B")

# 题目 3
# a1.x = 2 创建了 a1 的实例属性 x，遮蔽类属性。

# 2

# 3
```

## 属性查找

### 练习题

**题目 1：遮蔽关系**

创建类属性 `status = "class"`，实例上设置 `status = "instance"`，观察访问结果和 `__dict__`。

**题目 2：删除实例属性**

接上题，执行 `del obj.status` 后，再访问 `obj.status`，结果是什么？

**题目 3：安全读取**

用 `getattr(obj, "missing", "默认值")` 读取不存在的属性。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Demo:
    status = "class"

d = Demo()
print(d.status)  # class
d.status = "instance"
print(d.status)  # instance
print(d.__dict__)  # {'status': 'instance'}

del d.status
print(d.status)  # class，又回到类属性

print(getattr(d, "missing", "默认值"))
```

## `@property`

### 练习题

**题目 1：圆面积**

定义 `Circle(radius)`，提供只读属性 `area`，返回圆面积。

**题目 2：价格校验**

定义 `Product(name, price)`，使用 `@property` 控制 `price` 不能为负。

**题目 3：全名属性**

定义 `Person(first_name, last_name)`，提供：

- `full_name` getter，返回 `"first last"`
- `full_name` setter，允许通过 `"Alice Smith"` 修改名和姓

**题目 4：只读属性**

为什么给只定义 getter 的 property 赋值会报 `AttributeError`？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Circle:
    def __init__(self, radius):
        if radius <= 0:
            raise ValueError("半径必须为正")
        self.radius = radius

    @property
    def area(self):
        return 3.14159 * self.radius ** 2

print(Circle(2).area)

class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    @property
    def price(self):
        return self._price

    @price.setter
    def price(self, value):
        if value < 0:
            raise ValueError("价格不能为负")
        self._price = value

p = Product("Book", 50)
p.price = 80
print(p.price)

class Person:
    def __init__(self, first_name, last_name):
        self.first_name = first_name
        self.last_name = last_name

    @property
    def full_name(self):
        return f"{self.first_name} {self.last_name}"

    @full_name.setter
    def full_name(self, value):
        parts = value.split()
        if len(parts) != 2:
            raise ValueError("必须包含名和姓")
        self.first_name, self.last_name = parts

person = Person("Alice", "Smith")
print(person.full_name)
person.full_name = "Bob Lee"
print(person.first_name, person.last_name)

# 题目 4
# property 只有 getter，没有 setter，Python 不知道如何处理赋值，
# 所以会抛 AttributeError。
```

</details>

## 陷阱题

**题目 1：可变类属性**

下面代码输出什么？如何修复？

```python
class Bag:
    items = []

    def add(self, item):
        self.items.append(item)

b1 = Bag()
b2 = Bag()
b1.add("apple")
print(b2.items)
```

**题目 2：误改类属性**

为什么 `obj.count += 1` 可能不是在修改类属性，而是在创建实例属性？

**题目 3：拼写错误**

下面代码为什么没有报错却产生了 bug？

```python
class User:
    def __init__(self, name):
        self.name = name

u = User("Alice")
u.nmae = "Bob"
print(u.name)
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
# 输出 ['apple']，因为 items 是类属性，被所有实例共享。
class Bag:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

b1 = Bag()
b2 = Bag()
b1.add("apple")
print(b2.items)  # []

# 题目 2
# obj.count += 1 等价于 obj.count = obj.count + 1。
# 右边先查到类属性，左边赋值会在 obj 上创建实例属性 count。

# 题目 3
# u.nmae 是新属性，不是修改 name。Python 默认允许动态添加属性。
# print(u.name) 仍输出 Alice。
```

</details>

## 综合练习

### 综合题 1：库存商品

定义 `InventoryItem`：

- 类属性 `category = "general"`
- 实例属性 `name`、`price`、`stock`
- `price` 和 `stock` 使用 property 校验不能为负
- 只读属性 `total_value` 返回库存总价值

### 综合题 2：应用配置

定义 `AppConfig`：

- 类属性 `default_timeout = 30`
- 实例属性 `host`、`port`、`debug`
- `port` 必须在 1 到 65535 之间
- `url` 只读属性返回 `"http://host:port"`

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class InventoryItem:
    category = "general"

    def __init__(self, name, price, stock):
        self.name = name
        self.price = price
        self.stock = stock

    @property
    def price(self):
        return self._price

    @price.setter
    def price(self, value):
        if value < 0:
            raise ValueError("价格不能为负")
        self._price = value

    @property
    def stock(self):
        return self._stock

    @stock.setter
    def stock(self, value):
        if value < 0:
            raise ValueError("库存不能为负")
        self._stock = value

    @property
    def total_value(self):
        return self.price * self.stock


class AppConfig:
    default_timeout = 30

    def __init__(self, host, port, debug=False):
        self.host = host
        self.port = port
        self.debug = debug

    @property
    def port(self):
        return self._port

    @port.setter
    def port(self, value):
        if not 1 <= value <= 65535:
            raise ValueError("端口必须在 1 到 65535 之间")
        self._port = value

    @property
    def url(self):
        return f"http://{self.host}:{self.port}"

item = InventoryItem("Book", 50, 3)
print(item.total_value)     # 150

cfg = AppConfig("localhost", 8000)
print(cfg.url)              # http://localhost:8000
```

</details>
