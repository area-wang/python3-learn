## 为什么要学对象内置函数

面向对象章节里有两类容易混在一起的内容：

- **魔法方法**：定义在类里的特殊方法，例如 `__repr__`、`__len__`、`__call__`
- **内置函数**：Python 提供的工具函数，例如 `type()`、`dir()`、`getattr()`、`isinstance()`

内置函数通常用于观察对象、判断对象、动态访问对象属性。

```python
class User:
    def __init__(self, name):
        self.name = name

user = User("Alice")

print(type(user))
print(isinstance(user, User))
print(dir(user))
print(getattr(user, "name"))
```

学习这些函数，可以更清楚地理解“对象是什么、对象有哪些属性、对象能做什么”。

## `type()` 查看对象类型

`type(obj)` 返回对象所属的类。

```python
class Student:
    pass

stu = Student()

print(type(stu))       # <class '__main__.Student'>
print(type(123))       # <class 'int'>
print(type("hello"))   # <class 'str'>
```

类本身也是对象，它的类型通常是 `type`。

```python
print(type(Student))   # <class 'type'>
print(type(int))       # <class 'type'>
```

判断类型时，不建议写 `type(obj) == SomeClass` 作为首选，因为它不会考虑继承关系。多数场景优先使用 `isinstance()`。

## `isinstance()` 判断对象类型

`isinstance(obj, classinfo)` 判断对象是否属于某个类，或者属于该类的子类。

```python
class Animal:
    pass

class Dog(Animal):
    pass

dog = Dog()

print(isinstance(dog, Dog))      # True
print(isinstance(dog, Animal))   # True
print(type(dog) == Animal)       # False
```

第二个参数也可以是类型元组。

```python
value = 10

if isinstance(value, (int, float)):
    print("数字")
```

常见用途是做输入校验。

```python
class Cart:
    def add_quantity(self, quantity):
        if not isinstance(quantity, int):
            raise TypeError("quantity 必须是整数")
        if quantity <= 0:
            raise ValueError("quantity 必须大于 0")
```

注意：面向对象设计中不要到处写类型判断。能用多态时，通常让对象自己提供统一方法更清楚。

## `issubclass()` 判断继承关系

`issubclass(cls, classinfo)` 判断一个类是否是另一个类的子类。

```python
class Payment:
    pass

class AliPay(Payment):
    pass

print(issubclass(AliPay, Payment))  # True
print(issubclass(Payment, AliPay))  # False
```

它接收的是类，不是对象。

```python
pay = AliPay()

# issubclass(pay, Payment)  # TypeError
print(isinstance(pay, Payment))     # True
```

使用场景通常是框架、插件注册、类校验。

```python
def register_payment(cls):
    if not issubclass(cls, Payment):
        raise TypeError("必须继承 Payment")
    return cls
```

## `id()`、`is` 与 `==`

`id(obj)` 返回对象身份标识。可以把它理解成 Python 运行期间区分对象的编号。

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p1 = Point(1, 2)
p2 = Point(1, 2)
p3 = p1

print(id(p1))
print(id(p2))
print(p1 is p2)  # False，不是同一个对象
print(p1 is p3)  # True，引用同一个对象
```

`is` 判断两个变量是否引用同一个对象。

`==` 判断两个对象的值是否相等。默认情况下，自定义对象的 `==` 也接近身份比较；如果实现了 `__eq__`，就可以改成按值比较。

```python
class Product:
    def __init__(self, sku):
        self.sku = sku

    def __eq__(self, other):
        if not isinstance(other, Product):
            return NotImplemented
        return self.sku == other.sku

print(Product("A001") == Product("A001"))  # True
```

实践中：

- 判断是否是同一个对象，用 `is`
- 判断值是否相等，用 `==`
- 判断是否为 `None`，固定写 `is None` 或 `is not None`

## `dir()` 查看对象成员

`dir(obj)` 返回对象可访问的属性和方法名称列表。

```python
class User:
    role = "member"

    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"hello, {self.name}"

user = User("Alice")

print("name" in dir(user))    # True
print("greet" in dir(user))   # True
print("__init__" in dir(user)) # True
```

`dir()` 很适合学习和调试：当你不知道一个对象有哪些能力时，可以先看 `dir(obj)`。

```python
text = "hello"
print("upper" in dir(text))   # True
```

注意：`dir()` 只告诉你“名字有哪些”，不负责解释每个名字怎么用。想查看文档，可以结合 `help()` 或查看官方文档。

## `vars()` 与 `__dict__`

很多普通对象会把实例属性保存在 `__dict__` 中。

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

user = User("Alice", 20)

print(user.__dict__)   # {'name': 'Alice', 'age': 20}
print(vars(user))      # {'name': 'Alice', 'age': 20}
```

`vars(obj)` 通常等价于读取 `obj.__dict__`。

```python
attrs = vars(user)
attrs["age"] = 21

print(user.age)        # 21
```

不要把 `vars()` 返回的字典随意交给外部修改，因为它可能直接影响对象内部状态。

使用 `__slots__` 的对象默认没有 `__dict__`。

```python
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
print(hasattr(p, "__dict__"))   # False
```

## `getattr()`、`hasattr()`、`setattr()`、`delattr()`

这组函数用于按字符串动态操作属性。

### `getattr()`

`getattr(obj, name)` 等价于 `obj.name`，但属性名可以来自变量。

```python
class User:
    def __init__(self, name):
        self.name = name

user = User("Alice")

field = "name"
print(getattr(user, field))  # Alice
```

可以提供默认值，避免属性不存在时报错。

```python
print(getattr(user, "age", 0))  # 0
```

### `hasattr()`

`hasattr(obj, name)` 判断对象是否有某个属性。

```python
if hasattr(user, "name"):
    print(user.name)
```

如果只是想读取属性并给默认值，通常直接用 `getattr(obj, name, default)` 更简洁。

### `setattr()`

`setattr(obj, name, value)` 等价于 `obj.name = value`。

```python
setattr(user, "age", 20)
print(user.age)
```

### `delattr()`

`delattr(obj, name)` 等价于 `del obj.name`。

```python
delattr(user, "age")
print(hasattr(user, "age"))  # False
```

动态属性适合配置映射、表单字段、简单对象转换，但不要滥用。属性名如果来自外部输入，必须先做白名单校验。

```python
allowed_fields = {"name", "age"}

def update_user(user, data):
    for key, value in data.items():
        if key not in allowed_fields:
            raise ValueError(f"不允许修改字段: {key}")
        setattr(user, key, value)
```

## `callable()` 判断对象能否调用

`callable(obj)` 判断对象是否可以像函数一样使用 `obj()` 调用。

```python
def hello():
    return "hello"

class Greeter:
    def __call__(self, name):
        return f"hello, {name}"

print(callable(hello))      # True
print(callable(Greeter))    # True，类可以被调用来创建对象
print(callable(Greeter()))  # True，实现了 __call__
print(callable(123))        # False
```

类是可调用对象，因为调用类会创建实例。

```python
class User:
    pass

user = User()
```

实例是否可调用，取决于类有没有实现 `__call__`。

## `str()`、`repr()`、`len()`、`bool()` 与魔法方法

有些内置函数会触发对象的魔法方法。

| 内置函数 | 优先调用的魔法方法 | 常见用途 |
|---|---|---|
| `str(obj)` | `obj.__str__()` | 用户友好显示 |
| `repr(obj)` | `obj.__repr__()` | 开发调试显示 |
| `len(obj)` | `obj.__len__()` | 长度 |
| `bool(obj)` | `obj.__bool__()`，否则看 `__len__()` | 真值判断 |

```python
class Team:
    def __init__(self, members):
        self.members = list(members)

    def __repr__(self):
        return f"Team({self.members!r})"

    def __len__(self):
        return len(self.members)

team = Team(["Alice", "Bob"])

print(repr(team))   # Team(['Alice', 'Bob'])
print(len(team))    # 2
print(bool(team))   # True
```

如果对象没有实现对应魔法方法，Python 会使用默认行为或抛出异常。

```python
class Empty:
    pass

e = Empty()
print(str(e))       # 默认字符串表示
# len(e)            # TypeError
```

这部分和 `4.7-魔法方法` 是一体两面：内置函数是调用入口，魔法方法是类提供的协议实现。

## 常见错误与最佳实践

### 1. 用 `type()` 代替 `isinstance()`

```python
if type(obj) == Animal:
    ...
```

这会排除 `Animal` 的子类。多数类型判断应写成：

```python
if isinstance(obj, Animal):
    ...
```

### 2. 到处写类型判断

如果多个对象都有同名方法，优先直接调用这个方法，而不是反复判断类型。

```python
def notify(sender, user, message):
    return sender.send(user, message)
```

### 3. 盲目使用 `setattr()`

动态设置属性会降低代码可读性。只有属性名确实需要动态决定时才使用它。

```python
# 普通情况更清楚
user.name = "Alice"

# 字段名来自变量时才需要
setattr(user, field_name, value)
```

### 4. 把 `dir()` 当成对象文档

`dir()` 只能列出名字。想理解方法含义，还要看文档、注释、类型标注或源码。

### 5. 直接暴露 `__dict__`

`__dict__` 是对象内部状态。对外返回时更推荐复制一份，或提供明确的只读接口。

```python
class User:
    def to_dict(self):
        return dict(self.__dict__)
```

## 小结

- `type()` 查看对象类型，类型判断通常优先用 `isinstance()`。
- `issubclass()` 用于判断类之间的继承关系。
- `id()` 和 `is` 关注对象身份，`==` 关注值相等。
- `dir()` 用于查看对象有哪些属性和方法。
- `vars()` 和 `__dict__` 可以查看普通对象的实例属性。
- `getattr()`、`setattr()` 等函数用于动态属性操作。
- `callable()` 判断对象能否像函数一样调用。
- `str()`、`repr()`、`len()`、`bool()` 会和魔法方法配合工作。
