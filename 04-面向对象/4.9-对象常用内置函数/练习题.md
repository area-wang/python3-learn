## 类型与继承判断

### 练习题

**题目 1：类型查看**

定义 `Book(title)`，创建对象后分别打印：

- `type(book)`
- `type(Book)`
- `isinstance(book, Book)`

**题目 2：继承判断**

定义 `Animal`、`Cat(Animal)`，判断：

- `isinstance(cat, Cat)`
- `isinstance(cat, Animal)`
- `issubclass(Cat, Animal)`
- `issubclass(Animal, Cat)`

**题目 3：数字校验**

写函数 `ensure_number(value)`，如果 `value` 不是 `int` 或 `float`，抛出 `TypeError`；否则返回原值。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Book:
    def __init__(self, title):
        self.title = title

book = Book("Python")

print(type(book))
print(type(Book))
print(isinstance(book, Book))


class Animal:
    pass

class Cat(Animal):
    pass

cat = Cat()

print(isinstance(cat, Cat))
print(isinstance(cat, Animal))
print(issubclass(Cat, Animal))
print(issubclass(Animal, Cat))


def ensure_number(value):
    if not isinstance(value, (int, float)):
        raise TypeError("value 必须是数字")
    return value
```

## 对象成员查看

### 练习题

**题目 1：查看属性和方法**

定义 `User(name)`，包含实例属性 `name` 和方法 `greet()`。使用 `dir(user)` 判断 `"name"` 和 `"greet"` 是否在对象成员中。

**题目 2：查看实例属性**

定义 `Product(name, price)`，使用 `vars(product)` 打印实例属性字典。

**题目 3：保护内部状态**

给 `Product` 增加 `to_dict()` 方法，返回实例属性的副本，而不是直接返回 `__dict__`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class User:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"hello, {self.name}"

user = User("Alice")

print("name" in dir(user))
print("greet" in dir(user))


class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def to_dict(self):
        return dict(self.__dict__)

product = Product("Book", 80)

print(vars(product))
data = product.to_dict()
data["price"] = 100
print(product.price)  # 80，原对象不受影响
```

## 动态属性操作

### 练习题

**题目 1：动态读取属性**

定义 `User(name, age)`，写函数 `read_field(obj, field, default=None)`，使用 `getattr()` 动态读取属性。

**题目 2：安全更新属性**

写函数 `update_user(user, data)`，只允许更新 `"name"` 和 `"age"` 两个字段。其它字段抛出 `ValueError`。

**题目 3：删除临时属性**

给对象设置 `temp_token` 属性，然后使用 `delattr()` 删除它。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age


def read_field(obj, field, default=None):
    return getattr(obj, field, default)


def update_user(user, data):
    allowed_fields = {"name", "age"}
    for key, value in data.items():
        if key not in allowed_fields:
            raise ValueError(f"不允许修改字段: {key}")
        setattr(user, key, value)


user = User("Alice", 20)

print(read_field(user, "name"))
print(read_field(user, "email", "未填写"))

update_user(user, {"name": "Bob", "age": 21})
print(user.name, user.age)

setattr(user, "temp_token", "abc")
print(hasattr(user, "temp_token"))
delattr(user, "temp_token")
print(hasattr(user, "temp_token"))
```

</details>

## 可调用对象与协议函数

### 练习题

**题目 1：判断可调用**

分别判断普通函数、类、普通实例、实现了 `__call__` 的实例是否可调用。

**题目 2：显示对象**

定义 `Point(x, y)`，实现 `__repr__`，然后使用 `repr(point)` 查看结果。

**题目 3：长度与真值**

定义 `Bag(items)`，实现 `__len__`，观察 `len(bag)` 和 `bool(bag)` 的结果。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
def hello():
    return "hello"


class User:
    pass


class Greeter:
    def __call__(self, name):
        return f"hello, {name}"


print(callable(hello))
print(callable(User))
print(callable(User()))
print(callable(Greeter()))


class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x!r}, {self.y!r})"


point = Point(1, 2)
print(repr(point))


class Bag:
    def __init__(self, items):
        self.items = list(items)

    def __len__(self):
        return len(self.items)


print(len(Bag([1, 2, 3])))
print(bool(Bag([1])))
print(bool(Bag([])))
```

## 综合练习

### 综合题：对象调试工具

写函数 `inspect_object(obj)`，返回一个字典，包含：

- `"type"`：对象类型名
- `"id"`：对象身份标识
- `"attrs"`：如果对象支持 `vars()`，返回实例属性副本；否则返回空字典
- `"callable"`：对象是否可调用
- `"members_count"`：`dir(obj)` 的成员数量

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
def inspect_object(obj):
    try:
        attrs = dict(vars(obj))
    except TypeError:
        attrs = {}

    return {
        "type": type(obj).__name__,
        "id": id(obj),
        "attrs": attrs,
        "callable": callable(obj),
        "members_count": len(dir(obj)),
    }


class User:
    def __init__(self, name):
        self.name = name


print(inspect_object(User("Alice")))
print(inspect_object(123))
print(inspect_object(len))
```

</details>
