## 方法的概念

方法是定义在类中的函数。它和普通函数的主要区别是：方法通常通过对象或类调用，并且会参与绑定机制。

```python
class User:
    def greet(self):
        return "hello"

u = User()
print(u.greet())  # hello
```

常见方法类型：

| 类型 | 装饰器 | 第一个参数 | 适合场景 |
|---|---|---|---|
| 实例方法 | 无 | `self` | 操作某个具体对象的状态 |
| 类方法 | `@classmethod` | `cls` | 操作类状态、替代构造器 |
| 静态方法 | `@staticmethod` | 无自动参数 | 放在类命名空间下的工具函数 |

## 实例方法

实例方法是最常见的方法，第一个参数约定为 `self`。

```python
class BankAccount:
    def __init__(self, balance=0):
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

    def get_balance(self):
        return self.balance

account = BankAccount(100)
account.deposit(50)
print(account.get_balance())  # 150
```

实例方法适合：

- 读取或修改实例属性
- 表达对象行为
- 需要访问当前对象时

### 返回 self 支持链式调用

```python
class Query:
    def __init__(self):
        self.conditions = []

    def where(self, condition):
        self.conditions.append(condition)
        return self

    def build(self):
        return " AND ".join(self.conditions)

query = Query().where("age > 18").where("active = true").build()
print(query)
```

链式调用要谨慎：如果每一步都会改变原对象，应在文档或命名上体现这一点。

## 类方法

类方法使用 `@classmethod` 装饰，第一个参数约定为 `cls`，表示当前类。

```python
class User:
    count = 0

    def __init__(self, name):
        self.name = name
        type(self).count += 1

    @classmethod
    def get_count(cls):
        return cls.count

User("Alice")
User("Bob")
print(User.get_count())  # 2
```

### 1. 替代构造器

类方法常用于提供多种创建对象的方式。

```python
class Date:
    def __init__(self, year, month, day):
        self.year = year
        self.month = month
        self.day = day

    @classmethod
    def from_string(cls, text):
        year, month, day = map(int, text.split("-"))
        return cls(year, month, day)

d = Date.from_string("2026-07-14")
print(d.year, d.month, d.day)
```

使用 `cls(...)` 而不是写死类名，可以更好地支持继承。

```python
class SpecialDate(Date):
    pass

sd = SpecialDate.from_string("2026-07-14")
print(type(sd))  # <class '__main__.SpecialDate'>
```

### 2. 修改类级配置

```python
class Logger:
    level = "INFO"

    @classmethod
    def set_level(cls, level):
        cls.level = level

Logger.set_level("DEBUG")
print(Logger.level)
```

## 静态方法

静态方法使用 `@staticmethod` 装饰，不自动接收 `self` 或 `cls`。

```python
class Math:
    @staticmethod
    def add(a, b):
        return a + b

print(Math.add(2, 3))
```

静态方法适合：

- 与类主题强相关
- 不需要访问实例状态
- 不需要访问类状态

```python
class Password:
    @staticmethod
    def is_strong(text):
        return len(text) >= 8 and any(ch.isdigit() for ch in text)

print(Password.is_strong("abc12345"))  # True
```

如果一个函数完全不需要类上下文，也可以直接放在模块级函数中。不要为了“面向对象”强行使用静态方法。

## 方法绑定机制

从对象访问普通函数属性时，会得到绑定方法。

```python
class Demo:
    def f(self, x):
        return x

d = Demo()
print(d.f)       # bound method
print(Demo.f)    # function

print(d.f(10))        # Python 自动传 d
print(Demo.f(d, 10))  # 手动传 d
```

类方法绑定到类，静态方法不绑定额外参数。

```python
class Demo:
    @classmethod
    def cm(cls):
        return cls.__name__

    @staticmethod
    def sm():
        return "static"

print(Demo.cm())  # Demo
print(Demo.sm())  # static
```

## 方法之间的调用

实例方法中调用其它实例方法，使用 `self.method()`。

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, name, price):
        self.items.append((name, price))

    def total(self):
        return sum(price for _, price in self.items)

    def checkout(self):
        amount = self.total()
        self.items.clear()
        return amount
```

类方法中调用其它类方法，使用 `cls.method()`。

```python
class IDGenerator:
    prefix = "U"
    current = 0

    @classmethod
    def next_id(cls):
        cls.current += 1
        return cls.format_id(cls.current)

    @classmethod
    def format_id(cls, number):
        return f"{cls.prefix}{number:04d}"

print(IDGenerator.next_id())  # U0001
```

## 私有方法与辅助方法

单下划线表示内部使用约定。

```python
class Report:
    def generate(self, data):
        cleaned = self._clean(data)
        return self._format(cleaned)

    def _clean(self, data):
        return [x for x in data if x is not None]

    def _format(self, data):
        return ",".join(map(str, data))
```

双下划线会触发名称改写，常用于避免子类意外覆盖。

```python
class Base:
    def __helper(self):
        return "base"

    def run(self):
        return self.__helper()
```

多数情况下，单下划线已经足够。双下划线不是安全机制，而是名称改写机制。

## 方法设计原则

1. 方法名使用动词或动词短语，如 `save`、`calculate_total`。
2. 修改对象状态的方法，名字要体现动作，如 `mark_done`。
3. 返回布尔值的方法常用 `is_`、`has_`、`can_` 开头。
4. 查询方法尽量不要偷偷修改状态。
5. 参数过多时，考虑引入对象或拆分方法。
6. 优先让方法保持单一职责。
7. 类方法适合创建对象或操作类状态，不要拿来操作实例状态。
8. 静态方法不应依赖 `self` 或 `cls`。

## 常见错误

### 1. 忘记 `@classmethod`

```python
class User:
    count = 0

    # def get_count(cls):   # 通过 User.get_count() 调用会缺少绑定
    #     return cls.count
    @classmethod
    def get_count(cls):
        return cls.count
```

### 2. 在静态方法中访问 self

```python
class Bad:
    @staticmethod
    def f():
        # return self.x  # NameError
        return "ok"
```

### 3. 用实例修改类状态导致遮蔽

```python
class Counter:
    count = 0

c = Counter()
c.count += 1      # 创建实例属性，不是修改 Counter.count
print(Counter.count)  # 0
print(c.count)        # 1
```

### 4. 方法职责过大

如果一个方法同时读取输入、校验、计算、保存、打印结果，测试和复用都会变困难。拆成多个小方法更清晰。

---

## 小结

- 实例方法操作对象，自动接收 `self`。
- 类方法操作类，自动接收 `cls`。
- 静态方法不接收自动参数，是放在类命名空间下的工具函数。
- `obj.method()` 与 `Class.method(obj)` 对实例方法基本等价。
- 方法设计要关注职责、命名、是否修改状态。
