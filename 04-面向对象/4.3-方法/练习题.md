## 实例方法

### 练习题

**题目 1：计数器方法**

定义 `Counter`，包含 `increment()`、`decrement()`、`reset()`、`value()`。

**题目 2：任务对象**

定义 `Task(title)`：

- `mark_done()` 标记完成
- `rename(title)` 修改标题
- `is_done()` 返回是否完成

**题目 3：链式调用**

定义 `TextBuilder`：

- `append(text)` 追加文本并返回 `self`
- `upper()` 把当前文本变大写并返回 `self`
- `build()` 返回最终字符串

实现 `TextBuilder().append("hi").append(" python").upper().build()`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Counter:
    def __init__(self):
        self.count = 0

    def increment(self):
        self.count += 1

    def decrement(self):
        self.count -= 1

    def reset(self):
        self.count = 0

    def value(self):
        return self.count


class Task:
    def __init__(self, title):
        self.title = title
        self.done = False

    def mark_done(self):
        self.done = True

    def rename(self, title):
        if not title:
            raise ValueError("标题不能为空")
        self.title = title

    def is_done(self):
        return self.done


class TextBuilder:
    def __init__(self):
        self.text = ""

    def append(self, text):
        self.text += text
        return self

    def upper(self):
        self.text = self.text.upper()
        return self

    def build(self):
        return self.text

print(TextBuilder().append("hi").append(" python").upper().build())
```

## 类方法

### 练习题

**题目 1：对象计数**

定义 `User` 类，创建对象时 `count` 加 1，并通过 `User.get_count()` 获取数量。

**题目 2：替代构造器**

定义 `Person(name, age)`，提供 `from_string("Alice,20")` 创建对象。

**题目 3：配置切换**

定义 `Logger`：

- 类属性 `level = "INFO"`
- 类方法 `set_level(level)`
- 类方法 `is_debug()` 判断当前级别是否为 `"DEBUG"`

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class User:
    count = 0

    def __init__(self, name):
        self.name = name
        type(self).count += 1

    @classmethod
    def get_count(cls):
        return cls.count

User("A")
User("B")
print(User.get_count())

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_string(cls, text):
        name, age = text.split(",")
        return cls(name, int(age))

p = Person.from_string("Alice,20")
print(p.name, p.age)

class Logger:
    level = "INFO"

    @classmethod
    def set_level(cls, level):
        cls.level = level

    @classmethod
    def is_debug(cls):
        return cls.level == "DEBUG"

Logger.set_level("DEBUG")
print(Logger.is_debug())
```

## 静态方法

### 练习题

**题目 1：数学工具**

定义 `MathUtils.add(a, b)`、`MathUtils.is_even(n)` 为静态方法。

**题目 2：密码校验**

定义 `PasswordValidator.is_strong(password)`，要求长度至少 8，且包含数字和字母。

**题目 3：格式化工具**

定义 `StringUtils.to_snake_case(text)`，把 `"User Name"` 转成 `"user_name"`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class MathUtils:
    @staticmethod
    def add(a, b):
        return a + b

    @staticmethod
    def is_even(n):
        return n % 2 == 0

print(MathUtils.add(1, 2))
print(MathUtils.is_even(4))

class PasswordValidator:
    @staticmethod
    def is_strong(password):
        has_digit = any(ch.isdigit() for ch in password)
        has_alpha = any(ch.isalpha() for ch in password)
        return len(password) >= 8 and has_digit and has_alpha

print(PasswordValidator.is_strong("abc12345"))

class StringUtils:
    @staticmethod
    def to_snake_case(text):
        return "_".join(text.lower().split())

print(StringUtils.to_snake_case("User Name"))
```

### 参考答案

<details>

```python
class Demo:
    def f(self, x):
        return x * 2

d = Demo()
print(d.f(10))
print(Demo.f(d, 10))
print(Demo.f)
print(d.f)

class Base:
    @classmethod
    def create(cls):

class Child(Base):
```

## 陷阱题

**题目 1：缺少 self**

```python
class A:
    def hello():
        print("hi")

A().hello()
```

为什么报错？

**题目 2：静态方法访问实例属性**

```python
class A:
    def __init__(self):
        self.x = 1

    @staticmethod
    def show():
        return self.x
```

为什么错误？如何修改？

**题目 3：类属性计数错误**

下面代码为什么 `Counter.count` 还是 0？

```python
class Counter:
    count = 0

    def inc(self):
        self.count += 1

c = Counter()
c.inc()
print(Counter.count)
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
# 对象调用实例方法会自动传入 self，但 hello 没有参数。
# TypeError: hello() takes 0 positional arguments but 1 was given

# 题目 2
# staticmethod 不接收 self，self 没定义。
class A:
    def __init__(self):
        self.x = 1

    def show(self):
        return self.x

print(A().show())

# 题目 3
# self.count += 1 会在实例上创建 count，遮蔽类属性。
class Counter:
    count = 0

    @classmethod
    def inc(cls):
        cls.count += 1

Counter.inc()
print(Counter.count)
```

## 综合练习

### 综合题 1：用户注册

定义 `User`：

- 实例属性 `username`、`email`
- 类属性 `users = []`
- 类方法 `create(username, email)` 创建用户并加入列表
- 类方法 `find_by_username(username)` 查找用户
- 静态方法 `is_valid_email(email)` 简单判断是否包含 `@`

### 综合题 2：订单金额计算

定义 `Order`：

- `add_item(name, price, quantity=1)`
- `subtotal()`
- `discount(rate)` 返回打折后的金额
- 静态方法 `format_money(value)` 返回两位小数字符串

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class User:
    users = []

    def __init__(self, username, email):
        self.username = username
        self.email = email

    @staticmethod
    def is_valid_email(email):
        return "@" in email

    @classmethod
    def create(cls, username, email):
        if not cls.is_valid_email(email):
            raise ValueError("邮箱格式错误")
        user = cls(username, email)
        cls.users.append(user)
        return user

    @classmethod
    def find_by_username(cls, username):
        for user in cls.users:
            if user.username == username:
                return user
        return None


class Order:
    def __init__(self):
        self.items = []

    def add_item(self, name, price, quantity=1):
        self.items.append({"name": name, "price": price, "quantity": quantity})

    def subtotal(self):
        return sum(item["price"] * item["quantity"] for item in self.items)

    def discount(self, rate):
        if not 0 <= rate <= 1:
            raise ValueError("折扣率必须在 0 到 1 之间")
        return self.subtotal() * (1 - rate)

    @staticmethod
    def format_money(value):
        return f"{value:.2f}"

u = User.create("alice", "alice@example.com")
print(User.find_by_username("alice") is u)

order = Order()
order.add_item("Book", 50, 2)
print(Order.format_money(order.discount(0.1)))
```

</details>
