## 字符串表示

### 练习题

**题目 1：用户显示**

定义 `User(name, age)`，实现 `__str__` 返回 `"name(age)"`。

**题目 2：坐标表示**

定义 `Point(x, y)`，实现 `__repr__` 返回 `Point(x, y)`。

**题目 3：列表显示**

把 `Point` 对象放入列表，观察为什么列表使用 `__repr__`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"{self.name}({self.age})"

print(User("Alice", 20))

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x!r}, {self.y!r})"

p = Point(1, 2)
print(repr(p))
print([p])
```

## 比较与排序

### 练习题

**题目 1：学生比较**

定义 `Student(name, score)`，实现 `__lt__` 按成绩排序。

**题目 2：商品相等**

定义 `Product(sku, name)`，只要 `sku` 相同就认为相等。

**题目 3：版本号**

用 `total_ordering` 定义 `Version(major, minor, patch)`，支持比较大小。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
from functools import total_ordering

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __lt__(self, other):
        if not isinstance(other, Student):
            return NotImplemented
        return self.score < other.score

    def __repr__(self):
        return f"Student({self.name!r}, {self.score})"

print(sorted([Student("A", 90), Student("B", 80)]))

class Product:
    def __init__(self, sku, name):
        self.sku = sku
        self.name = name

    def __eq__(self, other):
        if not isinstance(other, Product):
            return NotImplemented
        return self.sku == other.sku

@total_ordering
class Version:
    def __init__(self, major, minor, patch):
        self.parts = (major, minor, patch)

    def __eq__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return self.parts == other.parts

    def __lt__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return self.parts < other.parts

print(Version(1, 2, 0) < Version(1, 3, 0))
```

## 运算符重载

### 练习题

**题目 1：向量加法**

定义 `Vector(x, y)`，支持 `v1 + v2`。

**题目 2：向量乘法**

支持 `v * 3` 和 `3 * v`。

**题目 3：购物金额**

定义 `Money(amount)`，支持两个 Money 相加，但不允许和普通数字直接相加。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):
        if not isinstance(scalar, (int, float)):
            return NotImplemented
        return Vector(self.x * scalar, self.y * scalar)

    __rmul__ = __mul__

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

print(Vector(1, 2) + Vector(3, 4))
print(Vector(1, 2) * 3)
print(3 * Vector(1, 2))

class Money:
    def __init__(self, amount):
        self.amount = amount

    def __add__(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        return Money(self.amount + other.amount)

    def __repr__(self):
        return f"Money({self.amount})"

print(Money(10) + Money(20))
```

## 容器协议

### 练习题

**题目 1：播放列表**

定义 `Playlist`，支持 `len(p)`、迭代、索引、`song in p`。

**题目 2：成绩册**

定义 `GradeBook`，内部保存字典，支持 `book[name]`、`book[name] = score`、`name in book`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Playlist:
    def __init__(self, songs):
        self._songs = list(songs)

    def __len__(self):
        return len(self._songs)

    def __iter__(self):
        return iter(self._songs)

    def __getitem__(self, index):
        return self._songs[index]

    def __contains__(self, song):
        return song in self._songs

p = Playlist(["A", "B"])
print(len(p))
print(p[0])
print("A" in p)
for song in p:
    print(song)

class GradeBook:
    def __init__(self):
        self._scores = {}

    def __getitem__(self, name):
        return self._scores[name]

    def __setitem__(self, name, score):
        self._scores[name] = score

    def __contains__(self, name):
        return name in self._scores

book = GradeBook()
book["Alice"] = 95
print(book["Alice"])
print("Alice" in book)
```

## 上下文与调用

### 练习题

**题目 1：可调用乘法器**

定义 `Multiplier(factor)`，实现 `__call__(value)`。

**题目 2：计时上下文**

定义 `Timer`，进入时记录时间，退出时打印耗时。

**题目 3：属性兜底**

定义 `DefaultObject`，访问不存在属性时返回 `"N/A"`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
import time

class Multiplier:
    def __init__(self, factor):
        self.factor = factor

    def __call__(self, value):
        return value * self.factor

print(Multiplier(3)(10))

class Timer:
    def __enter__(self):
        self.start = time.time()
        return self

    def __exit__(self, exc_type, exc, tb):
        self.end = time.time()
        print(f"耗时: {self.end - self.start:.6f}s")
        return False

with Timer():
    sum(range(10000))

class DefaultObject:
    def __getattr__(self, name):
        return "N/A"

print(DefaultObject().missing)
```

## 综合练习

### 综合题：二维向量类

定义 `Vector2D(x, y)`：

- `__repr__` 返回 `Vector2D(x, y)`
- `__eq__` 判断坐标相等
- `__add__` 支持向量相加
- `__sub__` 支持向量相减
- `__mul__` 和 `__rmul__` 支持数乘
- `__len__` 返回 2
- `__iter__` 支持解包：`x, y = vector`

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Vector2D:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Vector2D({self.x!r}, {self.y!r})"

    def __eq__(self, other):
        if not isinstance(other, Vector2D):
            return NotImplemented
        return self.x == other.x and self.y == other.y

    def __add__(self, other):
        if not isinstance(other, Vector2D):
            return NotImplemented
        return Vector2D(self.x + other.x, self.y + other.y)

    def __sub__(self, other):
        if not isinstance(other, Vector2D):
            return NotImplemented
        return Vector2D(self.x - other.x, self.y - other.y)

    def __mul__(self, scalar):
        if not isinstance(scalar, (int, float)):
            return NotImplemented
        return Vector2D(self.x * scalar, self.y * scalar)

    __rmul__ = __mul__

    def __len__(self):
        return 2

    def __iter__(self):
        yield self.x
        yield self.y

v = Vector2D(1, 2)
print(v + Vector2D(3, 4))
print(3 * v)
x, y = v
print(x, y)
```

</details>
