## 魔法方法的概念

魔法方法是双下划线开头和结尾的方法，例如 `__init__`、`__str__`、`__len__`。它们由 Python 在特定语法或内置函数中自动调用。

```python
class Box:
    def __len__(self):
        return 3

box = Box()
print(len(box))  # 自动调用 box.__len__()
```

魔法方法也叫特殊方法、dunder method。

## 对象创建与初始化

`__new__` 创建对象，`__init__` 初始化对象。

```python
class Demo:
    def __new__(cls, *args, **kwargs):
        print("__new__")
        return super().__new__(cls)

    def __init__(self):
        print("__init__")

Demo()
```

大多数业务类只需要写 `__init__`。

```python
class User:
    def __init__(self, name):
        self.name = name
```

`__del__` 在对象销毁时可能被调用，但不要依赖它处理核心资源释放。

## 字符串表示

### `__str__`

面向用户的友好字符串，供 `print()` 和 `str()` 使用。

```python
class User:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"用户: {self.name}"

print(User("Alice"))  # 用户: Alice
```

### `__repr__`

面向开发者的精确表示，供交互式环境、`repr()`、容器显示使用。

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x!r}, {self.y!r})"

p = Point(1, 2)
print(repr(p))  # Point(1, 2)
print([p])      # [Point(1, 2)]
```

推荐：能写 `__repr__` 就先写 `__repr__`；需要用户友好展示时再写 `__str__`。

## 比较运算

常见比较魔法方法：

| 运算 | 方法 |
|---|---|
| `==` | `__eq__` |
| `!=` | `__ne__` |
| `<` | `__lt__` |
| `<=` | `__le__` |
| `>` | `__gt__` |
| `>=` | `__ge__` |

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __eq__(self, other):
        if not isinstance(other, Student):
            return NotImplemented
        return self.name == other.name and self.score == other.score

    def __lt__(self, other):
        if not isinstance(other, Student):
            return NotImplemented
        return self.score < other.score

print(Student("A", 90) == Student("A", 90))
print(Student("A", 80) < Student("B", 90))
```

使用 `functools.total_ordering` 可以减少排序方法数量。

```python
from functools import total_ordering

@total_ordering
class Version:
    def __init__(self, major, minor):
        self.major = major
        self.minor = minor

    def __eq__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return (self.major, self.minor) == (other.major, other.minor)

    def __lt__(self, other):
        if not isinstance(other, Version):
            return NotImplemented
        return (self.major, self.minor) < (other.major, other.minor)
```

## 算术运算符重载

对象可以通过魔法方法支持 `+`、`-`、`*` 等运算。

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):
        if not isinstance(scalar, (int, float)):
            return NotImplemented
        return Vector(self.x * scalar, self.y * scalar)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

print(Vector(1, 2) + Vector(3, 4))
print(Vector(1, 2) * 3)
```

如果希望 `3 * Vector(1, 2)` 也能工作，需要实现反向方法 `__rmul__`。

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __mul__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)

    __rmul__ = __mul__

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"
```

## 容器协议

实现容器相关魔法方法后，对象可以像列表、字典一样使用。

```python
class Playlist:
    def __init__(self, songs):
        self._songs = list(songs)

    def __len__(self):
        return len(self._songs)

    def __iter__(self):
        return iter(self._songs)

    def __getitem__(self, index):
        return self._songs[index]

    def __contains__(self, song):
        return song in self._songs

p = Playlist(["A", "B", "C"])
print(len(p))
print(p[0])
print("B" in p)
for song in p:
    print(song)
```

常用协议：

| 行为 | 方法 |
|---|---|
| `len(obj)` | `__len__` |
| `for x in obj` | `__iter__` |
| `obj[i]` | `__getitem__` |
| `obj[i] = x` | `__setitem__` |
| `del obj[i]` | `__delitem__` |
| `x in obj` | `__contains__` |

## 可调用对象

实现 `__call__` 后，对象可以像函数一样调用。

```python
class Multiplier:
    def __init__(self, factor):
        self.factor = factor

    def __call__(self, value):
        return value * self.factor

times3 = Multiplier(3)
print(times3(10))  # 30
print(callable(times3))  # True
```

适合需要保存状态的函数式对象，例如计数器、配置化校验器。

## 上下文管理器

实现 `__enter__` 和 `__exit__` 后，可用于 `with` 语句。

```python
class ManagedResource:
    def __enter__(self):
        print("进入")
        return self

    def __exit__(self, exc_type, exc, tb):
        print("退出")
        return False  # False 表示不吞掉异常

with ManagedResource() as resource:
    print("使用资源")
```

真实项目中，文件、锁、数据库连接等资源常用上下文管理器保证释放。

## 属性访问魔法方法

谨慎使用这些方法，因为它们影响属性查找核心流程。

```python
class Demo:
    def __getattr__(self, name):
        return f"{name} 不存在"

d = Demo()
print(d.anything)  # anything 不存在
```

区别：

- `__getattr__`：普通查找失败后才调用
- `__getattribute__`：每次访问属性都会调用
- `__setattr__`：设置属性时调用
- `__delattr__`：删除属性时调用

```python
class Strict:
    def __setattr__(self, name, value):
        if name == "age" and value < 0:
            raise ValueError("年龄不能为负")
        super().__setattr__(name, value)
```

实现 `__getattribute__` 时必须小心调用 `super().__getattribute__`，否则容易无限递归。

## 常见错误与最佳实践

### 1. `__repr__` 返回非字符串

魔法方法要求返回特定类型。`__repr__` 和 `__str__` 必须返回字符串。

### 2. 比较不同类型时直接抛异常

更推荐返回 `NotImplemented`，让 Python 尝试其它处理。

### 3. 运算符语义不自然

不要让 `+` 做删除、发送邮件等奇怪动作。运算符重载应符合直觉。

### 4. 过度使用魔法方法

魔法方法能让对象更 Pythonic，但也会隐藏调用流程。只在对象确实需要参与某种语言协议时使用。

---

## 小结

- 魔法方法让对象接入 Python 语法和内置函数。
- `__str__` 面向用户，`__repr__` 面向开发者。
- 比较和运算符重载应返回符合直觉的新对象或结果。
- 容器协议让对象支持 `len`、迭代、索引、成员判断。
- `__call__` 让对象像函数一样调用。
- 属性访问魔法方法强大但容易出错。
