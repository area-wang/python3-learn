## 继承的概念

继承允许一个类复用另一个类的属性和方法。被继承的类叫父类、基类或超类；继承者叫子类或派生类。

```python
class Animal:
    def eat(self):
        print("eating")

class Dog(Animal):
    pass

dog = Dog()
dog.eat()
```

继承表达的是“is-a”关系：狗是动物，猫是动物。不要把“has-a”关系写成继承，例如汽车有发动机，不应让 `Car` 继承 `Engine`。

## 单继承

```python
class Person:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        return f"我是 {self.name}"

class Student(Person):
    def study(self):
        return f"{self.name} 正在学习"

s = Student("Alice")
print(s.introduce())
print(s.study())
```

`Student` 继承了 `Person` 的 `__init__` 和 `introduce`。

### 判断继承关系

```python
print(isinstance(s, Student))  # True
print(isinstance(s, Person))   # True
print(issubclass(Student, Person))  # True
```

## 方法重写

子类可以定义与父类同名的方法，覆盖父类行为。

```python
class Animal:
    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):
        return "汪"

print(Dog().speak())  # 汪
```

重写适合表达“同一个接口，不同的具体行为”。

```python
class Payment:
    def pay(self, amount):
        raise NotImplementedError

class AliPay(Payment):
    def pay(self, amount):
        return f"支付宝支付 {amount}"

class WeChatPay(Payment):
    def pay(self, amount):
        return f"微信支付 {amount}"
```

## `super()`

`super()` 用来按 MRO 调用父类或下一个类的方法。最常见用途是在子类 `__init__` 中复用父类初始化逻辑。

```python
class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
    def __init__(self, name, student_id):
        super().__init__(name)
        self.student_id = student_id

s = Student("Alice", "S001")
print(s.name, s.student_id)
```

### 扩展父类方法

```python
class Logger:
    def log(self, message):
        print(message)

class TimestampLogger(Logger):
    def log(self, message):
        super().log(f"[2026-07-14] {message}")
```

### 不建议直接写父类名

```python
class Student(Person):
    def __init__(self, name, student_id):
        Person.__init__(self, name)  # 可用，但不利于多继承和后续重构
        self.student_id = student_id
```

现代 Python 推荐使用无参数 `super()`。

## 继承属性与初始化

子类不会自动拥有父类 `__init__` 里创建的实例属性，除非父类初始化方法被调用。

```python
class Base:
    def __init__(self):
        self.x = 1

class Child(Base):
    def __init__(self):
        self.y = 2

c = Child()
# print(c.x)  # AttributeError，因为没有调用 Base.__init__
```

正确写法：

```python
class Child(Base):
    def __init__(self):
        super().__init__()
        self.y = 2
```

类属性会按继承链查找：

```python
class Base:
    role = "base"

class Child(Base):
    pass

print(Child.role)  # base
Child.role = "child"
print(Base.role)   # base
```

## 多继承

一个类可以继承多个父类。

```python
class Flyable:
    def fly(self):
        return "fly"

class Swimmable:
    def swim(self):
        return "swim"

class Duck(Flyable, Swimmable):
    pass

d = Duck()
print(d.fly())
print(d.swim())
```

多继承常用于 mixin：提供一小块可复用能力。

```python
class JsonMixin:
    def to_dict(self):
        return self.__dict__.copy()

    def to_json(self):
        import json
        return json.dumps(self.to_dict(), ensure_ascii=False)

class User(JsonMixin):
    def __init__(self, name):
        self.name = name

print(User("Alice").to_json())
```

Mixin 通常不单独实例化，命名常以 `Mixin` 结尾。

## MRO 方法解析顺序

MRO（Method Resolution Order）决定查找方法和属性时的类搜索顺序。

```python
class A:
    def hello(self):
        return "A"

class B(A):
    def hello(self):
        return "B"

class C(A):
    def hello(self):
        return "C"

class D(B, C):
    pass

print(D().hello())  # B
print(D.mro())
```

Python 使用 C3 线性化算法生成 MRO，保证继承顺序稳定且父类不会在子类之前被搜索。

`super()` 不是简单“调用父类”，而是调用 MRO 中当前类的下一个类。

```python
class A:
    def run(self):
        print("A")

class B(A):
    def run(self):
        print("B")
        super().run()

class C(A):
    def run(self):
        print("C")
        super().run()

class D(B, C):
    def run(self):
        print("D")
        super().run()

D().run()
print([cls.__name__ for cls in D.mro()])
```

输出：

```text
D
B
C
A
['D', 'B', 'C', 'A', 'object']
```

## 组合优于继承

继承适合稳定的 is-a 关系；组合适合 has-a 关系。

```python
class Engine:
    def start(self):
        return "engine start"

class Car:
    def __init__(self, engine):
        self.engine = engine

    def start(self):
        return self.engine.start()

car = Car(Engine())
print(car.start())
```

如果只是想复用代码，不一定要继承。组合通常更灵活，依赖关系更清楚。

## 常见错误与最佳实践

### 1. 子类重写 `__init__` 忘记调用 `super()`

```python
class Parent:
    def __init__(self):
        self.name = "parent"

class Child(Parent):
    def __init__(self):
        super().__init__()
        self.age = 10
```

### 2. 继承层级过深

超过 2 到 3 层继承就要警惕。层级越深，行为来源越难追踪。

### 3. 为了复用一两个方法而继承

这种情况优先考虑组合、工具函数或 mixin。

### 4. 多继承初始化不协作

多继承中每个类都应使用 `super()`，并尽量设计兼容的参数。

```python
class A:
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

class B:
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
```

### 5. 父类依赖子类细节

父类不应强依赖某个具体子类，否则继承方向会变混乱。

---

## 小结

- 继承表达 is-a 关系。
- 子类继承父类属性和方法，也可以重写方法。
- `super()` 按 MRO 调用下一个类的方法。
- 多继承适合 mixin，但要理解 MRO。
- 继承不是复用代码的唯一方式，组合往往更清晰。
