## 单继承

### 练习题

**题目 1：动物继承**

定义 `Animal`，包含 `eat()`；定义 `Dog(Animal)`，创建狗对象调用 `eat()`。

**题目 2：学生继承人**

定义 `Person(name)`，包含 `introduce()`；定义 `Student(Person)`，添加 `study()`。

**题目 3：继承判断**

用 `isinstance` 和 `issubclass` 判断 `Student` 与 `Person` 的关系。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Animal:
    def eat(self):
        return "eating"

class Dog(Animal):
    pass

print(Dog().eat())

class Person:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        return f"我是 {self.name}"

class Student(Person):
    def study(self):
        return f"{self.name} 正在学习"

s = Student("Alice")
print(s.introduce())
print(s.study())
print(isinstance(s, Student))  # True
print(isinstance(s, Person))   # True
print(issubclass(Student, Person))  # True
```

## 方法重写

### 练习题

**题目 1：叫声不同**

定义 `Animal.speak()` 返回 `"..."`，`Dog.speak()` 返回 `"汪"`，`Cat.speak()` 返回 `"喵"`。

**题目 2：支付方式**

定义父类 `Payment.pay(amount)` 抛出 `NotImplementedError`，子类 `CashPayment`、`CardPayment` 分别实现。

**题目 3：扩展父类行为**

定义 `Logger.log(message)` 打印消息；子类 `PrefixLogger` 重写 `log`，在消息前加 `[INFO]`，并调用父类 `log`。

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Animal:
    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):
        return "汪"

class Cat(Animal):
    def speak(self):
        return "喵"

print(Dog().speak())
print(Cat().speak())

class Payment:
    def pay(self, amount):
        raise NotImplementedError("子类必须实现 pay")

class CashPayment(Payment):
    def pay(self, amount):
        return f"现金支付 {amount}"

class CardPayment(Payment):
    def pay(self, amount):
        return f"银行卡支付 {amount}"

print(CashPayment().pay(100))
print(CardPayment().pay(100))

class Logger:
    def log(self, message):
        print(message)

class PrefixLogger(Logger):
    def log(self, message):
        super().log(f"[INFO] {message}")

PrefixLogger().log("started")
```

## `super()`

### 练习题

**题目 1：调用父类初始化**

定义 `Person(name)` 和 `Student(name, student_id)`，子类使用 `super().__init__(name)`。

**题目 2：员工工资**

定义 `Employee(name, base_salary)`，`Manager(name, base_salary, bonus)` 继承它，并提供 `total_salary()`。

**题目 3：错误分析**

下面代码为什么访问 `c.x` 报错？

```python
class Base:
    def __init__(self):
        self.x = 1

class Child(Base):
    def __init__(self):
        self.y = 2

c = Child()
print(c.x)
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
    def __init__(self, name, student_id):
        super().__init__(name)
        self.student_id = student_id

s = Student("Alice", "S001")
print(s.name, s.student_id)

class Employee:
    def __init__(self, name, base_salary):
        self.name = name
        self.base_salary = base_salary

class Manager(Employee):
    def __init__(self, name, base_salary, bonus):
        super().__init__(name, base_salary)
        self.bonus = bonus

    def total_salary(self):
        return self.base_salary + self.bonus

print(Manager("Bob", 10000, 3000).total_salary())

# 题目 3
# Child 重写了 __init__，但没有调用 Base.__init__，所以 x 没有被创建。
class Child(Base):
    def __init__(self):
        super().__init__()
        self.y = 2
```

## 多继承与 MRO

### 练习题

**题目 1：能力组合**

定义 `Flyable.fly()`、`Swimmable.swim()`，`Duck(Flyable, Swimmable)` 同时拥有两种能力。

**题目 2：Mixin**

定义 `DictMixin.to_dict()` 返回 `self.__dict__.copy()`，让 `User` 继承它。

**题目 3：MRO 输出**

写出下面代码输出顺序：

```python
class A:
    def run(self):
        print("A")

class B(A):
    def run(self):
        print("B")
        super().run()

class C(A):
    def run(self):
        print("C")
        super().run()

class D(B, C):
    def run(self):
        print("D")
        super().run()

D().run()
print([cls.__name__ for cls in D.mro()])
```

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Flyable:
    def fly(self):
        return "fly"

class Swimmable:
    def swim(self):
        return "swim"

class Duck(Flyable, Swimmable):
    pass

d = Duck()
print(d.fly())
print(d.swim())

class DictMixin:
    def to_dict(self):
        return self.__dict__.copy()

class User(DictMixin):
    def __init__(self, name):
        self.name = name

print(User("Alice").to_dict())

# 题目 3 输出：
# D
# B
# C
# A
# ['D', 'B', 'C', 'A', 'object']
```

</details>

## 陷阱题

**题目 1：继承关系误用**

`Car` 应该继承 `Engine` 吗？为什么？

**题目 2：父类方法被遮蔽**

```python
class A:
    def f(self):
        return "A"

class B(A):
    def f(self):
        return "B"

print(B().f())
```

为什么输出 `"B"`？

**题目 3：直接调用父类名的问题**

为什么多继承中不推荐写 `Parent.__init__(self)`，而推荐 `super()`？

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
# 题目 1
# 不应该。Car 和 Engine 是 has-a 关系：汽车有发动机。
# 应该组合：
class Engine:
    def start(self):
        return "engine start"

class Car:
    def __init__(self, engine):
        self.engine = engine

    def start(self):
        return self.engine.start()

# 题目 2
# 子类 B 定义了同名方法 f，方法查找先找 B，再找 A，所以输出 B。

# 题目 3
# super() 会按照 MRO 协作调用下一个类，适合多继承。
# 直接写父类名会绕开 MRO，可能导致某个父类初始化重复执行或漏执行。
```

## 综合练习

### 综合题 1：角色系统

定义：

- `Character(name, hp)`，有 `take_damage(amount)` 和 `is_alive()`
- `Warrior(Character)`，额外属性 `armor`，重写 `take_damage`：先用护甲抵消一部分伤害
- `Mage(Character)`，额外属性 `mana`，方法 `cast_spell(target)` 对目标造成伤害并消耗法力

### 综合题 2：通知系统

定义：

- `Notifier.send(message)` 抛出 `NotImplementedError`
- `EmailNotifier.send(message)` 返回 `"Email: message"`
- `SMSNotifier.send(message)` 返回 `"SMS: message"`
- `LogMixin.log(message)` 打印日志
- `LoggedEmailNotifier(LogMixin, EmailNotifier)` 在发送前记录日志

### 参考答案

<details>
<summary>点击查看答案</summary>

```python
class Character:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def take_damage(self, amount):
        self.hp = max(0, self.hp - amount)

    def is_alive(self):
        return self.hp > 0


class Warrior(Character):
    def __init__(self, name, hp, armor):
        super().__init__(name, hp)
        self.armor = armor

    def take_damage(self, amount):
        real_damage = max(0, amount - self.armor)
        super().take_damage(real_damage)


class Mage(Character):
    def __init__(self, name, hp, mana):
        super().__init__(name, hp)
        self.mana = mana

    def cast_spell(self, target):
        if self.mana < 10:
            raise ValueError("法力不足")
        self.mana -= 10
        target.take_damage(30)


class Notifier:
    def send(self, message):
        raise NotImplementedError


class EmailNotifier(Notifier):
    def send(self, message):
        return f"Email: {message}"


class SMSNotifier(Notifier):
    def send(self, message):
        return f"SMS: {message}"


class LogMixin:
    def log(self, message):
        print(f"LOG: {message}")


class LoggedEmailNotifier(LogMixin, EmailNotifier):
    def send(self, message):
        self.log(message)
        return super().send(message)


w = Warrior("warrior", 100, 5)
m = Mage("mage", 80, 20)
m.cast_spell(w)
print(w.hp)  # 75
print(LoggedEmailNotifier().send("hello"))
```

</details>
