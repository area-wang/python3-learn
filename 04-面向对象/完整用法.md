## 学习路线

### 第一阶段：会定义类和对象

目标是理解“类是模板，对象是实例”。

必须掌握：

- `class` 语句如何定义类
- 调用类名如何创建对象
- `self` 为什么代表当前对象
- `__init__` 如何初始化对象
- 属性表示状态，方法表示行为

最小示例：

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_passed(self):
        return self.score >= 60

stu = Student("Alice", 90)
print(stu.name)
print(stu.is_passed())
```

学习入口：[4.1-类与对象](./4.1-类与对象/用法.md)。

### 第二阶段：会管理对象状态

目标是分清实例属性和类属性。

必须掌握：

- 实例属性属于具体对象
- 类属性属于类，被实例共享访问
- `obj.attr` 的常见查找顺序
- 可变类属性会被所有实例共享
- `@property` 能把校验逻辑封装到属性访问中

典型示例：

```python
class Product:
    category = "book"

    def __init__(self, name, price):
        self.name = name
        self.price = price

    @property
    def price(self):
        return self._price

    @price.setter
    def price(self, value):
        if value < 0:
            raise ValueError("价格不能为负")
        self._price = value
```

学习入口：[4.2-属性](./4.2-属性/用法.md)。

### 第三阶段：会设计方法

目标是知道什么时候用实例方法、类方法、静态方法。

选择原则：

- 需要访问或修改对象状态：实例方法
- 需要访问或修改类状态：类方法
- 与类主题有关但不需要对象和类状态：静态方法

典型示例：

```python
class User:
    count = 0

    def __init__(self, name):
        self.name = name
        type(self).count += 1

    @classmethod
    def get_count(cls):
        return cls.count

    @staticmethod
    def is_valid_name(name):
        return bool(name)
```

学习入口：[4.3-方法](./4.3-方法/用法.md)。

### 第四阶段：会复用和扩展类

目标是正确使用继承，而不是滥用继承。

必须掌握：

- 继承表达 `is-a` 关系
- 子类可以重写父类方法
- 子类 `__init__` 通常要调用 `super().__init__`
- 多继承要理解 MRO
- 组合通常比继承更灵活

典型示例：

```python
class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
    def __init__(self, name, student_id):
        super().__init__(name)
        self.student_id = student_id
```

学习入口：[4.4-继承](./4.4-继承/用法.md)。

### 第五阶段：会用接口思维写代码

目标是让调用者依赖行为，而不是依赖具体类型。

多态写法：

```python
def total_area(shapes):
    return sum(shape.area() for shape in shapes)
```

只要对象有 `area()` 方法，就能参与计算。

学习入口：[4.5-多态](./4.5-多态/用法.md)。

### 第六阶段：会保护对象内部状态

目标是暴露稳定接口，隐藏实现细节。

封装原则：

- 对外暴露意图清晰的方法
- 内部辅助方法用单下划线
- 不让外部绕过校验直接破坏状态
- 对内部可变集合返回副本或只读视图

学习入口：[4.6-封装](./4.6-封装/用法.md)。

### 第七阶段：会接入 Python 对象协议

目标是让自定义对象自然支持 Python 语法。

常用魔法方法：

- `__repr__`：开发者表示
- `__str__`：用户友好显示
- `__eq__`、`__lt__`：比较
- `__add__`、`__mul__`：运算符
- `__len__`、`__iter__`、`__getitem__`：容器协议
- `__enter__`、`__exit__`：上下文管理器

学习入口：[4.7-魔法方法](./4.7-魔法方法/用法.md)。

### 第八阶段：会选择高级特性

目标是知道高级特性解决什么问题，并克制使用。

选择建议：

- 数据对象：优先 `@dataclass`
- 大量固定字段对象：考虑 `__slots__`
- 多个字段共享校验：考虑描述符
- 批量增强类：考虑类装饰器
- 子类自动注册：考虑 `__init_subclass__`
- 控制类创建过程：最后才考虑元类

学习入口：[4.8-高级特性](./4.8-高级特性/用法.md)。

### 第九阶段：会观察和动态操作对象

目标是掌握 Python 提供的对象工具函数，用它们调试对象、判断类型、动态读写属性。

常用内置函数：

- `type()`：查看对象类型
- `isinstance()`：判断对象是否属于某个类或其子类
- `issubclass()`：判断类之间的继承关系
- `id()`：查看对象身份标识
- `dir()`：查看对象可访问的属性和方法名
- `vars()`：查看普通对象的实例属性字典
- `getattr()`、`setattr()`、`hasattr()`、`delattr()`：动态操作属性
- `callable()`：判断对象是否可以被调用

学习入口：[4.9-对象常用内置函数](./4.9-对象常用内置函数/用法.md)。

## 常见设计判断

### 什么时候写类

适合写类：

- 数据和行为需要长期绑定
- 有清晰的业务实体，例如用户、订单、账户
- 需要维护状态
- 需要多个对象拥有相同结构但不同数据

不适合写类：

- 只是一次性计算
- 没有状态，只是几个简单工具函数
- 类里只有一个方法且没有扩展需求

### 什么时候用继承

适合继承：

- 子类确实是父类的一种
- 子类需要复用父类稳定接口
- 调用者希望用父类接口统一处理子类

不适合继承：

- 只是为了复用几行代码
- 对象之间是 has-a 关系
- 父类和子类职责边界不清

### 什么时候用 property

适合：

- 读取时需要计算
- 赋值时需要校验
- 要把公开属性保持为属性形式，同时内部实现变复杂

不适合：

- 访问属性会执行昂贵操作
- 赋值会产生明显副作用

## 综合示例：订单模型

```python
from dataclasses import dataclass, field


@dataclass(frozen=True)
class Product:
    name: str
    price: float

    def __post_init__(self):
        if self.price < 0:
            raise ValueError("价格不能为负")


class Order:
    def __init__(self):
        self._items = []

    def add_item(self, product, quantity=1):
        if quantity <= 0:
            raise ValueError("数量必须为正")
        self._items.append((product, quantity))

    @property
    def items(self):
        return tuple(self._items)

    @property
    def total(self):
        return sum(product.price * quantity for product, quantity in self._items)

    def __len__(self):
        return len(self._items)

    def __iter__(self):
        return iter(self._items)

    def __repr__(self):
        return f"Order(items={self._items!r})"


book = Product("Python", 80)
pen = Product("Pen", 3)

order = Order()
order.add_item(book, 2)
order.add_item(pen, 5)

print(order.total)
print(len(order))
for product, quantity in order:
    print(product.name, quantity)
```

这个例子综合使用了：

- `dataclass`
- 封装内部列表
- 只读属性
- 魔法方法
- 方法校验
